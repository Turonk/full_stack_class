# Teaching Protocol · планшет + проектор

Группа до **10** учеников. Два взрослых экрана + ученические ноутбуки.

## Роли устройств

| Устройство | Кто держит | Что открыто | Чего там быть не должно |
| --- | --- | --- | --- |
| **Планшет учителя** | педагог | `HOME.md` → `runbook.md` (+ `checks.md` во вкладке) | длинный deep-notes, код ученика |
| **Ноутбук → проектор** | педагог / ассистент | `slides.md` **или** `demo/` (PulseDeck) | README, teacher.md, файлы ученика |
| **Ноут ученика** | ученик | только `student/starter/` и свой Pulse FM | solution/, deep-notes |

## Переключения на уроке

Цель: **≤15 секунд** на любой ресурс.

1. Старт → слайды (retrieval).
2. Observe/Predict → слайд с вопросом, руки вверх.
3. I do / We do → **PulseDeck** на проектор, runbook на планшете.
4. You do → проектор можно приглушить или оставить критерий «готово»; учитель ходит с планшетом-checks.
5. Exit ticket → слайд с тремя полями.

## Реплики-переключатели (говорить вслух)

- «Сейчас смотрим **на стену**» = проектор / PulseDeck.
- «Сейчас смотрим **в свой файл**» = starter.
- «Предикт без кода» = руки / стикеры, DevTools ещё закрыт.

## Запреты доставки

- Не читать deep-notes вслух целиком.
- Не открывать solution на проекторе до peer-review / финала.
- Не давать вторую задачу, пока checkpoint не пройден большинством (≥7 из 10 или правило «все, кроме 1–2»).

## Ассистент (если есть)

Сидит у проектора: переключает slides ↔ demo по сигналу с планшета («слайд», «стенд», «критерий»).
