# Assessment Loop · группы ≤10

## Три петли

| Петля | Когда | Артефакт | Зачем учителю |
| --- | --- | --- | --- |
| Retrieval | минуты 0–5 | 3 вопроса на slides | срез вчера |
| Checkpoint mid | ~55–60 | checks.md | стоп-кран перед You do |
| Exit ticket | 110–120 | термин + скрин/ссылка | топливо следующего старта |

## Быстрая диагностика (карточка на планшет)

На каждого ученика за урок достаточно меток:

- `✓` checkpoint ok  
- `~` нужна помощь в You do  
- `✗` вернуть в We do / пару  

Не вести простыню оценок на обычном уроке.

## Peer-feedback (шаблон)

Использовать на A06 и каждом showcase (A12, A18, A24, B06, B12, B18, B24, B33):

1. Что сработало (факт на экране).  
2. Один совет (действие, не «сделай красивее»).  
3. Один вопрос автору.

Время: 2+2 минуты в паре, затем 1 фикс.

## Showcase ≤10

- Слот питча: **6 минут** (жёсткий таймер).  
- Бюджет питчей: ≤60 минут.  
- Затем 20 мин peer + 20 мин правок (см. RHYTHM.md).  
- Рубрика: визуал / понятность / один приём / время — как в A06 checks.

## Маршруты

| Ученик | Обычный урок | Showcase |
| --- | --- | --- |
| Отстающий | мини-задача из task.md «обязательный минимум» | слот 90 сек + добор дома |
| В темпе | task.md как есть | полный питч 6 мин |
| Быстрый | бонус в deep-notes / второй акцент UI | peer-лид: помогает соседу с ревью |

## Связь с HOME

После урока: перенести 1–2 mist из exit ticket в retrieval следующего `slides.md`.
