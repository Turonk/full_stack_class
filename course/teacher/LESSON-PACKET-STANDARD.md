# Lesson Packet Standard

Каждый урок — **один пакет** с одной точкой входа `README.md`.

## Обязательное дерево

```text
{CODE}-{slug}/
  README.md                 # hub: ссылки ≤15 сек
  teacher/
    runbook.md              # ≤2 экрана планшета на этап
    lecture.md              # теория вслух (тон kids-web-ритма, мир PulseLab)
    deep-notes.md           # полный сценарий, факты, FAQ, live-coding
    slides.md               # только проектор (Markdown-слайды)
    checks.md               # checkpoints + ответы + действие если mist
  demo/                     # PulseDeck / стенд (если есть)
    index.html
    …
  student/
    starter/                # то, с чего начинает ученик
    task.md                 # одна следующая задача + критерий готово
  solution/                 # эталон учителя
  homework.md               # опционально, ссылка из README
```

## Контракт README (hub)

Должен содержать таблицу:

| Поверхность | Ссылка | Экран |
| --- | --- | --- |
| Runbook | … | планшет |
| Lecture | … | планшет / подготовка (речь) |
| Slides | … | проектор |
| Demo | … | проектор |
| Starter | … | ученик |
| Task | … | ученик |
| Checks | … | планшет |
| Solution | … | только учитель |
| Deep notes | … | подготовка дома |

## Контракт runbook

- Тайминг этапов в минутах.
- Колонка «экран»: slides / deck / student.
- Checkpoint mid с критерием.
- Exit ticket одной строкой.
- Без портянок кода >6 строк (код — в deep-notes или demo).

## Контракт slides

Разделители слайдов: строка `---` между слайдами.  
На слайде: заголовок, 1 схема или 3 буллета, вопрос классу. Без ссылок на solution.

## Контракт checks

Каждый checkpoint:

1. Вопрос / действие ученика.
2. Ожидаемый ответ.
3. Если mist → что говорит учитель и куда возвращает (Observe / We do).

## Политика замены файлов

Не удалять старый `teacher.md` / корневой `starter/` пока README пакета не ссылается на новые пути и quality gate не пройден. После — удалить только дубли.
