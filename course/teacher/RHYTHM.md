# Rhythm · 120 минут

Базовый цикл для группы ≤10. Подстраивать ±10 мин, не ломая порядок фаз.

| Мин | Фаза | Экран | Смысл |
| --- | --- | --- | --- |
| 0–5 | Retrieval | slides | 3 вопроса / микро-правка вчера |
| 5–15 | Hook + Observe/Predict | slides + **lecture** | один факт + предикт без кода |
| 15–35 | I do | demo | учитель на PulseDeck, класс комментирует |
| 35–55 | We do | demo | класс диктует правки, учитель печатает |
| 55–60 | Checkpoint mid | slides + checks | ≥70% класса; иначе возврат We do |
| 60–65 | Пауза / вода | — | обязательна |
| 65–100 | You do | student | одна задача, критерий «готово» на слайде |
| 100–110 | Peer / gallery | student | соседу 2 мин или быстрый круг экранов |
| 110–120 | Exit ticket + bridge | slides | прогноз + термин + скрин/ссылка |

## Showcase-день (A06 и аналоги)

| Мин | Фаза |
| --- | --- |
| 0–10 | Правила сцены + рубрика на слайде |
| 10–70 | Питчи: до **6 мин × ученик** (≤10 → ≤60 мин) |
| 70–90 | Парное техревью по чек-листу |
| 90–110 | Правки по фидбеку |
| 110–120 | Голосование / родители (последние 45–60 мин можно пускать гостей) |

Родителям **не** показывают внутренний разбор багов первых 60 минут — только питчи и финал.

## Диагностика внутри ритма

- Retrieval = входной тест на вчера.
- Checkpoint mid = стоп-кран перед You do.
- Exit ticket = топливо для следующего retrieval.
