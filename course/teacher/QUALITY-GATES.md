# Quality Gates · готовность урока

Урок можно вести с группой только если **все** пункты ✓.

## Навигация преподавателя (30 секунд)

- [ ] Из `README.md` урока открываются: runbook, slides, demo (если есть), starter, checks, solution
- [ ] С `teacher/HOME.md` есть ссылка на hub урока
- [ ] Любой ресурс открывается ≤15 секунд (локальные пути, без охоты по дереву)

## Планшет

- [ ] `runbook.md` ≤ двух экранов на этап (без портянки кода)
- [ ] `lecture.md` есть: речь на Observe/теорию, тон по `LECTURE-VOICE.md`
- [ ] Подробности live-coding только в `deep-notes.md`
- [ ] Каждый checkpoint в `checks.md` имеет ответ + действие при mist

## Проектор

- [ ] На стену идут только `slides.md` или `demo/`
- [ ] Solution и deep-notes на проектор не попадают в сценарии runbook

## Ученик

- [ ] Одна следующая задача в `student/task.md`
- [ ] Критерий «готово» списком чекбоксов
- [ ] Starter запускается offline (шрифты/картинки с fallback)

## Чистка

- [ ] Нет битых ссылок на старый корневой `teacher.md` / `starter/` после миграции
- [ ] Удалены только дубли по политике replace-then-delete
- [ ] Нет папок `old/`, `legacy/`, параллельных копий документации

## Репетиция A01 (обязательна при изменении пакета)

- [ ] Педагог на планшете, проектор на slides/demo, второй человек = ученик
- [ ] Переходы ≤15 сек
- [ ] Новичок-препод ведёт первые 30 мин только по runbook

## Репетиция A06

- [ ] Таймер 6×N на N≤10
- [ ] Peer 20 + правки 20 влезают в остаток 120
