Остальные дни записаны заметками, пакетами ещё не собраны. Дни со второго по шестой лежат в [SPRINT1-OUTLINES.md](./SPRINT1-OUTLINES.md): там карточка. Дни с седьмого по восемнадцатый — в [SPRINT2-3-OUTLINES.md](./SPRINT2-3-OUTLINES.md): там страница и кнопка.

Дальше по смыслу собрать второй–шестой уроки по образцу первого, затем страницу, затем кнопку.
