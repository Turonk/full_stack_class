# S01 · Первый кадр

Браузер не видит файл стилей, пока в HTML нет явной стрелки. Сегодня эта стрелка появляется в первую же пару, а не «когда-нибудь потом, когда дойдём до настоящего CSS».

## Одна мысль

Страница и стиль живут в двух файлах. Между ними стоит `link`. Если стрелки нет, экран остаётся белым, даже когда файл стилей лежит рядом в той же папке.

```text
есть link     →     тёмный кадр
нет link      →     белый лист и фраза «файл же есть»
```

## Как вести этот кусок

Сначала показываем белый экран. Кто-нибудь из зала почти наверняка скажет, что файл стилей лежит в папке. Тогда произносим правило. На стенде снимаем стрелку и ставим её обратно, чтобы глаз запомнил разницу, а не только ухо.

## Стоп посередине пары

Снимаем `link`, сохраняем, обновляем страницу. Класс называет цвет экрана до того, как страница перерисуется. Если хором говорят «белый», можно идти дальше. Если звучит «ну он же в папке», возвращаемся на стенд и в свои файлы пока не пускаем.

## Что делает ученик

Открывает работу через Live Server, ставит тёмный фон, пишет своё имя полки и короткую подпись. Тексты со стены не копирует.

Учебный стенд называется WireShelf. Полка ученика называется MyShelf.
