# S01 · Первый кадр

На планшете во время пары открывайте [план по минутам](./teacher/runbook.md) и в соседней вкладке [стоп-кран](./teacher/checks.md). Речь лежит в [лекции](./teacher/lecture.md): её можно дочитать дома и почти дословно сказать в зале. На проектор идут [слайды](./teacher/slides.md) или [учебный стенд](./demo/), пока собираете кадр вместе.

Ученик работает из [стартовых файлов](./student/starter/) по [задаче](./student/task.md). Заметка автору, зачем урок устроен так, лежит в [OUTLINE.md](./OUTLINE.md) и на уроке не нужна.

На стене учебный стенд WireShelf. У ученика своя полка MyShelf. Их нельзя путать.
