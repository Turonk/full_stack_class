# S01 · Своя полка

Соберите первый кадр своей полки MyShelf.

Смысл задачи простой. Чтобы экран потемнел, браузер должен найти файл стилей. Файл, который просто лежит рядом в папке, сам собой не подхватится.

## Что сделать

1. Откройте `index.html` и `styles.css`.
2. В разделе `head` поставьте связь со стилями:

```html
<link rel="stylesheet" href="styles.css">
```

3. Напишите название полки и короткую подпись своими словами.
4. Сделайте тёмный фон и светлый текст. Цвета можете выбрать сами.

## Когда можно считать готовым

- [ ] Страница открыта через Live Server
- [ ] На экране не белый голый лист
- [ ] На экране не написано WireShelf

## Чего лучше не делать

Не копируйте тексты со стены. Не пишите весь CSS в атрибуте `style` на тегах.
