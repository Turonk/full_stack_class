# ShelfLab

ShelfLab — это не замена основного курса PulseLab, а второй вариант вводного модуля. Он закрывает тот же круг навыков, что открытая часть Практикума: HTML, CSS и JavaScript до страницы, на которой кнопка что-то меняет. Разница в устройстве. Практикум написан для одного человека за ноутбуком. Эта линейка собрана для живой группы до десяти человек, урока на два часа, учителя с планшетом и проектором.

У Практикума около восьмидесяти коротких шагов в тренажёре. У PulseLab длинная спираль продуктов: радио, каталог, игра, магазин. У ShelfLab восемнадцать встреч и три вещи, которые к концу курса лежат у ученика на экране: карточка полки, простая одностраничная страница и кнопка, по нажатию подставляющая новый текст.

Каждый ученик собирает свою полку и называет её как хочет. В материалах она зовётся MyShelf, чтобы было общее имя. На проекторе учитель работает на учебном стенде WireShelf. Это черновик на доске: с него берут приём, а не слоган и не чужие формулировки.

| | Практикум | PulseLab | ShelfLab |
| --- | --- | --- | --- |
| Как нарезан материал | около 80 микроуроков | длинная спираль блоков A и B | 18 уроков, три спринта по шесть |
| Когда говорят про коробку элемента | поздно | рано | на второй встрече |
| Когда появляется отдельный CSS-файл | часто через тег `style`, файл позже | с первого дня, через `link` | так же, с первого дня |
| Зачем нужен JavaScript | сначала консоль | после вёрстки | чтобы кнопка на странице ожила |
| Что есть у учителя | статьи тренажёра, без пульта | пакеты уроков A01–A06 | полный пакет первого урока и карты остальных |

Читать лучше в таком порядке: зачем нужна эта папка, сетка из восемнадцати уроков, как вести пару, откуда сжаты уроки Практикума, короткий вывод для решения. Первый урок собран целиком и лежит в папке [S01](./lessons/S01-first-frame-link/).
