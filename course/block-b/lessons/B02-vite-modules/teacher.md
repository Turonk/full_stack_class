## Новая тема

- npm create vite.
- type=module.
- import { button } from './ui.js'.
- Зачем сборка.

## Практика в классе

1. create vite vanilla.
2. Два модуля.
3. CSS import.
4. npm run dev.
5. build.

## Частые ошибки 12–14 лет

- Смешали Flask static и Vite без прокси слишком рано.
- node не установлен — чек в начале.
