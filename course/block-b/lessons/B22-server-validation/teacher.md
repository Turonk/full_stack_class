# Урок B22. Валидация на сервере

- Блок: B
- Тип: обычный
- Длительность: 120 минут
- Минипроект: Fullstack
- Практикум (опционально): нет

## Цель урока

Сервер режет score<0, пустое имя, слишком длинные строки.

## Результат на экране

POST мусора → 400 с текстом.
