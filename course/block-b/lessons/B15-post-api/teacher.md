# Урок B15. POST: новый скор / заказ

- Блок: B
- Тип: обычный
- Длительность: 120 минут
- Минипроект: PulseAPI
- Практикум (опционально): нет

## Цель урока

POST /api/scores JSON body, append в список, ответ 201.

## Результат на экране

Игра шлёт скор.

- request.get_json.
- валидация полей.
- 400 если нет name/score.

## Практика в классе

1. post route.
2. fetch POST headers Content-Type.
3. Обновить лидерборд.
4. Неверный JSON.
5. DevTools payload.
