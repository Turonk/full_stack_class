# Урок B08. REST глазами фронта

- Блок: B
- Тип: обычный
- Длительность: 120 минут
- Минипроект: API-клиент
- Практикум (опционально): нет

## Цель урока

Читает контракт hits: GET список, GET :id. Рисует таблицу полей.

## Результат на экране

Документ api.md в репо.

Для showcase/защиты: использовать тайминг из `course/templates/showcase.md` или `diploma.md` вместо таблицы выше.

## Новая тема

- GET/POST.
- статус 200/404/400/500.
- JSON ключи стабильны.

## Практика в классе

1. Описать контракт на доске.
2. api.md.
3. Примеры JSON.
4. Не менять ключи как попало.
5. Обсудить идемпотентность GET.
