# Минипроект. Название

- Спринт: уроки N–M
- Showcase: урок K
- Стек: HTML / CSS / JS / Flask
- Входит в MediaGameHub как: страница / игра / магазин / сервер

## Пользовательская история

Кто пользуется и зачем за 2–3 предложения.

## Must-have

Список функций, без которых проект не принимают на showcase.

## Nice-to-have

Челленджи для тех, кто быстрее.

## Страницы и файлы

Дерево файлов эталона. Что общее со следующим минипроектом (что переиспользуем).

## Критерии приёмки

Наблюдаемые проверки. «Открыл телефон / сузил окно / кликнул / отправил форму».

## Эталон

Путь к `etalon/`. Что можно менять: палитра, тексты, персонажи. Что нельзя: семантика, структура файлов, обязательные фичи.
