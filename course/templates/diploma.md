# Диплом. Название

- Блок: B
- Уроки: подготовка / защита / рефлексия
- Стек: HTML, CSS, JS (Vite), Flask, JSON API

## Продукт диплома

Что именно сдаём: репозиторий + работающий деплой фронта + локально/облачно поднятый Flask + 5-минутная защита.

## Must-have диплома

- 4+ страницы/роута, связанные в один продукт MediaGameHub.
- Адаптив до 360px.
- Одна интерактивная фича на JS.
- Один API-эндпоинт Flask, который фронт реально вызывает.
- README: как запустить за 3 команды.

## Защита 5–7 минут

1. Проблема пользователя.
2. Демо сценария.
3. Архитектура: что на клиенте, что на сервере.
4. Кусок кода, которым гордишься.
5. Что бы сделал, будь ещё месяц.

## Рубрика защиты

Работает / Архитектура / Рассказ / Самостоятельность / Доводка после фидбека.

## Рефлексия

Письменно: 5 навыков, 2 провала, 1 план на лето/каникулы.
