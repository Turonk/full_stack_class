# Стиль курса PulseLab

Свой визуальный и педагогический язык. Не опираемся на старые занятия и чужие платные курсы.

## Для кого

Подростки 12–14 лет. Уже знают Python. Frontend — новый слой. Flask — знакомый Python в роли сервера.

## Zero Ugly Screens

- К концу **каждого** обычного урока на экране есть оформленный кусок PulseLab: баннер, карточка, шапка, кнопка, плеер.
- Стартер урока уже тёмный. Ученик не начинает с белого Times New Roman.
- В спринте 1 два продукта: **PulseDeck** на проекторе (теория + пример вместе), **Pulse FM** у ученика (к родителям). Зелёный лаунчер не копируют в фиолетовое радио.
- CSS подключаем на A01, не «сначала шесть недель тегов».
- Float, таблицы-для-вёрстки, jQuery, Bootstrap-как-костыль — нельзя как основной путь.

## Deep Engagement · как говорит лектор

- Сначала результат на проекторе, потом разбор.
- Прямая речь в методичке — произносить, не пересказывать канцеляритом.
- Одна новая идея на live-coding. Остальное — практика руками.
- Ошибки нормализуем: «так ломается у всех, вот 15 секунд на починку».
- Сленг умеренный. Без сюсюканья и без корпоративного тона.

### Обязательные куски методички (Спринт 1 усилен)

1. Хук (реплика старта).
2. Презентация: схема Mermaid/доска + что говорить по стрелкам.
3. Инженерия: *почему* в проде (поддержка, UX, a11y), не только имя бренда.
4. Аналогия: Python и/или игра (скин, сцена, сейв, моб).
5. Вопрос-ловушка в зал.
6. Пошаговый скрипт PulseDeck: Показать / Сделать / Сказать / Спросить.
7. Мост стенд → радио (таблица переноса).
8. Лаборатория must/nice + запрет копипаста лаунчера.
9. Ошибки возраста 12–14 и фикс за 15 секунд.
10. Смотр только Pulse FM.

Шаблон: [templates/lesson.md](templates/lesson.md). Чек-лист: [block-a/lessons/SPRINT1-METHOD.md](block-a/lessons/SPRINT1-METHOD.md).

## Визуальный код

- Фон `#0B0F1A`, поверхность `#141A2A`, текст `#F4F1EA`, приглушённый `#9AA3B8`.
- Акцент `#7C5CFF`, успех `#2EE6A6`, удар `#FF6B6B`, искра `#FFC857`.
- Заголовки `Syne`, текст `IBM Plex Sans`, код `IBM Plex Mono`.
- Радиус 16–24px, тень `0 18px 40px rgba(0,0,0,.35)`.
- Mobile-first. Десктоп — бонус медиазапросом.
