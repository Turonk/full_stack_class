Командная работа

![](https://pictures.s3.yandex.net:443/resources/Frame_110_1_1698250217.png)

Ты уже несколько недель подряд трудишься над созданием сайта с кроссовками. В реальности для воплощения подобного проекта твоих мощностей может быть недостаточно. И даже с вымышленными персонажами получается маловато для полноценной команды.

Вот примерный список специалистов 👇🏻

**Проектный менеджер:** координирует все задачи, следит за сроками и обеспечивает коммуникацию внутри команды.

**Backend-разработчики:** работают над серверной частью проекта, обрабатывая данные и взаимодействуя с базами данных.

**Frontend-разработчики:** отвечают за то, что пользователи видят в браузере, и за взаимодействие интерфейса с сервером.

**Дизайнеры UI/UX:** создают интерфейс и обеспечивают его удобство для пользователей.

**QA-инженеры:** тестируют продукт на наличие ошибок и проблем, обеспечивая качество продукта.

**DevOps-разработчики:** управляют инфраструктурой проекта, автоматизируют процессы деплоя и поддерживают стабильную работу сервиса.

**Маркетологи и менеджеры по продукту:** исследуют рынок, определяют функционал и стратегии продвижения продукта.

Для того чтобы координировать такую команду, нужны специальные инструменты.

Вот минимальный набор:

1. Средства коммуникации Чтобы члены команды могли общаться друг с другом и обмениваться доками по проекту, им понадобятся электронная почта, мессенджеры, Zoom для видеовстреч. 2. Таск-менеджер Онлайн-доска, которой пользуется вся команда, для того чтобы следить за своими задачами. Чаще всего это зона ответственности проектного менеджера: он назначает ответственных на каждую текущую задачу, следит за дедлайнами, проставляет статус готовности, а доска автоматически фиксирует затраченное на работу время.

![](https://pictures.s3.yandex.net:443/resources/Frame_111_1_1_1698250977.png)

3. [Figma](https://www.figma.com/){target="_blank"} Основное место работы дизайнера. Там он рисует экраны нашего приложения, a фронтендер переносит эти экраны в веб (поэтому он тоже должен уметь работать с фигмой). 4. [GitHub](https://github.com/){target="_blank"} Инструмент, позволяющий всей команде работать над кодом в общем пространстве, каждому участнику — видеть все изменения, внесённые другими, а также откатиться к предыдущей версии проекта.
