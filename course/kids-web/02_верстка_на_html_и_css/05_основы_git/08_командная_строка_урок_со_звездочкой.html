Командная строка (урок со звёздочкой)

Привет!

Как вы с Аски уже обсудили, раньше у программ вообще не было графических интерфейсов в привычном нам понимании. Со всеми программами необходимо было взаимодействовать через командную строку (Command Line Interface, CLI).

**Командная строка**, она же **консоль**, она же **терминал**, — это текстовый интерфейс, позволяющий давать команды компьютеру.

Вот как консоль выглядит на современном компьютере:

![](https://pictures.s3.yandex.net:443/resources/Snimok_ekrana_2023-10-10_v_15.24.44_1_1698333806.png)

Обычные пользователи практически забыли про консоль, поскольку у программ для повседневной работы уже давно есть привычные интерфейсы с меню, кнопками и прочими графическими элементами. Однако некоторые инструменты, которыми пользуются разработчики, и сейчас лишены графического интерфейса.

Может показаться, что это пережиток прошлого, но у консоли есть преимущества. Для работы с ней нужно гораздо меньше ресурсов системы. А иногда разработчику легче ввести одну команду, чтобы выполнить действие, чем долго изучать незнакомый интерфейс (или повторять одни и те же шаги в уже знакомом интерфейсе).

К тому же многие рутинные задачи веб-разработчика выполняются через консоль: установка различных программных пакетов на компьютер, работа с Git (есть люди, которым так удобнее, чем через GitHub Desktop), настройка сервера, изменение прав доступа к файлам и директориям, сборка сайта. Даже с известным тебе Netlify есть [возможность](https://docs.netlify.com/cli/get-started/){target="_blank"} взаимодействовать через командную строку.

В этом уроке мы не станем глубоко изучать консоль, но ты потыкаешь её и узнаешь некоторые базовые команды, а также научишься редактировать текстовые файлы (ну и вдобавок выяснишь, как можно удивить маму, узнав прогноз погоды через командную строку).

Предположим, ты хочешь создать текстовый файл `hey.txt` в папке `cool` и в нём написать свой отзыв о курсе Практикума.

Для этого тебе понадобится:

- Научиться ходить по файловой системе компьютера. - Узнать, как создаются новые файлы. - Воспользоваться текстовым редактором.

Сейчас мы пошагово разберём этот процесс, и ты узнаешь базовые команды, необходимые для работы с консолью.

Запуск командной строки

На macOS и Linux для взаимодействия с командной строкой используется приложение Терминал.

На Windows всё слегка сложнее, тебе понадобится [PowerShell](https://learn.microsoft.com/ru-ru/powershell/scripting/overview?view=powershell-7.3&viewFallbackFrom=powershell-7.1){target="_blank"}. Также ты можешь работать в [терминале в VSCode](https://code.visualstudio.com/docs/terminal/basics/){target="_blank"}, если тебе удобнее иметь редактор кода и консоль в одном окне.

В консоли ты отправляешь компьютеру команды определённого вида. Команда — текстовая инструкция, что должен сделать компьютер. Когда компьютер выполняет команду, он, если нужно, выводит информацию о результате, тоже в виде текста.

Команды для перемещения по файловой системе

После того как ты открыл терминал, нужно проверить, где именно ты сейчас находишься. Для этого используй команду `pwd`: она покажет тебе путь к рабочей директории (папке, в которой ты сейчас находишься) от корневой директории (путь `/`). Вызов набранной команды — нажатие на клавишу `Enter`

Слова «директория» и «папка» — синонимы, но во многих командах терминала используется сокращение именно от слова `directory`. Например, `pwd` означает `present working directory`. Поэтому в уроке папки будут иногда называться директориями.

Чтобы посмотреть, что есть в рабочей директории, введи команду `ls`. Тебе станет виден список всех имеющихся в ней папок и файлов.

Для того чтобы создать новую директорию, есть команда `mkdir название_директории`. Создай директорию с названием `cool`, а затем открой её с помощью команды `cd cool`

А вот ещё команды, которые помогают бродить по файловой системе:

`cd ..` — вернуться на уровень выше

`cd ../..` — вернуться на два уровня выше (аналогично ../../.. — на три уровня выше и так далее)

`cd ~` — вернуться в домашнюю директорию

Команда `cd` также принимает и полный путь к директории: можно сразу ввести путь в то место, куда ты хочешь попасть.

![](https://pictures.s3.yandex.net:443/resources/Snimok_ekrana_2023-10-10_v_15.46.42_1_1698334068.png)

Ну, никто не мешает тебе назвать директорию пляжем 🤡

А чудесность мы тебе прямо сейчас покажем. В командной строке не обязательно вводить полное название файла или директории самостоятельно: можно начать писать название, нажать на `Tab`, и терминал либо введёт название файла автоматически, либо подскажет, какие файлы начинаются с тех же символов. Ну не чудо ли?

Так, по файловой системе походили, теперь надо разобраться, как работать с файлами через консоль. Для этого попрактикуемся с простыми текстовыми файлами.

Ты можешь создать файл, если введёшь команду `touch название_файла`.

Попробуй создать файл `hey.txt` в папке `cool`. Ты увидишь его в рабочей директории и сможешь открыть его в любом привычном текстовом редакторе. Но это:

а) Неинтересно.

б) Не так удобно при работе с удалёнными компьютерами.

Поэтому давай попробуем воспользоваться одним из текстовых редакторов, встроенных в командную строку — nano.

Работа с текстовыми файлами

Интерфейс редактора nano выглядит вот так:

Лови ещё несколько полезных команд для работы с файловой системой.

1) Тебе может понадобиться команда `cp`. Она позволяет копировать файл в другое место. Использовать её надо так: `cp название_файла путь_куда_ты_хочешь_скопировать файл название_копии>`. Если путь не указан, то файл копируется в ту же директорию, где мы работаем. Например, `hey.txt` можно скопировать так:

`cp hey.txt hey-copy.txt`

2) Для удаления файла используй команду `rm`

3) А если захочешь удалить папку с её содержимым, используй `rm -r`. `-r` в этой команде — специальный аргумент (их ещё называют «ключи», «флаги» или «параметры»), с помощью которого ты указываешь, как должна работать команда. Ключ `-r` в команде `rm` значит рекурсивное удаление всего содержимого. Будь осторожен: эта команда удаляет файлы безвозвратно, ты не найдёшь их в корзине.

4) Для того чтобы прочитать справку о команде (например, чтобы узнать обо всех доступных ключах), можно использовать команду `man`. Например, `man ls` покажет в режиме постраничного просмотра полную справку о команде `ls`. Чтобы выйти из режима просмотра, нажми `Q`

Погоди! Лови тогда пару реальных приколов, которыми можно блеснуть в компании мамы и бабушки.

1) С помощью команды `cal` можно вывести в терминале календарь.

![](https://pictures.s3.yandex.net:443/resources/Snimok_ekrana_2023-10-10_v_16.26.17_1_1698334322.png)

2) А с помощью команды `curl` можно делать URL-запросы. Команда `curl [wttr.in/](http://wttr.in/)` даст тебе обещанный в начале урока запрос прогноза погоды. В конце можешь указать название нужного города. Например, запрос для Москвы будет выглядеть так: `curl wttr.in/moscow`

![](https://pictures.s3.yandex.net:443/resources/Snimok_ekrana_2023-10-10_v_16.26.40_1_1698334336.png)

Если всё ещё хочешь на пляж, можешь самостоятельно глянуть прогноз в Рио-де-Жанейро или на ещё каком-нибудь курорте — кидай скрин в тусовку в дискорде, чтобы вместе погреться об него ☀️

3) А если у тебя компьютер с macOS, то можешь ещё использовать команду `say текст`, и компьютер произнесёт любую написанную тобой фразу.

И это правда! К этому моменту ты уже знаешь, что командная строка — текстовый интерфейс для взаимодействия с компьютером с помощью команд (специальных текстовых инструкций для выполнения определённой задачи). Ответ на введённую команду тоже приходит в виде текста.

С помощью команд ты умеешь перемещаться по файловой системе компьютера, создавать и редактировать тексты.

- `pwd` — путь к рабочей директории от корневой директории - `ls` — список файлов в директории - `mkdir` `название_директории` — создать новую директорию - `cd название_директории` — открыть директорию - `touch название_файла` — создать файл - `cp название_файла путь_куда_ты_хочешь_скопировать_файл название_копии` — копировать файл - `rm` — удалить файл - `rm -r` — удалить директорию со всем её содержимым - `man название_команды` — показать справку о команде

Эти знания помогут тебе решать многие задачи, часть из которых встретится и в последних модулях нашего курса.
