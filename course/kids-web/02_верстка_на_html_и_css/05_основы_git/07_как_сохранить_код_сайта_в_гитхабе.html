Как сохранить код сайта в гитхабе

В этом уроке мы покажем, как зарегистрироваться в GitHub и создать там репозиторий. Поможем с установкой официального приложения и клонированием в него созданного репозитория.

В итоге код нашего сайта будет сохранён в облаке на серверах GitHub и к нему можно будет получить доступ с любого устройства.

Шаг 1. Заведи аккаунт

Создай аккаунт на [GitHub](https://github.com/){target="_blank"} (сохрани себе где-нибудь логин и пароль, они пригодятся для входа в приложение).

В [официальной документации](https://docs.github.com/ru/desktop/overview/getting-started-with-github-desktop){target="_blank"} ты можешь подробно посмотреть, куда именно нажимать, чтобы точно не потеряться и залогиниться. Интерфейс и окно с настройками выглядят вот так:

![](https://pictures.s3.yandex.net:443/resources/Screenshot_2023-10-02_at_17.34.55_1698763903.png)

Шаг 2. Создай новый репозиторий

Создай новый репозиторий у себя в аккаунте платформы: зелёная кнопка, на которой написано «New».

![](https://pictures.s3.yandex.net:443/resources/Screenshot_2023-10-02_at_19.36.55_1698327234.png)

В окне создания есть только одно обязательное поле — **Repository name.** Это название твоего репозитория. Назови его английским словом, связанным с кодом, который ты зальёшь (если сайт с плейлистом, то Playlist, например).

Поле **Description** — это описание проекта, можешь заполнить его по желанию. И ниже можешь выбрать между **Public** и **Private** (в первом случае твой репозиторий смогут видеть все юзеры GitHub, а во втором — только ты или те, с кем ты им поделишься). Остальное оставь как есть.

![](https://pictures.s3.yandex.net:443/resources/Screenshot_2023-10-02_at_19.40.44_1698327260.png)

Шаг 3. Установи приложение

Время скачать приложение. Лети на [официальную страницу](https://desktop.github.com/){target="_blank"} и жми на большую кнопку **Download** посередине. Приложение доступно для всех платформ, оно бесплатное, но для установки тебе потребуются права администратора, имей это в виду.

Как скачаешь, зайди под своим логином.

![](https://pictures.s3.yandex.net:443/resources/Screenshot_2023-10-02_at_17.19.35_1698327323.png)

Шаг 4. Клонируй репозиторий в приложение

В приложении нажми на верхний левый прямоугольник, где написано **Current Repository** (в нём отображается, в каком репозитории ты сейчас находишься).

![](https://pictures.s3.yandex.net:443/resources/Screenshot_2023-10-02_at_20.05.45_1698327371.png)

После нажатия откроется панель со всеми твоими репозиториями. В ней жми на кнопку **Add** (на скрине выделена синим). В выпадающем контекстном меню выбери **Clone a Repository** (клонировать репозиторий).

![](https://pictures.s3.yandex.net:443/resources/Screenshot_2023-10-02_at_20.05.59_1698327426.png)

Тебе откроется окно с выбранной вкладкой твоего аккаунта на GitHub. Под заголовком **Your Repositories** ты увидишь все свои репозитории из аккаунта на сайте GitHub. Выбирай созданный недавно и кликай на синюю кнопку **Clone.**

![](https://pictures.s3.yandex.net:443/resources/Screenshot_2023-10-02_at_20.21.23_1698327469.png)

Готово! У тебя есть репозиторий, но он пока пустой. Нужно сохранить в него файлы с кодом.

Шаг 5. Добавь код в репозиторий

В открытом репозитории нажми на кнопку **Show in Finder** (если у тебя мак) или **Show in Explorer** (если винда). Это откроет папку репозитория на твоём компьютере. Перенеси в эту папку файлы своего проекта, такие как index.html, style.css и картинки. После добавления файлов в левой части экранов отобразятся названия файлов, в правой — их содержимое.

![](https://pictures.s3.yandex.net:443/resources/Screenshot_2023-10-02_at_20.48.01_1698327575.png)

Проверь, что в списке изменений отображаются именно те файлы, которые нужны.

Шаг 6. Сохрани коммит

Введи сообщение для коммита в поле (на скрине ниже выделен синим цветом) и нажми на кнопку **Commit to main.**

В коммите обычно коротко пишут, какие изменения произошли в коде, например: исправлен баг, сделана регистрация пользователей, добавлена возможность оплаты товара и всё в таком духе. Описания коммитов помогают разработчикам лучше ориентироваться в изменениях, которые были внесены в код.

В нашем случае описание можешь оставить пустым, а в названии коммита написать «старт проекта» или «добавил свой проект в гит». Главное, чтобы тебе было понятно.

![](https://pictures.s3.yandex.net:443/resources/Screenshot_2023-10-02_at_21.47.46_1698327645.png)

Шаг 7. Залей изменения в GitHub

Сделай пуш (от английского push — «толкать») своих изменений в GitHub.

Когда ты первый раз «толкаешь» проект, у тебя будет синяя кнопка с надписью **Publish Repository**, а все следующие разы на ней будет написано просто **Push.**

![](https://pictures.s3.yandex.net:443/resources/Screenshot_2023-10-02_at_21.58.33_1698327682.png)

Всё готово!

Теперь у тебя есть сайтик, сохранённый на GitHub. Все изменения ты можешь закидывать в свой репозиторий, за которым следит приложение GitHub Desktop, и пушить в GitHub.

Итого к этому часу:

1. У тебя есть аккаунт на GitHub с твоим первым репозиторием. 2. Ты умеешь создавать репозитории в GitHub и работать с ними через приложение: коммитить изменения в проекте и заливать их (пушить) в свой репозиторий на GitHub.

А теперь несколько вопросов, чтобы убедиться, что ты профессионально толкаешь код и изменения в нём.

Теперь, когда мы уверены в твоих знаниях, самое время подбодрить тебя последней теорией на неделе — уроком со звёздочкой!
