Чек-лист перед деплоем сайта

Теперь ты в курсе, что именно происходит перед тем, как у тебя в браузере откроется веб-страница. Но как конкретно твой сайт попадёт на серверы, чтобы Аски на другом конце Вселенной (ладно, хотя бы на другом конце города) мог ввести его название и увидеть то, что ты кропотливо создаёшь уже не одну неделю?

Чтобы поместить твоё детище во всемирную паутину, нужно познакомиться с деплоем.

**Деплой** (от английского deploy — «развёртывание») — перенос файлов сайта с локального компьютера на сервер, из которого сайт сможет отображаться в интернете.

Вообще, существует достаточно большое количество способов и подходов к развёртыванию сайта, но в ближайшее время мы с тобой будем это делать с помощью сервиса [Netlify](https://www.netlify.com/){target="_blank"}.

Надеемся, ты помнишь, что сайт — это папка с набором файлов.

Если прямо сейчас взять и залить твою папку в Нетлифай, возможно, появятся проблемы с открытием сайта.

Поэтому ниже мы собрали чек-лист самых важных вещей, которые нужно проверить перед заливкой. Доставай любой свой проект (например, сайт с плейлистом), и погнали 👇🏻

Пункт 1: Найди папку с твоим сайтом на компьютере

Если ты не знаешь, где она лежит, но она открыта в VSCode, нужно выделить любой файл из проекта, тыкнуть по нему правой кнопкой мыши и нажать «Показать в проводнике».

Пункт 2: Убедись, что в папке нет лишних файлов

В папке твоего сайта должны быть HTML, CSS, JS, картинки. Если туда вдруг затесался новый Mortal Combat (ну а вдруг?), загрузить ничего не выйдет. Поэтому следует проверить, что ничего лишнего в папке нет.

Пункт 3: Главная страница в папке — index.html

Это очень важно. HTML-файл с названием `index` — это главная страница, которая будет отображаться по умолчанию при попадании на твой сайт. Если вдруг в твоей папке нет такого файла, срочно исправляй, иначе сайт не откроется.

Пункт 4: Подключи стили

Если у тебя в проекте есть стили, проверь, что файл стилей создан и лежит на одном уровне с HTML-файлом index, и стили подключены в хеде HTML-файла.

Пункт 5: Оптимизируй изображения

Если в проекте есть картинки, их нужно оптимизировать специальным алгоритмом для сжатия изображений.

Фотография кота, сделанная на телефон, может весить больше 4 Мб, а её оптимизированая версия для сайта — около 200 Кб. Визуально разницу заметить сложно, а загрузка сайта ускоряется в 20 раз (никто не любит, когда сайт грузится долго).

![](https://pictures.s3.yandex.net:443/resources/Frame_100_1_1_1698149849.png)

Давай исправлять ситуацию. Есть популярный сервис для подобных задач — [TinyPng](https://tinypng.com/){target="_blank"}. Он помогает оптимизировать картинку, уменьшая её размер путём хитрых алгоритмов сжатия.

![](https://pictures.s3.yandex.net:443/resources/Screenshot_2023-10-23_at_09.37.35_1698149879.png)

Короткая инструкция к сервису: открывай сайт, выбирай в проводнике картинки, перетаскивай их в окно заливки (где иконка стрелочки), жди, пока выполнится оптимизация, скачивай облегчённые картинки, меняй в коде изначальные изображения на оптимизированные.

Теперь, когда проект подготовлен, как и обещали, задеплоим его. Для этого жми кнопку, чтобы перейти на следующий урок.
