Возможно, тебе приходилось видеть этого чела на стене на уроке литературы. Его зовут Александр Блок. И нет, в свободное от поэзии время он не был программистом, но в придачу со своим знаменитым стихотворением идеально годится, чтобы визуализировать новую тему в нашем курсе.

Ранее мы с тобой уже договорились, что в HTML-коде элементы служат для разметки контента и превращения его в сайты. А теперь большое откровение: все HTML-теги делятся на два основных типа — блочные и строчные элементы. 

На языке CSS это `display:block` и `display:inline`

### Что такое блочные и строчные элементы

Каждый блочный элемент начинается с новой строки и по умолчанию занимает всю доступную ширину контейнера. Под контейнером мы имеем в виду родительский тег (то есть тег, внутри которого находится наш тег). 

Например, если мы записали тег `<p>` в содержимое тега `<body>`, это значит, что элемент параграфа займёт всю ширину сайта, поскольку ширина тега `<body>` по умолчанию равна ширине окна браузера. 

А каждый последующий блочный элемент будет располагаться вертикально, начиная с новой строки (и тоже будет занимать всю ширину страницы).

```html
<html>
  <body>
    <p>Этот параграф займёт всю ширину страницы</p>
    <p>И этот тоже. Оба эти параграфа располагаются на новой строке</p>
  </body>
</html>
```

Параграф, боди — это блочные элементы. Другими примерами блочных элементов являются все теги заголовков от `<h1>` до `<h6>` (их всего шесть, больше не придумали), `<html>`, `<div>`, теги списков и элементов списков `<ul>`, `<ol>`, `<li>`, семантические теги `<header>`, `<main>`, `<footer>`, `<nav>` и многие другие.

Строчные же элементы располагаются внутри строки и занимают только ту ширину, которая необходима для их содержимого.

![](https://pictures.s3.yandex.net:443/resources/Frame_18_1_2_1695645241.png)

Например, тег `<а>` с ссылкой на магазин кроссовок [stockx.com](http://stockx.com/){target="_blank"}. Ширина этой ссылки будет равна названию магазина, которое мы укажем внутри тега.

А что будет, если мы решим сделать каталог сайтов? По умолчанию все ссылки на них будут находиться на одной линии, то есть строке. 

⚠️ Важный момент, который следует иметь в виду: если ширина браузера не позволяет вместить содержимое, его часть автоматически попадает на следующую строку. Такой вот брутальный адаптивный дизайн прямиком из 90-х.

Можешь понаблюдать, как это работает, меняя ширину окна браузера.

```html
<html>
  <body>
		<a href="https://stockx.com/">StockX</a> 
    <a href="https://www.ssense.com/">SSENSE</a>
    <a href="https://slamjam.com/ ">Slam Jam</a>
    <a href="https://kith.com/">KITH</a>
    <a href="https://shop.doverstreetmarket.com/">Dover Street Market</a>
  </body>
</html>
```

Помимо тега `<а>` примерами строчных элементов являются `<span>`, `<img>`, теги для форматирования текстов `<i>`, `<b>`, `<s>`, `<u>` и многие другие.

Но вернёмся к коду. Возможно, тебя смутило, что в коде каждый тег на новой строке, а в браузере они всё равно выстроились в ряд 😶

Дело в том, что браузеру нет никакого дела до этих наших пробелов в коде, он заведомо знает, что тег `<а>` — строчной. И отображает его соответственно.

Но существует ещё одна вещь, на которую браузер обращает внимание, когда превращает код в сайт — это значение CSS-свойства `display` 

В случае блочных элементов это `display:block`, а в случае линейных это `display:inline`

Шаришь! 

Да, это стили по умолчанию. Мы их не писали, но они есть. Они есть у каждого тега, и именно поэтому текст, помещённый в заголовок первого уровня `<h1>`, большой и жирный, а текст, помещённый в тег `<small>`, жесть какой маленький. Это всё они — скрытые стили, которые есть в каждом браузере на каждом сайте.

😶‍🌫️ Но почему так получилось? 

Изначально, как ты знаешь, язык разметки HTML разрабатывался для превращения очень умных и очень длинных текстов в веб-сайты (ЦЕРН, помнишь?).

Тогда и придумали блочные элементы использовать для разметки больших блоков текста — параграфов, заголовков, врезок, а иногда даже целых страниц! 

Строчными же элементами решили размечать совсем маленькие части текста внутри. Где-то акцент добавить жирным выделением, где-то подчеркнуть, вон там ссылочку вставить. Главное — не нарушать общий поток текста разрывами. 

По мере прогресса рода человеческого, ежегодного выхода футбольного симулятора FIFA, усложнения дизайна сайтов разработчики интернета решили использовать CSS для управления отображением элементов. Хочешь изменить стандартное поведение ссылок или заголовков — давай. Хочешь вообще ему новый способ придумать — пожалуйста. Всё это возможно благодаря CSS-свойству `display`

Благодаря изменению свойства `display` в стилях! 

Итогом кода ниже будет желаемая смена режима отображения: все ссылки станут блоками (то есть каждая на новой строке).

```css
a {
  display: block; 
}
```

Забегая вперёд, заметим, что существуют и другие значения `display`, позволяющие верстать сложные макеты, создание которых было бы невозможным раньше.

Действительно так. Раньше многие сайты верстались с применением запрещённого ныне приёма — вставкой изображений вместо вёрстки. Это когда элементы сложных макетов экспортировались в виде изображений и вставлялись в определённые места на сайте. Получался такой сайт-пазл-мозаика из картинок. 

Снега за воротник разработчикам с таким подходом никто не пихал, но и минусов у него достаточно: индексироваться поисковиками сайт не будет — нет текста, при этом много весит и долго грузится.
