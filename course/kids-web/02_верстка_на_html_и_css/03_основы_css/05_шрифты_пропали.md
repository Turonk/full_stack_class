### Подключаем шрифт на страницу

Шрифт, как ты можешь догадаться, подключается в файле стилей. 

```css
body {
  font-family: "SF Pro Text", "SF Pro Icons", "Helvetica Neue", Helvetica, Arial, sans-serif;
}
```

Починили!

Правила работы подобной записи следующие: 

```css
селектор { 
	font-family: 'Шрифт 1', 'Шрифт 2', Резервный шрифт, семейство шрифтов. 
}
```

Такой список позволяет браузеру выбрать дополнительный шрифт, если основной недоступен. 

В примере выше мы даём правило использовать шрифт «SF Pro Text», но если его нет, то «SF Pro Icons», а если и его нет, то «Helvetica Neue», а уж если и его нет, то Helvetica, ну а если его тоже нет (нас не остановить), то Arial, и на случай отсутствия всех вышеперечисленных — любой шрифт семейства Sans Serif.

![](https://pictures.s3.yandex.net:443/resources/Frame_11_1696434826.png)



Семейства Sans Serif, то есть без засечек. 

Все упомянутые шрифты являются представителями группы без засечек, и если вдруг ни одного из них на устройстве нет, то мы разрешаем браузеру использовать любой из схожего семейства. 

Это хорошая практика, которая позволяет избежать ситуации как на картинке выше: когда внезапно вылез Times, который с засечками и ну совсем не подходит 🐸

В общем, в CSS шрифты подразделяются на следующие типы:

1. С засечками (`serif`)
2. Без засечек (`sans-serif`)
3. Моноширинные (`monospace`)
4. Курсивные (`cursive`)
5. Фэнтези (`fantasy`)


![](https://pictures.s3.yandex.net:443/resources/Frame_40_1_1697203248.png)



Свойства шрифтов могут наследоваться от родительских элементов, но их также можно переопределить для конкретных элементов или классов ниже. 

```css
body {
  font-family: Arial, sans-serif;
}

h1 {
  font-family: 'Times New Roman', serif;
}

```

### **Наследование свойств и их перезапись**

Представь семью. Если у родителей есть дом, у их детей он автоматически тоже есть. Так же и в CSS: если у «родителя» есть определённый стиль, то и «дети» его получают.

Самый наглядный пример — шрифт и цвет текста.


![](https://pictures.s3.yandex.net:443/resources/Frame_25_1696434889.png)


У тега боди чёрный цвет и шрифт без засечек — эти значения автоматически получают дети `body` — `h1` и `div`, а также его внуки, и так далее до бесконечного колена. 

Но сын `h1` и внук `h2` — панки (отрицают устои), у них оранжевый цвет и шрифт с засечками (потому что значения шрифта и цвета мы переписали).

### **Основные свойства шрифтов**

Цвет задаётся с помощью свойства `color`, где в качестве значения указываем название цвета на английском языке. 

Полный список в доке — [https://doka.guide/css/web-colors/](https://doka.guide/css/web-colors/){target="_blank"}



![](https://pictures.s3.yandex.net:443/resources/Frame_6_1_1696434941.png)



Помимо цвета тексту можно задать ряд значений, которые влияют на его отображение: 

1. Font-Family: задаёт семейство шрифта.
2. Font-Size: задаёт размер шрифта.
3. Font-Weight: задаёт толщину символов шрифта.
4. Font-Style: задаёт стиль шрифта (например, наклонный — italic).

Все эти свойства можно также объединить в одно свойство — `font`:

```css
p {
  font: italic bold 16px/1.5 'Times New Roman', serif;
	color: black;
}
```

Здесь `16px` — это размер шрифта, `1.5` — межстрочный интервал, `italic` и `bold` — стиль и толщина шрифта соответственно.
