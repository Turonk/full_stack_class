То, что ты видишь перед фигурными скобками (смотри на стрелочки от пункта 1), называется селектором. И тут опять подсказка в английском, где select — выбирать. По факту, указывая в селекторе тот или иной HTML-элемент, ты выбираешь ту часть страницы, к которой применишь стиль. 

Ну а задаёшь ты этот стиль с помощью свойства (ищи его после фигурной скобки) и его значения (смотри на стрелочки от пункта 3).

Резонно. Вставляй себе стили в теги (это, кстати, называется inline) направо и налево, и тоже будет красиво…

НО! 

…есть несколько веских причин использовать `<style></style>`**,** разделяя файл стилей и файл вёрстки.

1. **Файл вёрстки сильно раздуется визуально и станет слишком тяжёлым для понимания, если прописывать стиль в каждом теге 🥴**
Представь, тебе нужно указать одному блоку, допустим, три свойства. 

   Видишь в коде снизу, как сильно растягивается один-единственный блок с ними? А ведь он в себе ещё даже ничего не содержит. А теперь вообрази, что таких блоков 50, и некоторые ещё вложены друг в друга — зрелище не для слабонервных!

```html
<body>
  <div style="font-size: 20px; color: white; background-color: black;"></div>
</body>
```


    
2. **Ты можешь переиспользовать классы стилей с другими блоками ♻️**
Незачем писать одно и то же в разных тегах по несколько раз. Можно задать `class` с набором свойств и юзать в любой момент с любым другим блоком, которому его пропишешь. Экологичный подход к коду, получается. 

```html
<style>
    .bro-block {
        background-color: red;
    }
</style>

<body>
    <!-- У всех блоков ниже будет красный фон, 
так как они обладают одним и тем же классом bro-block -->
    <div class="bro-block">
        Вот такой див
    </div>
    <div class="bro-block">
        И вот такой див
    </div>
    <div class="bro-block">
        И вот такой ещё див
    </div>
</body>
```

1. **Стиль, прописанный прямо в строке, «перевешивает» любые другие, написанные в `<style></style>` или в отдельном файле ⚖️**
Inline-стили почти невозможно переопределить, поэтому если вдруг напишешь стиль прямо в теге, к примеру с определённым цветом или шрифтом, то не сможешь установить другой цвет или шрифт за пределами этого тега.

```html
<style>
    .bro-block {
        background-color: red;
        /* Это не сработает из-за inline-стиля в теге */
    }
</style>

<body>
    <!-- Фон будет всё-таки зелёного цвета, 
так как inline-стили главнее -->
    <div style="background-color: green;" class="bro-block">
        Вот такой див
    </div>
</body>
```

### Шаг 2

Закинь туда следующий код:

```html
<!DOCTYPE html>
<html lang="ru">

<head>
    <meta charset="UTF-8">
    <title>Кроссы — и точка.</title>
</head>

<body>
    <div>Тут будет что-нибудь про кроссовки</div>
</body>

</html>
```

### Шаг 3

Создай файл с расширением `css`

![](https://pictures.s3.yandex.net:443/resources/Screenshot_2023-09-19_at_23.04.34_1695196595.png)

### Шаг 4

В этом файле самостоятельно напиши код, в котором укажи размер шрифта (используй `font-size` `32px`), цвет шрифта (используй `color` `white`) и цвет фона (используй`background-color` `lavender`).

Помни, что название свойства и его значение разделяются двоеточием `:`, а в конце каждой строчки стиля нужно ставить точку с запятой `;`

```css
font-size: 32px;
color: white;
background-color: lavender;
```

### Шаг 5

Теперь давай напишем название этого блока со стилем прямо перед его началом — таким образом, мы присвоим ему класс (который позже сможем применить к HTML-элементу). 

Для этого нужно поставить точку и после неё указать название (пусть будет`.first`).

```css
.first font-size: 32px;
color: white;
background-color: lavender;
```

Чего-то не хватает, не так ли?

Бинго!

### Шаг 6

Поставь одну открывающую фигурную скобку сразу после названия и одну закрывающую в самом конце.

```css
.first {
    font-size: 32px;
    color: white;
    background-color: lavender;
}
```

### Шаг 7

Вернись на HTML-страницу и в наш единственный `div` запиши атрибут `class` со значением `first`

```html
<body>
    <div class="first">Тут будет что-нибудь про кроссовки</div>
</body>
```

### Шаг 8

Мы почти у цели. Осталось только связать файл стилей и HTML-страницу.

Делается это с помощью тега `<link>`, который, кстати, и переводится как «связывать». 

В теге `<link>` указывается атрибут `rel` — это сокращение от relationship, что переводится как «отношение».

В значении этого атрибута указывают `stylesheet`, что означает «таблица стилей».

То есть дословно наш тег с атрибутом и значением можно перевести как «ссылка, которая имеет отношение к таблице стилей». 

В собранном виде эта часть кода выглядит так:

```html
<link rel="stylesheet">
```

Поместить эту строчку следует в контент тега `<head></head>`(можно сразу после названия сайта).

```html
<head>
    <meta charset="UTF-8">
    <title>Кроссы — и точка.</title>
    <link rel="stylesheet">
</head>
```

### Шаг 9

Теперь вторым атрибутом в теге `<link>` нужно указать путь до самого файла css. Делает это `href`, как ты помнишь. Значение атрибута — просто название файла со стилями (это сработает, только если наши HTML и CSS-файлы находятся в одной папке рядом друг с другом).

В итоге эта строчка с двумя атрибутами и их значениями будет выглядеть так:

```html
<link rel="stylesheet" href="style.css">
```
