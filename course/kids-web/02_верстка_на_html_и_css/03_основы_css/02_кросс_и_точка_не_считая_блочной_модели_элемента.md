# Кросс — и точка, не считая блочной модели элемента

```html
<html>
  <head>
    <title>КРОССЫ - И ТОЧКА</title>
  </head>
  <body>
    <h1>КРОССЫ - И ТОЧКА</h1>
    <div style="display: flex">

      <div>
        <img src="https://i.ibb.co/YRFKhcP/9060.png" width="200" />
        <p width="100%">New Balance 9060</p>
      </div>

      <div style="height: 20px; width: 81px; margin-top: 94px;">
        <img src="https://i.ibb.co/XJZ9pdV/vomero.png" width="200" />
        <p>Nike Zoom Vomero 5</p>
      </div>

      <div style="width: 100px;">
        <img src="https://i.ibb.co/0mRd0wp/stan-smith.png" width="200" />
        <p>Adidas Stan Smith</p>
      </div>

      <div style="width: 100%;">
        <img src="https://i.ibb.co/0DmLwnQ/jordan.png" width="200" />
        <p>Nike Air Jordan 1</p>
      </div>

    </div>
  </body>
</html>
```

![](https://pictures.s3.yandex.net:443/resources/Screenshot_2023-09-26_at_12.28.26_1695809266.png)

Зришь в корень! Проблем у кода Аски много, но одна из них в том, что он не шарит, что такое блочная модель. Сейчас тебе объясним, а вы уж там как-нибудь разберётесь потом со своим кроссовочным стартапом.

Если бы CSS проходил психологический тест, где нужно выбрать геометрическую фигуру, которая больше всего по душе, он выбрал бы…

ПРЯМОУГОЛЬНИК.

Да, все сайты в интернете, на самом деле, набор прямоугольников — блоков. По крайней мере, в глазах CSS.

Границы у этих прямоугольников по умолчанию прозрачные, поэтому мы их так не видим, но факт остаётся фактом: заголовок — это прямоугольный блок, изображение — прямоугольный блок, параграф — можешь догадаться…

Всё так! Сплошные блоки, прямо как в Майнкрафте.

У каждого из них есть следующие параметры:

- ширина — `width`
- высота — `height`
- граница — `border`
- внешний отступ — `margin`
- внутренний отступ —  `padding`


![](https://pictures.s3.yandex.net:443/resources/Untitled_Artwork_386_1695375347.png)

С помощью CSS все эти параметры можно менять, как вздумается — так появляется бесчисленное множество вариантов вёрстки одного и того же сайта. 

Представь, абзац. С помощью разных отступов его можно сделать вытянутым или квадратным, обвести его содержимое какой-нибудь цветной пунктирной границей и отодвинуть подальше от него остальные элементы страницы, задав широкие поля (внешние отступы). 

Браузер, учитывает всё вышеперечисленное, подгружая сайт и показывая элемент в том размере, который мы прописали в CSS-коде. Но в этой увлекательной (не очень) математике есть один минус: если границы и отступы мы задаём сами, то ширина и высота встроены в элемент по умолчанию. И иногда получается совсем не то, что хотелось бы.

![](https://pictures.s3.yandex.net:443/resources/css_is_awesome_1695375373.png)

Именно это мы сейчас и обсудим.

Твои предшественники-кодеры придумали штуку под названием `box-sizing` — буквально переводится как «размерность коробки». Она, если указано значение `border-box`, позволяет поменять стандартное поведение браузера и указать ему, что заданные в CSS ширина и высота нашего блока должны включать в себя в том числе внутренние отступы и рамки.

![](https://pictures.s3.yandex.net:443/resources/Frame_19_2_1695809499.png)

Сразу видно — наш человек! Как тут отказать?

Держи небольшой код с кроссовком для VSCode 👇🏻

Часть для HTML-файла:

```html
<!DOCTYPE html>
<html lang="ru">

<head>
    <meta charset="UTF-8">
    <title>Кроссы — и точка</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <div class="first">
        <div class="card">
            <img src="https://i.ibb.co/YRFKhcP/9060.png" alt="кроссовок" />
            <p>New Balance 9060</p>
        </div>
    </div>
</body>

</html>
```

И текущий файл стилей (вспоминай, куда его положить, или загляни в прошлый урок):

```css
body {
    background-color: #F1F1F1;
}

.card {
    border: 1px solid #898989;
}

.first {
    display: flex;
    justify-content: center;
    width: 100%;    
}

p {
    width: 100%;
}
```

*Начальный вид вёрстки*

Если всё готово, стартуем экспериментировать со всеми этими отступами, границами и волшебным `box-sizing`

## Шаг 1

Чтобы наглядно увидеть, как работают размеры элементов, задай границу для тега `p`

Добавь в стиль для селектора `p` свойство `border` и укажи значение `1px solid #898989` 

А чтобы параграф выделялся, давай сделаем ему белый фон с помощью свойства `background-color` со значением `white`

```css
p {
	background-color: white;
  border: 1px solid #898989;
  width: 100%;
}
```

Теперь благодаря границам и фону мы видим размер нашего параграфа (сохраняй код и чекай в браузере).

## Шаг 2

Сейчас добавь в стиль параграфа ещё и внутренний отступ `padding` со значением `10px`

Тем самым размер блока параграфа увеличится на `10px`, так как он отображается с помощью стандартной модели, о которой мы говорили в начале. 

Параграф теперь имеет 100% своего размера + `10px` отступа с каждой стороны, из-за чего выходит за пределы карточки, в которой он находится 🥲



![](https://pictures.s3.yandex.net:443/resources/Screenshot_2023-09-26_at_23.43.52_1697621685.png)
*Параграф уехал за границу (даже без загранпаспорта)*

```css
p {
	padding: 10px;
	background-color: white;
	border: 1px solid #898989;
  width: 100%;
}
```

## Шаг 3

А теперь давай потестим то самое свойство, придуманное разработчиками, чтобы избежать эту боль перфекциониста. 

К тому же самому тегу `p` добавь свойство `box-sizing` со значением `border-box`

После этого незначительного действия размер элемента будет считаться с учётом его дополнительных внутренних отступов `padding` и границ `border`.

```css
p {
	box-sizing: border-box;
  padding: 10px;
	background-color: white;
	border: 1px solid #898989;
  width: 100%;
}
```

Ну как, получилось? Параграф теперь находится внутри карточки, а не выходит за её пределы, при этом отступы тоже есть. Ну разве не магия?

С этим знанием ты можешь посчитать размер любого блока и предугадать его поведение при вёрстке.

## Шаг 4

Добавь тегу `p` внешние отступы `margin` со значением `10px` , только придётся у этого же тега убрать строчку кода про ширину (`width` со значением `100%`), чтобы элемент автоматически сжимался внутри родительского контейнера с кроссовком (в других уроках ещё объясним тебе, откуда тут взялись родители, а пока просто делай).


![](https://pictures.s3.yandex.net:443/resources/Screenshot_2023-09-26_at_23.44.53_1695809680.png)
*Твой код в итоге отображается так?*

```css
p {
	margin: 10px;
	box-sizing: border-box;
  padding: 10px;
	background-color: white;
	border: 1px solid #898989;
}
```

Честно говоря, есть ещё одна фича.

Все эти отступы и границы можно сделать разными с разных сторон. Всего их (как предсказуемо!) четыре: верхняя, нижняя, левая и правая. Но в коде, конечно, будем использовать их английские названия: `top`, `bottom`, `left`, `right` 

Для того, чтобы указать с какой стороны ты хочешь сделать отступ или границу, нужно написать одно из свойств (`margin`, `padding`, `border`) и через дефис `-` добавить название стороны. 

`margin-top`, `padding-left`, `border-right`, `margin-bottom` — вариантов много. 

Давай что-нибудь такое затестим!

## Шаг 5

Добавь нижний отступ нашему параграфу: `margin-bottom` со значением `35px`

Важно! Его обязательно нужно написать после общего свойства `margin`, как бы перезаписывая предыдущее значение.

```css
p {
    margin: 10px;
    margin-bottom: 35px;
    background-color: #fff;
    border: 1px solid #898989;
    padding: 10px;
    box-sizing: border-box;
}
```

Кстати, чтобы не писать аж четыре строчки, если мы хотим задать каждой стороне разный отступ, можно всё уместить в одну.

Достаточно просто указать `margin` и задать ему значения для четырёх сторон. 

Вот так `margin: 10px 25px 10px 40px;` 

Значения сторон применяются по часовой стрелке: первое значение — это верх, второе — правая сторона, потом — низ, и в конце — левая. 

А ещё можно указывать общие значения попарно: верх-низ и лево-право. Или верх и низ с разными отступами, а левая-правая стороны с одинаковыми. Вот наглядная подсказка, как это делать.

```css
/* Применяется ко всем четырём сторонам - 10px */
margin: 10px;

/* по вертикали, то есть сверху и снизу - 35px | по горизонтали, 
то есть справа и слева - 10px */
margin: 35px 10px;

/* сверху 35px | горизонтально - 10px | снизу - 40px */
margin: 35px 10px 40px;

/* сверху - 10px | справа - 35px | снизу - 5px | слева - 40px */
margin: 10px 35px 5px 40px;
```

Так же работает и с внутренним отступом (`padding`)

Давай теперь улучшим с этим знанием повторяющиеся части нашего кода!

## Шаг 6

Сейчас у тебя для тега `p` заданы два почти одинаковых свойства: `margin` и `margin-bottom` 

Сэкономь немного места, удали `margin-bottom` и с помощью указания сторон, как в примере выше, сделай отступы: сверху — `10px`, по горизонтали — `10px` и снизу — `35px`

```css
p {
    margin: 10px 10px 35px; /* сверху 10px | горизонтально - 10px | снизу - 35px */
    background-color: #fff;
    border: 1px solid #898989;
    padding: 10px;
    box-sizing: border-box;
}
```

Если да, то вот тебе ещё факт напоследок: размер отступа можно задать не только пикселями, но и в процентах (от ширины блока), и словом `auto` (в таком случае браузер сам выбирает подходящий размер отступа).
