# Сайт бардака

![](https://pictures.s3.yandex.net:443/resources/Untitled_Artwork_332_1694781941.png)

Давай для начала зададим структуру сайту: укажем тип документа (html), добавим открывающий и закрывающий теги `<html>` и между ними добавим теги `<head></head>` и `<body></body>`

```html
<!DOCTYPE html>
<html lang="ru">
  <head>

	</head>
  <body>
	
	</body>
</html>
```

Из вселенной оптимизации поиска 🕵🏻‍♀️

Это атрибут, который отвечает за основной язык страницы: в нашем случае значение — русский. Благодаря использованию этого атрибута поисковики лучше будут считывать, кому показывать твой сайт.

Теперь в `<head></head>` пропишем тег `<meta>` с указанием кодировки и `<title></title>`:

```html
<head>
		<meta charset="UTF-8">
    <title>Ретро свалка</title>
</head>
```

Ну название вкладки в `<title></title>` мы так, черново набросали — попробуй покреативить и дать своё.

А мы пока подключим стили. У нас уже есть готовый файл стилей от Цэ-эс-эсочки — в этот раз она любезно им поделилась. В дальнейшем такие придётся делать своими силами. Всё, что нужно сделать — в тег `<head>` добавить тег `<style>`, в который скопипастить стили, и не забудь потом закрыть тег!

Нам осталось только правильно привязать их к нашей странице с помощью классов. Для этого нужно вставить атрибут `class` с названием класса, содержащего нужные стили в CSS.

Смотри, как мы присвоили классы первым трём ссылкам, и сделай то же самое с остальными в своём коде (список названий под кодом).

```html
<img src="https://code.s3.yandex.net/kids-web/trash.png" class="trash" />
<img src="https://code.s3.yandex.net/kids-web/trash-bag.png" class="trash-bag" />
<img src="https://code.s3.yandex.net/kids-web/the-imagination-machine.png" class="imagination-text" />
```
