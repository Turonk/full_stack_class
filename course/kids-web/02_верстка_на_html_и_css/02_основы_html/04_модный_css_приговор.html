Аски не выходит на связь, и, судя по последним межгалактическим сплетням, он конкретно вкрашился.

Ну и ладно 😑 Проблема в том, что Аски теперь вообще никак не говорит, и всё потому что эту их свалку посетила какая-то модная девчуля, назвала все HTML-труды нашего рыцаря некрасивыми и скрылась непонятно куда, оставив только свой фирменный стикер.

Ей ещё что-то вслед бросил король, назвав то ли Цээссоской, то ли Цээссамкой.

О! Ты здесь, неужели.

Эх, а так хотелось немного любви в наши кодовые будни добавить. Тем более CSS действительно любовь всех веб-разработчиков, ведь благодаря этому языку серый HTML может заиграть новыми красками. Если конкретнее, CSS помогает задать такие параметры, как величина или жирность шрифта, цвет слова, размер картинки и все вот эти визуальные штуки, которые из обычного кода делают аэстетик код.

Прямо сейчас лучше любого CSS-стилиста покажем тебе, как это работает.

Для примера возьмём заголовок, параграф и div с двумя вложенными в него параграфами:

<h1>Это заголовок</h1>
<p>Это параграф</p>
<div>
	<p>
		Параграф в диве номер раз
  </p>
	<p>
		Параграф в диве номер два
	</p>
</div>

А теперь вызовем Цэ-эс-эсочку, используя открывающий и закрывающий теги `<style>`

Чтобы обратить её внимание на конкретный блок кода, нужно в контенте тега `<style>` указать соответствующий этому блоку тег, но (внимание!) без привычных нам угловых скобок. Зато следом, указывая свойства для тега (например, размер шрифта), мы откроем скобку фигурную — тебе вероятно, приходилось видеть её на уроках математики. А после свойства закроем её.

Лови, и тут же парочку важных комментариев о том, как именно нужно вести себя с Цэ-эс-эсочкой.

![](https://pictures.s3.yandex.net:443/resources/Untitled_Artwork_378_1695127607.png)

<style>
	h1 {
		font-size: 32px;
	}

	p {
		color: chocolate;
	}
</style>
<h1>Это заголовок</h1>
<p>Это параграф</p>
<div>
	<p>
		Параграф в диве номер раз
  </p>
	<p>
		Параграф в диве номер два
	</p>
</div>

Критику приняли! Попробуем нечто более изысканное.

Добавим цвет фона (`background-color`) для `div` и отступы снаружи с помощью свойства `margin`, а для параграфов внутри `div` сделаем внутренний отступ с помощью `padding` и цвет слоновой кости:

<style>
	h1 {
		font-size: 32px;
	}

	p {
		color: chocolate;
	}

	div {
		background-color: deeppink;
		margin: 10px;
	}

  div p {
		color: #FFFFF0; // ivory
		padding: 25px;
	}
</style>
<h1>Это заголовок</h1>
<p>Это параграф</p>
<div>
	<p>
		Параграф в диве номер раз
  </p>
	<p>
		Параграф в диве номер два
	</p>
</div>

Изи, не правда ли?

Обрати внимание: если в названии параметра есть два слова, то они пишутся через дефис — например, `background-color`. Этакий шашлычок из слов получается.

А цвета новая подружка рыцаря может воспринимать как с помощью слов (в коде использовали `ivory`), так и с помощью hex-кода с хешем #FFFFF0, но в это углубимся попозже.

А пока поздравляем, ты теперь можешь раздать стиля любому тегу веб-галактики. И для этого у тебя есть аж три способа:

**Способ номер один**

<style>

/* CSS код */

</style>

Написать стили в контенте парного тега `<style>`

**Способ номер два**

<p style="CSS_код">текст</p>

Дать стиля inline — прямо в качестве атрибута тега.

**Способ номер три**

<link href="style.css" rel="stylesheet" type="text/css">

Создать файл, в котором будут содержаться стили. В коде `href` указывает на местоположение файла, слева от точки — название файла, справа от точки — расширение (CSS в данной ситуации), а об остальных атрибутах узнаешь чуть дальше.

Мы тебя уже заждались с этого модного приговора с мисс Цэ-эс-эсочкой. Надеемся, она не сильно тебя замучила, ведь теперь ты знаешь достаточно, чтобы наконец-то приступить к работе над сайтом помойки!
