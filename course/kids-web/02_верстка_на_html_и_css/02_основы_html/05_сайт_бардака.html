Давай для начала зададим структуру сайту: укажем тип документа (html), добавим открывающий и закрывающий теги `<html>` и между ними добавим теги `<head></head>` и `<body></body>`

<!DOCTYPE html>
<html lang="ru">
  <head>

	</head>
  <body>
	
	</body>
</html>

Из вселенной оптимизации поиска 🕵🏻‍♀️

Это атрибут, который отвечает за основной язык страницы: в нашем случае значение — русский. Благодаря использованию этого атрибута поисковики лучше будут считывать, кому показывать твой сайт.

Теперь в `<head></head>` пропишем тег `<meta>` с указанием кодировки и `<title></title>`:

<head>
		<meta charset="UTF-8">
    <title>Ретро свалка</title>
</head>

Ну название вкладки в `<title></title>` мы так, черново набросали — попробуй покреативить и дать своё.
