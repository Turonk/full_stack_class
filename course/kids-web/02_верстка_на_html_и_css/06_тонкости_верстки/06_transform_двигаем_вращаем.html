Мы потрудились над плейлистом, добавили в него анимацию, пора бы поговорить о трансформах.

Ну, это CSS-свойство по своим мощностям не уступает Оптимусу Прайму. С ним ты сможешь делать ещё больше интересных анимаций в своих проектах.

Вот как оно выглядит:

.element {
	transform: rotate(180deg);
	/* поворот элемента на 180 градусов */
}

В значении `transform` пишется функция трансформации, которая применяется к элементу (если несколько функций, тогда они пишутся через пробел).

Например, функция `rotate` в примере выше значит, по сути, «поверни элемент на 180 градусов». При этом элемент трансформируется так, что изменения не повлияют на соседние элементы.

Вот, к примеру, плейлист с неестественно наклонённой карточкой — но она не мешает основному потоку элементов.

![](https://pictures.s3.yandex.net:443/resources/Snimok_ekrana_2023-10-25_v_15.39.05_1698851773.png)

Ниже рассмотрим несколько основных функций `transform`. После каждой из них тебе будет доступна песочница, где в файле `styles/style.css` ты можешь испытать трансформации в действии.

- `rotate(z)` — поворот элемента. Значение указывается в градусах. По умолчанию крутит элементы по оси Z (перпендикулярно экрану).

{iframe:https://sandbox-teens.practicum-team.ru/tasks/06-layout-details/01-sandboxes/05-transforms/sandbox-01-rotate/pre/|minWidth:400px|minHeight:600px}

- `translate(x, y)` — смещение элемента от его изначальной позиции. `x` — смещение по горизонтали, `y` — по вертикали. Можно расписывать смещения и отдельно по каждой оси с помощью функций `translateX`, `translateY`

{iframe:https://sandbox-teens.practicum-team.ru/tasks/06-layout-details/01-sandboxes/05-transforms/sandbox-03-translate/pre/|minWidth:400px|minHeight:600px}

- `scale(x, y)` — масштабирование элемента. `scale(0)` скрывает элемент, значения меньше единицы делают его меньше, а значения больше обозначают, во сколько раз он должен быть увеличен. Если в скобках только одно число (например, `scale(1.5)`), то браузером считывается как значение по обеим осям (`scale(1.5, 1.5)`).

{iframe:https://sandbox-teens.practicum-team.ru/tasks/06-layout-details/01-sandboxes/05-transforms/sandbox-02-scale/pre/|minWidth:400px|minHeight:600px}
