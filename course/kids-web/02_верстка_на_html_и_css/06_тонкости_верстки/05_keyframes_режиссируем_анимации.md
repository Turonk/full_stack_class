# Keyframes: режиссируем анимации

{video:https://code.s3.yandex.net/kids-web/Untitled_Artwork_510_1.mp4}

Раз уж ты теперь в курсе, что с помощью CSS можно анимировать элементы, то го копнём глубже в данном направлении. 

В этом уроке окунёмся в изучение `@keyframes`, чтобы обрести больше контроля над создаваемой анимацией.

`@keyframes` — это ключевые кадры (или точки перехода), которые свойственны сложной анимации.

Отличия анимации, сделанной с помощью `@keyframes`, от более простой, воплощённой через `transition`, следующие:

- Можно задать гораздо больше этапов состояния анимации, направление появления элемента, заставить его кружиться или вообще сделать так, чтобы буквы какого-нибудь заголовка выкатывались из-за угла экрана, посвистывая и приплясывая (да, с определёнными усилиями можно и такого добиться).
- Запуск анимации автоматический, можно задать временные рамки для начала (например, через одну секунду после загрузки сайта) и конца анимации.

А вообще, что разглагольствовать? Лучше смотри по [ссылке](https://doka.guide/css/animation/demos/shop-animation/){target="_blank"}, к каким результатам можно прийти, если научиться пользоваться `@keyframes`

Одобряем!

Для этого нам понадобится [страница плейлистов](https://www.figma.com/file/4fnZhhil07bpqr00KdScrI/%D0%9F%D0%BB%D0%B5%D0%B9%D0%BB%D0%B8%D1%81%D1%82?type=design&node-id=0-1&mode=design&t=96lvqDZGR0ueDTde-0){target="_blank"} с карточками треков.

Сначала элементу или блоку, которому мы хотим задать анимацию (в нашем случае это будет тег с классом `card`), нужно прописать следующие свойства:

`animation-name` — название анимации (название будет `drop`).

`animation-duration` — длительность анимации (установим пару секунд — `2s`).

`animation-iteration-count` — сколько раз анимация будет воспроизведена (установим, что бесконечное количество раз — `infinite`). 

```css
.card {
	animation-name: drop;
	animation-duration: 2s;
	animation-iteration-count: infinite;
}
```

Теперь нам нужно эту анимацию написать с помощью `@keyframes`, которому мы зададим имя, указанное нами в свойстве `animation-name`, — `drop`

```css
@keyframes drop {

}
```

Внутри правила `@keyframes` укажем ещё два. 

Первое — начальная точка, которая пишется как `from` (буквально с английского переводится как «от»).

Второе — конечная точка, которая пишется как `to` (и переводится как «к»). 

```css
@keyframes drop {
	from {}
	to {}
}
```

Теперь этим точкам нужно задать значения. 

Мы сделаем анимацию с помощью свойства `margin-top`, чтобы карточки выпадали сверху вниз. 

Для этого в правиле `from` пропишем свойство `margin-top: -10%;`, а в правиле `to` — `margin-top: 0;`

```css
@keyframes drop {
    from {
        margin-top: -10%;
    }

    to {
        margin-top: 0;
    }
}
```

Теперь каждая карточка буквально падает:

{iframe:https://sandbox-teens.practicum-team.ru/tasks/06-layout-details/01-sandboxes/04-advanced-animations/sandbox-02/pre/|minWidth:400px|minHeight:600px}

Сейчас воспроизведение анимации не останавливается, так как установлено свойство `animation-iteration-count: infinite;`, то есть количество запусков анимации бесконечно. 

Этому свойству можно задать любое число проигрывания анимации, даже дробное (например, 3.5) — тогда анимация будет проигрываться указанное количество полных раз и ещё чуть-чуть в соответствии с цифрой после точки.

Но есть ещё одна проблема. 

В данный момент положение элементов меняется путём изменения отступа сверху.  Для примера пойдёт, но использование отступов в анимации на практике чревато частичной поломкой вёрстки или не совсем корректной работой анимации на элементе/блоке. 

Для перемещения элементов лучше использовать свойство `transform`, которому задают значение движения по вертикальной оси `translateY(значение)` и значение движения по горизонтальной оси `translateX(значение)` (кое-что с этим кодом ждёт тебя ниже, но более подробно — в следующем уроке).

Ок-ок! Сделаем так, чтобы карточки не только выпадали из-за верхней границы экрана, но ещё и были невидимыми в начале анимации и постепенно проявлялись. 

Для этого в текущий CSS-код добавим свойство `opacity`. В правиле `from` зададим для `opacity` значение 0, а в правиле `to` — 1.

```css
@keyframes drop {
    from {
        transform: translateY(-100px);
        opacity: 0;
    }

    to {
        transform: translateY(0);
				opacity: 1;
    }
}
```

### Анимируем заголовок

Попробуем добавить и анимировать заголовок для плейлистов в нашей же песочнице (но можешь и в редакторе кода этим заняться).

{iframe:https://sandbox-teens.practicum-team.ru/tasks/06-layout-details/01-sandboxes/04-advanced-animations/sandbox-03/pre/|minWidth:400px|minHeight:600px}

### Шаг 1. Назови анимацию

Создай анимацию для элемента `header__logo` внутри `header`. Назови её `rolling` и установи длительность — две секунды.

```css
.header h1 {
    animation-name: rolling;
    animation-duration: 2s;
}
```

### Шаг 2. Создай анимацию

Используя `@keyframes` с именем анимации, добавь два этапа анимации: 0% и 100%. 

С помощью свойства `transform` на этапе 0% пропишем значение `translateX(-100%)`, на этапе 100% установим такое же свойство, только с другим значением `transform: translateX(0)`.

Теперь заголовок выезжает из-за левого края. Для проигрывания анимации нужно обновлять страницу.

```css
@keyframes rolling {
    0% {
        transform: translateX(-100%)
    }

    100% {
        transform: translateX(0)
    }
}
```

### Шаг 3. Заставь заголовок крутиться

Для того чтобы добавить вращения вокруг своей оси для заголовка, пропиши свойству `transform` значение `rotate(0deg)` в начале анимации (0%) и `rotate(360deg)` в конце анимации (100%).

```css
@keyframes rolling {
    0% {
        transform: translateX(-100%) rotate(0deg);
    }

    100% {
        transform: translateX(0) rotate(360deg);
    }
}
```

### Шаг 4. Добавь промежуточный этап анимации

В анимации можно внедрять сколько угодно промежуточных состояний. 

В качестве примера добавь ещё этап 50% и пропиши в него `transform: rotate(180deg);`. Теперь заголовок будет переворачиваться не сразу, а только когда дойдёт до центра экрана.

```css
@keyframes rolling {
    0% {
        transform: translateX(-100%) rotate(0deg);
    }

    50% {
        transform: rotate(180deg);
    }

    100% {
        transform: translateX(0) rotate(360deg);
    }
}
```

Вариантов анимации множество. Можно анимировать появление элементов, управляя их прозрачностью, вращать их вокруг своей оси, плавно менять им цвет, форму, размеры. Все доступные возможности можно посмотреть [тут](https://doka.guide/css/animation/){target="_blank"}.

Но ты уже сейчас заслуживаешь статус почётного веб-аниматора, ведь теперь ты знаешь:

- Про свойство `@keyframes`, как его записывать и какие правила указывать внутри.
- Как созданную анимацию связать по имени с определённым блоком, задать время анимации и количество проигрываний.
- Что промежуточных этапов анимации может быть много. В каждом из них можно прописывать особенности поведения проигрываемой анимации конкретно в рамках этого этапа.
- Ты знаешь, что свойству `transform` можно прописывать значения в ряд (мы так делали с `rotate()` и `translate()`).
