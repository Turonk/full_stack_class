Чек-лист

Чтобы перейти в следующий модуль, нужно сдать код, который запускается без ошибок и соответствует написанному ниже.

1. Требования по блокам и элементам страницы: - на сайте есть девять карточек кроссовок - первые три карточки — это ссылки, они ведут на внутренние страницы кроссовок (отдельная страница для каждой модели) - первые три карточки кроссовок также имеют анимации при наведении — поднимаются наверх - все три уникальные страницы кроссовок содержат контент из макета в фигме - на всех трёх уникальных страницах кроссовок ссылка-логотип ведёт на главную страницу - все изображения из макета отображаются на сайте 2. Требования по синтаксису: - в разметке используются теги `header`, `nav`, `footer` - в HTML-коде нет незакрытых тегов 3. Требования по стилю: - все страницы кроссовок используют один и тот же файл стилей - В CSS-коде отсутствуют синтаксические ошибки, что подтверждается отсутствием подсветки красным цветом в редакторе VSCode 4. Требования по адаптивности: - главная страница сайта и отдельные страницы для трёх моделей кроссовок корректно работают не только с компа, но и на мобильном телефоне: ничего не обрезается и соответствует макету сайта (для ширины экрана компьютера — 1440px, мобильная версия шириной 375px). - в мобильной версии также изменяются размеры элементов страницы (карточки кроссовок немного у́же) и шрифтов, отступы, порядок элементов во flex-контейнере (header и footer).

- код сохранен в гитхабе - сайт опубликован в интернете

ПЫСЫ: эту часть не проверяем, присылай результат работы в дискорд.
