Transitions: плавные переходы

![](https://pictures.s3.yandex.net:443/resources/Frame_114_1_1_1698761279.png)

С помощью псевдоклассов мы сделали элементы анимированными, но реализация пока оставляет желать лучшего: в анимации цвет слишком резко меняется на другой.

Пришло время добавить плавности!

Чтобы сделать анимации плавными и более приятными, надо использовать свойство `transition`. На русский переводится как «переход», что достаточно хорошо отражает его суть.

В CSS свойство выглядит так:

.element {
	transition: opacity 200ms ease-in-out;
}

На самом деле `transition` — сокращённая запись нескольких свойств:

- `transition-property` Какое свойство будет изменяться (например, в коде выше — `opacity`). - `transition-duration` Сколько времени будет идти анимация (в примере выше — 200 миллисекунд). - `transition-timing-function` Как анимация будет меняться во времени (в примере выше — `ease-in-out`). С помощью этого ты сможешь делать `transition` плавнее.

Здесь список основных значений `transition-timing-function`: а) `linear` — линейное изменение (скорость изменения свойства не меняется). б) `ease-in` — изменение свойств ускоряется к концу анимации. в) `ease-out` — изменение свойств замедляется к концу анимации. г) `ease-in-out` — медленное начало, быстрая середина и медленный конец.

Это, конечно, не все доступные варианты, но их должно быть достаточно, чтобы анимировать элементы на твоём сайте! Полный список значений этого свойства ты всегда можешь чекнуть в [Доке](https://doka.guide/css/transition-timing-function/){target="_blank"}.

- `transition-delay` Задержка перед началом анимации (в примере выше её нет, но она бы добавлялась последней в этой записи).

Заметь, что мы задаём `transition` для изначального состояния элемента, а не для его состояния, описанного с помощью псевдокласса.

Плавно менять с помощью `transition` можно многие свойства, но чаще всего так изменяют значения `box-shadow`, `background-color`, `color`, `opacity` и `transform`

Намёк понят! Лови песочницу, в которой можно поиграть с разными значениями и посмотреть, в чём разница между ними.

Попробуй ставить не очень высокую скорость анимации в этом тренажёре, это поможет лучше вникнуть в то, как работают свойства.

Тогда давай вернёмся к нашему плейлисту, с которым работали в предыдущем уроке. В нём уже добавлены псевдоклассы для состояния с наведённым на карточку курсором и для нажатия на карточку.

Поэтому теперь ты можешь добавить элементам в плейлисте свойство `transition` и увидеть, что анимации стали плавными! Сделай так, чтобы за 200 миллисекунд изменялось свойство `box-shadow`, значением `transition-timing-function` пусть будет `ease-in-out`. Работай в файле `styles/style.css`

{iframe:https://sandbox-teens.practicum-team.ru/tasks/06-layout-details/01-sandboxes/03-transitions/sandbox-02/pre/|minWidth:400px|minHeight:600px}

.card {
    /* Другие свойства */
    transition: box-shadow ease-in-out 200ms;
}

{quiz-task} background: | #f5f6f7 content: | Обрати внимание: при указании свойства `transition` записи для псевдоклассов остаются нетронутыми. Иначе `transition` будет добавляться элементу только в тех состояниях, которые эти псевдоклассы описывают. Например, наведение курсора на карточку будет происходить плавно, а когда курсор покинет карточку, она будет дёргаться, словно никакого `transition` у неё и не задано. {/quiz-task}
