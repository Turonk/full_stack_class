# Класс про псевдоклассы

{video:https://code.s3.yandex.net/kids-web/Untitled_Artwork_17.mp4}

Теперь, когда ты знаешь, что такое анимация и зачем она нужна на сайтах, мы начнём добавлять простую анимацию с помощью CSS в твой проект. 

Наиболее простой вид анимации — разное поведение элемента при изменении его свойств. К примеру, когда при наведении на ссылку меняется её цвет. Получается, для состояния «покоя» ссылки — один стиль, а под курсором — другой.

Для этого нужно использовать псевдоклассы — ключевые слова, добавляемые к CSS-селектору, которые определяют, как должен вести себя элемент в разных состояниях. 

Выглядят они так:

```css
/* элемент класса link без псевдокласса */
.link {
	color: black;
}

/* элемент класса link с псевдоклассом hover */ 
.link:hover {
	color: blue;
}
```

Вот список псевдоклассов с описанием (включая `:hover`):

- `:hover` — наведение курсора на любой элемент.
    
{video:https://code.s3.yandex.net/kids-web/Untitled_Artwork_16.mp4}
    
- `:active` — состояние интерактивного элемента при взаимодействии с ним. Например, в момент, когда пользователь кликает на ссылку или кнопку.
    
{video:https://code.s3.yandex.net/kids-web/Untitled_Artwork_11.mp4}
    
- `:focus` — состояние фокуса (возникает, если пользователь нажимает на интерактивный элемент или перемещается между интерактивными элементами с помощью клавиши `Tab`). Фокуса на элементах `<button>` при нажатии на них нет в браузерах Safari и Firefox.
    
{video:https://code.s3.yandex.net/kids-web/Untitled_Artwork_15.mp4}
    
- `:visited` — особое состояние для элементов с атрибутом `href` (например, элемента ссылки `<a>`). Оно обозначает ссылку, которую уже посетил пользователь. У этого свойства есть ряд ограничений (подробнее в [Доке](https://doka.guide/css/visited/#ogranicheniya){target="_blank"}), поэтому его используют не так часто.
    
{video:https://code.s3.yandex.net/kids-web/Untitled_Artwork_12.mp4}
    
- `:link` — состояние, похожее на `:visited`, но обозначающее ещё не посещённую ссылку.
    
{video:https://code.s3.yandex.net/kids-web/Untitled_Artwork_14.mp4}
    
- `:disabled` — состояние отключённого интерактивного элемента (кнопки или поля ввода). Именно этот псевдокласс встречается при заполнении форм: пока ты не введёшь все необходимые поля, кнопка не будет работать.
    
{video:https://code.s3.yandex.net/kids-web/Untitled_Artwork_13.mp4}
    

Конечно, псевдоклассов в CSS гораздо больше, но они, скорее всего, не понадобятся тебе для работы с анимациями. Но ты можешь удовлетворить любопытство в [Доке](https://doka.guide/css/pseudoclasses/){target="_blank"}.

Вот как будет выглядеть образцовый порядок на примере класса `element__link`:

```css
.element__link {}

.element__link:link {}

.element__link:visited {}

.element__link:hover {}

.element__link:active {}
```

Сначала записываем начальные стили для элемента.

Затем — неинтерактивные `link` и `visited` (в таком порядке записи свойств проще читать: непосещённых ссылок обычно больше, чем посещённых).

Потом — интерактивные `hover` и `active`. Если записать `active` перед `hover`, то стили при наведении на элемент будут перезаписывать указанные ранее стили при нажатии.

Мы всегда за!

### Практикум с псевдоклассами 💪🏻

Посмотрим, как работают псевдоклассы, на примере нашего плейлиста «Треки — и точка»👇🏻

![](https://pictures.s3.yandex.net:443/resources/Snimok_ekrana_2023-10-13_v_13.12.26_1698759718.png)

У ссылок есть прописанные в браузере стили по умолчанию, и в них уже используется псевдокласс:

- `:any-link` с префиксом `-webkit` в Chrome, Яндекс Браузере и Safari.
- `:any-link` с префиксом `-moz` в Firefox.

Он выглядит так (в Chrome и Яндекс Браузере):

![](https://pictures.s3.yandex.net:443/resources/Frame_101_2_1_1698759740.png)

Но ссылка со стилями по умолчанию выглядит не очень красиво в нашем дизайне.

Не переживай. Это легко исправить!

В CSS пропишем, что у элемента не должно быть подчёркивания, а также зададим буквам очень-очень тёмно-синий (почти чёрный!) цвет: `#121723`

```css
.card {
    /* другие свойства */
    color: #121723;
    text-decoration: none;
}
```

![](https://pictures.s3.yandex.net:443/resources/Snimok_ekrana_2023-10-23_v_15.15.58_1698846000.png)

Так-то лучше.

В наш плейлист можно добавить стили для состояния `:visited`: вдруг пользователю будет удобнее, если те треки, которые он уже послушал, будут как-нибудь отмечаться. Пусть такие ссылки красятся в серый цвет. 

```css
.card__link:visited {
    color: grey;
}
```

![](https://pictures.s3.yandex.net:443/resources/Snimok_ekrana_2023-10-13_v_13.44.18_1698760308.png)

Славно! Но пользователю при первом взаимодействии всё ещё не совсем ясно, есть ли за названиями треков ссылки, ведь при наведении текст по-прежнему тёмно-синий.

Тут на помощь и приходят анимации и псевдокласс `:hover`

Сделаем так, чтобы при наведении курсора карточкe добавлялась тень. Добавь нужное правило и укажи в нём свойство `box-shadow` (тень элемента) со значением `10px 10px 13px 0px rgba(0, 0, 0, 0.25)`. Работай в файле `styles/style.css`

{iframe:https://sandbox-teens.practicum-team.ru/tasks/06-layout-details/01-sandboxes/02-pseudoclasses/sandbox-01/pre/|minWidth:400px|minHeight:600px}

{video:https://code.s3.yandex.net/kids-web/Untitled_Artwork_9.mp4}

Теперь при наведении карточка поднимается и получает тень, и пользователю становится интуитивно понятно, что на элемент можно кликнуть.

Давай отработаем ещё и псевдокласс `:active`

Он действует, как упомянуто выше, при нажатии на элемент. Например, пусть при нажатии тень становится немного светлее – укажи `box-shadow` со значением `10px 10px 13px 0px rgba(0, 0, 0, 0.1)`. Работай в файле `styles/style.css`

{iframe:https://sandbox-teens.practicum-team.ru/tasks/06-layout-details/01-sandboxes/02-pseudoclasses/sandbox-02/pre/|minWidth:400px|minHeight:600px}

Ура, теперь карточка реагирует на действия пользователя. 

Но перфекционисты могут заметить, что между обложкой альбома и элементом с названиями песни и группы остался небольшой треугольник без тени 😐


![](https://pictures.s3.yandex.net:443/resources/Frame_175_1698761125.png)

Это можно поправить, если указать, что наведение на карточку влияет на стиль элементов с классами `card__image` и `card__info` . Укажи для `:hover` тень (свойство `box-shadow`) со значением `10px 10px 13px 0px rgba(0, 0, 0, 0.25)`, а для `:active` со значением `10px 10px 13px 0px rgba(0, 0, 0, 0.1)`. Работай в файле `styles/style.css`
