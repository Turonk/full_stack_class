# Качалка: шапка и футер для плейлиста

Не без этого! 

Предлагаем сделать плейлист. Точнее, добавить в существующий код две важные составляющие: `<header>` (или шапка сайта) и `<footer>` (подвал). Но сперва поясним, что это за элементы и зачем они вообще нужны.

Погнали. В подвале (или футере) обычно размещают контактную информацию: телефон, адрес, электронную почту и прочие полезные, но не первоочередные сведения. 

Например, у той же Доки футер выглядит так:

![](https://pictures.s3.yandex.net:443/resources/Snimok_ekrana_2023-10-19_v_15.33.39_1697817936.png)

В этом примере в футере есть ссылки на сторонние сервисы, связанные с Докой: GitHub (про него будет урок на грядущей неделе), рассылку, соцсети. Там же — список ссылок на страницы, подробнее рассказывающие о проекте.  

Ещё в футере бывает полезно продублировать навигацию: когда пользователь долистает до конца страницы, это поможет ему продолжить путешествие по сайту.

Навигация включает в себя список ссылок на разные страницы. 

Для него обычно используют тег списка `<ul>` c элементом списка `<li>` (а внутри каждого элемента уже размещают ссылку). 

Чётенькая структура навигации, скорее всего, будет выглядеть примерно так:

```html
<nav> <!-- элемент навигации -->
	<ul> <!-- ненумерованный список -->
		<li> <!-- элемент списка -->
			<a></a> <!-- ссылка -->
		</li>
	</ul>
</nav>
```

Что тебе нужно сделать:

- Добавить элемент `<header>`, в котором есть ссылка с атрибутом `href=’/’` (слешем обозначили относительный путь от корня сайта: например, на сайте Доки на месте `/` будет https://doka.guide/) и картинкой-логотипом внутри.
- Добавить элемент `<footer>`, в котором будет ссылка с атрибутом `href=’/’`. Картинка-логотип должна быть слева, а справа — блок навигации со ссылками на внешние ресурсы. Потренируйся и поставь туда ссылки на свои социальные сети.
- Расположи элементы в хедере и футере с помощью флексов. Особенно это поможет, когда ты будешь делать навигацию в футере.

-  `<header>`
-  `<footer>`
-  `<nav>`
-  `<ul>`
-  `<li>`
-  и теги `<a>` и `<img>`, конечно!

### **🤫** Секретные ссылки*

Если хочешь быть реально крутым спецом, в футере добавь якорные ссылки на свои любимые треки. 

Для этого 👇🏻

1. **Выдели два своих любимых трека:**
    - Добавь контейнерам этих треков атрибут `id` с произвольным значением в HTML-коде.  Для простоты в качестве названия используй цвет. Например, `id="green"`
    - Обратись к каждому из них селектором по `id` и добавь ему фон в CSS
    - Каждому айди должен быть присвоен свой фон
2. **В меню футера добавь ссылки:**
    - В меню со ссылками для контента ссылок используй эмоджи, подходящие трекам, — 🔥 💔
    - В атрибуте `href` укажи соответствующий ID (например, `href="#green"`)
    - Cсылка может указывать только на один элемент, поэтому каждый айди должен быть уникальным

    Таким образом, это будут секретные ссылкы на твоих музыкальных фаворов.

Теперь ты знаешь, для чего на сайтах существуют хедер и футер. 

В них можно добавлять логотипы, навигацию и ссылки на сторонние сервисы — так пользователю проще ориентироваться по сайту.
