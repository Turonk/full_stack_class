А вот и тот самый урок, в котором окно для кроссовок 👟 Ну то есть для твоего проекта с сайтом кроссовок.

Напоминаем: тебе надо отправить свой код в окошко внизу урока на проверку наставнику до 30 октября, а то все кроссы мира расстроятся и перестанут подходить тебе по размеру. Ну и курс заблокируется через неделю после дедлайна. Поэтому давай со всей ответственностью!

Супер! Ещё раз основная инфа, чтобы проверить себя, в тогглах ниже👇🏻

Добавить на сайт:

1. ШЕСТЬ новых карточек кроссовок. 2. Шапку сайта с логотипом и навигацией с якорными ссылками. 3. Футер.

1. Скачать код, который у нас уже написан к этому моменту, отсюда: [crossyy.zip](https://code.s3.yandex.net/kids-web/crossyy.zip){target="_blank"}

1. Чтобы визуально ориентироваться на нужный итог, открыть макет в фигме: [вот ссылка](https://www.figma.com/file/5VxgsJYsGiSS0QsI6bOkRY/%D0%9A%D0%A0%D0%9E%D0%A1%D0%A1%D0%AB-%E2%80%94-%D0%98-%D0%A2%D0%9E%D0%A7%D0%9A%D0%90.?type=design&node-id=0-1&mode=design&t=F5tPfURcwvHOgy7G-0){target="_blank"}. 2. Выполнить задания этой недели у себя в редакторе кода.

Лови чеклист:

- Твой сайт при открытии в браузере практически идентичен макету (вёрстка нигде не ломается). - На нём есть девять карточек кроссовок (`9*.sneaker`), текст и картинки которых соответствуют макету. - Есть хедер-контейнер с классом `header`. Внутри хедера: 1. Картинка-логотип в контенте ссылки 2. Список с ссылками на соцсети - Есть футер-контейнер с классом `footer`. Внутри футера: 1. Картинка-логотип в контенте ссылки 2. Список с ссылками на соцсети - Текстовым элементам в хедере, футере и в карточках (заголовок, подзаголовок) заданы размер и жирность (CSS-свойства `font-weight`, `font-size`, `font-family`).

Если всё ок, положи свой код в архив и отправляй в окошко ниже. Держим пальчики за тебя 🤞🏻
