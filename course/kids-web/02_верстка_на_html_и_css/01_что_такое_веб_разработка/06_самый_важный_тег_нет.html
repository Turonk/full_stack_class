Самый важный тег (нет)

Лови обещанный тег с романтикой Почты России — тег марки `<marquee>`

Он используется для создания анимации текста или изображения, которые движутся по горизонтали или вертикали.

Кто-то скажет, что тег устарел и им нельзя пользоваться, но это самый поехавший тег всей HTML-коллекции элементов. Артефакт культуры интернета. Знакомимся с аутсайдером👇🏻
