# Как устроено тестирование

Всего в итоговом тесте **четыре блока**: мотивационный, алгоритмика, программирование на JavaScript и социальное исследование. 

Первые два блока тебе знакомы, ведь они уже были в тесте, который состоялся перед твоим поступлением на курс. За последний не переживай тоже — тебе нужно будет ответить всего на несколько вопросов про твой опыт обучения на курсе.

В тесте по **JS** ты увидишь шесть задач разного уровня: начального, базового и продвинутого. Начальный — это простые арифметические операции. Базовый — это отслеживание потока выполнения. Продвинутый — умение писать код самостоятельно. 

В каждой задаче тебе нужно дать короткий ответ (например, написать число или исправить ошибку в коде). В задачах продвинутого уровня тебе нужно написать небольшой скрипт.

### **Задача 3**. Базовый уровень

Ниже дана программа, которая вычисляет количество символов `4` в строке, хранящейся в переменной `str` 👇🏻

```javascript
let count = 0;
let str = 'e4p04mak et0 vkusno';
for (let i = 0; i < str.length; i++) {
  if (str[i] === 4) {
    count++;
  }
}
console.log(count);
```

Так, для строки, хранящейся в переменной `str`, алгоритм должен вывести результат `2`

Напиши самостоятельно программу, которая поможет решить задачу.

        🔢 Пользователь последовательно вводит 10 чисел с клавиатуры, где каждое число — это количество товара на складе каждый день в течение 10 дней. Твоя задача — рассчитать среднее количество товара за это время.
{/quiz-task}

В программе должны использоваться циклы для обработки исходных значений (последовательный набор чисел), которые необходимо сохранить в переменной в виде массива, а также функция для вычисления среднего количества товара.

Для получения данных можно использовать функцию `prompt()`

**Входные данные:**

Десять чисел, которые пользователь вводит последовательно.

**Выходные данные:**

Вывести одно число в консоль — среднее количество товара за две недели.

**Проверь работу кода на следующих данных:**

При вводе последовательности `30, 20, 10, 20, 10, 40, 40, 40, 30, 10` программа выдаст `25`

А с последовательностью `50, 40, 60, 50, 40, 50, 70, 50, 60, 60` получится `53`
