Выбор базы NoSQL

Когда ты определишься с типом БД и подходом к обработке информации внутри неё, может возникнуть ещё один важный вопрос: какую именно NoSQL базу данных выбрать?

Для серверного приложения Pindie лучшим выбором будет **MongoDB**, так как одно из её ключевых преимуществ — совместимость с форматом JSON, который по праву можно считать родным для JavaScript.

{quiz-task} background: | #f1f1ef content: | ❗ **MongoDB** — это лидер среди NoSQL баз данных и самая популярная БД для проектов, разработанных на Node.js. MongoDB предлагает разработчикам мощный набор инструментов для работы с данными, обеспечивая гибкость, масштабируемость и высокую скорость, необходимые для развития приложения. {/quiz-task}

Существует множество типов NoSQL: документоориентированные, колоночные и другие. Каждый из них обладает своими преимуществами и подходит для определённых задач. С ними ты при желании можешь познакомиться самостоятельно.

Для начала необходимо скачать установщик с [официального сайта](https://www.mongodb.com/try/download/community){target="_blank"}. Найди на странице карточку с заголовком «MongoDB Community Server Download» и выбери конфигурацию, как на скриншоте ниже. Если версия `7.0.7` недоступна или плашка `current` отображается у другой, это не критично. Выбери любую рекомендованную тебе версию 👇🏻

![](https://pictures.s3.yandex.net:443/resources/1_1_1713454213.jpg)

При установке не забудь также скачать Compass, который облегчает работу с базой данных 🧭

После окончания загрузки запусти установщик и нажми кнопку `Next` 👇🏻

![](https://pictures.s3.yandex.net:443/resources/2_1_1713454260.jpg)

Поставь галочку, соглашаясь с условиями использования MongoDB, и нажми `Next` 👇🏻

![](https://pictures.s3.yandex.net:443/resources/3_1_1713454280.jpg)

В следующем окне выбери `Complete` 👇🏻

![](https://pictures.s3.yandex.net:443/resources/4_1_1713454299.jpg)

Затем снова нажми `Next` 👇🏻

![](https://pictures.s3.yandex.net:443/resources/5_1_1713454315.jpg)

Поставь галочку слева снизу, для того чтобы сразу установить Compass, который облегчает работу с базой данных, — он нам точно пригодится. После чего снова нажми `Next` 👇🏻

![](https://pictures.s3.yandex.net:443/resources/6_1713454334.jpg)

Кул! Теперь на кнопку `Install` и дождись окончания загрузки 👇🏻

![](https://pictures.s3.yandex.net:443/resources/7_1713454355.jpg)

После окончания загрузки нажми `Finish` 👇🏻

Ещё необходимо создать директории для локального хранения баз данных. Для этого запусти терминал Git Bash от имени администратора.

Найти его можно в поиске Windows 👇🏻

![](https://pictures.s3.yandex.net:443/resources/9_1713454849.jpg)

Введи команду, чтобы перейти в корневую директорию диска `C`. Если на твоём компьютере основной диск называется иначе, к примеру `D` или `F`, то введи его название 👇🏻

cd /C

Следующей командой ты сможешь создать две директории: `data` и внутри неё директорию `db`. Общий путь до баз данных будет `C:/data/db` 👇🏻

mkdir -p data/db

Заключительным этапом необходимо добавить путь к папке `bin` с исполняемыми файлами MongoDB в переменную окружения.

Для начала перейди в папку по этому пути. Сделать это можно прямо из стандартного проводника Windows 👇🏻

C:\Program Files\MongoDB\Server\7.0\bin

![](https://pictures.s3.yandex.net:443/resources/10_1713454898.jpg)

Теперь открой стандартный поиск Windows, нажав клавишу `Win`, и введи «Изменение переменных среды текущего пользователя». Для системы с английским языком по умолчанию эта настройка будет называться «Edit the System Environment Variables» 👇🏻

![](https://pictures.s3.yandex.net:443/resources/11_1713454938.jpg)

Выбери `Открыть` и в появившемся окне в верхнем списке найди переменную с названием `Path`, а затем нажми кнопку `Изменить` 👇🏻

![](https://pictures.s3.yandex.net:443/resources/12_1713454960.jpg)

Ок! Теперь в окне с заголовком «Изменить переменную среды» нажми `Создать`, после чего скопируй путь до папки `bin`, которую мы открыли в проводнике, и вставь в новую строку. Должно получиться вот так 👇🏻

![](https://pictures.s3.yandex.net:443/resources/13_1713454979.jpg)

После чего нажми `ОК` во всех открытых окнах, и переменная окружения будет добавлена.

На этом процесс установки MongoDB завершён! Если у тебя на каком-то из этапов возникли проблемы, можешь свериться с [официальной инструкцией](https://www.mongodb.com/docs/manual/tutorial/install-mongodb-on-windows/#install-mdb-edition){target="_blank"}.

Для установки на macOS мы будем пользоваться [инструкцией](https://www.mongodb.com/docs/manual/tutorial/install-mongodb-on-os-x/){target="_blank"} с официального сайта, в которой для MongoDB используется пакетный менеджер Homebrew.

Перед тем как установить Homebrew, добавь инструменты командной строки для `Xcode`, выполнив команду 👇🏻

xcode-select --install

Далее необходимо установить сам пакетный менеджер Homebrew. Для этого скопируй команду, которая указана на [официальном сайте](https://brew.sh/#install) 👇🏻

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Приступаем к установке MongoDB. Последовательно выполни три команды.

Во-первых 👇🏻

brew tap mongodb/brew

Во-вторых 👇🏻

brew update

В-третьих 👇🏻

brew install mongodb-community@7.0

В процессе будут установлены следующие утилиты:

- **`mongosh`** — представляет консольный интерфейс для взаимодействия с базами данных, своего рода консольный клиент. - **`mongod`** — сервер БД MongoDB. Он обрабатывает запросы, управляет форматом данных и выполняет различные операции в фоновом режиме по управлению базами данных. - **`mongos`** — служба маршрутизации MongoDB, которая помогает обрабатывать запросы и определять местоположение данных в кластере MongoDB.

Кроме того, при установке в зависимости от архитектуры компьютера (`Intel` или `ARM`) будут созданы:

- Файл конфигурации — посмотрим на него чуть ниже. - Каталог для записи логов — если вдруг по какой-то причине сервер MongoDB не запускается или при запуске/работе сервера возникают какие-нибудь ошибки, то мы можем проверить файл лога, чтобы понять причину ошибок. - Каталог для баз данных — в этой папке будут храниться БД.

![](https://pictures.s3.yandex.net:443/resources/14_1713455181.jpg)

Лови пути для компьютеров на `Intel`:

- Файл конфигурации — `/usr/local/etc/mongod.conf` - Каталог логов — `/usr/local/var/log/mongodb` - Каталог баз данных — `/usr/local/var/mongodb`

Пути для компьютеров на `ARM`:

- Файл конфигурации — `/opt/homebrew/etc/mongod.conf` - Каталог логов — `/opt/homebrew/var/log/mongodb` - Каталог баз данных — `/opt/homebrew/var/mongodb`

Для компьютера на `Intel` файл конфигурации выглядит так 👇🏻

systemLog:
  destination: file
  path: /usr/local/var/log/mongodb/mongo.log
  logAppend: true
storage:
  dbPath: /usr/local/var/mongodb
net:
  bindIp: 127.0.0.1, ::1
  ipv6: true

А для компьютера на `ARM` файл конфигурации `mongod.conf` следующий 👇🏻

systemLog:
  destination: file
  path: /opt/homebrew/var/log/mongodb/mongo.log
  logAppend: true
storage:
  dbPath: /opt/homebrew/var/mongodb
net:
  bindIp: 127.0.0.1, ::1
  ipv6: true

Пути в файле `mongod.conf` можно поменять, в том числе и сам `mongod.conf`, переложив в другую папку, но мы не советуем этого делать. Дальнейшие уроки мы пишем, предполагая, что всё лежит в тех же местах, что и при начальной установке.
