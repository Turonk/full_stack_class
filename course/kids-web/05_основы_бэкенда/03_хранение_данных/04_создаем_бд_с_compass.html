Создаём БД с Compass

![](https://pictures.s3.yandex.net:443/resources/mongoDB_1_1713455704.jpg)

Существует множество способов взаимодействия с БД, каждый из которых подходит для разных задач:

- **MongoDB Shell,** или просто **mongosh,** — это такой терминал, созданный специально для MongoDB. Он позволяет работать с данными, управлять настройками и тестировать запросы, общаясь с базой специальными командами. - **MongoDB Atlas** — для проектов, требующих использования облачных технологий и масштабируемости. Это полностью управляемое облачное решение, которое способно автоматизировать многие процессы управления базой данных. - **MongoDB Compass** — удобный графический интерфейс на замену скучному терминалу. Этот инструмент визуализирует данные, а также позволяет ими управлять, анализировать запросы и настраивать базу, не вдаваясь в сложности синтаксиса команд.

Начало работы с Compass

Если у тебя Windows, то при установке MongoDB по инструкции из прошлого урока программа Compass должна была настроиться автоматически. Если у тебя система macOS, то программу нужно будет установить отдельно, следуя инструкции ниже 👀

Заходи на [официальный сайт](https://www.mongodb.com/try/download/compass){target="_blank"}, с которого сможешь загрузить Compass. В графе `Platform` необходимо выбрать `macOS arm64`, если у тебя компьютер на `ARM`-процессоре, или `macOS 64-bit`, если на процессоре `Intel`👇🏻

![](https://pictures.s3.yandex.net:443/resources/1_2_1713455799.jpg)

Теперь установим Compass 👇🏻

![](https://pictures.s3.yandex.net:443/resources/2_2_1713455819.jpg)

Гуд!

Теперь запусти программу, где тебя встретит приветственное окно 👇🏻

![](https://pictures.s3.yandex.net:443/resources/3_2_1713455841.jpg)

Нажми кнопку `Start` и обрати внимание на карточку с надписью `New connection`. В интерфейсе Compass можно работать с разными серверами MongoDB, удобно переключаясь между ними, когда это требуется. Нажми кнопку `Connect`, чтобы подключиться к нашей локальной базе данных.

![](https://pictures.s3.yandex.net:443/resources/4_2_1713455858.jpg)

mongod --config /usr/local/etc/mongod.conf --fork
mongod --config /opt/homebrew/etc/mongod.conf --fork
mongod

Если первая команда для Windows не сработала, воспользуйся альтернативной 👇🏻

mongod --port 27017 --dbpath "C:\data\db"

Сохрани в удобное место команду, которая запускает MongoDB в твоей системе. Её нужно будет вводить всякий раз, начиная работу с локальным сервером MongoDB.

При запуске сервера MongoDB локально он по умолчанию будет доступен по адресу `localhost` на порту `27017`. Теперь попробуй ещё раз нажать кнопку `Connect`, и перед тобой откроется интерфейс для работы с MongoDВ по тому самому адресу 👇🏻

![](https://pictures.s3.yandex.net:443/resources/5_2_1713455877.jpg)

Обзор возможностей Compass

В левом боковом меню представлено несколько вкладок:

- **My Queries** — для хранения избранных запросов и операций. - **Performance** — для отслеживания работы MongoDB, скорости проведения операций, загрузке сети и памяти. - **Databases** — со списком всех баз данных, доступных на локальном сервере.

Первые две вкладки нам пока не понадобятся, но ты можешь пользоваться ими самостоятельно, чтобы ближе познакомиться с Compass и всеми его возможностями. А пока перейди на вкладку **Databases**, где будут отображены уже существующие БД.

Создание базы данных

Создай ещё одну, нажав зелёную кнопку `Create Database` 👇🏻

![](https://pictures.s3.yandex.net:443/resources/6_1_1713455898.jpg)

В появившемся окне введи название новой базы данных для твоего приложения — `pindie`

Также введи название твоей первой коллекции, начнём с простого — с коллекции `users` 👇🏻

![](https://pictures.s3.yandex.net:443/resources/7_1_1713455916.jpg)

Перед нами откроется интерфейс для работы с созданной базой данных и коллекцией `users` внутри неё.

Работа с коллекциями и документами

В уроке «Что такое базы данных?» мы говорили о том, что в нереляционных БД вместо таблиц используются коллекции, а вместо записей — документы. Создай свой первый документ — пользователя с нужными характеристиками. Для этого нажми кнопку `Add data`, а в выпадающем списке `Insert document` 👇🏻

![](https://pictures.s3.yandex.net:443/resources/8_1_1713455934.jpg)

В появившемся окне удобно работать с документом, добавляя нужные поля и данные. Приветственный комментарий сообщает о том, что ты можешь создать сразу несколько документов, но пока ограничимся работой с одним. Нажми на переключатель с надписью `View`, выбрав иконку с тремя полосками 👇🏻

![](https://pictures.s3.yandex.net:443/resources/9_1_1713455953.jpg)

В таком режиме отображения у документа не будет лишних скобок, а все характеристики будут представлены в виде обычных строк в формате «**ключ — значение»**.

{quiz-task} background: | #f1f1ef content: | ❗ По умолчанию в любом созданном документе есть характеристика `_id`, которая состоит из набора букв и чисел, образуя уникальный номер этого документа. Работая над созданием коллекций и документов, важно не переписывать идентификаторы из видео или картинок, так как во всех базах идентификаторы будут отличаться. {/quiz-task}

Добавь новые характеристики для пользователя, указывая их названия в виде ключа, а также сами значения, как на видео 👇🏻

{video:https://code.s3.yandex.net/kids-web/vids/M4/2024-04-02_01-07-20.mp4|controls:true|autoplay:0|pip:false|controlsList:nodownload}

Ура! В коллекции `users` появился первый документ.

Compass открывает много возможностей для работы не только с базами данных, но и с коллекциями и документами внутри неё. Если ты наведёшь курсор мыши на документ, то справа увидишь кнопки, позволяющие его отредактировать, скопировать, продублировать или удалить.

Создание коллекции категорий

Одной коллекции будет маловато. Так как мы реализуем серверное приложения для Pindie, тебе потребуется также хранить названия категорий и данные самих игр. Для начала создай новую коллекцию и назови её `categories` 👇🏻

{video:https://code.s3.yandex.net/kids-web/vids/M4/2024-04-02_01-36-13.mp4|controls:true|autoplay:0|pip:false|controlsList:nodownload}

Внутри этой коллекции добавь первый документ для категории популярных игр. Сам документ кроме стандартной характеристики `_id` будет обладать всего одной — `name` 👇🏻

![](https://pictures.s3.yandex.net:443/resources/10_1_1713455982.jpg)

Попробуй самостоятельно создать документы для остальных категорий: `new`, `TDS`, `shooter`, `pixel`, `popular` и `runner`. После добавления коллекция будет выглядеть так 👇🏻

![](https://pictures.s3.yandex.net:443/resources/11_1_1713456018.jpg)

Не стоит переживать, если идентификаторы в поле `_id` отличаются от тех, что находятся на изображении выше. Они уникальны для каждой базы данных и коллекции.

Создание коллекции игр

Первым документом этой коллекции будет игра **G.U.N.N.E.R**. Сам документ должен обладать следующими характеристиками и значениями:

- `title` — заголовок со значением `G.U.N.N.E.R` - `description` — описание игры со значением `Продержись как можно дольше, отбиваясь от врагов, которых будет становиться всё больше` - `developer` — автор игры со значением `IDKWIAm` - `image` — баннер игры со значением `https://code.s3.yandex.net/teens/pindie-games/gunner/cover.png` - `link` — ссылка на игру со значением `https://code.s3.yandex.net/teens/pindie-games/gunner/game/index.html`

Добавь все характеристики самостоятельно, а после можешь проверить себя 👇🏻
