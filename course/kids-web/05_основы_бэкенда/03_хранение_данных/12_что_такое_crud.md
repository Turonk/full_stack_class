# Что такое CRUD

![](https://pictures.s3.yandex.net:443/resources/CRUD_1714036610.jpg)

В конце этой недели приложение, которое ты разрабатываешь, будет уметь выполнять четыре главных действия с документами в MongoDB:

- Create — создавать
- Read — читать
- Update — обновлять
- Delete — удалять

Все эти четыре действия обозначаются единым сокращением CRUD — по первым буквам английских названий.

В этом уроке мы бегло покажем каждое из действий на примере эндпоинта `/games` в приложении, которое тебе предстоит создать, а уже в следующих уроках разберёшь их основательно с нашими супергероями. Для демонстрации будем использовать уже знакомые Postman и Compass. Запустим Node.js-приложение, принимающее запросы от Postman и выполняющее соответствующие действия, результат которых увидим благодаря Compass.

## Создание документа. Create

Давай скриэйтим документ с данными об одной игре. 

Чтобы это сделать, сначала необходимо создать в базе данных файл о категории, к которой будет относиться будущая игра. Данные категории в соответствии с моделью в файле `models/category.js` запиши вот так 👇🏻

```javascript
{
    "name": "shooter"
}
```

{video:https://code.s3.yandex.net/kids-web/vids/M4/M4T3/1.mp4|controls:true|autoplay:0|pip:false|controlsList:nodownload}

На видео сначала запускается приложение и подключается к Compass, а затем с использованием Postman отправляется `POST`-запрос, в теле которого необходимо указать имя новой категории. Обрати внимание на строку `661409e16f295459a0872d85` — это идентификатор категории, он понадобится тебе при добавлении данных об игре. 

Теперь создай документ для новой игры. Её данные в соответствии с моделью из `models/game.js` 👇🏻

```javascript
{
  "title": "G.U.N.N.E.R.",
  "image": "https://code.s3.yandex.net/teens/pindie-games/gunner/cover.png",
  "link": "https://code.s3.yandex.net/teens/pindie-games/gunner/game/index.html",
  "description": "Продержись как можно дольше, отбиваясь от врагов, которых будет становиться всё больше.",
  "developer": "CoolDeveloper",
  "categories": "661409e16f295459a0872d85"
}
```

Пока в игре используется только одна категория, её можно указать строкой: при добавлении новой игры в БД это не вызовет ошибок, так как Mongoose автоматически адаптирует данные под схему документа. Для передачи нескольких категорий уже необходимо использовать соответствующий для них массив. В качестве значения для поля `categories` используй идентификатор категории, которую мы только что добавили 👇🏻

## Чтение документов. Read

Следующим шагом попробуй выполнить самую простую операцию — чтение списка игр из базы данных. Она выполняется с помощью запроса методом `GET`. Для проверки лови скринкаст 👇🏻

## Обновление документа. Update

Теперь обнови данные об игре, которую мы только что добавили, и измени значение поля `developer` с `CoolDeveloper` на `BestDeveloper`. Обновление выполняется `PUT`-запросом по адресу `http://localhost:3000/games/66140ce96f295459a0872d88`. Обрати внимание, что идентификатор документа игры взят из БД.
