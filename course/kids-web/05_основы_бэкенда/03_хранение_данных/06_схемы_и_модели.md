Предлагаем рассмотреть пример данных об игре 👇🏻

```json
{
  "title": "G.U.N.N.E.R.",
  "image": "https://code.s3.yandex.net/teens/pindie-games/gunner/cover.png",
  "link": "https://code.s3.yandex.net/teens/pindie-games/gunner/game/index.html",
  "description": "Продержись как можно дольше, отбиваясь от врагов, которых будет становиться всё больше.",
  "developer": "CoolDeveloper"
}
```

Это объект с полями `title`, `image`, `link`, `description`, `developer`, каждому из которых соответствует конкретное значение. Подобных объектов в базе данных может быть сколь угодно, но все они соответствуют единой схеме 👇🏻

```json
{
  "title": String,
  "image": String,
  "link": String,
  "description": String,
  "developer": String
}
```

Но задача схемы состоит не только в том, чтобы наглядно описывать типы значений для каждого из полей документа. **Основное назначение** заключается в наложении ограничений при записи нового файла в БД. Например, попробуй записать в базу данные об игре, где в поле `description` вместо строкового значения будет число 👇🏻

```json
{
  "title": "G.U.N.N.E.R.",
  "image": "https://code.s3.yandex.net/teens/pindie-games/gunner/cover.png",
  "link": "https://code.s3.yandex.net/teens/pindie-games/gunner/game/index.html",
  "description": 12345,
  "developer": "CoolDeveloper"
}
```

Операция не будет выполнена, и мы получим ошибку. Это связано с тем, что объект выше не соответствует схеме: значение в `description` имеет неподходящий тип.

## Создаём схемы с помощью Mongoose

В библиотеке Mongoose для создания схем используется конструктор `Shema`. Лови пример одной из них, иллюстрирующий, какие типы можно использовать для полей 👇🏻

```javascript
const mongoose = require('mongoose');

const internalSchema = new mongoose.Schema({
  deepStringField: String, // Поле со строковым значением
  deepNumberField: Number, // Поле с числовым значением
  deepBooleanField: Boolean, // Поле со значением true или false
})

const exampleSchema = new mongoose.Schema({
  stringField: String, // Поле со строковым значением
  anotherStringField: {type: String} // Тоже поле со строковым значением, просто в другой записи
  numberField: Number, // Поле с числовым значением
  booleanField: Boolean, // Поле со значением true или false
  arrayOfStrings: [String], // Поле, где значение — это массив строк
  arrayOfNumbers: [Number], // Поле, где значение — это массив чисел
  arrayOfBooleans: [Boolean], // Поле, где значение — это массив c true или false
  withDefaultValue: { type: String, default: 'aski' }, // Поле со строковым значением, где по умолчанию будет использоваться значение 'aski'
  withRestrictions: { // Поле со строковым значением и дополнительными ограничениями
    type: String,
    minlength: 2, // Минимальная длина строки — 2 символа,
    maxlength: 30, // а максимальная — 30 символов
  },
  withEnum: { // Строковое поле, которое может принимать одно из значений, указанных в enum
    type: String,
    enum: ['Один', 'Два', 'Три']
  },
  objectField: internalSchema // Поле, где значением является другой объект с полями
})
```

Но и это ещё не всё. Чтобы использовать схему по её основному назначению, необходимо создать модель. **Модель** — это результат вызова функции `mongoose.model`. Благодаря ей осуществляется чтение, запись и удаление данных из базы. Создать модель можно следующим образом 👇🏻

```javascript
const exampleModel = mongoose.model('example', exampleSchema)
```

Первым аргументом в `mongoose.model` передай строку — название модели, а вторым — нашу схему. Когда, используя её, ты будешь записывать данные в базу, тип каждого поля будет проверяться на соответствие типу, указанному для этого поля в схеме.

Сначала нужно понять, что именно должно содержаться в БД: в нашем случае мы хотим хранить данные об играх, категориях, к которым эти игры относятся, и данные о пользователях. Соответственно тебе нужно создать три модели и схемы для каждой из них так, чтобы они были связаны между собой. Сейчас вместе разберёмся, как их скриэйтить, а в следующих уроках — как реализовать эту связь в коде.

![](https://pictures.s3.yandex.net:443/resources/scheme_1713537018.jpg)

Итак, создай в проекте папку `models`, а в ней — три файла cо следующим содержимым:

- В файле `game.js` 👇🏻

    ```jsx
    const mongoose = require('mongoose');

    const gameSchema = new mongoose.Schema({
      title: {
          // Поле со строковым значением
        type: String,
        // Явно указываем, что поле обязательно при записи в базу нового документа
        required: true,
      },
      description: {
        type: String,
        required: true,
      },
      developer: {
        type: String,
        required: true
      },
      image: {
        type: String,
        required: true
      },
      link: {
        type: String,
        required: true
      }
    });

    module.exports = mongoose.model('game', gameSchema);
    ```

- В файле `category.js` 👇🏻

    ```jsx
    const mongoose = require('mongoose');

    const categorySchema = new mongoose.Schema({
      name: {
        type: String,
        required: true,
      },
    });

    module.exports = mongoose.model('category', categorySchema);
    ```

- В файле `user.js` 👇🏻

    ```jsx
    const mongoose = require('mongoose');

    const userSchema = new mongoose.Schema({
      username: {
        type: String,
        required: true,
      },
      email: {
        type: String,
        required: true,
      },
      password: {
        type: String,
        required: true
      },
    });

    module.exports = mongoose.model('user', userSchema);
    ```
