Часть 2. C — Create

Убедись, что настроена функция **Create** — метод для добавления новых данных в базу.

1. Создана асинхронная функция `createGame` в файле `/middlewares/games.js` 👇🏻 Она принимает три аргумента: объект запроса `req`, объект ответа `res`, а также метод `next()` для запуска следующего по списку миддлвара. В теле запроса `req.body` будут переданы данные игры, которые пользователь заполнял через форму. Нужно обратиться к модели `games` и вызвать метод `create`, передав аргументом `req.body` (перед вызовом `create` должно быть ключевое слово `await`). Результат запроса записывается в `req.game` Не забудь про обработку ошибок: метод `create` возвращает промис, значит, код следует обернуть в конструкцию `try … catch` или обработчики `then`/`catch`. В случае ошибки устанавливается статус `400` и отправляется сообщение `Ошибка создания игры`

const createGame = async (req, res, next) => {
  console.log("POST /games");
  try {
    console.log(req.body);
    req.game = await games.create(req.body);
    next();
  } catch (error) {
    res.status(400).send("Error creating game");
  }
};

Убедись, что настроена функция **Update** — методы для обновления уже имеющихся в базе данных записей.

1. Обновлён миддлвар `findGameById` в файле `/middlewares/games.js` 👇🏻 Теперь вместо метода `.find({})` нужно использовать `.findById()`, а аргументом передавать значение `id` из `req.params.id`. Не забудь обернуть это всё в `try/catch`. В блоке `try` обратись к БД: у модели `games` методами `findById` найди запись и воспользуйся методами `populate` для загрузки данных о категориях и пользователях, связанных с искомой игрой.

// Файл middlewares/games.js

const findGameById = async (req, res, next) => {
  try {
	  // Пробуем найти игру по id
    req.game = await games
      .findById(req.params.id) // Поиск записи по id
      .populate("categories") // Загрузка связанных записей о категориях
      .populate("users"); // Загрузка связанных записей о пользователях
    next(); // Передаём управление в следующую функцию
  } catch (error) {
    // На случай ошибки вернём статус-код 404 с сообщением, что игра не найдена
    res.status(404).send({ message: "Игра не найдена" });
  }
};

2. Создан миддлвар `updateGame` в файле `middlewares/games.js` 👇🏻 Это должна быть асинхронная функция, обёрнутая в блок `try/catch`. Для этого воспользуйся методом `findByIdAndUpdate`, который принимает два параметра: `id` (получи его из `req.params.id`) и объект со свойствами, которые нужно обновить.

// Файл middlewares/games.js

const updateGame = async (req, res, next) => {
  try {
	  // В метод передаём id из параметров запроса и объект с новыми свойствами
    req.game = await games.findByIdAndUpdate(req.params.id, req.body);
    next();
  } catch (error) {
    res.status(400).send({ message: "Ошибка обновления игры" });
  }
};

    return req.body.name === category.name;
  });
  if (isInArray) {
    res.setHeader("Content-Type", "application/json");
		res.status(400).send(JSON.stringify({ message: "Категория с таким названием уже существует" }));
  } else {
    next();
  }
};

const checkIfCategoriesAvaliable = async (req, res, next) => {
  if (!req.body.categories || req.body.categories.length === 0) {
    res.setHeader("Content-Type", "application/json");
		res.status(400).send(JSON.stringify({ message: "Выберите хотя бы одну категорию" }));
  } else {
    next();
  }
};
