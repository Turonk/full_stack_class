Чтение всех документов в коллекции

![](https://pictures.s3.yandex.net:443/resources/Worn-Ass-Semi-Gloss_6_1713537160.jpg)

При дальнейшей работе с Mongoose в библиотеке будет храниться множество документов, у каждого из которых строго заданная форма. Для описания информации о том, что будет находиться в БД, используется схема с описанными полями и значениями. Согласно ей создаются целые документы, описывающие данные для приложения.

Сейчас в твоём проекте существует всего три сущности:

- Игра — `game` - Пользователь — `user` - Категория — `category`

Для их обработки и быстрого поиска каких-либо данных в БД тебе потребуется специальный метод.

Метод `find()`

В Mongoose метод модели `find()` является основным инструментом для запросов к базе данных. Первый параметр `find()` — объект фильтра. Благодаря ему MongoDB выполнит поиск всех документов, соответствующих фильтру, а если передать пустой фильтр `find({})` — вернёт все документы обратно.

Поиск данных в проекте

Кстати, об играх! В проекте по `GET`-запросам можно и нужно выводить соответствующие данные:

- `GET /categories` — массив категорий. - `GET /users` — массив пользователей.

Для этого достаточно создать отдельные миддлвары, каждый из которых будет содержать функции по работе с БД.

Итак, в папке `middlewares` скриэйть файл `categories.js`, импортируй в него модель `categories` и запиши функцию для поиска всех категорий. Важно помнить, что подобные операции требуют времени на обработку, так как это асинхронные функции. Для них воспользуйся ключевыми словами `async/await` 👇🏻

// Файл middlewares/categories.js

// Импортируем модель
const categories = require('../models/category');

const findAllCategories = async (req, res, next) => {
	// По GET-запросу на эндпоинт /categories найдём все документы категорий
  req.categoriesArray = await categories.find({});
  next();
}

// Экспортируем функцию поиска всех категорий
module.exports = findAllCategories;

Для поиска пользователей алгоритм аналогичный 👇🏻

// Файл middlewares/users.js

// Импортируем модель
const users = require('../models/user');

const findAllUsers = async (req, res, next) => {
	// По GET-запросу на эндпоинт /users найдём все документы пользователей
  req.usersArray = await users.find({});
  next();
}

// Экспортируем функцию поиска всех пользователей
module.exports = findAllUsers;

Поиск всех игр в проекте происходит так же, но есть один нюанс, поскольку в их схеме сразу два поля: `users` и `categories`. Это две отдельные коллекции, с которыми мы сейчас взаимодействовали. Они не знают друг о друге и существуют независимо. А вот третья коллекция проекта — `games` — имеет взаимосвязи и с играми, и с пользователями.

Актуальное состояние проекта

Сегодня тебе необходимо добавить миддлвары для поиска пользователей и категорий в проекте, а ещё описать контроллеры и использовать их в роутах для `GET`-запросов. Приступим!

Шаг 1

Создай миддлвары, как описано в уроке, — должно получиться два файла — `users.js` и `categories.js`

Для проверки можешь подсмотреть код выше.

Шаг 2

Теперь добавь в папку `controllers` два файла с этими же названиями и следуй нашей инструкции:

- В `categories.js` опиши ответ сервера на запрос всех категорий в проекте 👇🏻

    const sendAllCategories = (req, res) => {
    	// Установим заголовок ответа в формате JSON
      res.setHeader('Content-Type', 'application/json');
      // Отправим данные в виде JSON-объекта, 
      // которые подготовим в миддлваре findAllCategories
      res.end(JSON.stringify(req.categoriesArray));
    };
    
    // Экспортируем контроллер
    module.exports = sendAllCategories;

- В `users.js` опиши функцию для отправки всех пользователей — `sendAllUsers`, как в примере выше для `categories.js`

Шаг 3

В папке `routes` создай два файла с теми же названиями: `users.js` и `categories.js`

- В `categories.js` опиши роут для обработки `GET`-запроса по эндпоинту `'/categories'`. Ответ нужно сформировать с помощью миддлвара для поиска всех категорий `findAllCategories` и отправить данные контроллером `sendAllCategories` 👇🏻

    // Создаём роут для запросов категорий 
    const categoriesRouter = require('express').Router();
    
    // Импортируем вспомогательные функции
    const findAllCategories = require('../middlewares/categories');
    const sendAllCategories = require('../controllers/categories');
    
    // Обрабатываем GET-запрос с роутом '/categories'
    categoriesRouter.get('/categories', findAllCategories, sendAllCategories);
    
    // Экспортируем роут для использования в приложении — app.js
    module.exports = categoriesRouter;

- В `users.js` опиши роут для обработки `GET`-запроса по эндпоинту `'/users'`. Ответ нужно сформировать с помощью миддлвара для поиска всех пользователей `findAllUsers` и отправить данные контроллером `sendAllUsers`
