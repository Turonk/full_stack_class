Тренажёрка

Лови шпаргалку с тем, что понадобится для успешного прохождения сегодняшних тренажёров 👇🏻

- Для подключения роутера используй команду `app.use()` в `app.js`. Первым аргументом передай путь, по которому он должен быть подключён, а вторым — сам роутер. Например, если хочешь, чтобы запросы `“/”` отрабатывал `mainRouter`, то нужно написать команду `app.use(”/”, mainRouter)` - Чтобы написать обработчик `GET`-запросов в роутере, используй команду `router.get()`. Первый аргумент — путь, по которому будут приходить запросы, а второй — функция-колбэк, обрабатывающая запрос. Она работает с объектами `req` (объект запроса) и `res` (объект ответа), которые тебе уже знакомы. - Чтобы найти данные в БД, используй метод модели `find()`. Для получения данных обо всех документах нужно передавать аргумент `{}`. Например, если ты хочешь получить данные обо всех играх, пользуясь моделью `Game`, тебе нужно сделать следующий запрос: `Game.find({})` - Для написания обработчика `POST`-запросов используй команду `router.post()`. Как и в `router.get()`, первый аргумент — путь, второй — функция-колбэк для обработки запросов. - Чтобы добавить новые данные в базу, используй метод модели `create()`, аргументом которого будет объект с ними же. Например, если хочешь через модель `Game` отправить новую игру, выведи запрос `Game.create({name: "Название игры", link: "Ссылка на игру"})`
