# Первый шаг к проекту

Да! Начинать советуем с чего-то простого, например с создания своего сервера.

Лови требования 👇🏻

{quiz-task}
    background: |
        #f5f6f7
    content: |
        По итогу у тебя должен получиться сервер, который при запуске выдаёт по любому запросу `h1` c заголовком «Скоро тут будет сервис рейтинга».
{/quiz-task}

Чтобы справиться с задачей, проверь, все ли пункты выполнены:

- Создай файл `index.js`
- Подключи модуль `http` и импортируй его в код файла `index.js` командой `require`
- Создай сервер. Для этого объяви переменную `server` и присвой ей результат вызова метода `createServer` модуля `http`
- В метод `createServer` передай функцию-колбэк с двумя аргументами — объектом запроса `req` и ответа `res`
- В теле функции-колбэка у объекта ответа `res` вызови метод `writeHead` и передай статус ответа `200` и подходящий для HTML заголовок в значение `Content-Type`
- Чтобы завершить ответ в теле функции-колбэка, вызови на объекте ответа `res` метод `end` с двумя аргументами:

    1. Первый аргумент — **строка** с тегом `<h1>`, в котором лежит текст `Скоро тут будет сервис рейтинга`

    2. Второй аргумент — **строка** с кодировкой для `html` элементов `utf-8`

- В конце файла `index.js` после описания метода `createServer` у переменной `server` вызови метод `listen` и передай аргументом номер порта — `3000`
