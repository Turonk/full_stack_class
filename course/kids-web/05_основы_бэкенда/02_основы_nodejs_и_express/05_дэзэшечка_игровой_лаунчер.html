Шаг 1. Импорт модулей

Сначала импортируй модули необходимые для работы лаунчера. Среди них есть уже подготовленные модули `dictionary` и `games` 👇🏻

const dictionary = require("../dictionary");
const games = require("../games");

Затем подключи встроенный модуль `readline` и сразу настрой его работу, передав объект с опциями в метод `createInterface`. Стандарт CommonJS достаточно продвинутый и мощный, поэтому позволяет работать с модулями сразу после их подключения. Смотри 👇🏻

const readline = require("readline").createInterface({
  input: process.stdin,
  output: process.stdout,
  terminal: false,
  prompt: "",
});

Настраивая интерфейс `readline`, используй базовые опции, которые подробно описаны в уроке «Глобальные переменные и встроенные модули».

Шаг 2. Работа с массивом игр

При импорте модуля `games` мы не используем деструктуризацию, а просто собираем все игры в объект `games`. В будущем пользователь будет вводить номер игры, а лаунчер — её запускать. Чтобы лаунчер понимал, какое число соответствует нужной игре, создай массив `gamesArray`, в котором для каждой игры необходимо задать объект с двумя полями: `id` и `game`. Теперь каждая игра будет связана с нужным числом (её идентификатором) 👇🏻

const gamesArray = [
  { id: "1", game: games.knightDragonAndPrincessGame },
  { id: "2", game: games.poleChudesGame },
  { id: "3", game: games.makeWordGame },
  { id: "4", game: games.blackJackGame },
  { id: "5", game: games.trueOrFalseGame },
  { id: "6", game: games.dropCoin },
];

Шаг 3. Настройка запуска игр

Для запуска нужной игры создай асинхронную функцию `startGame`, которая будет принимать идентификатор игры в качестве параметра `gameId` 👇🏻

async function startGame(gameId) {}

Прежде всего функция должна проверить число из параметра `gameId`, которое ввёл пользователь, и найти соответствующую игру в массиве `gamesArray`. Для этого создай переменную `selectedGame`, в которой будет храниться выбранная игра. Для поиска используй метод `find`, сравнивая поле `id` у каждой игры в массиве `gamesArray` с параметром `gameId` 👇🏻

async function startGame(gameId) {
  const selectedGame = gamesArray.find((game) => game.id === gameId);
}

Не забывай и про обработку ошибок. После поиска необходимо проверить переменную `selectedGame` на наличие внутри неё игры. Если метод `find` ничего не найдёт, в переменной будет храниться значение `false`

Для проверки используй конструкцию `if…else`. В случае, если игра найдена методом `find`, её необходимо запустить. Важно понимать, что каждая игра — это просто функция, которая возвращает результат при своём завершении. Чтобы сообщить пользователю о его результатах, создай переменную `result` и затем запусти игру, обратившись к `selectedGame` и вызвав функцию `game` 👇🏻

async function startGame(gameId) {
  const selectedGame = gamesArray.find((game) => game.id === gameId);
	if (selectedGame) {
		const result = await selectedGame.game();
	}
}

Так как функция `startGame` асинхронная, а процесс игры может занять определённое время, используй ключевое слово `await`. Благодаря `await` функция `startGame` дождётся полного завершения игры и только после этого будет запускать другие функции.

Через массив `gamesArray` каждой игре присваивается функция для её запуска, хранящаяся в поле `game` объекта данной игры. Другими словами, при вызове функции `game` ты на самом деле запускаешь выбранную игру.

Шаг 4. Функция подсчёта результатов

После завершения игры нужно вывести её результат, иначе пользователь не поймёт, выиграл он или проиграл. Создай функцию `countResult`, принимающую параметр `gameResult` — результат завершённой игры 👇🏻

function countResult(gameResult) {}

Используй конструкцию `if…else`, где будешь проверять параметр `gameResult`, который может содержать одно из трёх значений:

- Булевое значение `true`, если пользователь победил - Булевое значение `false`, если пользователь проиграл - Строковое значение `"draw"`, если в игре победила дружба (ничья)

Первым шагом проверь `gameResult` на наличие значения `"draw"`. Если в игре ничья, выведи в консоль сообщение из словаря с ключом `dictionary.global.draw` 👇🏻

function countResult(gameResult) {
	if (gameResult === "draw") {
		console.log(dictionary.global.draw);
	}
}

Ниже, в блоке `else`, используй тернарный оператор, чтобы сократить код и сделать его чище. Он также будет проверять переменную `gameResult`, но уже на оставшиеся два значения: `true` или `false`. Если `gameResult` содержит `true`, выведи в консоль сообщение о выигрыше. Найти его можно в словаре по ключу `dictionary.global.win`. Иначе, если `gameResult` содержит `false`, выведи сообщение о проигрыше, которое также находится в словаре с ключом `dictionary.global.lose` 👇🏻

function countResult(gameResult) {
	if (gameResult === "draw") {
		console.log(dictionary.global.draw);
	} else {
		console.log(gameResult ? dictionary.global.win : dictionary.global.lose);
	}
}

Вернёмся к функции `startGame` и усовершенствуем её. Для этого после завершения игры вызови функцию подсчёта результатов. Здесь нам и пригодится переменная `result`, в которой хранится результат завершённой игры. Передай эту переменную в качестве параметра функции `countResult` 👇🏻

async function startGame(gameId) {
  const selectedGame = gamesArray.find((game) => game.id === gameId);
	if (selectedGame) {
		const result = await selectedGame.game();
		countResult(result);
	}
}

Шаг 5. Запуск и остановка лаунчера

Следующим шагом создай функции для запуска и прекращения работы самого лаунчера. Рекомендуем начать с первой и назвать её `startLauncher`. Эта функция будет использовать модуль `readline` для взаимодействия с пользователем и вывода меню с доступными играми 👇🏻

function startLauncher() {
	readline.question(dictionary.global.chooseGame);
}

Переменная `chooseGame` в объекте `global` из словарика содержит список всех игр, доступных для запуска. После вывода сообщения пользователь вводит идентификатор желаемой игры, и лаунчер должен запустить эту игру. Здесь пригодится ранее созданная функция `startGame`

Для обработки ответа пользователя передай вторым аргументом стрелочную функцию с параметром `answer`, который будет содержать в себе ответ пользователя — число, соответствующее определённой игре. Внутри этой функции нужно вызвать `startGame`, передавая в неё параметр `answer` 👇🏻

function startLauncher() {
	readline.question(dictionary.global.chooseGame, (answer) => {
		startGame(answer);
	});
}

Теперь создай функцию для остановки лаунчера. Функция `stopLauncher` будет выводить прощальное сообщение пользователю, которое можно найти в словаре по ключу `dictionary.global.goodbye`. Для полной остановки приложения достаточно обратиться к `readline` и вызвать метод `close`. Он прекратит принимать от пользователя сообщения через консоль VS Code, а так как приложению после этого ничего не нужно делать, оно просто завершит свою работу 👇🏻

function stopLauncher() {
  console.log(dictionary.global.goodbye);
  readline.close();
}

Модифицируй функцию `startLauncher` для обработки ещё одного сценария. Дело в том, что при выводе сообщения из переменной `chooseGame` пользователь может не только выбрать желаемую игру, но и прекратить работу лаунчера, если введёт цифру `7`. Чтобы код работал исправно, добавь проверку ответа пользователя конструкцией `if…else`. Сразу проверь переменную `answer` на соответствие цифре `7` в строковом формате. Если это так, вызови функцию `stopLauncher`, иначе будет запускаться игра 👇🏻

function startLauncher() {
	readline.question(dictionary.global.chooseGame, (answer) => {
    if (answer === "7") {
      stopLauncher();
    } else {
      startGame(answer);
    }
	});
}

Шаг 6. Выбор действия после игры

Половина пройдена! Лаунчер готов к запуску, предлагая пользователям игры, запуская их, а также отображая результат при завершении. Осталось реализовать функцию, которая будет срабатывать после того, как пользователь доиграет в любую из игр. Она должна спрашивать пользователя, что делать дальше и совершать нужное действие в зависимости от ответа.

Создай функцию `afterGame`, которая будет принимать параметр `gameToRepeatId` — идентификатор игры, которую только что завершил пользователь 👇🏻

function afterGame(gameToRepeatId) {}

Для начала воспользуйся модулем `readline` и выведи сообщение, содержащее варианты продолжения. Оно находится в словаре с ключом `dictionary.global.playAgain` 👇🏻

function afterGame(gameToRepeatId) {
	readline.question(dictionary.global.playAgain);
}

Обработай каждый из ответов с помощью конструкции `if…else`. При вводе пользователем числа «1» необходимо перезапустить игру, в которую он только что играл. При вводе числа «2» — отобразить начальное меню со всеми играми, чтобы можно было выбрать любую другую. При вводе числа «3» полностью заверши работу лаунчера 👇🏻

function afterGame(gameToRepeatId) {
	readline.question(dictionary.global.playAgain, (answer) => {
		if (answer === "1") {
			startGame(gameToRepeatId);
    }
    if (answer === "2") {
      startLauncher();
    }
    if (answer === "3") {
      stopLauncher();
    }
	});
}

Метод `question` модуля `readline` вновь принимает вторым аргументом стрелочную функцию, внутри которой ты проводишь нужные проверки. Перезапуская игру в первом случае, ты передаёшь в функцию `startGame` параметр `gameToRepeatId`, чтобы функция понимала, какую игру ей нужно перезапустить. Во втором случае просто вызываешь функцию `startLauncher` для отображения меню со списком игр. В третьем, финальном, варианте прекращаешь работу приложения, вызывая функцию `stopLauncher`

Шаг 7. Улучшение запуска игр

Вернёмся к функции `startGame`, чтобы модифицировать её. После завершения игры и подсчёта результатов необходимо вызвать функцию `afterGame`, которая будет спрашивать пользователя, что делать дальше. Для этого вызови функцию `afterGame` после функции подсчёта результата, передавая параметром переменную `gameId` 👇🏻

async function startGame(gameId) {
  const selectedGame = gamesArray.find((game) => game.id === gameId);
	if (selectedGame) {
		const result = await selectedGame.game();
		countResult(result);
		afterGame(gameId);
	}
}

Теперь обработаем ошибки ввода пользователя. Добавь блок `else`, в котором будем выводить сообщение о некорректном вводе и вызывать функцию `stopLauncher`. Сообщение доступно по ключу `dictionary.global.wrongInput` 👇🏻

async function startGame(gameId) {
  const selectedGame = gamesArray.find((game) => game.id === gameId);
	if (selectedGame) {
		const result = await selectedGame.game();
		countResult(result);
		afterGame(gameId);
	} else {
    console.log(dictionary.global.wrongInput);
    startLauncher();
	}
}

Эта часть кода будет срабатывать в том случае, если пользователь введёт число, не соответствующее ни одной игре или сценарию завершения работы лаунчера.

Финальные штрихи

Осталось импортировать функцию запуска лаунчера в основной исполняемый файл `index.js`. Для этого сначала экспортируй функцию `startLauncher`, используя `module` и `exports` в конце файла `/AppModules/launcher/index.js` 👇🏻

module.exports = { run: startLauncher };

При экспорте мы хотим сделать функцию `startLauncher` доступной для использования в других частях приложения. Мы присваиваем её свойству `run` объекта, который экспортируем. Таким образом, когда мы импортируем этот модуль в другом месте программы, мы сможем вызвать функцию `startLauncher`, обращаясь к свойству `run`

Перейди в файл `index.js` в корневой папке проекта и импортируй игровой лаунчер 👇🏻

const launcher = require('./AppModules/launcher');

В этом файле уже есть некоторые импорты и настройки. После команды `console.log` с выводом сообщения `hello` вызови функцию `run`, обращаясь к объекту `launcher` 👇🏻

launcher.run();

Теперь ты можешь запустить приложение и поиграть самостоятельно. Для этого введи команду `node index.js` в терминале VS Code.
