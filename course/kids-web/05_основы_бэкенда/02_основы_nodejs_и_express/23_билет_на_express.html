Билет на Express

Программирование сервера во многом сводится к решению типовых задач: настроить авторизацию или реализовать логирование запросов (запись в базу данных). Поскольку разработка — это дело творческое, программисты решают даже классические задачи по-разному.

К тому же разрабатывать сервер придётся намного дольше: все детали каждый раз нужно прописывать вручную.

В таких ситуациях помогают **фреймворки** — наборы стандартных решений. С ними ты можешь перейти из одного проекта в другой и сразу въехать в логику, заложенную в прогу. Кроме того, выстроить логику будет намного проще и быстрее — она уже расписана и реализована, а тебе нужно лишь правильно воспользоваться синтаксисом.

Но есть две крайности. Одна — писать весь код на чистой ноде. Вторая — бездумно обращаться к методам фреймворка, не понимая, как они устроены. Такой подход ещё называют **monkey coding** (с английского — «мартышкино программирование»). Лучше не впадать ни в одну из крайностей: разработчику следует пользоваться современными инструментами и понимать, как именно они работают и что за задачи решают.

Начнём с практики. В этом уроке развернём сервер с помощью Express.

Шаг 1. Устанавливаем экспресс

Экспресс — пакет ноды, поэтому его устанавливают из `npm` 👇🏻

# Инициализируй package.json, чтобы нода могла устанавливать зависимости
npm init -y # Флаг -y ответит «Да» на все вопросы по настройке package.json

# Установи экспресс
npm install express

Шаг 2. Настраиваем hot reload

Когда мы работали с проектами первых трёх модулей, сначала нам помогал Live Server, затем с Next.js использовали `dev`-режим сборки: запускали команду `npm run dev`. В этих случаях сайт автоматически обновлялся при сохранении любого файла — такое поведение называют **hot reload** (c английского — «горячая перезагрузка»).

В Next.js это делал сборщик проекта — отдельная библиотека. В проектах на Express мы не используем библиотеки-сборщики, поэтому hot reload будет выполнять специальный пакет `nodemon`

Так как перезагрузка нужна только для разработки, установи `nodemon` как `dev`-зависимость 👇🏻

# Флаг --save-dev установит nodemon как dev-зависимость
npm install nodemon --save-dev

Работа с `npm` — это набор большого количества команд и символов, которые каждый разработчик мечтал бы минимизировать.

Ты можешь встретить более короткие записи: например, команда `install` имеет короткую версию `i`, а флаг `--save-dev` аналогичную короткую версию `-D` 👇🏻

# Аналогичная короткая запись для установки nodemon как dev-зависимости
npm i nodemon -D

{quiz-task} background: | #f1f1ef content: | 📚 Про все команды и их сокращения можно почитать в официальной [документации](https://docs.npmjs.com/cli/v10/commands/npm-install){target="_blank"}. {/quiz-task}

Осталось, чтобы `nodemon` и программа запускались вместе. Открой `package.json` и отредактируй раздел `"scripts"` 👇🏻

{
	...
	"scripts": {
		"start": "nodemon index.js"
	},
	...
}

Шаг 3. Устанавливаем точку входа

Создай файл `index.js` и опиши в нём приложение. Для этого подключи `express`, а затем попробуй скриэйтить приложение этим же методом 👇🏻

const express = require('express');
const app = express();

Шаг 4. Проверяем, всё ли работает

Настрой порт, который должен слушать приложение. Для этого запиши его значение в одноимённую переменную 👇🏻

const express = require('express');
// Слушаем 3000 порт
const PORT = 3000;

const app = express();

app.listen(PORT, () => {
	// Если всё работает, консоль покажет, какой порт приложение слушает
	console.log(`App listening on port ${PORT}`)
})

Запусти приложение 👇🏻

node index.js
# В терминале окажется сообщение «App listening on Port 3000»

Перейди в браузере по адресу `http://localhost:3000`. Ты увидишь сообщение `Cannot GET /`. Это означает, что экспресс запущен и работает, просто пока ему нечего нам отдать.

В следующем уроке исправим это — разберёмся, как настраивать роутинг.

Время практики

Давай создадим на своём компьютере `express`-приложение.

Лови подробный пошаговый алгоритм 👇🏻

- Создай папку для проекта. Это будет сервис для карточек с играми, своего рода админка, где ты сможешь добавлять и редактировать доступный список игр для таких сайтов, как Pindie. Сейчас идёт третья неделя четвёртого модуля, так что можешь использовать варианты: `week3`, `adminka`, `admin-panel` - Открой терминал с папкой проекта и выполни первоначальную настройку 👇🏻

1. Инициализируй `package.json` командой: `npm init -y`

2. Из `npm` установи экспресс командой: `npm install express`

3. Установи пакет hot reload для перезагрузки проекта как `dev`-зависимость командой `npm install nodemon -D`

- Открой `package.json` и отредактируй раздел `"scripts"`, добавив команду `"start"` 👇🏻

    	...
    	"scripts": {
    		"start": "nodemon app.js"
    	},
    	...

- Добавь в папку проекта файл `app.js`. Чекай 👇🏻

{video:https://code.s3.yandex.net/kids-web/vids/M4/install-express.mp4|controls:true|autoplay:0|pip:false|controlsList:nodownload}

- В `app.js` импортируй `express` и создай приложение двумя строчками кода 👇🏻

    const express = require('express');
    const app = express();

- Создай переменную для порта, например `const PORT = 3000`, и вызови в своём приложении метод `listen` для прослушивания порта с сообщением для консоли 👇🏻

    app.listen(PORT, () => {
    	console.log(`App listening on port ${PORT}`)
    })

В качестве проверки запусти проект командой `npm run start` через терминал в папке проекта. Если все этапы инструкции выполнены верно, увидишь сообщение: `App listening on port 3000` — это хороший знак! Для проверки прикрепляем видео 👇🏻
