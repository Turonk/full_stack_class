Postman

Что правда, то правда — чтобы узнать о запросе (например, о заголовках), придётся лезть во вкладку **Network** в инструментах разработчика. Чтобы отправить `PATCH`-запрос, нужно и вовсе редактировать файл с кодом, сохранять и открывать в браузере.

![](https://pictures.s3.yandex.net:443/resources/IMG_4932_1711639917.jpg)

Инструмент для тестирования API

Чтобы отправлять запросы на сервер и получать ответы, есть специальные приложения. Мы расскажем об одном из самых популярных — **Postman.** Скачать и установить его можно по ссылке: [www.getpostman.com/downloads](https://www.getpostman.com/downloads/){target="_blank"}.

После установки заходи в прогу, перед тобой появится вот такой экран 👇🏻

![](https://pictures.s3.yandex.net:443/resources/Frame_1649_1711639941.png)

Теперь нажми на плюс в левом верхнем углу. Появится окно для создания запроса. В выпадающем списке слева от адресной строки можно указать тип запроса. Пока оставим `GET` 👇🏻

![](https://pictures.s3.yandex.net:443/resources/Frame_1650_1711639956.png)

В адресной строке нужно указать `URL`, куда мы хотим отправить запрос. Протестируем на уже знакомом `https://api-code-2.practicum-team.ru/games`

Смело вбивай адрес и нажимай **Send** 👇🏻

![](https://pictures.s3.yandex.net:443/resources/Frame_1651_1_1711639982.png)

Бэкенд проекта Pindie вернёт ответ. В нижней панели отобразятся статус ответа, его тело и заголовки. Проверяй 👇🏻

![](https://pictures.s3.yandex.net:443/resources/Frame_1652_1711640002.png)

Редактирование запроса

В Postman можно редактировать тело и заголовки запроса. Для примера попробуй создать такой запрос 👇🏻

POST https://jsonplaceholder.typicode.com/posts

Content-Type: application/json

{
  "title": "Привет, мир!",
  "userId": 42
}

Для этого сначала сделай `POST`-запрос с соответствующим `URL` и заголовками 👇🏻

![](https://pictures.s3.yandex.net:443/resources/Frame_1653_1711640051.png)

Перейдём к настройке тела запроса: зайди во вкладку **Body,** затем выбери радиокнопку `raw` и скопируй необходимый `JSON`-объект в текстовую область ниже 👇🏻

![](https://pictures.s3.yandex.net:443/resources/Frame_1654_1711640069.png)

Чтобы сохранить запрос, нажми **Save.** Это полезно, если ты собираешься неоднократно тестировать сервер этим запросом 👇🏻

![](https://pictures.s3.yandex.net:443/resources/Frame_1655_1711640087.png)

Проектное задание

Создай коллекцию для тестирования сервера из проекта этой недели и запиши туда три запроса:

- Основной к корню проекта `"/"` - К роуту `"/game"` - К роуту `"/vote"`

Коллекции в Postman позволяют сохранять и обмениваться запросами. Тестируя сервер, тебе не придётся вручную описывать запрос каждый раз, достаточно создать коллекцию и использовать её, то есть осуществить автоматизацию.

Показываем:

- В меню слева выбери **Collections** и нажми **+**, чтобы создать новую коллекцию 👇🏻

![](https://pictures.s3.yandex.net:443/resources/Frame_1656_1711640207.png)

- В выпадающем списке выбери пустую коллекцию — `Blank collection` 👇🏻

![](https://pictures.s3.yandex.net:443/resources/Frame_1658_1711640227.png)

- В поле, где написано `New Collection`, введи желаемое имя коллекции (например, `week2`) 👇🏻

![](https://pictures.s3.yandex.net:443/resources/Frame_1657_1711640267.png)

- Открой новую вкладку для создания запроса 👇🏻

![](https://pictures.s3.yandex.net:443/resources/Frame_1659_1711640290.png)

- Заполни адрес запроса. Локальный сервер будет запускаться на определённом порту. В качестве примера будем использовать порт `3005`, поэтому основной запрос к проекту будет по адресу `http://localhost:3005/`. Для этого введи адрес запроса и метод `GET`, затем нажми кнопку «Сохранить» — **Save** 👇🏻

![](https://pictures.s3.yandex.net:443/resources/Frame_1660_1711640314.png)

- Выбери коллекцию, куда сохранять запрос 👇🏻

![](https://pictures.s3.yandex.net:443/resources/Frame_1661_1711640339.png)

- Сохрани кликом по активной кнопке **Save** 👇🏻

![](https://pictures.s3.yandex.net:443/resources/Frame_1662_1711640372.png)

- В левом блоке с коллекцией появился первый сохранённый запрос! К нему можно получить доступ, выбрав его из коллекции 👇🏻

![](https://pictures.s3.yandex.net:443/resources/Frame_1663_1711640395.png)

- Аналогичным образом добавь запросы с роутом `/game` и `/vote` 👇🏻

![](https://pictures.s3.yandex.net:443/resources/Frame_1664_1711640418.png)
