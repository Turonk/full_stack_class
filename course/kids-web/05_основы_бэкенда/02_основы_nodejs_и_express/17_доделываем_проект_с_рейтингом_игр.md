## Выдача случайной игры

Давай вспомним, как происходит отображение игры в интерфейсе. Сейчас, когда пользователь заходит на главную страницу через `localhost:3005`, он видит информацию только об одной игре, выбранной из списка, самой первой: так настроен `gameRouteController`, обрабатывающий запросы по маршруту `/game` 👇🏻

```javascript
const game = data[0];
...
res.end(JSON.stringify(game));
```

Данный подход ограничивает пользователей: они не могут увидеть и оценить другие игры. Давай это изменим, добавив возможность показывать случайную игру каждый раз, когда кто-то посещает сайт или обновляет страницу.

### Создаём функцию `getRandomGame`

Для этого создай функцию `getRandomGame`, которая будет выбирать случайную игру. Следом добавь её в модуль для работы с API в файл `api-utils.js`. Аргументом она будет принимать массив игр и возвращать одну случайную игру из этого массива. Таким образом, каждый раз при обращении к нашему приложению пользователи смогут видеть разные игры 👇🏻

```javascript
// ...функция getData

function getRandomGame(array) {
  const randomIndex = Math.floor(Math.random() * array.length);
  return array[randomIndex];
}
```

Сначала функция вычисляет случайный индекс из переданного ей массива игр. Для этого `Math.random()` генерирует случайное число между `0` и `1` (не включая `1`), которое умножается на длину массива. Затем `Math.floor()` округляет полученное число вниз до ближайшего целого числа, чтобы индекс мог быть использован для доступа к элементам массива.

Используя полученный случайный индекс, функция возвращает элемент массива под этим индексом — случайно выбранную игру.

Чтобы использовать функцию в игровом контроллере, не забудь экспортировать её, а также обновить оглавление модуля — файл `index.js` в папке `api`

### Обновляем `gameRouteController`

Теперь нам нужно обновить игровой контроллер, чтобы вместо отправки ответа с первой игрой сервер отправлял случайную игру. В папке с контроллерами в файле `game.js` импортируй функцию и примени её при выборе игры 👇🏻

```javascript
const { getRandomGame } = require("../appModules/api");

async function gameRouteController(res) {
  try {
    const ratingFile = await fs.readFile(config.PATH_TO_RATING_FILE);
    const data = JSON.parse(ratingFile);
    const game = getRandomGame(data); // Получаем случайную игру
    res.setHeader("Content-Type", "application/json");
    res.end(JSON.stringify(game));
  } catch (error) {
    res.statusCode = 500;
    res.end("Internal Server Error");
  }
}
```

Выбрав случайную игру из массива, функция `getRandomGame` возвращает её, записывая в переменную `game`, которую мы отправляем в теле ответа интерфейсу.

## Рассчитываем рейтинг

Пользователь оценивает каждую игру по трём критериям: геймплей, дизайн и идея. Чтобы посчитать общий рейтинг, можно просто складывать эти значения.

### Добавляем веса

Определим веса для каждого из критериев рейтинга в модуле `rating` в файле `config.js`. Для этого создадим объект `WEIGHT`, в котором у каждого показателя будет своё весовое поле 👇🏻

```javascript
const WEIGHT = {
  gameplay: 2,
  design: 1,
  idea: 3,
};
```

### Работаем с рейтингом

Для работы с рейтингом необходимо добавить две основные функции — для создания рейтинга и для его обновления. В модуле `rating` помести новый файл `calculations.js`

Первой создадим функцию `createRating`, которая будет вычислять рейтинг игры на основе её показателей и веса каждого из них. Аргументами она принимает: `obj` — объект критериев рейтинга, а также `weight` — объект весов для каждого критерия 👇🏻

```javascript
function createRating(obj, weight) {
  return (
    obj.gameplay * weight.gameplay +
    obj.design * weight.design +
    obj.idea * weight.idea
  );
}
```

Теперь займёмся функцией `updateRating`, которая будет обновлять рейтинг определённой игры в массиве всех игр. Аргументами она будет принимать сам массив — `array`; идентификатор игры, рейтинг которой нужно обновить, — `id`; а также сам рейтинг — `rating` 👇🏻

```javascript
function updateRating(array, id, rating) {
  const index = array.findIndex((item) => item.id === id);
  array[index].rating += rating;
  return array;
}
```

Действие её следующее: 

1. Сначала функция найдёт в массиве игру с нужным `id`, используя метод `findIndex`, который возвращает индекс элемента в массиве. 
2. Затем к рейтингу найденной игры добавится новое значение `rating`. В результате функция вернёт обновлённый массив игр.

### Обновляем `voteRouteController`

Рассчитывать и обновлять уже существующий рейтинг необходимо в специальном контроллере — `voteRouteController`. Первым шагом импортируй всё необходимое — новые функции, а также содержимое файла конфигурации из всего модуля `rating` 👇🏻

```javascript
const { config, createRating, updateRating } = require("../appModules/rating");
```

В контроллере уже готова базовая логика проверки метода запроса, а также обработки ошибок. Логику работы с рейтингом мы будем писать внутри блока `try`, содержимое которого сейчас выглядит так 👇🏻

```javascript
const body = await parseBody(req);
console.log(body);
res.statusCode = 200;
res.end("Success!");
```

Получение и парсинг тела запроса уже готовы. Вместо вывода показателей в консоль, преобразуй их из строки JSON в JS-код, используя метод `parse`. Затем обратись к функции `createRating`, передав аргументами сами показатели `data` и весы для этих показателей `config.WEIGHT` 👇🏻

```javascript
res.statusCode = 200;
const body = await parseBody(req);
const data = JSON.parse(body);
const rating = createRating(data, config.WEIGHT);
```

В переменной `rating` сейчас находится рассчитанный общий рейтинг самой игры. Теперь асинхронно считай содержимое файла с рейтингом всех игр, обращаясь к модулю `fs`, и преобразуй его из формата JSON в JS-код, с которым можно работать. А после используй функцию `updateRating`, чтобы обновить рейтинг конкретной игры в массиве, добавляя новый 👇🏻

```javascript
const ratingFile = await fs.readFile(config.PATH_TO_RATING_FILE);
const ratingArray = JSON.parse(ratingFile);
const newRating = updateRating(ratingArray, data.id, rating);
```

Массив игр с обновлённым рейтингом хранится в переменной `newRating`, а значит, нам нужно использовать эту переменную, чтобы обновить содержимое самого файла рейтинга. Для этого преобразуй `newRating` обратно в формат JSON и асинхронно сохрани в файл, используя метод `writeFile` модуля `fs` 👇🏻

```javascript
await fs.writeFile(config.PATH_TO_RATING_FILE, JSON.stringify(newRating));
```

В интерфейс необходимо отправить обновлённый рейтинг, но прежде чем это сделать, установи заголовок ответа `Content-Type`, чтобы браузер явно понимал тип данных, которые ты отправишь в ответе. Затем отсортируй массив `newRating` по убыванию рейтинга (игры с высшим рейтингом будут первыми в списке) и отправь обратно в браузер 👇🏻

```javascript
res.setHeader("Content-Type", "application/json");
res.end(JSON.stringify(newRating.sort((a, b) => b.rating - a.rating)));
```

Можно запустить проект командой `npm run dev` или `node app.js` и насладиться процессом игры, честно оценивая каждую из них. Если при запуске возникли трудности, проверь код своего контроллера с его конечным вариантом под тогглом 👀

```javascript
const fs = require("fs").promises;
const parseBody = require("../appModules/http-utils/parse-body");
const { config, createRating, updateRating } = require("../appModules/rating");

async function voteRouteController(req, res) {
  if (req.method !== "POST") {
    res.statusCode = 404;
    res.end("Not Found");
  } else {
    try {
      res.statusCode = 200;
      const body = await parseBody(req);
      const data = JSON.parse(body);
      const rating = createRating(data, config.WEIGHT);

      const ratingFile = await fs.readFile(config.PATH_TO_RATING_FILE);
      const ratingArray = JSON.parse(ratingFile);
      const newRating = updateRating(ratingArray, data.id, rating);

      await fs.writeFile(config.PATH_TO_RATING_FILE, JSON.stringify(newRating));
      res.setHeader("Content-Type", "application/json");
      res.end(JSON.stringify(newRating.sort((a, b) => b.rating - a.rating)));
    } catch (error) {
      res.statusCode = 500;
      res.end("Internal Server Error");
    }
  }
}

module.exports = voteRouteController;
```
