## Что такое CORS

        ❗ **CORS** (Cross-Origin Resource Sharing) — это тот самый охранник.
{/quiz-task}

Этот механизм помогает решить, кто может отправлять запросы к твоему серверу и какие именно они должны быть. Без этого любой незваный гость с другого сайта мог бы спокойно воспользоваться данными или ресурсами сервера, а это небезопасно.

Давай вместе настроим CORS в приложении, добавив специальный миддлвар. Для этого создай модуль `cors.js` в директории `middlewares`

### Настройка CORS

Создай функцию с названием `cors`, которая принимает `req` — информацию о запросе, `res` — ответ, `next` — функцию для запуска следующего миддлвара 👇🏻

```javascript
function cors(req, res, next) {}
```

Когда к приложению приходит запрос, нужно проверить, откуда он. За это отвечает заголовок `origin` в объекте `req`. Он содержит адрес сайта, с которого выполняется запрос. Для проверки нам нужно только это поле, поэтому используй деструктуризацию объекта 👇🏻

```javascript
function cors(req, res, next) {
	const { origin } = req.headers; // Смотрим, кто стучится к серверу
}
```

Чтобы разрешить определённому сайту выполнять запросы к твоему приложению, нужно всего лишь добавить специальный заголовокAccess-Control-Allow-Origin». В качестве значения укажи адрес сайта, которому ты разрешаешь вход.

Сейчас мы работаем с приложением локально, выполняя запросы из нашего интерфейса по адресу `localhost:3000`. Добавь его в качестве значения нового заголовка👇🏻

```javascript
function cors(req, res, next) {
	const { origin } = req.headers;
	res.header('Access-Control-Allow-Origin', 'http://localhost:3000'); // Говорим: «Добро пожаловать!»
}
```

Всё, что останется сделать дальше, — передать управление следующему миддлвару, вызвав функцию `next`, которую надо принять в качестве аргумента 👇🏻

```javascript
function cors(req, res, next) {
	const { origin } = req.headers;
	res.header('Access-Control-Allow-Origin', 'http://localhost:3000');
	next(); // Идём дальше, не задерживаем очередь
}
```

### Особенности CORS

Прописывать вручную заголовок доступа каждому из них не самое лучшее решение. Поэтому давай модифицируем миддлвар, добавив список друзей нашего приложения. Для этого создай массив `allowedCors` 👇🏻

```javascript
const allowedCors = [
  'https://practicum.yandex.ru',
  'https://students-projects.ru',
  'http://localhost:3000'
];
```

Кроме локального адреса, здесь будет ещё два важных адреса, с которыми взаимодействует наше приложение.

В самом миддлваре добавь простую проверку: находится ли адрес сайта, с которого выполняется запрос, в массиве разрешённых адресов. А вместо одного определённого адреса укажи переменную `origin` 👇🏻

```javascript
function cors(req, res, next) {
	const { origin } = req.headers;
	
	if (allowedCors.includes(origin)) { // Если это наш друг
		res.header('Access-Control-Allow-Origin', origin);
	}
	
	next();
}
```

Всё готово!

Давай ещё раз посмотрим, как работает механизм:

1. **Смотрим на запрос.** Когда на сервер приходит запрос, смотрим, откуда он. Это как проверить, есть ли у посетителя пригласительный билет.
2. **Проверяем список друзей.** Если сайт, с которого пришёл запрос, есть в нашем списке доверенных, разрешаем ему взаимодействие с приложением.
3. **Открываем дверь.** Добавляем в ответ специальный заголовок `Access-Control-Allow-Origin`, где указываем, кто может общаться с нашим сервером.

CORS как наш охранник может не только проверять пригласительные, но и объяснять правила вечеринки:

- «Можно звонить по телефону и писать письма» — это как разрешённые методы запросов: `GET`, `POST`, `PUT` и т. д. и т. п. 👇🏻

    ```javascript
    res.header('Access-Control-Allow-Methods', 'GET,HEAD,PUT,PATCH,POST,DELETE');
    ```

- «Можно спрашивать только о погоде и музыке» — это как разрешённые заголовки запросов: `Origin`, `Content-Type` 👇🏻

    ```javascript
    res.header('Access-Control-Allow-Headers', 'Origin, X-Requested-With, Content-Type, Accept');
    ```


Таким образом, CORS помогает разрешить взаимодействовать с приложением только указанным сайтам. Кроме того, при каждом запросе он будет следить, чтобы эти сайты соблюдали правила и выполняли разрешённые тобой действия. 

Осталось экспортировать этот модуль, а затем добавить в общий список используемых в приложении — и дело в шляпе! 

Первым рекомендуем указать именно его, чтобы он сначала проверял сайт, с которого выполняется запрос, а уже после передавал управление другим миддлварам и функциям 👇🏻

```javascript
app.use(
  cors, // Добавляем CORS самым первым
  bodyParser.json(),
  express.static(path.join(__dirname, 'public')),
  mainRoute,
  gamesRouter
)
```

## День открытых дверей

Во время разработки или тестирования может понадобиться открыть доступ к приложению любым сторонним сайтам. Это можно сделать, изменив список разрешённых адресов в заголовке `Access-Control-Allow-Origin` на `*` 👇🏻

```javascript
res.header('Access-Control-Allow-Origin', '*'); // Открываем доступ всем
```
