Шаг 1. Миддлвары

Для начала убедись, что в `app.js` подключён миддлвар из библиотеки `body-parser`. Он нужен для того, чтобы прочитать данные из тела запроса `req.body` как JSON-объекты. Если вдруг этот шаг был пропущен, лови подробную инструкцию в тоггле 👀

1. Загрузи библиотеку командой 👇🏻

    npm install body-parser

2. Добавь её в файл `app.js` 👇🏻

    // app.js 
    const express = require('express');
    const path = require('path');
    // Импортируем библиотеку
    const bodyParser = require('body-parser');
    const mainRoute = require('./routes/main');
    const gamesRouter = require('./routes/games'); 
    
    const PORT = 3000;
    const app = express();
    
    // Настраиваем миддлвар-функцию bodyParser
    app.use(
        bodyParser.json(),
        express.static(path.join(__dirname, 'public')),
        mainRoute,
        gamesRouter
    ); 
    
    app.listen(PORT, () => {
        console.log(`Server is running at PORT http://localhost:${PORT}`);
    })

Теперь `middleware`-функция `bodyParser.json` подключена глобально и будет вызываться для всех маршрутов приложения.

В первом файле мы настраивали CORS — механизм, способный решать, кто может отправлять запросы к твоему серверу (подробно о том, что это такое, говорили в уроке «CORS»). В нём должен находиться список разрешённых сайтов и функция-миддлвар `cors`, которая следит за тем, чтобы запрос к серверу поступал от разрешённого сайта.

Рекомендуем пробежаться по шагам и проверить себя ещё раз 👇🏻

1. В файле `middlewares/cors.js` хранится функция `cors`, которая принимает `req` — информацию о запросе, `res` — ответ, `next` — функцию для запуска следующего миддлвара. 2. Через заголовок запроса `origin` можно проверить, кто обращается к серверу. Лови реализацию для проверки 👇🏻

function cors(req, res, next) {
	const { origin } = req.headers; // Смотрим, кто стучится к серверу
}

module.exports = cors;

3. Чтобы сайт мог выполнять запросы к твоему приложению, убедись, что добавлен заголовок `Access-Control-Allow-Origin`. Значением заголовка должен быть адрес сайта, которому разрешено делать запрос. В твоём случае — `'http://localhost:3000'`. Можешь добавить и пару других адресов, чтобы попрактиковаться, — `https://practicum.yandex.ru` и `https://students-projects.ru` 4. В конце нужно передать управление следующему миддлвару с помощью функции `next()` 5. Не забудь подключить миддлвар в `app.js`. Это нужно сделать первым делом, чтобы сначала проверялся сайт, отправляющий запрос, а уже после передавалось управление другим миддлварам и функциям 👇🏻

    app.use(
      cors, // Добавляем CORS самым первым
      
      // Остальные миддлвары и контроллеры
    )
// Список сайтов, которым мы разрешаем обращаться к серверу
const allowedCors = [
  'https://practicum.yandex.ru',
  'https://students-projects.ru',
  'localhost:3000'
];

// Функция, которая принимает объекты req (информация о запросе),
// res (объект ответа) и функцию next (для запуска следующего миддлвара)
function cors(req, res, next) {
	const { origin } = req.headers; // Смотрим, кто стучится к серверу
	if (allowedCors.includes(origin)) { // Если это наш друг,
		res.header('Access-Control-Allow-Origin', origin); // говорим: «Добро пожаловать!»
	}
	
	next(); // Идём дальше, не задерживаем очередь
}

module.exports = cors;

Во второй файл мы начали переносить общие функции из `/controllers/games.js`. К этому моменту у тебя уже должен быть готов миддлвар `getAllGames`, в который вынесли код для получения игр. Теперь тебе предстоит разбить его на несколько миддлвар, каждый из которых будет нужен для выполнения одной подзадачи. Так код удобнее читать и поддерживать в будущем. Вот список миддлвар, которые должны у тебя получиться:

a. `getAllGames` — функция для чтения из файла `data/games.json`. Мы уже рассказывали, как подготовить эту функцию, в уроке «Миддлвары». Эту функцию можно разбить на несколько миддлваров — код для них тебе нужно написать самому, ниже описываем подробнее, как это сделать.

b. `checkIsTitleInArray` — проверка, есть ли игра в списке игр, который прочитан функцией `getAllGames`. Вынеси в этот миддлвар код из `getAllGames`, который был нужен для этой проверки, и не забудь использовать функцию `next()` в конце (это касается всех миддлваров, которые тут описаны).

c. `updateGamesArray` — обновление списка игр. В этот миддлвар нужно вынести код, с помощью которого в `getAllGames` добавлялись новые игры. В нём будет проверка, что отправляются данные новой игры (это как раз проверяет миддлвар `checkIsTitleInArray`). В случае, если игра новая, список игр в объекте `req` обновляется и в конце используется функция `next()`. Если игра уже есть в списке игр, нужно отправлять ошибку 400 с текстом “Игра с таким именем уже есть”.

d. `updateGamesFile` — запись обновлённого списка в файл `data/games.json`. Вынеси код, который использовался в `getAllGames` для записи списка.

e. `deleteGame` — удаление игры.

f. `findGameById` — поиск игры по ID. В этом миддлваре должен быть код для поиска игры по ID из функции `deleteGame`

const { readData, writeData } = require("../utils/data");

const getAllGames = async (req, res, next) => {
  const games = await readData("./data/games.json");
  if (!games) {
    res.status(400);
    res.send({
      status: "error",
      message: "Нет игр в базе данных. Добавь игру."
    });
    return;
  }
  req.games = games;
  next();
};

const checkIsTitleInArray = (req, res, next) => {
  req.isNew = !Boolean(req.games.find(item => item.title === req.body.title));
  next();
};

const updateGamesArray = (req, res, next) => {
  if (req.isNew) {
    const inArray = req.games.map(item => Number(item.id));
    let maximalId;
    if (inArray.length > 0) {
      maximalId = Math.max(...inArray);
    } else {
      maximalId = 0;
    }

    req.updatedObject = {
      id: maximalId + 1,
      title: req.body.title,
      image: req.body.image,
      link: req.body.link,
      description: req.body.description
    };
    req.games = [...req.games, req.updatedObject];
    next();
  } else {
    res.status(400);
    res.send({ status: "error", message: "Игра с таким именем уже есть." });
  }
};

const updateGamesFile = async (req, res, next) => {
  await writeData("./data/games.json", req.games);
  next();
};

const findGameById = (req, res, next) => {
  const id = Number(req.params.id);
  req.game = req.games.find(item => item.id === id);
  next();
};

const deleteGame = (req, res, next) => {
  const id = req.game.id;
  const index = req.games.findIndex(item => item.id === id);
  req.games.splice(index, 1);
  next();
};

module.exports = {
  getAllGames,
  checkIsTitleInArray,
  updateGamesArray,
  updateGamesFile,
  findGameById,
  deleteGame
};

Шаг 2. Контроллеры

О них мы подробно рассказали в уроке «Ещё пара слов про контроллеры». Сейчас у тебя должен быть файл `/controllers/games.js` — в него мы сначала переносили инструкции, как обрабатывать полученные запросы из файла `/routes/games.js`, а после создания миддлваров, куда мы вынесли общий код, в этом файле нужно описать две функции для отправки данных:

a. `sendAllGames` — отправляет игры, записанные в объект `req`

b. `sendUpdatedGames` — обновляет игры, записанные в объект `req`, и данные обновлённой игры.

const sendAllGames = (req, res) => {
  res.send(req.games);
};

const sendUpdatedGames = (req, res) => {
  res.send({
    games: req.games,
    updated: req.updatedObject
  });
};

module.exports = { sendAllGames, sendUpdatedGames };

Шаг 3. Роуты

На всякий случай рекомендуем заглянуть в урок «Роуты в Express». Сейчас у тебя в проекте должно быть уже три роута: для обработки `GET`, `POST` и `DELETE`-запросов:

1. `GET`

a. должен отправляться на роут `/games`

b. должны быть подключены миддлвары `getAllGames` и `sendAllGames` из `/middlewares/middlewares.js`

2. `POST`

a. тоже отправляется на роут `/games`

b. должны быть подключены миддлвары:

а) `getAllGames`

б) `checkIsTitleInArray`

в) `updateGamesArray`

г) `updateGamesFile`

д) `sendUpdatedGames`

3. `DELETE`

a. отправляется на роут `"/games/:id"`, где через параметр `id` передаётся ID игры, которую надо удалить

b. должны быть подключены миддлвары:

а) `getAllGames`

б) `findGameById`

в) `deleteGame`

г) `updateGamesFile`

д) `sendUpdatedGames`

const gamesRouter = require("express").Router();

const {
  getAllGames,
  checkIsTitleInArray,
  updateGamesArray,
  updateGamesFile,
  findGameById,
  deleteGame
} = require("../middlewares/games");
const { sendAllGames, sendUpdatedGames } = require("../controllers/games");

gamesRouter.get("/games", getAllGames, sendAllGames);

gamesRouter.post(
  "/games",
  getAllGames,
  checkIsTitleInArray,
  updateGamesArray,
  updateGamesFile,
  sendUpdatedGames
);

gamesRouter.delete(
  "/games/:id",
  getAllGames,
  findGameById,
  deleteGame,
  updateGamesFile,
  sendUpdatedGames
);

module.exports = gamesRouter;
