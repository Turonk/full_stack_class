**Чек-лист**

1. **Устанавливаем `express` и другие зависимости в проект**

a. Проверь, что у тебя создана папка, где ты будешь хранить проект. Название — на твоё усмотрение, но на всякий случай лови наши варианты: `week3`, `adminka`, `admin-panel`. Если папки не было, открывай терминал в ней — через него сейчас будешь устанавливать нужные для работы пакеты.

b. Напомним, что `express` — пакет для Node.js, который тебе нужно было подгрузить командой `npm`👇🏻

        # Инициализируй package.json, чтобы нода могла устанавливать зависимости
        npm init -y # Флаг -y ответит «Да» на все вопросы по настройке package.json
        
        # Установи экспресс
        npm install express

c. Для того чтобы в проекте при разработке работал {{hot reload}}[web_teens_theme2_lesson_5_hot reload], тебе понадобится пакет `nodemon`. Убедись, что он установлен из `npm` как `dev`-зависимость 👇🏻

        # Флаг --save-dev установит nodemon как dev-зависимость
        npm install nodemon --save-dev

d. Чтобы `nodemon` и программа запускались вместе, нужно было изменить `package.json`. Если это не сделано, отредактируй раздел `scripts` прямо сейчас 👇🏻

        {
        	...
        	"scripts": {
        		"start": "nodemon index.js"
        	},
        	...
        }

        const express = require('express');

b. Если помнишь, мы подготовили вспомогательные функции `readFile` и `writeFile` — они нужны для чтения и записи файлов на сервере. Убедись, что они скачаны из архива…

… и хранятся в папке `/utils/data`

c. Логику обработки входящих запросов удобно хранить в файле `games.js` из папки `routes`. Пока что он получается достаточно большим — расскажем, как разбить его на меньшие файлы, в следующих уроках. А пока сверься с кодом для запросов 👇🏻

        // routes/games.js
        const gamesRouter = require("express").Router(); // Создали роутер
        const { readData, writeData } = require("../utils/data"); // Чтение и запись данных в JSON-файл
        
        // Получим игры из JSON-файла и отправим в ответ на запрос
        const getAllGames = async (req, res) => {
          const games = await readData("./data/games.json");
          if (!games) {
            res.status(400);
            res.send({
              status: "error",
              message: "Нет игр в базе данных. Добавьте игру."
            });
            return;
          }
          req.games = games;
          res.send(req.games);
        };
        
        const deleteGame = async (req, res) => {
        	// Получим данные из файла
          const games = await readData("./data/games.json");
          if (!games) {
            res.status(400);
            res.send({
              status: "error",
              message: "Нет игр в базе данных. Добавьте игру.",
            });
            return;
          }
          req.games = games;
          
          // Прочитаем запрашиваемый id игры из запроса
        	const id = Number(req.params.id);
        	
        	// Найдём игру, которую хотят удалить, в общем массиве с играми по id
        	req.game = req.games.find((item) => item.id === id);
        	
        	// Найдём индекс удаляемой игры в общем массиве игр
        	const index = req.games.findIndex((item) => item.id === req.game.id);
        	
        	// Удалим из массива игр игру
        	req.games.splice(index, 1);
        	
        	// Запишем обновлённый массив игр в JSON-файл
        	await writeData("./data/games.json", req.games);
        	
        	// Вернём ответ о проделанной операции с данными о играх
        	res.send({
            games: req.games,
            updated: req.game
          });
        }
        
        gamesRouter.get("/games", getAllGames)
        gamesRouter.delete("/games/:id", deleteGame);
        
        module.exports = gamesRouter;

d. Проверь наличие в папке `routes` файла `main.js`. Если в нём нет обработчика `GET`-запроса по роуту `/main` — добавляй. Он будет читать `/public/index.html`, который скоро ты внедришь в проект 👇🏻

        // routes/main.js
        const mainRoute = require("express").Router();

            res.header("Content-Type", "text/html").send(data);
          });
        });
        
        module.exports = mainRoute;

e. Чекни импорт созданных роутеров в `app.js` 👇🏻

        // app.js 
        const express = require('express');
        
        // Импортируем роутеры
        const mainRoute = require('./routes/main');
        const gamesRouter = require('./routes/games'); 
        
        const PORT = 3000;
        const app = express();
        
        // Запускаем
        app.use(mainRoute, gamesRouter); 
        
        app.listen(PORT, () => {
          console.log(`Server is running at PORT http://localhost:${PORT}`);
        })

4. **Раздаём статические HTML-страницы**

a. Надеемся, архив с `public` успешно скачан и одноимённая папка уже вставлена в корень проекта (адрес будет `/public`). Если нет, лови 👇🏻

[public.zip](https://code.s3.yandex.net/kids-web/vids/M4/public.zip){target="_blank"}

b. Проверь, что `/public` доступна для внешних пользователей. Для этого достаточно в `app.js` использовать метод `static` 👇🏻

        // Теперь клиент имеет доступ только к публичным файлам
        app.use(express.static(path.join(__dirname, 'public')));

c. Метод `static` делает так, что, если обратиться к корню сервера, ты автоматически попадёшь в папку `public` и получишь `index.html`. Получается, что не нужно добавлять в запрос имя файла, достаточно просто обратиться в корень — по адресу `"/"`
