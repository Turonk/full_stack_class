# Отправляем проект на проверку

## Чек-лист с требованиями 📋

- В проекте есть директория для хранения модулей `appModules`
- В директории `appModules` есть три основных модуля:

    1. Модуль `api` для взаимодействия со сторонним API и работы с играми.
    2. Модуль `http-utils` для работы со статическими файлами и запросами.
    3. Модуль `rating` для работы с рейтингом игр, а также общим файлом рейтинга.

- В проекте есть директория для хранения контроллеров `controllers`:

    1. Контроллер `default` для обработки запросов, которые не относятся ни к одному из маршрутов. Цель контроллера в нашем приложении — обрабатывать статические файлы, которые интерфейс запрашивает у сервера.
    2. Контроллер `game` для обработки запросов по маршруту `/game`, который возвращает случайную игру из файла рейтинга обратно в интерфейс.
    3. Контроллер `main` для обработки запросов по главному маршруту `/`, который отображает интерфейс из папки `public`
    4. Контроллер `vote` для обработки запросов по маршруту `/vote`, который формирует рейтинг, обновляет файл с ним и возвращает результат обратно в интерфейс.

- В проекте есть директории с файлом рейтинга `dataset`, а сам файл рейтинга хранит массив данных в формате JSON.
- В проекте есть директория с файлами интерфейса `public`, которую можно скачать из заготовленного набора в уроке «Подготовка проекта».
- В проекте есть главный исполняемый файл `app.js`, в котором:

    1. Для приложения указывается порт `3005`
    2. Создаётся сервер средствами встроенного модуля `http`
    3. Сервер прослушивает порт `3005` и обрабатывает маршруты `/`, `/game`, `/vote`, а также обрабатывает исключения. 

- В проекте установлена сторонняя библиотека `nodemon` для запуска в режиме разработки.
