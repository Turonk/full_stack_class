HTTP-сервер на Node.js

Да! Сегодня мы рассмотрим простой пример сервера, который в ответ на запрос присылает HTML-разметку с фразой «Привет, мир!». Расслабляться не советуем, ведь потом тебя ждёт тренажёрка из двух заданий, а уже в следующем уроке ты сможешь применить все скиллы и создать сервер для проекта этой недели.

![](https://pictures.s3.yandex.net:443/resources/IMG_4929_1711631219.jpg)

Шаг 1. Подключение встроенного модуля `http`

Программу нужно научить принимать сообщения, которые поступают на сервер, так как в JavaScript нет такой встроенной возможности. Но зато она есть в модуле `http` из Node.js, с которым мы уже знакомы.

Импортируй `http` в код файла `index.js` командой `require` 👇🏻

const http = require('http');

Шаг 2. Создание сервера

Добавь сервер — так мы даём библиотеке команду подключиться к компьютеру и принимать сообщения 👇🏻

const http = require('http');

const server = http.createServer(); // Создаём сервер

Теперь доступ к сообщениям осуществляется из JavaScript-кода.

Шаг 3. Настройка порта

На компьютере может работать несколько программ, которые принимают сообщения. Чтобы это было возможно, предусмотрен специальный механизм в виде точек входа — **портов**.

Именно так!

Укажи Node.js принимать сообщения с порта `3000` 👇🏻

const http = require('http');

const server = http.createServer(); // Создаём сервер

server.listen(3000); // Будем принимать сообщения с 3000 порта

Шаг 4. Установка ответа

Ок! Входящие сообщения считывать научились, осталось указать, как на них реагировать. Для этого применим функцию `createServer`, которая принимает колбэк-функцию — в ней и описывают код, который нужно запустить при получении запроса 👇🏻

const http = require('http');

// Передаём обработчик
const server = http.createServer(() => {
  console.log('Пришёл запрос!');
});

server.listen(3000);

Функция-обработчик, которую передали в `createServer`, будет вызываться при каждом входящем запросе, пришедшем на порт `3000`

Сохрани этот код в файле `index.js` и запусти его в терминале командой `node index.js`. Далее в браузере введи `http://localhost:3000` — и увидишь сообщение в терминале: `Пришёл запрос!`, что означает, что браузер успешно отправил запрос на твой локальный сервер.

Чекай, как это выглядит 👇🏻

Шаг 5. Настройка запроса и ответа

В предыдущем шаге наш сервер уже принимал запросы и даже реагировал на них. Но пока его реакция — всего лишь сообщение в консоли. Нам же нужно отправить ответ пользователю. Чтобы это сделать, сначала разберёмся с параметрами функции-колбэка.

Первый параметр — объект запроса, второй — объект ответа 👇🏻

const http = require('http');

const server = http.createServer((request, response) => {
  console.log('Пришёл запрос!');
  console.log(request); // Объект запроса
  console.log(response); // Объект ответа
});

server.listen(3000);

Шаг 6. Определение объекта запроса

Обычно его называют `request`, или сокращённо `req`. Вся информация о запросе содержится в свойствах объекта 👇🏻

// Запусти этот файл и перейди
// в браузере по адресу: http://localhost:3000/hello

const http = require('http');

const server = http.createServer((req, res) => {
  console.log(req.url); // /hello
  console.log(req.method); // GET
  console.log(req.headers); // Здесь будут заголовки запроса,
  console.log(req.body); // а здесь тело запроса, но у GET-запроса его нет
});

server.listen(3000);

Шаг 7. Определение объекта ответа

Второй параметр обработчика называют `response`, или `res`. Он содержит свойства и методы для работы с ответом 👇🏻

// Запусти этот файл и перейди
// в браузере по адресу: http://localhost:3000

const http = require('http');

const server = http.createServer((req, res) => {
  res.statusCode = 200; // Статус ответа
  res.statusMessage = 'OK'; // Сообщение ответа
  res.setHeader('Content-Type', 'text/plain'); // Добавление заголовка ответу

  res.write('Hello, '); // Отправление части ответа — строки 'Hello, '
  res.write('world!'); // Отправление части ответа — строки 'world!'

  res.end(); // Окончание отправки ответа
});

server.listen(3000);

Ура! Ответ от сервера получен! Мы отправляем его частями методом `res.write`

Когда все данные получены, вызови метод `res.end`. Так ты обозначишь, что ответ пришёл полностью. Обрати внимание: отправку всех частей ответа нужно прописать до вызова `res.end`

А вот такой код приведёт к ошибке 👇🏻

const http = require('http');

const server = http.createServer((req, res) => {
  res.write('Hello, ');
  res.end();

  res.write('world!'); // Вызовет ошибку
});

server.listen(3000);

Отправить ответ можно и в методе `res.end` 👇🏻

// Запусти этот файл и перейди
// в браузере по адресу: http://localhost:3000

const http = require('http');

const server = http.createServer((req, res) => {
  res.statusCode = 200; // Статус ответа
  res.statusMessage = 'OK'; // Сообщение ответа
  res.setHeader('Content-Type', 'text/plain'); // Добавление заголовка ответу

  res.write('Hello, '); // Отправление части ответа — строки 'Hello, '
  res.write('world!'); // Отправление части ответа — строки 'world!'

  res.end('END'); // Отправление части ответа и окончание отправки
});
server.listen(3000);

Более того, ты можешь не описывать каждое свойство отдельно. Код статуса ответа и заголовки можно передать одним методом — `writeHead`. В качестве ответа можно отправлять в том числе и HTML-строку. Для правильного отображения HTML браузеру нужно указывать кодировку, и в этом тоже поможет метод `res.end`

Метод `res.end([data], [encoding])` первым параметром принимает ответ — `data`, вторым параметром (`encoding`) устанавливает кодировку ответа, по умолчанию это `'utf8'`. Имя кодировки в Node.js часто пишут без дефиса, как это принято в HTML. Каждый запрос должен заканчиваться вызовом этого метода.

Отправь заголовок `h1` с сообщением 👇🏻

const http = require('http');
const server = http.createServer((req, res) => {
	res.writeHead(200, {
    // Установи подходящий для HTML заголовок (обрати внимание на дефис, в заголовке он нужен)
		'Content-Type': 'text/html; charset=utf-8'
	});
	// В методе end тоже можно передать данные, в том числе HTML-строку
	res.end('<h1>Привет, мир!</h1>', 'utf8');
});

server.listen(3000);

Передавая HTML, чтобы избежать проблем с отображением в разных браузерах, лучше не полагаться на параметр по умолчанию и вручную дописывать кодировку ответа.
