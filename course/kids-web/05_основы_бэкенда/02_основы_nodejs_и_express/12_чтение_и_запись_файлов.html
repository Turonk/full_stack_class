Чтение и запись файлов

![](https://pictures.s3.yandex.net:443/resources/IMG_4971_1712130362.jpg)

Для работы с файлами в ноде используют модуль `fs`. Вот как его добавить в проект 👇🏻

const fs = require('fs');

Начнём с чтения данных из файла — для этого воспользуемся функцией `readFile` (с английского — «прочесть файл»). Она работает асинхронно и принимает два аргумента: имя файла, из которого нужно прочитать данные, и функцию, в которой описывают, что нужно сделать с прочитанными данными. Сама функция принимает два параметра: ошибку и данные файла.

Вот пример её использования 👇🏻

const fs = require('fs');

// Читаем файл data.json
fs.readFile('data.json', (err, data) => {
	// Если при чтении файла происходит ошибка, выводим её в консоль
  if (err) {
    console.log(err);
    return;
  }
	// Если ошибки не возникает, в консоли появится 
	// Текст файла data.json (перекодированный в строку utf8)
  console.log('data: ', data.toString('utf8'));
});

Данные файла поступают в виде двоичных (буфера). Прежде чем работать с ними, преобразуем их в строку одним из двух способов:

- Метод `toString`, как в примере выше: `data.toString('utf8')`. Параметр `toString` — строка с кодировкой, которую нужно использовать*.* - Передача кодировки внутри свойства `encoding` объекта опций. В таком случае объект опций становится вторым параметром метода `readFile`. Данные при этом поступают сразу в виде строки, их дополнительное преобразование не требуется. Смотри 👇🏻

    // app.js
    
    const fs = require('fs');
    
    // Добавляем в вызов объект опций, в котором указываем нужную кодировку
    fs.readFile('data.json', { encoding: 'utf8' }, (err, data) => {
    	console.log(data); // Выводим его содержимое в консоль
    });

Ок! Откроем `app.js` с таким кодом 👇🏻

// app.js

const fs = require('fs');

const readFile = () => {
  const file = fs.readFile('file.txt', { encoding: 'utf8' }, (err, data) => {
		console.log(data); // Выводим содержимое файла в консоль
	}); // Здесь читаем файл file.txt по относительному пути
};

readFile();

Перенесём файл и логику работы с ним в отдельную папку. Тогда получим следующую файловую структуру 👇🏻

![](https://pictures.s3.yandex.net:443/resources/Frame_1665_1712130385.png)

Логика работы теперь находится в отдельном модуле в файле `./files/read-file`. Его нужно подключить к точке входа — `app.js`

Экспортируй функцию из `read-file.js` 👇🏻

// read-file.js

const fs = require('fs');

module.exports.readFile = () => {
  const file = fs.readFile('file.txt', { encoding: 'utf8' }, (err, data) => {
		console.log(data);
	});
};

А теперь импортируй `readFile` в `app.js` 👇🏻

// app.js

const fs = require('fs');
const { readFile } = require('./files/read-file');

readFile();

Проблема возникла из-за относительного пути к файлу. Функция `readFile` определена в `/files/read-file.js` (`file.txt` хранится здесь же), но исполняется она в `app.js` (путь до `file.txt` из `app.js` — `/files/file.txt`).

Чтобы создать динамические пути, нужно:

- Знать, где находится модуль, из которого мы обращаемся к файлу. - Добавить модуль, который будет собирать пути к файлам.

Сначала обсудим, как узнать, где находится модуль. Если говорить о Node.js, все они содержат информацию о самом себе и окружении. Внутри каждого модуля хранятся переменные `__filename` и `__dirname`, в которых содержится имя файла модуля и путь к папке, где он лежит, соответственно 👇🏻

// app.js

console.log(__filename); // /usr/local/project/app.js
console.log(__dirname); // /usr/local/project

Мы могли бы сделать путь к файлу `file.txt` динамическим, используя шаблонную строку 👇🏻

const file = fs.readFile(`${__dirname}/file.txt`, { encoding: 'utf8' }, (err, data) => {});

Модуль `path` хранит методы для работы с путём к файлу. Задачу по преобразованию выполняет метод `join`, который учитывает контекст исполнения, поэтому не приходится думать, например, о разделителях в пути к файлу 👇🏻

// read-file.js

const fs = require('fs');
// Импортируем модуль path
const path = require('path');

module.exports.readFile = () => {
  const filepath = path.join(__dirname, 'file.txt'); // Собрали абсолютный путь к файлу
  const file = fs.readFile(filepath, { encoding: 'utf8' }, (err, data) => {
		console.log(data);
	});
};

С чтением файла разобрались, теперь обсудим другие возможности модулей `fs` и `path`

Сначала про `fs` 👇🏻

- Записывает данные в файл

Для этого есть метод `fs.writeFile`, который принимает три параметра:

1. Файл, куда нужно записать данные. 2. Сами данные, записанные строкой. 3. Функция для обработки ошибки.

    const fs = require('fs');
    
    fs.writeFile('data.json', JSON.stringify([1, 2, 3]), (err) => {
      if (err) console.log(err);
    });

- Читает все файлы директории

Здесь применим метод `fs.readdir`, который читает все файлы внутри директории. Первый аргумент метода — путь к директории, второй — функция, в которой описано, что делать с полученными данными. Для её обработки предусмотрено два параметра: первый — ошибка, второй — массив имён найденных файлов 👇🏻

    const fs = require('fs');
    
    fs.readdir('.', (err, files) => {
      if (err) {
        console.log(err);
        return;
      }
    
      console.log('data: ', files);
    });

- Создаёт папки

С этим поможет метод `fs.mkdir`. Он принимает два параметра: имя новой папки и функцию для обработки ошибок. Вместе с именем можно передать и путь, где необходимо создать папку 👇🏻

    const fs = require('fs');
    
    fs.mkdir('incomingData/data', (err) => {
      if (err) console.log(err);
    });

- Удаляет файлы

Это делает метод `fs.unlink`. У него два параметра: имя файла и колбэк для обработки ошибок 👇🏻

    const fs = require('fs');
    
    fs.unlink('data.json', (err) => {
      if (err) {
        console.log(err);
        return;
      }
    
      console.log('Файл удалён!');
    });

- И ещё много чего…

Остальные методы модуля `fs` по большей части работают аналогично. Так что, если будет желание скриэйтить что-то этакое с файлом, чего мы не объясняли, — добро пожаловать в документацию 👇🏻

[Ссылка на документацию модуля fs.](https://nodejs.org/api/fs.html){target="_blank"}

А вот ещё несколько полезных методов модуля для работы с путём файла `path` 👇🏻

const fs = require('fs');
const path = require('path');

// path.normalize убирает из пути лишние
// разделители и символы .. и .
path.normalize('/foo/bar//baz/asdf/quux/..'); // /foo/bar/baz/asdf

// path.dirname извлекает путь к папке из переданного пути
path.dirname(require.main.filename); // /usr/local/my-project

// path.extname извлекает расширение файла
path.extname('app.js'); // .js
