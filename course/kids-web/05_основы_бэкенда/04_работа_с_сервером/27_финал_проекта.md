# Финал проекта

Для того чтобы сдать результат своих трудов через платформу, нужно:

1. Зайти на свой сервер по SSH.
2. Найти абсолютный путь к папкам, где лежат твои фронтенд- и бэкенд-приложения. Для этого по очереди зайди в них командой `cd <имя_папки>`  и, находясь внутри, введи `pwd`. Эта команда тебе хорошо знакома — именно она выведет абсолютные пути. Скопируй их куда-нибудь, чтобы не потерять, ведь уже через пару пунктов они тебе понадобятся.
3. Вернись в папку своего пользователя командой `cd ~`
4. Запусти скрипт, который мы для тебя подготовили, используя команду в терминале 👇🏻

```bash
curl https://backup-project.students-projects.ru/create_backup.sh > create_backup.sh && chmod +x create_backup.sh && ./create_backup.sh
```

Она скачает и запустит программу, которая сохранит все ключевые файлы с твоего сервера в ZIP-архив, содержащий результат всей работы в модуле про бэкенд. Кроме кода твоих приложений там окажутся и файлы конфигурации твоего сервера, все команды, которые вводились на нём, база данных, список программ, которые были установлены на сервер.

5. Скрипт задаст тебе вопросы:
    - `Укажи путь к своему репозиторию фронтенда (например, /home/student/<path>)`
    **Фронтенд-репозиторий:** сюда вставь ссылку на фронтенд (во втором пункте просили тебя сохранить её).
    - `Укажи путь к своему репозиторию бэкенда (например, /home/student/<path>)`
    **Бэкенд-репозиторий:** сюда вставь ссылку на бэкенд (она тоже из второго пункта).
    - `Укажи конфигурационный файл nginx, где описывается твой фронтенд (например, /etc/nginx/sites-available/default)`
    **Конфиг Nginx для фронтенда:** если все шаги выполнялись строго по нашим инструкциям, введи сюда `/etc/nginx/sites-available/default`
6. Если нигде нет опечаток, скрипт начнёт свой хакерский процесс 👇🏻
