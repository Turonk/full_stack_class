Постоянная работа приложения. PM2

Компьютер привык выполнять задачи. Какие-то из них могут выполняться параллельно, а какие-то фокусируют на себе всё внимание сервера, не позволяя делать ничего, кроме них. Запуск API — это тоже задача, которую можно решать в фоновом режиме, продолжая взаимодействовать с сервером и не прекращая при этом работу самого приложения.

![](https://pictures.s3.yandex.net/resources/6_les_PM2_1715278800.jpg)

Установка PM2

Как подключиться к своему собственному серверу, подробно рассказали в уроке «Доступ к серверу по SSH». Для этого ты всегда будешь пользоваться командой формата 👇🏻

ssh student@<Твой IP-адрес> -i <Путь до ключа>

После подключения к серверу установи PM2 командой 👇🏻

sudo npm install pm2 -g

Обрати внимание, что ты скачиваешь этот инструмент через менеджер пакетов NPM, который устанавливали на сервер в уроке «Установка Node.js, Mongo, Git». Также добавляешь флаг `-g`, чтобы PM2 установился глобально и был доступен в любом месте твоего сервера.

Запуск приложения через PM2

Отлично! Для запуска приложения в фоновом режиме достаточно перейти в папку твоего проекта. В этом поможет команда `cd` с указанием пути до директории. Внутри корневой директории проекта нас интересует главный исполняемый файл приложения — `app.js`

Именно через него можно запустить приложение, введя команду 👇🏻

pm2 start app.js

В результате ты увидишь таблицу с запущенными задачами в консоли 👇🏻

![](https://pictures.s3.yandex.net/resources/1_5_1715278853.jpg)

Теперь, закрыв терминал или продолжив работу над другими задачами в нём, ты увидишь, что приложение не завершило свою работу. Менеджер PM2 также позволяет просматривать подробную информацию о запущенной задаче.

Чтобы увидеть, какие ошибки или успешные сообщения отображаются при работе приложения и другую подробную информацию, используй команду 👇🏻

pm2 monit

![](https://pictures.s3.yandex.net/resources/3_3_1715278892.jpg)

Выйти из режима мониторинга можно сочетанием клавиш `CTRL + C`

Возможности PM2

Кроме команды `start` в PM2 есть ещё несколько важных команд на все случаи жизни.

Чтобы посмотреть список всех задач, введи 👇🏻

pm2 ls

Чтобы остановить работу задачи 👇🏻

pm2 stop <название задачи>
// Например, pm2 stop app

Чтобы перезапустить задачу 👇🏻

pm2 restart <название задачи>
// Например, pm2 restart app

Чтобы совсем удалить задачу 👇🏻

pm2 delete <название задачи>
// Например, pm2 delete app

Чтобы завершить работу PM2 и всех запущенных задач 👇🏻

pm2 kill

Стабилизируем приложение

Если сервер перезапустится, все задачи, запущенные PM2, будут остановлены. Сразу настрой автозапуск PM2, чтобы избежать таких неприятных моментов 👇🏻

pm2 startup

После выполнения PM2 предложит тебе скопировать команду, которую он сгенерировал специально для твоего сервера 👇🏻

![](https://pictures.s3.yandex.net/resources/2_4_1715278966.jpg)

Команда начинается с `sudo env` и заканчивается `/home/student`. В нашем примере полная команда выглядит так 👇🏻

sudo env PATH=$PATH:/usr/bin /usr/lib/node_modules/pm2/bin/pm2 startup systemd -u student --hp /home/student

Её нужно скопировать, вставить в новую строку в терминале и выполнить, нажав `Enter`

Последним шагом сохрани изменения, выполнив команду 👇🏻

pm2 save
