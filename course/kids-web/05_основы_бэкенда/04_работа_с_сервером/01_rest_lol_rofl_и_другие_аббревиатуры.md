# REST, LOL, ROFL и другие аббревиатуры

![](https://pictures.s3.yandex.net/resources/Worn-Ass-Semi-Gloss_17_1714758647.jpg)

На самом деле четыре буквы **REST** описывают подход к построению сервисов, взаимодействующих с приложениями. 

Когда ты создаёшь сайт, ему нужны данные, которые он получает через API (опять аббревиатура, но уже знакомая тебе 🤓) из базы данных. Принцип, по которому это API создано, чаще всего называется REST. Есть и другие варианты, про них мы тоже расскажем, но упомянутый — самый популярный. На этой неделе тебе предстоит изучить набор правил, по которым принято настраивать взаимодействие между бэкендом и фронтендом.

Да, в современном мире приходится постоянно где-то регистрироваться и вводить логины и пароли. На бэкенде здесь будет много работы: нужно не просто создавать и проверять пользователей в базе данных, но ещё и думать про безопасность, предусматривать возможность запоминать пользователя и не выводить лишний раз формы ввода логинов и паролей.

Если стало грустно, то вспомни главное: у тебя на руках будет готовое приложение на Express, админка к нему, сайт Pindie, который взаимодействует с твоим собственным бэкендом. Это полный набор, дальше останется только научиться это всё выкладывать в интернет. 

Мы тебе уже рассказывали, что людей, кто такое умеет, называют **фулстек-разработчиками.** Такой специалист может создать проект целиком: написать и фронтенд (например, на React), и бэкенд (Express и Mongo). Тебя уже вполне можно назвать фулстекером, пусть и на старте своей карьеры. Можешь хвастаться этим друзьям и родственникам.
