Команды для навигации и редактирования

Просмотр файлов

Команда `ls` в терминале используется для вывода списка файлов и папок в текущей папке. Она является одной из наиболее часто используемых в командной строке.

Синтаксис у неё следующий 👇🏻

ls [опции]

По умолчанию `ls` выводит список файлов и папок в алфавитном порядке, но благодаря опциям порядок вывода можно изменить.

Собрали для тебя несколько примеров использования команды `ls` 👇🏻

- `ls` — вывести список файлов и папок в текущей папке. - `ls -l` — вывести подробную информацию о файлах и папках в текущей папке. - `ls -a` — включить в вывод скрытые файлы и папки. - `ls -lh` — вывести подробную информацию о файлах и папках в человекочитаемом формате.

Перемещение по папкам

Команда `cd` используется для изменения текущей рабочей папки. Она позволяет пользователю перемещаться по файловой системе: переходить в разные папки и выполнять операции с файлами и папками внутри них.

Синтаксис команды 👇🏻

cd путь

Здесь `путь` — это путь к папке, в которую нужно перейти. Он может быть абсолютным — начинаться с корня файловой системы, а также относительным — относительно текущей рабочей папки.

{quiz-task} background: | #f1f1ef content: | 📚 Если не очень помнишь, в чём разница, то вот [статья об этом](https://extra.students-projects.ru/general/absolute-and-relative-path){target="_blank"}. {/quiz-task}

Когда ты подключаешься к серверу, автоматически попадаешь в папку своего юзера. То есть ты оказываешься в папке с путём `/home/username/`, где `username` — это имя твоего пользователя.

В примерах ниже мы используем папку `Documents`, хотя её на самом деле нет, для того, чтобы объяснить, как работают команды. Представь сейчас, что она создана в папке пользователя.

Лови примеры пользования 👇🏻

- `cd Documents` — перейти в папку `Documents` в домашней папке пользователя. - `cd /home/username/Documents` — перейти в папку `Documents` в домашней папке пользователя с именем `username` - `cd ..` — перейти в родительскую папку текущей рабочей папки. - `cd ~` — перейти в домашнюю папку текущего пользователя.

Просмотр текущей папки

Команда `pwd` в терминале используется для вывода текущей рабочей папки. Она показывает путь к папке, в которой ты находишься в данный момент.

Синтаксис команды 👇🏻

pwd

После ввода команды в терминал ты увидишь полный путь к текущей директории. Это полезно, например, если нужно узнать, в какой папке ты находишься, чтобы перейти в другую папку или выполнить действия с файлами в ней.

Лови пример использования команды `pwd` 👇🏻

cd /home/username/Documents
pwd

Здесь мы сначала перешли в папку `/home/username/Documents`, а затем использовали команду `pwd`, чтобы узнать полный путь к этой папке. Результат будет следующим 👇🏻

/home/username/Documents

Создание папки

Команда `mkdir` используется для создания новых папок (их ещё называют директории) в файловой системе.

Синтаксис команды 👇🏻

mkdir имя_папки

Здесь `имя_папки` — это имя создаваемой папки. Если необходимо создать несколько папок одновременно, их имена разделяют пробелами.

Лови примеры 👇🏻

- `mkdir myFolder` — создать папку `myFolder` в текущей рабочей папке. - `mkdir /home/username/myFolder` — создать папку `myFolder` в домашней папке пользователя с именем `username` - `mkdir -p /path/to/new/directory` — создать все промежуточные папки в указанном пути, если они не существуют.

Удаление папок и файлов

Команда `rm` используется для удаления файлов и папок. Это одна из самых мощных и опасных команд в ОС Linux, поскольку её использование может привести к потере данных.

Синтаксис команды различается в зависимости от желаемого результата:

- Для удаления одного или нескольких файлов 👇🏻

    rm файл1 файл2 ...

- Для удаления папки и её содержимого 👇🏻

    rm -r папка

Здесь опция `-r` указывает команде `rm` на необходимость рекурсивного, то есть последовательного удаления всего содержимого папки, включая её саму.

Примеры использования команды `rm` 👇🏻

- `rm file.txt` — удалить файл `file.txt` - `rm -r directory` — удалить папку `directory` и всё её содержимое.

Ограничение прав через Sudo

**Sudo** — это программа, созданная для определения прав пользователя. **Основная идея** заключается в том, чтобы предоставлять юзерам минимальный набор прав, необходимый для выполнения задач в системе. Это помогает повысить безопасность и ограничить возможности пользователя для использования потенциально опасных команд и операций.

Да, без Sudo пользователю `user1` пришлось бы войти в систему под учётной записью администратора {{`root`}}[web_teens_theme4_lesson_4_«root»], что представляет угрозу безопасности, ведь любая ошибка может навредить всей системе компьютера.

Используя команду `sudo`, `user1` может выполнить установку ПО, введя свой пароль. Таким образом `user1` получает все необходимые права только на время выполнения команды, после чего права возвращаются к обычным. Это снижает риск возникновения ошибок при работе с системой.

Посмотри пример установки Node.js на удалённый сервер (скоро ты это сделаешь самостоятельно, тут мы только показываем). При использовании команды `apt install nodejs` ПО не сможет установиться, отправив сообщение об отсутствии прав администратора. А вот с командой `sudo apt install nodejs` таких проблем не возникнет и ПО будет установлено 👇🏻

{video:https://code.s3.yandex.net/kids-web/vids/M4/M4T4/с_sudo_или_без.mp4|controls:true|autoplay:0|pip:false|controlsList:nodownload}

| Задача | Без Sudo возникнут проблемы с доступом и команда не выполнится | Вместе с Sudo команда выполнится | | --- | --- | --- | | Установка программного обеспечения | `apt install package-name` | `sudo apt install package-name` | | Изменение системных настроек | `systemctl restart service-name` | `sudo systemctl restart service-name` | | Редактирование файлов конфигурации | `nano /etc/config-file` | `sudo nano /etc/config-file` | | Удаление пакетов | `apt remove package-name` | `sudo apt remove package-name` | | Изменение владельца файла или папки | `chown username file-or-directory` | `sudo chown username file-or-directory` |

Эти команды требуют повышенных привилегий для выполнения, так как они могут повлиять на работу системы или безопасность. Использование Sudo позволяет временно получить эти привилегии для выполнения команды от имени суперпользователя.

Работа с Nano

Давай рассмотрим пример работы с Nano на практике. Предположим, у тебя есть файл `example.txt`, который ты хочешь отредактировать.

Сначала проверь, установлен ли Nano в твоей системе. Для этого введи в терминале 👇🏻

nano —version

Если Nano установлен, а по идее это так и есть, ты увидишь информацию о версии программы.

- Теперь открой файл `example.txt` для редактирования. В терминале введи команду 👇🏻

    nano example.txt

Команда `nano <имя файла>` позволяет открыть существующий файл или создать новый и приступить к его редактированию.

- Сейчас перед тобой окно редактора Nano. Здесь можно начать редактировать файл, например, добавив текст `Это тестовый файл`. Для этого используй клавиши со стрелками для перемещения курсора, а затем начинай вводить текст 👇🏻

![](https://pictures.s3.yandex.net/resources/s_1715277907.jpg)

- Чтобы закончить редактирование и сохранить изменения, нажми `Ctrl+O/Сontrol-O`, а затем `Enter` - Теперь закрой файл. Для этого нажми `Ctrl+X/Сontrol-X`. Также, если сразу закрыть файл с изменениями, тебе будет предложено сохранить его. Для подтверждения операции нужно нажать `Y`

Да, но это лишь базовый пример работы с Nano. Благодаря этому редактору можно выполнять более сложные операции, такие как поиск и замена текста, копирование и вставка фрагментов текста и многое другое.
