Вот что тебе понадобится в этом уроке 👇🏻

- **Node.js для запуска API** Самый важный инструмент, позволяющий запускать JavaScript, на котором написано твоё приложение. - **MongoDB для хранения данных** Чтобы твоё приложение не просто запускалось, а работало с данными, как мы и задумывали. - **Git для управления кодом** Чтобы не переносить каждый файл по отдельности, а клонировать приложение на сервер одной командой и также просто его обновлять.

Все эти инструменты требуют отдельной установки и настройки. Мы последовательно с тобой пройдёмся по каждому из них, начиная с Node.js и заканчивая Git.

Установка Node.js

Но перед его установкой на удалённый сервер важно убедиться, что версия на сервере будет совпадать с версией на твоём компе. Версии Node.js отличаются, и то, что работает в одной, может не работать в другой.

Шаг 1. Проверяем версию

Проверить это можно в командой строке или прямо в терминале проекта VS Code, выполнив одну команду 👇🏻

node -v

В ответе ты увидишь номер версии, состоящий из трёх чисел, разделённых точками. Первое число — это **мажорная версия,** которую тебе нужно запомнить для дальнейшей установки 👇🏻

![](https://pictures.s3.yandex.net/resources/1-1_2_1715278276.jpg)

Шаг 2. Устанавливаем на сервер

Для начала подключись к своему серверу, выполнив команду `shh student…` из урока «Доступ к серверу по SSH». Теперь для установки Node.js потребуются **две команды**.

**Первая** команда добавит репозиторий Node.js на твой сервер. В ней нужно заменить число `20` на мажорную версию, которую мы узнали ранее 👇🏻

curl -sL https://deb.nodesource.com/setup_20.x | sudo -E bash -

**Вторая** команда установит сам Node.js 👇🏻

sudo apt install -y nodejs

Чтобы проверить, что установка прошла успешно, выполни команду `node -v`. В ответе ты увидишь номер установленной версии. Лови пошаговую инструкцию в скринкасте 👀

Установка MongoDB

Для этого необходимо установить MongoDB, но не последней версии, а версии `4.4`. Для начала добавь ключ, который позволит тебе безопасно загрузить MongoDB из твоего репозитория 👇🏻

curl -fsSL https://repo.mongodb.prakticum-team.ru/keys/server-4.4.asc | sudo apt-key add -

Результатом выполнения команды будет сообщение `OK`

Затем добавь адрес репозитория в список источников твоего сервера 👇🏻

echo "deb [ arch=amd64 ] https://repo.mongodb.prakticum-team.ru/apt/ubuntu focal/mongodb-org/4.4 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-4.4.list

Теперь обнови информацию о доступных пакетах на сервере 👇🏻

sudo apt update

И наконец, установи MongoDB 👇🏻

sudo apt install -y mongodb-org

После установки запусти MongoDB, чтобы убедиться, что всё работает корректно 👇🏻

sudo service mongod start

Команда будет выполнена успешно в том случае, если после запуска не произойдёт ничего. Да-да, так и работают сервера! Но, чтобы точно убедиться, что MongoDB установилась и запустилась, успокоить душу, так сказать, проверь статус её работы 👇🏻

systemctl status mongod

Зелёный огонёк и надпись `active (running)` подтвердит, что всё прошло окей 👇🏻

![](https://pictures.s3.yandex.net/resources/1_4_1715278379.jpg)

Да, запускать MongoDB каждый раз при перезагрузке сервера совсем не хочется. Чтобы она запускалась автоматически при старте системы, выполни команду 👇🏻

sudo systemctl enable mongod.service

Установка Git

Для установки Git в терминале сервера выполни команду 👇🏻

sudo apt install -y git

После установки нужно проверить, что гит установлен правильно. По аналогии с проверкой Node.js проверь установку Git, спросив у сервера его версию 👇🏻

git --version

Команда должна вывести на экран номер версии Git, подтвердив тем самым установку 👇🏻

![](https://pictures.s3.yandex.net/resources/2_3_1715278441.jpg)

Клонирование приложения

Все инструменты установлены, поздравляем! Для запуска админки не хватает самого приложения. Его нужно склонировать из твоего репозитория. Для начала определись с местом. Если в процессе установки инструментов тебя случайно переместило в другую папку, вернись в самое начало, командой 👇🏻

cd ~

Проверить путь, в котором ты находишься, можно благодаря `pwd`, которая переводится как **«напиши рабочую папку».** В результате увидишь, где конкретно ты сейчас обитаешь на сервере 👇🏻

![](https://pictures.s3.yandex.net/resources/3_2_1715278479.jpg)

Папка `student` — это твоя личная папка, в которой можно делать всё что душе желается. Именно в неё и нужно будет склонировать приложение.

{quiz-task} background: | #f1f1ef content: | ❗ Для того чтобы безопасно клонировать приложения, понадобится обратиться к сервису GitHub через SSH. Чтобы работать по SSH, понадобится ключ, который мы уже создали в уроке «Работа с сервером по SSH». Не стыдись заглянуть туда ещё раз, если вдруг что. {/quiz-task}

Находясь в своей личной папке на сервере, тебе нужно выполнить команду `git clone`, подставив в неё специальную ссылку из твоего репозитория. Найти её можно, нажав на зелёную кнопку `Code` и перейдя во вкладку `SSH`, как на картинке ниже 👇🏻

![](https://pictures.s3.yandex.net/resources/4_1_1715278523.jpg)

Полная команда для клонирования получится такая 👇🏻

git clone git@github.com:твой_ник/твой_репозиторий.git

При клонировании сервер спросит, действительно ли ты хочешь подключиться к сервису GitHub и склонировать репозиторий. Нужно будет ответить словом `yes` и нажать на кнопку `Enter` 👇🏻

![](https://pictures.s3.yandex.net/resources/5_copy_1715278539.jpg)

Запускаем админку

Теперь тебе нужно установить все пакеты для работы приложения и выполнить заветную NPM-команду для запуска. Для начала перейди в папку проекта, который только что склонировался. Сделать это можно командой 👇🏻

cd название_папки

Здесь `название_папки` — это название твоего репозитория, но без добавления расширений типа `.git` и прочих. В нашем примере это папка `kb-backend-week-6` 👇🏻

cd kb-backend-week-6

А ты подставь своё название и выполни эту же команду.

Теперь установи пакеты хорошо известной тебе `install` 👇🏻

npm install

Когда установка завершится, запусти приложение, выполнив 👇🏻

npm start

В консоли увидишь логи, которые часто мелькали в процессе разработки на твоём компьютере. Но теперь это происходит на твоём собственном сервере! Вот смотри 👇🏻

![](https://pictures.s3.yandex.net/resources/6_copy_1715278591.jpg)

Чтобы увидеть запущенное приложение и начать им пользоваться, открой браузер и перейди на IP-адрес своего сервера, добавив порт `3001` через знак `:`

Его можно найти в команде, которая позволяет подключиться к серверу по SHH. В ней IP-адрес находится вот здесь 👇🏻

ssh student@твой_ip_адрес

Получается, полный путь будет выглядеть так 👇🏻

http://158.160.163.60:3001/

Обрати внимание, что здесь вместо `158.160.163.60` должен быть твой IP-адрес.
