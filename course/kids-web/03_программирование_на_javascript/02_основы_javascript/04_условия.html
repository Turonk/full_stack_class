Условия

На пути к проекту мы уже столкнулись с такими понятиями:

![](https://pictures.s3.yandex.net:443/resources/Frame_1342_1700762674.png)

Но что, если программе нужно выполняться не всегда, а при определенных обстоятельствах?

В этом уроке мы как раз узнаем, как в таком случае помогают условия.

![](https://pictures.s3.yandex.net:443/resources/Frame_1336_3_1_1700762703.png)

Когда в JavaScript нам нужно указать условие для выполнения программы, мы используем специальную конструкцию:

if (тут указываем условие) {   
	// здесь прописываем действие, если условие верно
}

Инструкция `if(...)` вычисляет условие в скобках и, если результат `true`, выполняет блок кода.

Для примера с Собакой нам пригодятся знакомые тебе из школьной математики операторы сравнения.

`>` — больше

`<` — меньше

`>=` — больше или равно

`<=` — меньше или равно

`===` — проверка на равенство (да, символ `=` уже занят присваиванием значения для переменной, поэтому для проверки равенства нужно использовать `===`)

`!==` — проверка на неравенство (восклицательный знак в операторе неравенства позаимствован из логической алгебры, он означает отрицание)

Операции сравнения позволяют **сравнить** (иногда приходится быть капитанами) различные значения: например, определить равенство `10 === 10` или какое значение больше `10 > 2`

Такая операция всегда возвращает один из двух результатов:

- `true` — если условие верно (`10 > 2` условие верно, так как 10 больше, чем два) - `false` — если условие ложно (`10 < 2` условие ложно, так как 10 больше, чем два)

Может показаться странным, что `"яйцо"` оказывается больше чем `"курица"`, но в этом есть логика, при желании о ней подробнее почитай [тут](https://developer.mozilla.org/ru/docs/Web/JavaScript/Equality_comparisons_and_sameness){target="_blank"}.

Вот так:

 // Когда мяч просит Аски, Собака его приносит

let dogOwner = "Аски"; // в переменную записываем имя хозяина Собаки

if (dogOwner === "Аски") {
		console.log('Собака принесёт мяч') // в консоли браузера мы увидим сообщение: 'Собака принесёт мяч'
}

Теперь ты в курсе, как работает условный оператор `if` с операторами сравнения, но иногда этого недостаточно.

Окружающий мир гораздо разнообразнее бинарной логики, и только лишь односложными условиями с `true`/`false` невозможно описать происходящее. В случаях, когда нужно учесть много условий (например, Аски может давать разные команды Собаке), необходимо предусмотреть целую цепочку из условий (описать разные действия для Собаки под разные команды).

Такие развилки в логических операциях называют **ветвлением.** Мы можем указывать условие за условием, чтобы выводить разные результаты для каждого условия.

Схематично это выглядит так:

![](https://pictures.s3.yandex.net:443/resources/Frame_1344_2_2_1_1700762792.png)

Добавление нового условия в коде происходит с помощью дополнительной конструкции `else if`:

if (условие1) {
    // Код, который выполняется, если условие1 истинно
} else if (условие2) {
    // Код, который выполняется, если условие1 ложно, но условие2 истинно
} else {
    // Код, который выполняется, если оба условия ложны
}
// Собака научилась выполнять несколько команд, отразим это в переменной
let commands = ["принеси мяч", "дай лапу", "сидеть"];

// Если мы передадим Собаке одну из первых двух команд, она их выполнит. 
// В остальных случаях будет сидеть в ожидании других инструкций
if (command === "принеси мяч") {
    console.log('Собака принесёт мяч')
} else if (command === "дай лапу") {
    console.log('Собака протянет лапу')
} else {
    console.log('Собака будет сидеть')
}

Иногда эти усложнения приводят к огромной логической цепочке. Давай попрактикуемся, чтобы не пугаться, когда придётся столкнуться с такой на следующих неделях.

Ну всё! Теперь мы уверены, что ты можешь:

- описывать различные условия - использовать специальную инструкцию `if(...){}`, где в круглых `()` скобках описывается условие, и если результат условия — истина (возвращает `true`), то JavaScript выполнит код из блока с фигурными `{}` скобками - применять инструкции `else` и `else if (...)` для выполнения других операций, если условие ложно (возвращает `false`)

Совсем скоро узнаешь, как вся эта инфа пригодится тебе на грядущей неделе. Увидимся на следующем уроке.
