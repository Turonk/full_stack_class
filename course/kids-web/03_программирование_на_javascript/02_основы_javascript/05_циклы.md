Мы уже зафиксировали, что условия часто встречаются не только в жизни, но и в коде. Кроме того, при помощи условий мы можем объяснить JavaScript, что определённый код (инструкции) нужно выполнить несколько раз.

Такая простая задача, а целых 10 шагов. Каждый шаг — это вызов функции, которую нужно записать и вызвать заново. Но никто не любит повторений. К тому же писать одни и те же инструкции (код) — это непродуктивно, отнимает много времени и приводит к ошибкам. 

Если необходимо выполнить однотипную инструкцию — запустить один и тот же код несколько раз, — нам на помощь приходят циклы.

![](https://pictures.s3.yandex.net:443/resources/Frame_1334_1_1_1700472744.png)

**Цикл** — это специальная операция, которая позволяет выполнять какие-либо инструкции (код) много раз. Цикл состоит из **условия** и **тела цикла:** 

- Условие определяет, нужно ли запускать цикл: если условие верно — повторить цикл, и наоборот.
- Тело цикла — это код, который будет повторно выполняться, пока верно условие цикла.

```javascript
while (условие) {
    // тело цикла
}
```

Чтобы верно указать условие цикла, нам понадобятся знания из прошлого урока.

Выведем в консоль браузера значение переменной `number`, уменьшая её с каждым повтором цикла:

```javascript
let number = 2;

while (number > 0) {
		console.log(number);
		number = number - 1;
}
```

Пока условие `number > 0` верно, цикл будет выполнять код внутри тела цикла вновь и вновь, уменьшая с каждым повтором значение `number` на единицу. 

На втором повторе значение `number` станет равно нулю `number = 0;`, и при очередной проверке условия `number > 0` оно будет ложно (`false`), так как ноль не может быть больше ноля. Из-за ложного условия цикл остановится и в консоли браузера мы увидим 2 и 1 — изменение значения переменной при первом и втором повторах цикла. На этом программа остановится.

### Типы циклов

Есть два часто используемых цикла — `while` и `for`:

- Цикл `while` более гибкий при выборе условия. Его можно использовать в случаях, когда мы не знаем заранее число повторений цикла. В подобном цикле главное, чтобы условие в какой-то момент перестало выполняться и вернуло `false`. Иначе он будет выполняться бесконечно.

    ```javascript
    let number;
    // пока переменной не присвоили значение, условие цикла будет ложно 
    // и тело цикла выполняться не будет
    while (number) {
        // тело цикла
    }
    ```

- Цикл `for` чаще используется для счётчиков или случаев, когда число повторений известно заранее.

    ```javascript
    for (переменная цикла и её исходное значение; условие выполнения цикла; изменение переменной после каждого повтора) {
        // тело цикла
    }
    
    // в цикле for обязательно указывать шаг цикла - количество повторений
    for (let number = 0; number < 5; number = number + 1) {
    		// тело цикла повторится 5 раз
    }
    ```

В качестве примера выведем в консоль браузера слово `"Программирование"` по буквам. Для этого понадобится счетчик `index`, который будет увеличиваться с каждым повтором цикла, а само слово сохраним в переменной `lesson`

Пусть цикл будет повторяться, пока условие будет верным: пока счётчик `index` меньше длины слова `"Программирование"` `lesson.length`:

В нашем проекте с появляющимися эмодзи нам повезло, потому что мы точно знаем, сколько повторений нам надо сделать. Для таких задач есть особый цикл — `for`, самый популярный из всех циклов. Его тебе предстоит использовать чаще всего.

Цикл `for` используют для случаев с заранее известным количеством повторений цикла. В условии цикла создаётся переменная-счётчик, записывается условие выполнения цикла и то, как должен меняться счётчик повторений. Это позволяет чётко описать условие цикла и не сделать ошибок, как с циклом `while`, которые приводят к бесконечным циклам.

В коде цикл выглядит так:

```javascript
for (переменная цикла и её исходное значение; условие выполнения цикла; изменение переменной после каждого повтора) {
    // тело цикла
}
```

Выражение в круглых скобках `(...)` состоит из трёх частей:

1. Сперва задаётся переменная `let i = 0`
2. Затем условие выполнения цикла `i < 5`
3. И в конце — как переменная должна меняться после каждого повторения `i + 1`

Разберём подробнее начиная со второй части — условия. В цикле `for` условие всегда связано с особой переменной — счётчиком цикла.

**Счётчик цикла** — переменная, которая определяет число повторений. В начальной точке цикла мы задаём первоначальное значение этой переменной, а затем проверяем перед каждой итерацией, соответствует ли счётчик цикла условию. Если соответствует, цикл совершает ещё одно повторение. Если нет — не совершает.

Последняя часть внутри круглых скобок — шаг изменения переменной. Он определяет, насколько счётчик цикла изменяется после каждого повторения.

Таким образом:

- сначала мы задаём исходное значение счётчика, `let count = 0`
- затем устанавливаем условие выполнения цикла, `count < 5` — условие цикла: пока `count` меньше 5, счётчик будет выполняться.
- И затем описываем, как счётчик цикла меняется при каждом повторе. `count = count + 1` — определяет, насколько увеличивается переменная `count` после каждого повторения  (`count++` — аналогичная запись, подробнее с инкрементом можно ознакомиться [тут](https://ru.wikipedia.org/wiki/Инкремент){target="_blank"}).

Вот как будет выглядеть наш код по созданию предсказания с изученным циклом:

```javascript
for (let count = 0; count < 5; count = count + 1) {
		getRandomElementFromArray(emojis) // функция получения emoji
		displayEmoji() // функция вывода на экран emoji
}
```
