Массивы

{video:https://code.s3.yandex.net/kids-web/Untitled_Artwork_20.mp4}

Ты уже знаешь про такие типы данных, как строка, числовой и логический типы, но что если Аски решит сохранить не одну Собаку в переменную, а всю коробку щенят?

Такая коллекция однотипных элементов, чисел, строк (в нашем случае животных) и других типов данных называется **Array** (c английского «множество, массив»).

С удовольствием!

Допустим, нам нужно перечислить самые популярные имена собак, чтобы назвать всех в коробке. Если записывать каждую кличку в отдельную переменную, получится громоздко:

let dog1 = "Полкан";
let dog2 = "Бим";
let dog3 = "Бобик";
let dog4 = "Дружок";
let dog5...

Так работать с большим количеством переменных неудобно. Пока ищешь определённое имя, разбираясь в названиях и их соответствии, можно потерять что-нибудь важное.

Массив решает эту проблему:

let dogs = ["Полкан", "Бим", "Бобик", "Дружок", "Шарик", "Пират", "Барбос", "Мухтар", "Рекс", "Джек", "Тоби"];

Попробуй самостоятельно тоже (в комментариях песочницы, как обычно, подсказки) 👇🏻

**Основные фишки массива:**

- Массив создаётся с помощью квадратных скобок `[]`, значения внутри скобок перечисляются через запятую:

let blackHole = []; // пустой массив
let names = ["Аски", "Цэ-Эс-Эсочка", "Ящерка", "Собака"] // массив имен
let numbers = [2, 4, 15, 36, 45, 87] // массив чисел

- В массиве можно хранить любые, даже не схожие друг с другом значения, в том числе и другие массивы:

let array = ["Аски", 23, true, ["Собака", "Ящерка"], "😇"];

Но чаще его используют именно для однотипных данных. В коде, как и во всём остальном, порядок очень упрощает жизнь. Представь, как неудобно искать тарелку в кухонном шкафу, если там лежит не только посуда, но и коньки, документы, детские игрушки и всё в таком духе.

- У массива есть длина, она показывает общее число элементов. Чтобы её узнать, достаточно к массиву через точку `.` дописать слово — `length` (с английского  «длина»):

let names = ["Аски", "Цэ-Эс-Эсочка", "Ящерка", "Собака"];
array.length // 4 - длина массива names, так как в нём четыре элемента.

- Обращаясь к массиву с указанием номера элемента в квадратных скобках, можно получить значение этого элемента, но нужно помнить, что отсчёт начинается с 0:

let names = ["Аски", "Цэ-Эс-Эсочка", "Ящерка", "Собака"];
names[0] // "Аски" - элемент массива №0
names[1] // "Цэ-Эс-Эсочка" - элемент массива №1
names[3] // "Собака" - элемент массива №3

В следующих уроках.

А пока поздравляем, теперь ты знаешь как работать с массивами.
