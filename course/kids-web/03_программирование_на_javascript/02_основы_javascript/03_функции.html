Функции

Теперь ты умеешь сохранять данные в переменные.

Следующий шаг — дать компьютеру инструкции, что с этими данными сделать. За это отвечают функции. В этом уроке ты узнаешь, что это такое, как их вызывать и записывать.

Обычно нам нужно, чтобы программы выполняли много действий.

Именно. То, что ты сейчас описал, Аски, в программировании называют **функцией.** Они создаются, чтобы не прописывать один и тот же код несколько раз.

И теперь, чтобы Собака принесла нам мяч, достаточно вызвать функцию.

собакаПринесиМяч()

Кстати, помни, что это только пример, в реальном коде кириллические символы не прокатят.

А теперь допустим, что мы хотим выбрать цвет мяча, который принесёт Собака, и персонажа, которому она его принесёт. Для этого можно указать **параметры** — данные внутри тела функции.

Они указываются в круглых скобках после названия функции и затем в списке действий:

![](https://pictures.s3.yandex.net:443/resources/Untitled_Artwork-3_4_1700762124.png)

Теперь мы можем менять запрос, передав функции необходимые значения для указанных параметров — **аргументы**.

Предположим, для параметра `цветМяча` аргумент будет `yellow`, а для параметра `персонаж` — `Цэ-эс-эсочка`. Тогда вызов функции будет выглядеть так:

![](https://pictures.s3.yandex.net:443/resources/js_dog_collar_1700055222.png)

В ошейнике оказалась полезная штука — функции для получения предсказания, они называются:

`getRandomElementFromArray` — достаёт случайный элемент массива.

`displayTitle` — выводит текст астрологического гороскопа.

`displayEmoji` — выводит полученный эмодзи.

Сейчас ты будешь вызывать их в песочнице. Погнали по шагам, что тебе нужно сделать!

Шаг 1

Найди функцию `getRandomElementFromArray` — она возвращает случайный элемент массива, переданного ей аргументом.

Шаг 2

Получи с помощью функции `getRandomElementFromArray` случайный эмодзи. Для этого вызови функцию, передав ей массив эмодзи `emojis`. Как вызывать функцию, мы обсуждали в начале урока. Запиши эмодзи в переменную `randomEmoji`

Шаг 3

Получи с помощью функции `getRandomElementFromArray` случайный астрологический заголовок. Для этого вызови функцию, передав ей массив эмодзи `astrologyTitles`. Запиши заголовок в переменную `randomTitle`

Шаг 4

Используй функцию `displayEmoji`, чтобы показать полученный случайный эмодзи. При вызове функции передай аргументом эмодзи, записанный в переменной `randomEmoji`

Шаг 5

Используй функцию`displayTitle`, чтобы показать полученный заголовок. При вызове функции передай аргументом заголовок, записанный в переменной `randomTitle`

Ееее! Теперь ты знаешь, что функции — это блоки программы, в которых хранится сразу несколько команд, а ещё тебе удалось продвинуться в работе над проектом недели — сайтом с гаданием по эмодзи. `console.log(”молодец!”)`, что сказать.

На следующей неделе мы вернёмся к этой теме, и ты научишься писать свои функции.
