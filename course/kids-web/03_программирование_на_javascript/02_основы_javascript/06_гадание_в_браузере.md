### Шаг 3: Добавление пяти эмодзи с помощью цикла

Теперь с помощью цикла необходимо добавить на страницу пять эмодзи. В одном из уроков упоминались функции, которые помогут тебе справиться с этой задачей:

- `getRandomElementFromArray` — функция, которая достаёт из массива случайный элемент.
- `displayEmoji` — функция для добавления эмодзи на страницу.

Чтобы добавить несколько эмодзи, можно использовать цикл. Попробуй сделать это самостоятельно, поскольку циклы — очень важный инструмент для работы с JS.

```javascript
/* 
Вот что происходит в этом цикле:
	1. Создаём переменную count
	2. Добавляем условие, что цикл должен повторяться, пока значение count меньше пяти
	3. При каждом шаге цикла увеличиваем count на один
*/
for (let count = 0; count < 5; count = count + 1) {
		let emoji = getRandomElementFromArray(emojis); // функция получения emoji — сохрани его в переменную
		displayEmoji(emoji); // функция добавления emoji на страницу
}
```

### Шаг 4. Показать предсказание

Остался последний шаг — показать случайное предсказание на странице. Вот функции, которые тебе понадобятся:

- снова `getRandomElementFromArray`, чтобы достать из массива случайный элемент.
- `displayTitle` — функция для отображения названия.

Чтобы вывести на экран предсказание, тебе нужно получить случайный элемент из массива предсказаний, записать его в переменную, а затем вызвать функцию для отображения названия.

```javascript
let title = getRandomElementFromArray(titles);
displayTitle(title);
```
