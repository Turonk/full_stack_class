### **Ключевые слова**

Чтобы сохранить переменную в памяти компьютера для дальнейшей работы с ней, её нужно объявить в коде. Раньше для этого использовалась команда `var`, но этот способ уже устарел. 

Ему на смену пришли ключевые слова `let` и `const`: 

- `let` объявляет переменную, значение которой можно **перезаписать или не указывать** вообще.
- `const` используют, когда важно, чтобы переменной было присвоено определённое значение и оно ни в коем случае не менялось, то есть было постоянным. Константы защищают код от случайной перезаписи важных значений.
Попытка изменить значение константы приведёт к ошибке в коде: 

```javascript
const dogName = "Собака";
// При изменении значения JavaScript выдаст ошибку:
dogName = "Кошка"; // Uncaught TypeError: Assignment to constant variable.
```

### **Правила именования переменных**

Название переменной дают таким образом, чтобы по нему было понятно, какие данные она хранит. 

Можно использовать: 
— буквы латинского алфавита
— цифры
— символы `$` и `_`

Нельзя использовать:
— цифру в качестве первого символа переменной
— зарезервированные ключевые слова (это не только `let` и `const`, но и слова с другим функционалом — полный список можно посмотреть [тут](https://developer.mozilla.org/ru/docs/Web/JavaScript/Reference/Lexical_grammar#зарезервированные_ключевые_слова_в_ecmascript_2015){target="_blank"})

Ты еще можешь встретить переменные, которые объявлены с помощью `const`, а их имена записаны с заглавных букв. ```

### Значения переменных

Значения переменных устанавливают с помощью оператора присваивания `=`

После равно в коде может быть восемь основных типов данных, но на этом этапе тебе достаточно знать три основных (остальное — по [ссылке](https://developer.mozilla.org/ru/docs/Web/JavaScript/Data_structures){target="_blank"}):

1. **String/Строка**
Строка в JavaScript должна быть заключена в кавычки. Всё, что обрамлено кавычками (одно слово или несколько, различные символы и цифры), JavaScript интерпретирует как строку. Кавычки можно использовать разные:

```javascript
let str = "Hello"; // двойные
let str2 = 'World'; // одинарные 
let greeting = `Hello World` // обратные 
let number = "+7(987)654-32-10" // обрати внимание, это тоже строка (хоть и с числами), потому что в кавычках
```

2. **Number/Число** 
Числовой тип данных представляет целые или дробные числа:

```javascript
let n = 43;
n = 1.2;
```

- **Boolean / Логический тип**
Булевый, или логический, тип может принимать только два значения: `true` (истина) и `false` (ложь). 
Примеры использования:
а) При поиске чёрных кроссовок на маркете ты можешь установить фильтр сортировки товаров, для программы это выглядит так: `let isBlack = true` 
б) Когда создаёшь новый никнейм в программе (почте, социальной сети, онлайн-игре), он проверяется на уникальность, и, если он уникальный, возвращается `true` и ник сохраняется, либо `false` — тогда нужно придумывать незаюзанный.

```javascript
let isLogin = true; // переменная показывает, прошёл ли пользователь регистрацию (да)
let isClient = false; // а здесь показывает, является ли пользователь клиентом (нет)
```

Намёк поняли! Точка с запятой (`;`) в языках программирования нужна для разделения инструкций. Можно было бы просто перенести на другую строку, но в JavaScript это не всегда интерпретируется правильно и может привести к ошибкам. Поэтому точки с запятой должны присутствовать после каждого выражения, даже если они отделены переносами строк. Это правило широко используется в сообществе разработчиков.

3. Существует ряд правил для именования переменных, при несоблюдении которых программа выдаст ошибку.
