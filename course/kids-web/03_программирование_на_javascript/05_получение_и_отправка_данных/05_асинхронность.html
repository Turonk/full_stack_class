Асинхронность

![](https://pictures.s3.yandex.net:443/resources/Untitled_Artwork_24_1703163638.gif)

Когда ты работаешь с JavaScript, твой код выполняется постепенно — одна команда за другой. Это называется **синхронным** выполнением кода. Браузер не может приступить к следующей команде, пока не выполнится начатая ранее (блокирующая) команда.

Но, как ты помнишь, серверу нужно время, чтобы получить запрос и отправить ответ. Представь, что на это время блокируется исполнение кода: в таком случае использование сайта было бы малоприятным 🥴

Чтобы справиться с проблемой блокирующего кода, в JavaScript существуют **промисы** (от английского promise — «обещание»). Это специальная штука для работы с **асинхронным** кодом (то есть для таких команд, результаты которых будут доступны не сразу).

![](https://pictures.s3.yandex.net:443/resources/Untitled_Artwork_601_1703235575.png)

**Промисы** — результат работы асинхронных функций (примером одной из таких функций является `fetch()`, о которой мы говорили в предыдущем уроке). Посмотрим на нашем примере запроса к серверу. Если мы выведем в консоль функцию `fetch` с запросом к серверу с карточками, то увидим промис👇🏻

console.log(
  fetch("https://api-code.practicum-team.ru/heroes?_where[_or][0][studentEmail]=${studentEmail}&_where[_or][1][studentEmail]=")
);

![](https://pictures.s3.yandex.net:443/resources/Frame_1375_1703163733.png)

Разберём этот промис внимательнее.

У всех промисов есть три состояния:

1. `pending` (состояние в начале операции) 2. `fulfilled` (результат получен) 3. `rejected` (ошибка, и результат не получен)

У промиса, появившегося после нашего запроса к серверу, состояние `fulfilled` — значит, запрос прошёл и ответ был успешно получен.

Если с запросом что-то не так и он не выполняется, промис перейдёт в состояние `rejected`. На примере ниже запрос не проходит из-за выключенного интернета: промис не получает результат с сервера и переходит в состояние `rejected` 👇🏻

![](https://pictures.s3.yandex.net:443/resources/Frame_1376_1_1_1703272398.png)

Мы подробно опишем, как работать с промисами, на примере функции `fetch`, если захочешь узнать больше, то почитай статью в [Доке](https://doka.guide/js/promise/){target="_blank"}.

Для этого нужно воспользоваться особенной функцией для промисов: `then`. Мы уже показывали код с `then` в прошлом уроке, там использовали его для обработки результатов запроса.

В функции `then` мы описываем, что делать в случае успешного запроса. Результат запроса доступен как аргумент этой функции, обычно для обращения к нему используют название `response`

Выглядит это так:

// Делаем запрос к серверу
fetch("https://api-code.practicum-team.ru/heroes?_where[_or][0][studentEmail]=${studentEmail}&_where[_or][1][studentEmail]=")
	// В then описываем, что делать в случае успешного запроса
	// В параметре response хранится ответ сервера
  .then((response) => {
    console.log(response);
    return response;
  })

В ответ от сервера приходит `Response` — данные о произошедшем запросе 👇🏻

![](https://pictures.s3.yandex.net:443/resources/Frame_1368_1_1703272449.png)

Чтобы достать из этого сообщения полученные данные, тебе нужно воспользоваться функцией `json()`. Она преобразует ответ в формат JSON, который мы можем использовать на клиенте.

Получится такая конструкция:

fetch("https://api-code.practicum-team.ru/heroes?_where[_or][0][studentEmail]=${studentEmail}&_where[_or][1][studentEmail]=")
  .then((response) => {
    return response.json();
  })

И кстати, ты можешь создавать цепочки из `.then()`, в таком случае в каждом следующем `then` будет доступен результат из прошлого! В примере ниже это работает так:

- `then` 1: Мы обрабатываем результат запроса к серверу с помощью функции `json()` и возвращаем то, что передал сервер - `then` 2: А теперь мы берём результат первого `then` и выводим его в консоль

fetch("https://api-code.practicum-team.ru/heroes?_where[_or][0][studentEmail]=${studentEmail}&_where[_or][1][studentEmail]=")
  .then((response) => {
		// Получаем запрос и достаём оттуда данные
    return response.json();
  })
	// Выводим полученные в первом then данные в консоль
	.then((response) => console.log(response));

Теперь в консоли мы видим полученные с сервера данные 👇🏻

![](https://pictures.s3.yandex.net:443/resources/Frame_1377_2_1703163874.png)

Данные удалось получить, но никто не застрахован от ошибки. Как раз на случай ошибок есть функция `catch` — с её помощью мы можем предупредить пользователя или описать, в чём проблема (например, вывести информацию об ошибке в консоль).

fetch("https://api-code.practicum-team.ru/heroes?_where[_or][0][studentEmail]=${studentEmail}&_where[_or][1][studentEmail]=")
  .then((response) => {
		// Получаем запрос и достаём оттуда данные
    return response.json();
  })
	// Выводим полученные в первом then данные в консоль
	.then((response) => console.log(response));
	// В catch описываем, что делать в случае ошибки
	// В параметре e хранится сообщение об ошибке
	.catch((e) => console.log(e));
