Тип данных **«Объект»**

В предыдущих уроках мы рассматривали простые типы данных, такие как `string` (строка), `number` (число), `boolean` (логический тип данных). Все эти типы крайне важны, ведь всё вокруг нас так или иначе состоит из простых, примитивных данных.

Но если присмотреться к окружающему миру чуть пристальнее, можно заметить, как эти простые значения вокруг нас объединяются в группы, в нечто большее. Поэтому пора поговорить про сложные типы данных: объект — один из них (и фух, пока нам хватит только его).

**Объект** — это сущность, которая может хранить в себе различные данные: простые значения, функции и даже другие объекты. Кстати, с одним из подвидов объекта — массивом — мы уже знакомились на прошлой неделе.

Объект состоит из набора свойств. Каждое свойство состоит из названия и значения. Название может быть строкой `string`, а значение — любым.

Прекрасное знание фольклора, поощрим тебя примерами! Так точно станет понятнее.

Всё вокруг нас можно описать объектом:

1. Твоего верного друга из сторитела👇🏻

2. Любимый фильм 👇🏻

const movie = {

Возможно, вам двоим удалось заметить, что объекты объявляют ключевым словом `const`. Это связано с тем, что обычно после создания объекта мы будем менять лишь его «внутренности»: добавлять, модифицировать и удалять отдельные свойства объекта.

Чтобы создать объект, достаточно использовать фигурные скобки. Точно так же, как и с массивом, только другой вид скобок:

const student = {};

А теперь наглядно покажем, почему **объекты — это удобно**.

Представим, что нам нужно заполнить информацию о студенте: имя, ник, почта, возраст. Используя простые типы данных, нам пришлось бы объявлять множество переменных:

let studentName = "Пальто";
let studentNickname = "Нечушпан";
let studentEmail = "palto@slovopacana.com";
let studentAge = 14;

Получается, мягко говоря, по-чушпански.

Представь, что нужно заполнить данные о каком-то сложном объекте, например полную анкету пользователя социальной сети. В ней должно быть очень много полей: имя, никнейм, город, фото профиля и так далее. Создавать столько переменных — очень плохая идея. Как раз тут нас и выручают объекты.

Когда нужно создать объект со свойствами, их описывают внутри фигурных скобок.

Свойства указываются в формате `имяСвойства : значение,`, между свойствами ставится запятая:

const student = {
	//Имя свойства – name ; значение – "Пальто"
	name: "Пальто",
	nickname: "Нечушпан",
	email: "palto@slovopacana.com",
	age: 14,
	// Остальные 100500 полей очень подробной формы
};

В объектах **свойство** — это пара «ключ: значение», где `ключ` — это строка, а значениями ключей могут быть:

- строки `title: "Пальто",` - числа `str: 30,` - логические значения - объекты `attributes: {…},` и массивы

Таким образом, данные отлично структурированы, их легко найти и обработать.

Обмен данными и JSON

Учитывая возможную разницу в языках фронтенда и бэкенда сайта, для передачи данных были разработаны специальные форматы. Самый распространённый из них — JSON**.**

**JSON** расшифровывается как **JavaScript Object Notation** — текстовый формат обмена данными.

Вот как выглядит персонаж проекта в формате JSON:

[
  {
		"additionalStat": null, 
		"agi": 70,
		"created_at": "2023-12-18T16:19:02.032Z", 
		"description": "Лунная призма, дай мне силу, пожалуйста.", 
		"hp": 100, 
		"id": 2, 
		"int": 90, 
		"name": null, 
		"published_at": "2023-12-18T16:20:37.767Z", 
		"str": 50,  
		"title": "Цэ-эс-эсочка", 
		"updated_at": "2023-12-19T18:02:28.719Z"
	}
]

Похоже на объект в JS, о котором мы говорили выше, не так ли? Только обрати внимание, что имена свойств взяты в двойные кавычки — в JSON-формате это обязательно.

Все данные, которыми необходимо делиться с сервером, на клиенте хранятся в объектах. Для передачи информации в запросе к серверу её необходимо преобразовать в универсальный формат JSON, так сервер сможет её обработать. А при ответе от сервера клиент получает данные в виде JSON, которые нужно преобразовать в объект.

![](https://pictures.s3.yandex.net:443/resources/IMG_4251_1703234372.png)

Для преобразования объекта в строку формата JSON и обратно нам понадобятся две функции: **`JSON.stringify`** и **`JSON.parse`**, которым мы передадим данные в качестве аргумента функции.

Функция `JSON.stringify` делает из объекта JSON и используется для отправки данных на сервер:

// Переменная с объектом, который надо отправить на сервер
const hero = {
	additionalStat: null, 
	agi: 70, 
	created_at: "2023-12-18T16:19:02.032Z", 
	description: "Лунная призма, дай мне силу, пожалуйста.", 
	hp: 100, 
	id: 2, 
	int: 90,
	name: null, 
	published_at: "2023-12-18T16:20:37.767Z", 
	str: 50, 
	title: "Цэ-эс-эсочка",
	updated_at: "2023-12-19T18:02:28.719Z"
}

// Формируем из объекта JSON и записываем в переменную heroesJSON для отправки на сервер
const heroJSON = JSON.stringify(hero);

Функция `JSON.parse` преобразует JSON, который пришёл с сервера, в объект:

// Преобразуем JSON, который пришёл с сервера, в объект 
const heroesObject = JSON.parse(heroJSON);

Важно, что в функцию `JSON.parse` можно передавать только объект, где свойства и значения — это строки, и они должны быть в двойных кавычках.

JSON.parse('Любая строка или число'); // Ошибка

Ну вот теперь вы с Аски точно готовы к работе с данными на фронтенде!

**Обращение к свойствам объекта**

К свойствам объекта можно обращаться — читать или записывать значение в них.

Чтобы обратиться к свойству объекта, нужно написать название объекта и нужное свойство через точку. Например, если нам нужно свойство `id` объекта `hero`, то обращение к нему будет выглядеть так: `hero.id`

Вот более развёрнутый пример:

const hero = {
	additionalStat: null, 
	agi: 70, 
	created_at: "2023-12-18T16:19:02.032Z", 
	description: "Лунная призма, дай мне силу, пожалуйста.", 
	hp: 100, 
	id: 2, 
	int: 90,
	name: null, 
	published_at: "2023-12-18T16:20:37.767Z", 
	str: 50, 
	title: "Цэ-эс-эсочка",
	updated_at: "2023-12-19T18:02:28.719Z"
};

console.log(hero.id) // 2
// Обратившись к свойству title, увидим в консоли значение этого свойства
console.log(hero.title) // "Цэ-эс-эсочка"
// Таким же образом можно перезаписать значение свойства
hero.title = "Аски";
console.log(hero.title) // "Аски"

Если обратиться к несуществующему свойству объекта, увидим `undefined`. Это значит, что такого значения для указанного свойства попросту нет.

hero.power // undefined

В большинстве случаев свойство в объекте — строка. И строгие правила для именования на них не действуют, как с именами переменных. Они могут содержать пробелы, любые слова, символы — такие свойства оборачивают в кавычки. Поэтому через точку к ним не достучаться:

const hero = {
	additionalStat: null, 
	agi: 70, 
	created_at: "2023-12-18T16:19:02.032Z", 
	description: "Лунная призма, дай мне силу, пожалуйста.", 
	hp: 100, 
	id: 2, 
	int: 90,
	name: null, 
	published_at: "2023-12-18T16:20:37.767Z", 
	str: 50, 
	title: "Цэ-эс-эсочка",
	updated_at: "2023-12-19T18:02:28.719Z",
	"защита от магии": 26.6,
	"45+урона": true,
};

hero.защита от магии; // Ошибка
hero.45+урона; // Ошибка

На этот случай есть второй способ — универсальный. В нём нужно передать имя свойства в кавычках и квадратных скобках, вот так:

hero["title"]; // "Цэ-эс-эсочка"
hero["защита от магии"]; // 26.6
hero["45+урона"]; // true

На сегодня, пожалуй, достаточно информации про объекты, этого хватит для выполнения проекта и погружения в обмен данными с сервером.

Теперь нам нужно получить из объекта `hero` значение свойства `title` и разместить его в теге `<h2 class="card-title-text">${hero.title}</h2>`. В этом нам помогут шаблонные строки — так мы отобразим имя персонажа. Далее информацию из свойства `description` таким же образом разместим в теге `<p class="card-description-text">${hero.description}</p>`

Шаг за шагом мы внесём характеристики персонажа в заготовленную вёрстку карточки, а затем вставим карточку в веб-страницу.

// Заполним вёрстку карточки данными 
// из значений свойств объекта 
const cardHtml = `
	<div class="card-wrapper">
	  <div class="card">
	    <div class="card-title">
	      <h2 class="card-title-text">${hero.title}</h2>
      </div>
      <div class="card-description">
	      <p class="card-description-text">${hero.description}</p>
        <div class="card-parameters">
	        <div class="card-parameter">
	          <p class="card-parameter-title">str</p>
	          <p class="card-parameter-value">${hero.str}</p>
          </div>
          <div class="card-parameter">
            <p class="card-parameter-title">agi</p>
            <p class="card-parameter-value">${hero.agi}</p>
          </div>
          <div class="card-parameter">
	          <p class="card-parameter-title">hp</p>

          </div>
          <div class="card-parameter">
	          <p class="card-parameter-title">int</p>
            <p class="card-parameter-value">${hero.int}</p>

Тут вспоминаем наш проект с гаданием по emoji. Нам достаточно пройти по массиву `heroes` циклом. На каждой итерации цикла нужно доставать объект персонажа из массива (для удобства сохраним его в переменную `hero`) и передавать его значения свойств в вёрстку:

// Находим контейнер для карточек в вёрстке по идентификатору id = 'cards-container'
const container = document.getElementById('cards-container'); 

// Передаём массив с данными аргументом в функцию отрисовки карточек
function renderCards(heroes) {
    // Очищаем контейнер для карточек
    container.innerHTML = "";

    //  В цикле достаём из каждого объекта данные о персонаже и вставляем вёрстку карточки
    for (let i = 0; i < heroes.length; i++) {
        let hero = heroes[i];

        // Создаём вёрстку карточки и вставляем значения характеристик персонажа
        const cardHtml = `
        <div class="card-wrapper">
            <div class="card">
                <div class="card-title">
                    <h2 class="card-title-text">${hero.title}</h2>
                </div>
                <div class="card-description">
                    <p class="card-description-text">${hero.description}</p>
                    <div class="card-parameters">
                        <div class="card-parameter">
                            <p class="card-parameter-title">str</p>
                            <p class="card-parameter-value">${hero.str}</p>
                        </div>
                        <div class="card-parameter">
                            <p class="card-parameter-title">agi</p>
                            <p class="card-parameter-value">${hero.agi}</p>
                        </div>
                        <div class="card-parameter">
                            <p class="card-parameter-title">hp</p>
                            <p class="card-parameter-value">${hero.hp}</p>
                        </div>
                        <div class="card-parameter">
                            <p class="card-parameter-title">int</p>
                            <p class="card-parameter-value">${hero.int}</p>
                        </div>
                    </div>
                </div>
            </div>
        </div>
    `;

        // Добавляем вёрстку карточки в контейнер
        container.innerHTML += cardHtml;
    }
}

Теперь мы знаем, что данные передаются между клиентом и сервером в особом формате, и умеем с этим форматом работать. А вот о том, какая функция в JavaScript помогает отправлять запросы, как она устроена и что нужно сделать для отправки запроса, поговорим в следующем уроке.
