Исправить это поможет отправка данных на сервер и сохранение данных о новых карточках. При обновлении страницы будет происходить запрос на сервер — а сервер будет отдавать уже обновлённые данные, которые мы сможем показывать вместо стартового набора карточек.

Сначала предстоит заменить текстовые поля ввода на форму со специальным тегом в вёрстке — так можно получить более крутой функционал. Затем нужно научиться получать данные о персонаже через новую форму и отправлять их на сервер для сохранения и обновления списка героев. 

Лови мини-план для получения данных через форму:

- собрать данные из формы в объект
- сформировать JSON
- отправить данные на сервер

## Формы и как собрать данные

В уроке прошлой недели мы с тобой уже получали данные из тегов `<input>` и обновляли нашу переменную с карточками.

На нашем сайте была такая вёрстка:

```javascript
<!DOCTYPE html>
<html>
<head>
    <title>КарП</title>
</head>
<body>
    <input type="text" id="heroName" placeholder="Имя героя">
    <input type="text" id="heroClass" placeholder="Класс героя">
    <button id="addButton">Добавить героя</button>
		<div id="heroesContainer"></div>
    <script src="script.js"></script>
</body>
</html>
```

Как ты можешь заметить, в ней находятся два одиноких тега `<input>` и кнопка, при помощи которой мы получали данные из полей ввода и сохраняли их в переменную. 

В этот раз у нас более сложная вёрстка с большим количеством тегов:

```javascript
<!DOCTYPE html>
<html lang="en">
```

В таком случае можно запутаться и упустить важные данные. Лучшей практикой считается объединять подобные поля ввода в отдельные **формы**. 

Ты сталкиваешься с кучей форм в интернете, настала пора познакомиться с ними поближе и научиться создавать их самостоятельно.

**Формы** — основной инструмент для получения информации от пользователя. Создание профиля в соцсети, страница оплаты заказа в интернет-магазине, окно загрузки файла в облачных хранилищах — всё это делается с помощью форм.

Чтобы создать форму, достаточно обернуть нашу вёрстку с полями ввода и кнопкой в тег `<form>`:

```html
<!DOCTYPE html>
<html lang="en">
    <head>
        <meta charset="UTF-8" />
        <meta name="viewport" content="width=device-width, user-scalable=no, initial-scale=1.0, maximum-scale=1.0, minimum-scale=1.0"/>
        <meta http-equiv="X-UA-Compatible" content="ie=edge" />
        <title>КарП</title>
        <link rel="preconnect" href="https://fonts.googleapis.com" />
        <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
        <link href="https://fonts.googleapis.com/css2?family=Roboto+Mono:wght@300;400;700&display=swap" rel="stylesheet"/>
        <link rel="stylesheet" href="styles.css" />
    </head>
    <body>
        <header>
            <div class="container">
                <h1 class="page-heading">КарП</h1>
            </div>
        </header>
        <main class="container">
            <section class="form-wrapper">
								<!-- Тут установим тег form -->
                <form name="addHero" class="form">
                    <input class="form-input" type="text" name="title" id="title" required placeholder="Имя героя"/>
                    <input class="form-input" type="text" name="description" id="description" required placeholder="Описание"/>
                    <div class="form-parameters">
                        <input class="form-input parameter-input" type="number" name="str" id="str" min="1" max="99" placeholder="Сила" />
                        <input class="form-input parameter-input" type="number" name="agi" id="agi" min="1" max="99" placeholder="Ловкость" />
                        <input class="form-input parameter-input" type="number" name="hp" id="hp" min="1" max="100" placeholder="Очки жизни" />
                        <input class="form-input parameter-input" type="number" name="int" id="int" min="1" max="99" placeholder="Интеллект" />
                    </div>
                    <button class="form-button" id="addHero">Добавить героя</button>
                </form>
								<!-- Тут установим тег form -->
            </section>
            <section class="cards" id="cards-container"></section>
        </main>
        <script src="script.js"></script>
    </body>
</html>
```

Он позволяет объединить интерактивные элементы в один логический блок — так удобнее обрабатывать информацию. Теперь данные из формы ты сможешь доставать из всемогущей переменной `document`. Для этого тебе надо будет просто обратиться к ней через точку. Например, достать все формы, имеющиеся на странице, ты можешь так: `document.forms`

Если форм несколько, проще будет различать их по уникальному названию. Давай и мы дадим нашей форме имя: `<form name="addHero">`. Так её можно будет найти по имени: `document.forms.addHero`

### Поля ввода и кнопки

В формах бывают различные теги `<input>`, и, чтобы проще было их распознавать, им дают имена. В нашем случае просто скопируем их из идентификаторов `id`:

```javascript
<form name="addHero" class="form">
	<input class="form-input" type="text" name="title" id="title" required placeholder="Имя героя"/>
	<input class="form-input" type="text" name="description" id="description" required placeholder="Описание"/>
	<div class="form-parameters">
		<input class="form-input parameter-input" type="number" name="str" id="str" min="1" max="99" placeholder="Сила" />
		<input class="form-input parameter-input" type="number" name="agi" id="agi" min="1" max="99" placeholder="Ловкость" />
		<input class="form-input parameter-input" type="number" name="hp" id="hp" min="1" max="100" placeholder="Очки жизни" />
		<input class="form-input parameter-input" type="number" name="int" id="int" min="1" max="99" placeholder="Интеллект" />
	</div>
	<input class="form-input" type="email" name="studentEmail" id="studentEmail" placeholder="student@yandex.ru" />
  <button class="form-button" id="addHero">Добавить героя</button>
</form>
```

Кнопки в формах также бывают разные, вот три основных типа:

1. Отправка формы на сервер (при нажатии на кнопку происходит событие `submit`)
2. Сброс полей ввода (происходит событие `reset`)
3. Прочее (нет события по умолчанию, можно назначить на кнопку что угодно с помощью `addEventListener`)

По умолчанию любая кнопка внутри формы имеет тип `submit`. И при нажатии на кнопку происходит событие `submit`. Оно же происходит и при нажатии Enter, если пользователь находится в одном из полей формы. Поэтому дополнительные обработчики нажатия клавиш для `submit` делать не нужно. 

Чаще всего цель формы — отправить данные на сервер для их обработки. Прямо перед отправкой происходит событие `submit`: оно перезагружает страницу.

При необходимости в обработчике события `submit` отменяют стандартную отправку на сервер и проверяют данные, которые ввёл пользователь, или преобразуют их нужным образом:

```javascript
const form = document.forms.addHero; // Получаем форму

// Вешаем на неё обработчик события submit
form.addEventListener('submit', function (evt) {
  // Отменяем стандартное поведение
  evt.preventDefault();
  // Выполняем какие-то действия с данными:
	// например, проверяем данные пользователя или как-то их преобразовываем
});
```

Если в обработчике события `submit` вызвать `evt.preventDefault`, то перезагрузки страницы и стандартной отправки данных не произойдёт.

Элементы формы лежат внутри самой формы в свойстве `elements`, поэтому их тоже легко получить из переменной `document`

```javascript
const form = document.forms.addHero; // Получаем форму
form.elements.title // <input type="text" name="title" ...
form.elements.description // <input type="text" name="description" ...
```

## Отправка данных на сервер

Давай соберём всё, что обсудили, в единую картину — можешь потренироваться в VSCode, а мы пошагово расскажем, что должно быть в коде.

### Шаг 1

Получаем форму и поля ввода. Всё можно найти внутри переменной `document`:

```javascript
//Получение элементов формы
const form = document.forms.addHero; // Получаем форму
const titleInput = form.elements.title; // Получаем поле с именем
const descriptionInput = form.elements.description; // Получаем поле с описанием
const strInput = form.elements.str; // Получаем поле с уровнем силы
const agiInput = form.elements.agi; // Получаем поле с уровнем ловкости
const hpInput = form.elements.hp; // Получаем поле с уровнем здоровья
const intInput = form.elements.int; // Получаем поле с уровнем интеллекта
```

### Шаг 2

За отправку данных по клику на кнопку или нажатие на клавишу `Enter` отвечает событие `submit` у формы. Установим слушатель для этого события и отменим стандартные процессы, происходящие при действии `submit`, так как нам нужно подготовить данные и сформировать запрос:

```javascript
form.addEventListener('submit', function (evt) {
  // Отменяем стандартное поведение
  evt.preventDefault();

  // Формируем данные и запрос
});
```

### Шаг 3

Каждый из элементов формы содержит свойство со значением, которое ввёл пользователь. В нашем случае текстовые поля формы хранят значения в свойстве `value`. Обратившись к ним, мы получим введённое пользователем значение:

```javascript
titleInput.value // "Цэ-эс-эсочка"
descriptionInput.value // "Лунная призма, дай мне силу, пожалуйста."
```

Соберём данные из полей ввода и создадим объект с новым персонажем:

```javascript
// Создаём объект с новым персонажем и записываем данные
let newHero = {
	title: titleInput.value,
  description: descriptionInput.value,
  str: strInput.value,
  agi: agiInput.value,
  hp: hpInput.value,
  int: intInput.value,
	// укажем тестовую почту для регистрации карточки
	studentEmail: "student@yandex.ru",

};
```

И с помощью известной нам функции `JSON.stringify()` сформируем JSON:

```javascript
let newHeroJSON = JSON.stringify(newHero);
```

Распаковав JSON, сервер сможет понять, что за информация к нему пришла, даже если сервер написан на другом языке программирования.

### Шаг 4

Самый сложный шаг — верно составить запрос на сервер. Из урока про функцию `fetch()` ты узнал про метод `POST`, который используется для информирования сервера, что нужно получить данные с клиента и сохранить их. А также ты уже умеешь добавлять файл к запросу в свойство `body` и с помощью свойства `headers` информировать сервер о типе передаваемых данных прямо в запросе. Давай запишем этот запрос:

```javascript
// Используем api нашего сервера 
fetch("https://api-code.practicum-team.ru/heroes", {
	method: "POST", // POST нужен для сохранения и записи данных
  body: newHeroJSON, // Тело запроса в JSON-формате
  headers: {
	  // Добавляем необходимые заголовки
	  "Content-type": "application/json; charset=UTF-8",
	},
})
	.then((response) => response.json())
	// Смотрим ответ сервера на наш запрос
  .then((data) => console.log(data))
```

### Шаг 5

После того как форма обработана, её поля обычно сбрасывают до исходных значений. Чтобы не сбрасывать каждое поле отдельно, у формы есть функция сброса полей `reset()`

```javascript
form.addEventListener('submit', function (evt) {
  // Отменяем стандартное поведение
  evt.preventDefault();
  // Формируем данные и запрос...

	// Сбрасываем все поля
	form.reset();
});
```

Если все сделать по шагам, то запрос благополучно отправится на сервер с новыми данными. Останется только проверить ответ от сервера: если он положительный, то можно обновить страницу сайта и посмотреть, какие данные к нам придут в этот раз!

```javascript
//Получение элементов формы
const form = document.forms.addHero; // Получаем форму
const titleInput = form.elements.title; // Получаем поле с именем
const descriptionInput = form.elements.description; // Получаем поле с описанием
const strInput = form.elements.str; // Получаем поле с уровнем силы
const agiInput = form.elements.agi; // Получаем поле с уровнем ловкости
const hpInput = form.elements.hp; // Получаем поле с уровнем здоровья
const intInput = form.elements.int; // Получаем поле с уровнем интеллекта

// Вешаем на форму обработчик события submit
form.addEventListener('submit', function (evt) {
  // Отменяем стандартное поведение
  evt.preventDefault();
	// Создаём объект с новым персонажем и записываем данные
	let newHero = {
		title: titleInput.value,
	  description: descriptionInput.value,
	  str: strInput.value,
	  agi: agiInput.value,
	  hp: hpInput.value,
	  int: intInput.value,
		// укажем тестовую почту для регистрации карточки
		studentEmail: "student@yandex.ru",

	};
	// Формируем JSON-строку из объекта
	let newHeroJSON = JSON.stringify(newHero);

	// Используем API нашего сервера 
	fetch("https://api-code.practicum-team.ru/heroes", {
		method: "POST", // POST нужен для сохранения и записи данных
	  body: newHeroJSON, // Тело запроса в JSON-формате
	  headers: {
		  // Добавляем необходимые заголовки
		  "Content-type": "application/json; charset=UTF-8",
		},
	})
		.then((response) => response.json())
		// Cмотрим ответ сервера на наш запрос
	  .then((data) => console.log(data))
		// Сбрасываем все поля
		form.reset();
});
```
