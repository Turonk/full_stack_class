1. Загрузим стартовый набор карточек персонажей и отобразим эти данные на сайте 2. Реализуем на сайте возможность добавить в стартовый набор карточек своих собственных персонажей

Есть такое, поэтому вот постепенный пошаговый алгоритм для сборки нашего проекта.

Загрузка и отображение данных стартового набора карточек

Шаг 1

Давай для начала разберёмся с тем, как сделать наш сайт персональным, чтобы не отвлекаться на карточки других студентов курса (а если, наоборот, хочется обсудить свои творения, го в дискорд).

Итак, сервер должен как-то отличать твои карточки от всех остальных. Для этого тебе нужно указать **свою** **электронную почту**, запишем её в коде проекта в JS-файле:

//Сохраняем почту для доступа к проекту
const studentEmail = "student@yandex.ru";

Чуть позже в проекте нам понадобится личная ссылка для работы с сервером. Запрос на получение карточек нужно отправлять по этой ссылке:


`https://api-code.practicum-team.ru/heroes?_where[_or][0][studentEmail]=${studentEmail}&_where[_or][1][studentEmail]=`

В ссылку передаётся переменная `studentEmail` — та самая почта, которую указали ранее. Именно так сервер поймёт, какой набор карточек принадлежит твоему проекту.

А теперь соберём логику проекта в JavaScript-файле!

Шаг 2

Найдём в начальной вёрстке проекта контейнер для отрисовки карточек и сохраним его в переменную для последующего использования в функциях. В этом тебе поможет переменная `document` и функция `getElementById`, в которую нужно передать строкой название идентификатора контейнера для карточек:

<div id="cards-container"></div>
// Контейнер для карточек
const container = document.getElementById("cards-container");

И объявим переменную, в которую будем записывать полученные от сервера данные:

// Переменная для хранения данных от сервера
let cards;

Шаг 3

При первом запуске проекта будем загружать данные о карточках с сервера. Используя функцию `fetch`, составим запрос на сервер для получения данных. Для этого передадим адрес для получения карточек с сервера :

fetch(`https://api-code.practicum-team.ru/heroes?_where[_or][0][studentEmail]=${studentEmail}&_where[_or][1][studentEmail]=`)
    .then((response) => response.json())
    .then((data) => {
        console.log(data); // В консоли можно исследовать полученные данные
				cards = data; // Запишем данные в переменную
        renderCards(cards); // Функция отрисовки полученных данных
    })
    .catch((error) => console.error("Ошибка:", error));

Шаг 4

Создадим функцию для генерации вёрстки карточки из полученных данных с сервера и отрисовки актуального набора карточек.

Функция должна принимать данные, полученные с сервера, — это будет массив объектов. Далее мы очистим содержимое контейнера для карточек, чтобы потом вставить актуальные данные, для этого при помощи свойства `innerHTML` присвоим контейнеру пустую строку: `container.innerHTML = '';`

При помощи цикла пройдём по всем элементам массива. Из каждого элемента (объекта с данными о персонаже) достанем свойства и, используя шаблонные строки, вставим каждое значение в нужное место в вёрстке карточки, а напоследок добавим вёрстку карточки в контейнер:

// Передаём массив с данными аргументом в функцию отрисовки карточек
function renderCards(heroes) {
    // Чистим контейнер для карточек
    container.innerHTML = "";

    //  В цикле достаём из каждого объекта данные о персонаже и вставляем в вёрстку карточки
    for (let i = 0; i < heroes.length; i++) {
        let hero = heroes[i];

        // Создаём верстку карточки и вставляем значения характеристик персонажа
        const cardHtml = `
        <div class="card-wrapper">
            <div class="card">
                <div class="card-title">
                    <h2 class="card-title-text">${hero.title}</h2>
                </div>
                <div class="card-description">
                    <p class="card-description-text">${hero.description}</p>
                    <div class="card-parameters">
                        <div class="card-parameter">
                            <p class="card-parameter-title">str</p>
                            <p class="card-parameter-value">${hero.str}</p>
                        </div>
                        <div class="card-parameter">
                            <p class="card-parameter-title">agi</p>
                            <p class="card-parameter-value">${hero.agi}</p>
                        </div>
                        <div class="card-parameter">
                            <p class="card-parameter-title">hp</p>
                            <p class="card-parameter-value">${hero.hp}</p>
                        </div>
                        <div class="card-parameter">
                            <p class="card-parameter-title">int</p>
                            <p class="card-parameter-value">${hero.int}</p>
                        </div>
                    </div>
                </div>
            </div>
        </div>
    `;
        // Добавляем вёрстку карточки в контейнер
        container.innerHTML += cardHtml;
    }
}

Теперь при каждом обновлении страницы браузер будет запрашивать данные с сервера и обновлять список карточек персонажей на актуальный.

Добавление персонажей

Шаг 1

Используем форму для заполнения данных о новом персонаже на сайте КарПа, через которую пользователь вносит информацию. Форма для добавления персонажа выглядит так:

<form name="addHero" class="form">
	<input class="form-input" type="text" name="title" id="title" required placeholder="Имя героя"/>
	<input class="form-input" type="text" name="description" id="description" required placeholder="Описание"/>
	<div class="form-parameters">
		<input class="form-input parameter-input" type="number" name="str" id="str" min="1" max="99" placeholder="Сила" />
		<input class="form-input parameter-input" type="number" name="agi" id="agi" min="1" max="99" placeholder="Ловкость" />
		<input class="form-input parameter-input" type="number" name="hp" id="hp" min="1" max="100" placeholder="Очки жизни" />
		<input class="form-input parameter-input" type="number" name="int" id="int" min="1" max="99" placeholder="Интеллект" />
	</div>
  <button class="form-button" id="addHero">Добавить героя</button>
	<p id="errorText"></p>
</form>

Шаг 2

Найдём и сохраним в переменные элементы формы, чтобы впоследствии собирать данные из формы:

//Получение элементов формы
const form = document.forms.addHero; // Получаем форму
const titleInput = form.elements.title; // Получаем поле с именем
const descriptionInput = form.elements.description; // Получаем поле с описанием
const strInput = form.elements.str; // Получаем поле с уровнем силы
const agiInput = form.elements.agi; // Получаем поле с уровнем ловкости
const hpInput = form.elements.hp; // Получаем поле с уровнем здоровья
const intInput = form.elements.int; // Получаем поле с уровнем интеллекта

Шаг 3

В момент срабатывания события `submit` на форме сформируем данные в объект и преобразуем их в формат `JSON` для отправки на сервер:

// Вешаем на форму обработчик события submit
form.addEventListener("submit", function (evt) {
    // Отменяем стандартное поведение
    evt.preventDefault();

    // Создаём объект с новым персонажем и записываем данные
    let newHero = {
				title: titleInput.value,
        description: descriptionInput.value,
        str: strInput.value,
        agi: agiInput.value,
        hp: hpInput.value,
        int: intInput.value,
				// Чтобы выделить карточки проекта, указываем почту 
        studentEmail: studentEmail,
    };
    // Формируем JSON-строку из объекта
    let newHeroJSON = JSON.stringify(newHero);
});

Шаг 4

Чтобы отправить данные на сервер, необходимо использовать функцию `fetch` с подходящими параметрами запроса.

Также при отправке новой карточки на сервер нужно будет добавить поле с почтой в объект с данными о карточке — переменную `studentEmail`. Так сервер сможет отличить твои карточки от всех остальных.

// Вешаем на форму обработчик события submit
form.addEventListener("submit", function (evt) {
    // Отменяем стандартное поведение
    evt.preventDefault();

    // Создаём объект с новым персонажем и записываем данные
		// Добавляем поле с почтой, чтобы сервер узнавал твои карточки
    let newHero = {
        title: titleInput.value,
        description: descriptionInput.value,
        str: strInput.value,
        agi: agiInput.value,
        hp: hpInput.value,
        int: intInput.value,
        studentEmail: studentEmail, 
    };
    // Формируем JSON-строку из объекта
    let newHeroJSON = JSON.stringify(newHero);

    fetch("https://api-code.practicum-team.ru/heroes", {
        method: "POST", // POST нужен для сохранения и записи данных
        body: newHeroJSON, // Тело запроса в JSON-формате
        headers: {
            // Добавляем необходимые заголовки
            "Content-type": "application/json; charset=UTF-8",
        },
    })
        .then((response) => response.json())
        .then((data) => {
						console.log(data); // Смотрим ответ сервера на наш запрос
            cards.push(data); // Добавляем в переменную cards данные о новой карточке
            renderCards(cards); // Отображаем обновлённый набор карточек
            form.reset(); // Сбрасываем все поля формы
        })
});

Если отправка данных прошла успешно, то необходимо сбросить значения в полях формы, для этого достаточно вызвать функцию `reset()` на форме.
