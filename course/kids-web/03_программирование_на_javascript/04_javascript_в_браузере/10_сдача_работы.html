Сдача работы

Всё так. Ориентируясь на прошлые уроки, тебе нужно самостоятельно создать веб-страницу с двумя полями ввода и кнопкой, при нажатии на которую на странице создаётся карточка героя. Карточка состоит из имени героя и его класса.

В этот раз у тебя не будет макета 😱

Срок сдачи кода проекта — 25 декабря.

Что должно быть сделано, чтобы работа была зачтена

1. в HTML-файле есть базовая структура, а в теге `<body>` находится контейнер для карточек и два тега `<input>` с кнопкой `<button>` для добавления новой карточки 2. стили проекта записаны в отдельный CSS-файл и правильно подключены в HTML-файле 3. в JS-файле должна быть переменная с исходными данными: двумерный массив, каждый элемент которого хранит две строки (имя и класс персонажа) 4. в JS-файле нужно: 1. создать функцию `displayHeroes()`, которая сможет найти контейнер для карточек и с помощью переменной с исходными данными заполнить контейнер карточками 2. не забыть вызвать функцию `displayHeroes()` 5. должна быть реализована возможность добавления новых карточек, для этого: 1. создана функция `addHero()` , которая будет получать данные из тегов `<input>` 2. создан новый массив для карточки и сохранён в переменную с исходными данными 3. вызвана функция `displayHeroes()` для обновления вёрстки страницы 4. очищены поля вода `<input>` после добавления новых данных 6. необходимо правильно установить слушатель события `click` на кнопку добавления новой карточки — так, чтобы при клике вызывалась функция `addHero()` и на сайте появлялась новая карточка

Если всё выполнишь правильно, у тебя получится отличная страница с тематическими карточками, на которую пользователь сможет добавлять новый, собственный контент 👍

Что можно сделать дополнительно

Ты можешь заменить идею с персонажами из предыдущих уроков на любую другую тематику: карточки игр, фильмов, подарков, — всё, что придёт в голову. Главное, чтобы карточка содержала минимум два текстовых поля.

Более того, ты можешь проявить фантазию и стилизовать сайт с карточками на своё усмотрение, попрактикуй навыки вёрстки 🙃

Важно

- Чтобы получить **зачёт**, нужно реализовать всю обязательную функциональность. - Можно и нужно задавать вопросы наставнику!
