# Переменная event

К этому моменты ты уже умеешь писать функции и отслеживать события в JS-коде, настало время соединить одно с другим. Это позволит тебе сделать так, чтобы нажатие на клавишу вызывало функцию для проигрывания аудио, а значит, почти закончить наш синтезатор!

С этим нам поможет аргумент функции `event`, в котором хранится информация о событии.

![](https://pictures.s3.yandex.net:443/resources/Untitled_Artwork_562_1_1701418511.png)

Эта переменная появляется автоматически, когда на странице происходит какое-либо событие. Рассмотрим на примере клика на кнопку:

1. Пользователь нажимает на кнопку. 
2. Браузер создаёт событие. **Событие** — набор данных о том, что произошло на странице. Например, сам факт нажатия кнопки, какую кнопку нажали, в какой момент времени. 
3. Когда создаётся функция-обработчик события, ему как аргумент передаётся переменная — её можно назвать `event`  
4. Теперь функция-обработчик может пользоваться переменной `event`, а значит, ты можешь брать из неё данные о произошедшем событии. Например, выводить сообщение о том, какая кнопка была нажата. 

Закрепим: событие автоматически возникает при взаимодействии пользователя с сайтом и может быть использовано в функции для обработки события. 

Вот список важных свойств события, которые мы можем получить из `event`:

- `event.target`
Ссылка на элемент, нажатие на которое вызвало событие. То есть, например, при клике на кнопку мы получим ссылку на эту кнопку.
- `event.currentTarget`
Ссылка на элемент, на который установлен обработчик события. К примеру, ты ставишь функцию-обработчик на кнопку, в которой есть элемент `<span>`, и при нажатии на `<span>` ссылка на кнопку с обработчиком события будет значением `currentTarget`, тогда как в `target` будет записана ссылка на элемент `<span>`
- `event.type`
Тип события (клик, наведение мыши, нажатие на клавишу, прокручивание страницы и другое).
- `event.preventDefault()`
С помощью этой команды можно предотвратить стандартное поведение при клике на элемент. Например, нажатие на кнопку отправки формы не будет перезагружать страницу.

Из события `KeyboardEvent` (`’keydown’`/`’keyup’`) можно получить код нажатых клавиш — как раз то, что нам нужно для синтезатора. Код клавиши будет записан в `event.code`. Например, вот так его можно вывести в консоли:

```javascript
console.log(event.code);
```

Если нажать, например, на клавишу `Q`, то вернётся код `KeyQ`. Такой формат игнорирует язык, которым пользуется пользователь сейчас, и альтернативную раскладку клавиатуры. Поэтому при нажатии на клавишу `Й` или `q` ты тоже получишь код `KeyQ`. Если понадобится значение нажатой клавиши, то можешь использовать свойство `key`: тогда при нажатии на клавишу `й` ты получишь строку `“й”`

Это далеко не всё, что можно узнавать о событиях через объект `event`. Подробную статью об этом ты можешь прочитать в [Доке](https://doka.guide/js/event/){target="_blank"}, а мы перейдём к рассказу, как использовать данные о событии в нашем синтезаторе. 

Событие передаётся параметром в функцию-обработчик. То есть, простыми словами, чтобы иметь к нему доступ в функции, он должен быть указан в скобках после названия функции. 

```javascript
// Здесь параметр с переменной события назван event
// Назвать его можно как угодно, но обычно выбирают event, evt или e
function makeSomething(event) {}
// В таком случае можно указать у addEventListener только название функции
element.addEventListener('click', makeSomething);

// Можно передавать функции вторым аргументом и без их определения заранее

// Вариант с классической записью функции
element.addEventListener('click', function(event) {});
// Вариант со стрелочной функцией
element.addEventListener('click', (event) => {});
```

Теперь, когда ты знаешь о переменной `event`, которая автоматически передаётся функции, обрабатывающей события, мы можем приступить к написанию функции `handleKeyDown` для отслеживания нажатий на клавиши клавиатуры. Эта функция будет работать так:

- По коду клавиши выбирается HTML-элемент, соответствующий нажатой клавише (если ты не помнишь или не понимаешь, что хранится в переменной `keyElement` , посмотри ещё раз наш урок про DOM).
- Если элемент найден, то проигрывается звук, соответствующий коду нажатой клавиши.

```javascript
// Функция для обработки события нажатия клавиши
function handleKeyDown(event) {
  let keyElement = document.querySelector('[data-key="' + event.keyCode + '"]');
  if (keyElement) {
    playSound(keyElement.dataset.key);
  }
}
```

События `keydown` и `keyup` работают с элементами, на которых пользователь может сфокусироваться (например, поле ввода текста: когда ты нажимаешь на поле ввода, ты на нём фокусируешься, и только тогда оно начинает обрабатывать нажатия клавиш). Но если добавить обработчик этих событий объекту `document`, то не будет иметь значения, есть ли какой-либо элемент в фокусе или нет.

```javascript
document.addEventListener('keydown', handleKeyDown);
```

Теперь нажатие на клавишу вызывает событие `keydown`, а оно вызывает функцию `handleKeyDown`, которая вызывает функцию `playSound`, — и вот наш синтезатор начинает играть.
