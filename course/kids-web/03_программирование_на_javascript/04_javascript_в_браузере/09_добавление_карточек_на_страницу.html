Добавление карточек на страницу

![](https://pictures.s3.yandex.net:443/resources/Untitled_Artwork_573_1702641678.png)

В предыдущем уроке мы вышли на финишную прямую проекта — научились показывать заранее записанные карточки героев на сайте с помощью JavaScript. Это очень круто!

Но чтобы сайт был ещё лучше, нужно предусмотреть возможность добавлять новые карточки на страницу с помощью текстовых полей.

Чтобы это было возможно, тебе предстоит:

- ознакомиться с элементами для ввода данных — `<input>` - узнать об элементе `<button>` — кнопке (на неё мы поставим обработчик события, который будет добавлять значение полей ввода на страницу при нажатии)

`<input>` — тег для создания интерактивных элементов на странице. У него достаточно много типов: от полей ввода текста до чекбокса, от даты до выбора файла. Но сейчас для проекта нам понадобится именно текстовый `input`. Однако, если очень не терпится, вот тебе ссылка на [Доку](https://doka.guide/html/input/){target="_blank"}, где ты можешь глянуть, какие ещё бывают `input`-элементы.

Текстовое поле ввода в HTML создаётся вот так:

<!-- Обрати внимание, что тегу input не нужен закрывающий тег </input> -->
<input type="text" />

![](https://pictures.s3.yandex.net:443/resources/Screenshot_2023-12-11_at_09.42.51_1702641753.png) *Элемент инпут*

В случае с нашим проектом нам понадобятся два текстовых поля: в одном мы будем вводить имя персонажа, в другом — его класс. Сейчас у тебя должна получиться такая вёрстка:

<!DOCTYPE html>
<html>
<head>
    <title>КарП</title>
</head>
<body>
    <div id="heroesContainer"></div>
    <input type="text" id="heroName" placeholder="Имя героя">
    <input type="text" id="heroClass" placeholder="Класс героя">
    <script src="script.js"></script>
</body>
</html>

![](https://pictures.s3.yandex.net:443/resources/Screenshot_2023-12-11_at_09.48.21_1702655562.png)

Ответ прост: нам нужно найти элементы с помощью `document.querySelector()` или `document.getElementById()` и достать из них значения. Вот как это будет выглядеть:

// Находим поле ввода
let nameInput = document.getElementById("heroName");
// Значение поля ввода хранится в value — и его можно достать таким образом:
console.log(nameInput.value);

Этих знаний достаточно, чтобы приступить к написанию функции `addHero`, которая будет добавлять героя на страницу.

Сейчас опишем её пошагово.

Шаг 1. Ищем поля ввода

Здесь всё просто: мы находим нужные нам элементы на странице и сохраняем их в переменные.

function addHero() {
	/* Ищем поля ввода */
	let nameInput = document.getElementById("heroName");
  let classInput = document.getElementById("heroClass");
}

Шаг 2. Дополняем массивы новыми данными из полей ввода

Теперь нам нужно обновить массив с данными о героях. Новое имя персонажа и его клаcс объединим в массив `newHero` и положим его в общий массив героев `heroes`. Для этого воспользуемся функцией для добавления элемента в массив — `push`. Чтобы получить значение полей ввода, нам нужно достать его из `value` (то есть значение поля `nameInput` можно достать так: `nameInput.value`).

function addHero() {
	// Ищем поля ввода
	let nameInput = document.getElementById("heroName");
  let classInput = document.getElementById("heroClass");
	
	// Создаем массив с новым персонажем 
	let newHero = [nameInput.value, classInput.value];
	
	// Кидаем нового персонажа в массив с героями на нашем сайте
	heroes.push(newHero);
}

Будь внимателен!🚨 Тут мы рассчитываем, что пользователь введёт какие-то данные в инпуты. А если пользователь нечаянно нажмет кнопку «Добавить героя», но не введёт данные? Возникнет проблема, для решения которой ты можешь использовать условия `if... else`. Напиши код, который будет проверять, что пользователь ввёл не пустое значение, и только потом выполнять остальные операции.

Шаг 3. Обновляем список на странице

Итак, чтобы отобразить обновлённые данные, надо вызвать подготовленную в прошлом уроке функцию `displayHeroes()`

function addHero() {
	/* Ищем поля ввода */
	let nameInput = document.getElementById("heroName");
  let classInput = document.getElementById("heroClass");

	// Создаем массив с новым персонажем
	let newHero = [nameInput.value, classInput.value];
	
	// Кидаем нового персонажа в массив с героями на нашем сайте
	heroes.push(newHero);
	
	// Используем функцию, которую мы подготовили в прошлом уроке, 
	// чтобы обновить список героев на странице 
	displayHeroes();
}

Шаг 4. Очищаем поля ввода после добавления героя — и функция готова!

function addHero() {
	/* Ищем поля ввода */
	let nameInput = document.getElementById("heroName");
  let classInput = document.getElementById("heroClass");

	// Создаём массив с новым персонажем
	let newHero = [nameInput.value, classInput.value];
	
	// Кидаем нового персонажа в массив с героями на нашем сайте
	heroes.push(newHero);
	
	// Используем функцию, которую мы подготовили в прошлом уроке, 
	// чтобы обновить список героев на странице 
	displayHeroes();

	// Очищаем поля ввода, чтобы пользователю было удобнее 
	// сразу иметь возможность вводить данные нового персонажа 
	nameInput.value = "";
	classInput.value = "";
}

Теперь проект практически готов. Но нам нужно сделать так, чтобы функция `addHero` вызывалась нажатием на кнопку. Поэтому сейчас мы поговорим о `<button>` — элементе, нужном для того, чтобы создать кнопку.

Добавим кнопку в нашу вёрстку:

<!DOCTYPE html>
<html>
<head>
    <title>КарП</title>
</head>
<body>
    <div id="heroesContainer"></div>
    <input type="text" id="heroName" placeholder="Имя героя">
    <input type="text" id="heroClass" placeholder="Класс героя">
    <button id="addButton">Добавить героя</button>
    <script src="script.js"></script>
</body>
</html>

На эту кнопку мы добавим обработчик события, который будет вызывать функцию `addHero`, чтобы добавлять героя и класс на страницу. Если подзабылось, что такое обработчики события, перечитай уроки предыдущей недели.

document.getElementById("addButton").addEventListener("click", addHero);

Теперь при нажатии на кнопку будет запускаться функция `addHero` — и, соответственно, персонаж будет добавляться на страницу.

Проект готов, ещё разок чекай всё в своём редакторе кода и переходи к следующему уроку, чтобы сдать код на проверку наставнику.
