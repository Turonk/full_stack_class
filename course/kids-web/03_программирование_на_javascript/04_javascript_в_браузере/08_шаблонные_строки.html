Шаблонные строки

В прошлом уроке ты создал необходимые для проекта переменные и подготовил нужные элементы DOM в своём коде. Теперь тебе нужно будет понять, как отображать данные на странице и автоматически создавать новые элементы в вёрстке. Для этого научимся создавать и изменять элементы DOM с помощью JS.

Как создать новый элемент с помощью JavaScript?

Шаг 1. Создание нового элемента и запись его в переменную

Начнём с создания нового элемента с помощью JS. Это можно сделать с помощью функции `document.createElement()`

Шаг 2. Добавление элемента на страницу с помощью функции `appendChild`

На данный момент созданный в прошлом шаге элемент `div` не будет виден на странице, потому что пока он только записан в переменную `newElement`. После создания элемента его нужно добавить на страницу — для этого можно выбрать элемент, в который мы хотим вставить новый, и воспользоваться функцией `appendChild`. Например, чтобы вставить элемент в конец `<body>`, нужно использовать `appendChild` так:

// Создание элемента div
let newElement = document.createElement("div");
// Добавление нового элемента на страницу – так он добавится в конец <body>
document.body.appendChild(newElement);

Как ты можешь догадаться, необязательно вставлять новые элементы в конец `<body>`. Можно указывать и другие DOM-элементы, которые ты можешь найти с помощью `querySelector`. Это будет выглядеть примерно так:

// Добавление нового элемента в другой элемент будет выглядеть так:

// Создаём элемент div
let newElement = document.createElement("div");

// Выбираем элемент-контейнер
let container = document.querySelector(".container");
// Добавляем в него новый элемент – если container не пустой, то элемент
// newElement будет добавлен в конце, после других элементов, имеющихся 
// в container
container.appendChild(newElement);

Шаг 3. Наполняем элемент контентом

Добавлять элементы здорово, но сейчас они пусты. Надо понять, как менять их содержание, так что поговорим об изменении HTML внутри элементов. Для этого ты можешь использовать функцию `innerHTML` — она позволяет записывать новое содержимое в элемент. Пользоваться ей надо так:

// Находим элемент из DOM
let element = document.querySelector(".element");

// Меняем HTML-содержание элемента
element.innerHTML = "<p>Гав-гав!</p>";

// Теперь в элемент будет записан элемент <p> с текстом «Гав-гав!»

Шаблонные строки

Как видишь, с помощью `innerHTML` можно записывать строки HTML-разметки в элемент. Раньше, чтобы отобразить в строках какие-либо значения, тебе, скорее всего, приходилось складывать несколько строк и значение переменной вот так (на примере приветствия пользователя):

let string = "Привет, " + username + "!";

Поэтому тебе нужно знать о **шаблонных строках** — ещё одном (более крутом) способе записать строку в JS. Почему он круче? Потому что короче 👇🏻

let coolString = `Привет, ${username}!`

Как можно понять, такая строка выделяется символами `` `с обеих сторон. Для того чтобы записать в неё любое выражение JS (которое будет приведено к типу `string`), нужно вписать его между фигурных скобок в такой конструкции: `${выражение}`

Вернёмся к функции, которая будет отображать героев. Внимательно изучи код: он тебе понадобится, когда будешь сдавать проект недели.

// Функция, которая отображает героев на странице

function displayHeroes()  {
	// Достаём контейнер, в который будем добавлять новые карточки героев
  let heroesContainer = document.getElementById("heroesContainer");

	// Очищаем текущее содержимое
  heroesContainer.innerHTML = ''; 

	// С помощью цикла проходимся по массиву героев
	// (переменная i будет равняться индексу элемента в массиве)
  for (let i = 0; i < heroes.length; i++) {
		// Создаём элемент, в который будем добавлять информацию о герое
    let heroDiv = document.createElement("div");

		// Записываем в созданный элемент разметку, подставляя необходимые данные
		// (данные достаём из массивов по индексу – если не помнишь, как это делать,
		// перечитай наш урок про массивы)
		// Так как элемент массива heroes[i] и есть массив - hero = ["имя", "класс"],
		// нужно взять отдельно имя и класс по индексу массива: [0]- имя [1]- класс
    heroDiv.innerHTML = `<h3>${heroes[i][0]}</h3><p>${heroes[i][1]}</p>`;

		// Добавляем карточку героя в контейнер
    heroesContainer.appendChild(heroDiv);
  }
}

// Вызываем написанную функцию
displayHeroes();
