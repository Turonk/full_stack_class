Работаем с DOM

В прошлом шаге мы подготовили структуру проекта. Теперь подготовим данные, на основе которых будет генерироваться сайт и обрабатываться пользовательский ввод.

Изначально добавим несколько персонажей для сайта, сохраним их в переменные для последующих изменений при помощи JavaScript. Также найдём теги `<input>` и сделаем так, чтобы информация от пользователя сохранялась в переменные и JavaScript мог её обработать.

Для этого мы:

- организуем хранение изначальных данных — информации о персонажах - найдём и сохраним в переменные теги `<input>` и контейнер для отображения информации о персонажах - научимся получать значение тега `<input>`, чтобы обрабатывать пользовательский ввод

Создаём переменную с непростым массивом

Создадим переменную для описания персонажей. У каждого персонажа будет имя `"Axe"` и класс `"Tank"` — это строковые значения, и, чтобы было удобнее работать с ними, положим их в массив: `["Axe", "Tank"]`. Так описание одного персонажа будет храниться в одном массиве. Мы будем знать, что первое значение массива — это имя персонажа, а второе — его класс.

Для начала создадим пару персонажей, а дальше пользователь сможет добавлять своих героев. Если мы будем сохранять каждого персонажа в отдельную переменную, то в итоге просто запутаемся или потеряем важного персонажа, ведь их может быть сколько угодно.

Чтобы упростить хранение данных о персонажах, просто сгруппируем их в один набор и сохраним в переменной `heroes`. В этом нам опять поможет массив, только в этот раз элементом массива `heroes` будет информация о персонаже — массив с именем и классом `["Axe", "Tank"]`

Таким образом мы создали двумерный массив! Или другими словами — массив с массивами 👇🏻

// Информация, на основе которой генерится сайт
let heroes = [["Axe", "Tank"], ["Crystal Maiden", "Support"]];

Ищем и сохраняем HTML-контейнер и теги `<input>`

Далее нам понадобится контейнер, в нём будет отображаться информация о героях. Для этого в HTML-файле выделен тег `<div>` с помощью идентификатора ``id="heroesContainer"`, а в JS-файле воспользуемся функцией `getElementById`, которую нам предоставляет переменная `document`. Эта функция находит HTML-элемент в DOM-дереве по идентификатору, затем её нужно сохранить в переменную `heroesContainer` 👇🏻

let heroesContainer = document.getElementById("heroesContainer");

Так через переменную `heroesContainer` ты сможешь обращаться к этому контейнеру в JavaScript-функциях и добавлять в него новую вёрстку.

Аналогичным образом найдём HTML-элементы в DOM-дереве, отвечающие за ввод пользовательских данных. Для этого в вёрстке страницы предусмотрены два тега `<input>`: первый отвечает за имя персонажа, второй — за его класс в игре. Их заранее в прошлом уроке выделили разными идентификаторами: `heroName` и `heroClass`👇🏻

let nameInput = document.getElementById("heroName");
let classInput = document.getElementById("heroClass");

Используя эти переменные в функциях, ты сможешь получать из HTML-элементов значения, которые ввёл пользователь.

Как получать значения из `<input>`

Обращаясь к `input`-элементам, которые мы только что сохранили в переменные, мы можем прочитать значение — текст, который находится внутри тега `<input>`. Для этого необходимо к переменной `input`-элемента через точку дописать `value`👇🏻

nameInput.value // "Имя персонажа"
classInput.value // "Класс персонажа"

Если юзер захочет добавить нового персонажа, нам потребуется использовать новые значения в JavaScript, поэтому давай сохраним их отдельно, в дополнительные переменные 👇🏻

let newHeroName = nameInput.value;
let newHeroClass = classInput.value;

Это поможет переиспользовать данные о персонаже, а также влиять на состояние тега `<input>` в вёрстке HTML-страницы: например, когда пользователь нажмёт кнопку «Добавить», ты изменишь вёрстку с помощью JavaScript-функции и зачистишь поля тегов `<input>` с введёнными значениями.

**Какие могут возникнуть сложности 😵‍💫**

1. Ошибки в массивах

При использовании массива в качестве переменной помни о том, как он записывается. Сам массив — это набор элементов в квадратных скобках, разделённых запятой. Элементы массива могут иметь разные типы данных, но в нашем случае используются только строки, а они должны быть заключены в кавычки `"Tank"` 👇🏻

// Пример переменной с массивом:
let arr = ["Alchemist", "Axe", "Bristleback"];

// ошибка 1 — потерянная запятая:
let error1 = ["Alchemist" "Axe", "Bristleback"];
// ошибка 2 — потерянная кавычка: 
let error2 = ["Alchemist", Axe", "Bristleback"];
// ошибка 3 — потерянная скобка: 
let error3 = ["Alchemist", "Axe", "Bristleback";

Так как мы используем массив для описания персонажа `["имя", "класс"]`, то в результате в переменной `heroes` у нас должен лежать массив с массивами:

let heroes = [["Axe", "Tank"], ["Crystal Maiden", "Support"]];

Очень важно не запутаться в скобках и кавычках. Одна опечатка — и приложение сломается!

2. Работа с идентификаторами

В этом проекте все необходимые элементы в HTML-документе мы пометили идентификаторами `id` и при помощи функции `document.getElementById` находим HTML-элементы в файле JS. Это очень удобный способ поиска, так как идентификаторы уникальны в HTML-странице и мы точно найдём искомый элемент.

Главное — правильно передать название идентификатора `id` в функцию `getElementById`. Для этого достаточно просто передать название идентификатора аргументом в функцию в виде строки `"heroesContainer"`👇🏻

let heroesContainer = document.getElementById("heroesContainer");
