Отличный настрой, команда! Но давайте сперва условимся, что наш музыкальный инструмент — это веб-страница, на которой при помощи HTML и CSS изображён синтезатор с виртуальными клавишами.

Наша задача — оживить эту статичную страницу. Синтезатор должен воспроизводить звуки:

- при нажатии на кнопки на клавиатуре компьютера - при нажатии на виртуальные кнопки на веб-странице

В прошлых уроках мы разобрали и подготовили части кода проекта, осталось собрать всё воедино. Но прежде чем переходить к коду, давай вспомним ключевые моменты теории:

1. Нам понадобятся **переменные**, чтобы сохранить информацию о клавишах и переиспользовать их в функциях. 2. Для поиска элементов HTML-страницы и взаимодействия с ними нам понадобится **DOM** и функции `querySelector` и `querySelectorAll`. Мы будем определять клавиши синтезатора при помощи CSS-селекторов: классов и атрибутов. 3. Вспомним, как **создавать и использовать функции**. Разработаем логику, позволяющую воспроизводить звук — функция `playSound`, и обрабатывать нажатия клавиш — функции `handleKeyDown` и `init` 4. Используем такие **события**, как `click` и `keydown`, для взаимодействия с клавишами синтезатора. А с запуском функций в момент пользовательских событий нам поможет **слушатель событий** `addEventListener`, который будет отслеживать их и запускать подходящие функции. 5. Также мы будем использовать **циклы** и **условные операторы** для определения клавиш синтезатора и запуска мелодий.

Шаг 1: Готовим функцию для проигрывания мелодии `playSound`

Вся логика синтезатора состоит из функций, поэтому начнём с основной — воспроизведения мелодий, а именно функции `playSound`. Мы уже показывали её на прошлых уроках 👇🏻

// Функция для воспроизведения звука в зависимости от кода клавиши
function playSound(keyCode) {
    let audio;

    if (keyCode === '65') { // Если это клавиша A
        audio = new Audio('path_to_sound_for_A.mp3');
    } else if (keyCode === '83') { // Если это клавиша S
        audio = new Audio('path_to_sound_for_S.mp3');
    } else if (keyCode === '68') { // Если это клавиша S
        audio = new Audio('path_to_sound_for_D.mp3');
    }
    // Если аудиофайл определён, воспроизводим его
    if (audio) {
        audio.play();
    }
}

Обрати внимание на условие `else if`, в нём мы проверяем, какой код у нажатой клавиши синтезатора. И в зависимости от кода запускаем разные мелодии.

Шаг 2: Готовим функцию для обработки события нажатия клавиши `handleKeyDown`

Из урока **«Переменная event»** мы возьмём функцию `handleKeyDown`:

// Функция для обработки события нажатия клавиши
function handleKeyDown(event) {
  let keyElement = document.querySelector('[data-key="' + event.keyCode + '"]');
  if (keyElement) {
    playSound(keyElement.dataset.key);
  }
}

Когда происходит событие `keydown`, создаётся переменная `event`, которая хранит много полезной информации (в том числе код клавиши клавиатуры, на которой произошло нажатие). С помощью `data-`атрибута и функции `querySelector` найдём HTML-элемент: если такой существует в вёрстке, запустим функцию `playSound` и передадим ей код клавиши.

Шаг 3: Готовим функцию установки обработчиков событий `init`

Создадим функцию `init`, которая добавит обработчика (он же слушатель) событий после загрузки страницы. Она позволит запускать функции после нажатия на клавиши синтезатора.

Для этого нам понадобится:

- Найти и сохранить все клавиши синтезатора. Используем уже знакомый код:

    let keys = document.querySelectorAll('.key');

Тут при помощи переменной `document` и функции `querySelectorAll` мы находим все клавиши. Для этого мы передаём в функцию класс `.key`, чтобы выбрать именно HTML-элементы, отвечающие за все клавиши. И сохраняем найденные элементы в переменную `keys`

- С помощью цикла `for` пройти по каждой клавише из переменной `keys` и установить обработчик событий. Будем отслеживать событие `click` и вызывать для него функцию `playSound`, передавая код клавиши из `data`-атрибута элемента:

    // Для каждого элемента (клавиши из массива)
    // добавляем обработчик события нажатия (click)
        
        for (let i = 0; i < keys.length; i++) {
                        keys[i].addEventListener('click', function() {   
                    playSound(keys[i].dataset.key); // Передаем код клавиши в функцию
                });
            };

- Установить обработчик событий на нажатие клавиш клавиатуры. Для события `keydown` вызывать функцию `handleKeyDown`. Слушатель событий `addEventListener` нужно установить на основную переменную `document`, так как нажатия клавиатуры нужно отслеживать на всей странице приложения:

    document.addEventListener('keydown', handleKeyDown);

Вот функция `init` и готова:


function init() {
    let keys = document.querySelectorAll('.key');

		for (let i = 0; i < keys.length; i++) {
				keys[i].addEventListener('click', function() {
            playSound(keys[i].dataset.key);
        });
    };
    document.addEventListener('keydown', handleKeyDown);
}

Присоединяемся к словам восхищения!

- JS взаимодействует с DOM при помощи переменной `document` - искать элементы удобно при помощи `querySelector` и `querySelectorAll`, передавай различные селекторы так же, как в CSS - правильно объединяй блоки кода и переиспользуй их при помощи функций `function makeSomething () {}` - применяй слушатели событий `addEventListener` для обработки пользовательских действий, указывая, какому событию соответствует запуск функции - используй в своих проектах **циклы** и **условия** для повторяющихся действий и обработки данных или более сложной логики - изучи ящик Пандоры под названием `event` — там скрывается уйма полезной информации (почитать подробно [тут](https://doka.guide/js/event/){target="_blank"})
