Есть три основные составляющие любого сайта (веб-приложения) — HTML, CSS и JavaScript. В этот раз большая часть работы ляжет на JavaScript (обработка данных, создание вёрстки и изменение страницы), но, несмотря на всю мощь JavaScript, без HTML и CSS невозможно создать интерфейс.

Шаг 1. Подготовка

Создаём новую папку для проекта

Первое, что стоит сделать, — создать новую папку, где будут лежать файлы проекта.

Сайт с КАРточками Персонажей (Карп), который мы сделаем, будет собирать готовую вёрстку для проекта с помощью JS. На самом деле принцип работы над проектом будет одинаковый для сайта с любыми карточками — любимых фильмов, списка литературы или новогоднего вишлиста.

Всё, что создаст JavaScript, нужно где-то отобразить. Собирать весь контент будет некуда, если не подключить JavaScript к HTML-странице, а значит, пора создать файл `index.html`

Создаём базовую вёрстку для HTML-страницы

HTML-страница с названием `index.html` — главная страница сайта, открывающаяся по умолчанию. Помнишь что внутри?

Вручную их писать не обязательно, есть приём, который используют все разработчики, он позволяет сэкономить время и сгенерировать начальную структуру сайта. Команда внутри редактора VSCode: `! + tab` 👇🏻🏻

Шаг 2. Стили и информация о проекте

В этом пункте подключаем стили и заполняем базовую информацию о сайте.

В КарПе нам нужно будет отображать карточки с персонажами. За это отвечает файл стилей, в нём мы стилизуем элементы, задаём свойства контейнерам.

Подключают стили с помощью тега `<link>` внутри `<head>`

`<head>`

**Подключаем файл стилей**

В теге `<head>` подключаем CSS-файл, в котором будут находиться стили проекта: `<link href="styles.css" rel="stylesheet" />`

⚠️ Не забудь создать сам файл стилей, назвать его `styles.css`

**`<title>`**

В тег `<title>` размещают текст, который будет отображаться во вкладке в браузере. Это называется «заголовок сайта»: `<title>КарП</title>`

`<body>`

В теге `<body>` будет вся наша вёрстка. В него добавим контейнер для карточек и несколько тегов для взаимодействия с пользователем и добавления новых карточек.

Вёрстку мы дадим. А JavaScript код не дадим 😬

**Задаём ID-атрибут контейнеру**

Основному тегу-контейнеру, в котором будут лежать карточки, зададим id-атрибут `<div id="container"></div>`

В дальнейшем с помощью id-атрибута и JS-функции для поиска элементов найдём элемент и вставим в него карточки. Подразумевается, что айди уникальный, то есть второго такого `id="container"` быть не должно, но может быть любой другой — просто с другим именем.

**Тег `<input>`**

Нам нужно реализовать функциональность добавления новых карточек, для этого пригодится тег для ввода данных — `<input>`. Он позволяет вводить данные в специальное поле на странице — это, например, та самая область, куда мы вводим логин и пароль для доступа к почте и другим аккаунтам на просторах интернета.

Нам пригодится два инпута: один для названия, а второй для описания героя 👇🏻

<body>
	<input type="text" id="heroName" placeholder="Имя героя">
  <input type="text" id="heroClass" placeholder="Класс героя">
	<div id="heroesContainer"></div>
</body>

**Атрибуты `<input>`**

Тег `<input>` позволяет вводить разные данные — строки, числа, изображения и многое другое. Для имени и описания нам необходим текст, поэтому в качестве атрибута указываем соответсвующий тип инпута: `type="text"`

Атрибут `placeholder` является подсказкой, которая отображается по умолчанию, когда поле для ввода пустое. Идентификатор `id` будем использовать для поиска элементов в JavaScript, поэтому задаём простые названия — `heroName` и `heroClass`

**Тег `<button>`**

Последний шаг в вёрстке: добавляем кнопку, которая всё запустит. Кнопки — это тег `<button>`. При нажатии на неё будет происходить алгоритм добавления персонажа на странице (опишем логику в следующем уроке).

И не забудем добавить идентификатор👇🏻

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>КарП</title>
	<link href="./styles.css" rel="stylesheet" />
</head>
<body>
	<input type="text" id="heroName" placeholder="Имя героя">
  <input type="text" id="heroClass" placeholder="Класс героя">
	<button id="addButton">Добавить героя</button>
	<div id="heroesContainer"></div>
</body>
</html>

Шаг 3. Подключаем JS в HTML

Тег `<script>`

На финишной прямой подключаем тег `<script>`

По умолчанию в браузере открывается HTML-файл. JS можно писать внутри HTML-файла, но это неудобно. А можно писать в отдельном файле, добавив затем в HTML-файл. Совсем как с CSS. Делается это вот так:

<script src="./script.js"></script>

Тег `<script>` является двойным тегом. Это, означает, что он имеет открывающий `<script>` и закрывающий `</script>` теги, что позволяет вставлять JavaScript-код непосредственно в HTML-документ между этими тегами 👇🏻

<script>
		let greetAski = "Привет, Аски!";
		console.log(greetAski);
</script>

Либо указать путь до отдельного JS-файла в атрибуте `src` 👇🏻

<script src="./script.js"></script>

Про подключение скриптов и работу браузера

При загрузке страницы браузер читает код сверху вниз. В момент, когда он доходит до тега `<script>`, он останавливается и сперва читает, что в этом теге. В этот момент вся остальная страница простаивает и не загружается. Если код внутри `<script>` большой, то это может существенно повлиять на скорость загрузки страницы.

По этой причине принято ставить теги `<script>` в самом конце разметки, перед закрывающим тегом `</body>`. Тогда браузер, дойдя до скриптов, уже загрузит всю страницу и пользователь сможет взаимодействовать с контентом.

Конец

Вот и всё! Мы подготовили HTML-структуру проекта 👇🏻

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Герои Dota</title>
	<link href="./styles.css" rel="stylesheet" />
</head>
<body>
	<div id="heroesContainer"></div>
	<input type="text" id="heroName" placeholder="Имя героя">
  <input type="text" id="heroClass" placeholder="Класс героя">
	<button id="addButton">Добавить героя</button>
  <script src="./script.js"></script>
</body>
</html>

- Неправильная вложенность тегов. Используй инструменты разработчика в браузере `devtools`, чтобы наглядно проверять свою вёрстку. Обращай внимание на подсветку блочной модели на странице — она отлично помогает определять пропорции элементов и находить причины поломки в вёрстке страницы. - Потерянные или незакрытые теги: и снова на помощь приходят инструменты разработчика в браузере `devtools` - Отсутствие семантической вёрстки, из-за которого тяжело ориентироваться в интерфейсе программы. Используй подходящие теги: для кнопок — `<button>`, для текстовых элементов — теги `<p>`, `<h>` и так далее.
