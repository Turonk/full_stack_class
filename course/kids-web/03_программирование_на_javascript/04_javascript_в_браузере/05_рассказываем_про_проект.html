Рассказываем про проект

На этой неделе изучим концепцию создания сайтов с помощью JavaScript (JS). В двух словах это работает так: вёрстку делаем как раньше — с помощью HTML и CSS, но в этот раз HTML-вёрстку сохраняем в переменных в JS-коде, это будет шаблон для будущих элементов. А шаблоны всегда упрощают работу 🤓 Контент для элементов вёрстки тоже сохраняется в переменных. С помощью JS объединяем контент и шаблон, а с помощью DOM-функций создаём и вставляем полученные элементы на страницу и получаем сайт, который полностью сделан с JS.Такой подход позволит создавать интерактив на сайтах, чтобы внешний вид сайта соответствовал его состоянию и менялся по запросу пользователя.

Тренироваться будем, как всегда, на классном проекте. В этот раз создадим сайт с коллекционными карточками героев. Для контента возьмём команду Аски, героев «Доты» и популярных персонажей из аниме.

{quiz-task} background: | #f1f1ef content: | 🦎 Кстати, сейчас нам предстоит работать с данными, которые будут храниться локально — в нашем коде. А уже на следующей неделе научимся получать и сохранять их на сервере. {/quiz-task}

На этой неделе предусмотрена сдача проекта (архива кода), поэтому работать нужно будет в редакторе кода.

1. В связи с этим стартанём с азов — с урока о том, как начать проект, в нём подготовим HTML-структуру и подключим в код JavaScript. 2. В следующем уроке создадим переменные, в которые будем собирать необходимую информацию из формы ввода данных об игровом персонаже, в том числе научимся делать поиск по DOM. 3. Чтобы красиво отображать результат работы программы, научимся изменять DOM с помощью новых методов и узнаем, что такое шаблонные строки. 4. В конце недели соберём вместе всё, чему научились до этого, и напишем функцию, которая добавляет героя на страницу. 5. К последнему уроку проект должен быть завершён и отправлен на проверку наставнику. Дедлайн сдачи — **25 декабря**.
