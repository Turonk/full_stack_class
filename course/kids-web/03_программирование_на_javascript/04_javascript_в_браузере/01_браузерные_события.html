События на странице

Ты даже не представляешь, как много всего происходит в браузере, когда ты производишь обычные для себя действия. Браузер постоянно отслеживает, над каким элементом ты проводишь мышкой, нажимаешь ли на клавиатуру, прокручиваешь ли страницу и много чего ещё.

То, что происходит на странице или в системе, в коде называют `event` — событием. Таких событий огромное множество, большинство из них разбито по группам:

- события по работе с документом (пропорциями): `scroll`, `resize`, `fullscreenchange` - события по работе с буфером обмена: `cut`, `copy`, `paste` - события нажатия клавиш: `keydown`, `keypress`, `keyup` - события мыши: `click`, `dblclick`, `select`, `wheel`, `mousemove` - остальные события, как обычно, можешь изучить по [ссылке](https://developer.mozilla.org/ru/docs/Web/Events){target="_blank"}.

В проекте недели нам необходимо отслеживать нажатия на клавиши синтезатора. Пользователь может воздействовать на клавиши двумя способами: при помощи нажатия клавиш клавиатуры и клика мыши. Поэтому мы остановимся на основных и часто используемых событиях: `click` и `keydown`

- `click` — кнопка мыши, которую нажали и отпустили на элементе. - `keydown` — любая нажатая клавиша.

**Слушатель событий**

В JS есть универсальный способ отслеживания и реакции на любое событие — функция `addEventListener` (с английского — «слушатель событий»). Она позволяет добавить элементу действие, которое будет выполнено после срабатывания [события](https://doka.guide/js/events/){target="_blank"}. Например, на клик мышки или нажатие клавиши.

Это настоящий мультитул 🛠️ для отслеживания событий, потому что в функцию можно передать два аргумента `addEventListener(название события, функция)` — таким образом мы легко и просто объясняем JavaScript, что нужно слушать определённое событие и выполнять конкретную логику для этого элемента (для события `click` своя функция, для события `keydown` — своя). Таких слушателей на элементе может быть сколько угодно, можно устанавливать несколько разных слушателей на один элемент или на одно событие. Например, мы хотим при клике на карточку показывать анимацию, а при зажатой клавише и движении мыши изменять положение карточки на странице. Или, как в случае с синтезатором, для клика по клавише запускать одну функцию, а по нажатию на клавиатуру использовать другую.

Рассмотрим простой пример клика и нажатия на клавишу клавиатуры по кнопке «Купить» в карточке с кроссовком 👇🏻

<main>
		<div class="sneaker">
				<img alt="adidas Yeezy Foam RNNR" src="./images/1.png" class="sneaker-image"/>
        <div class="sneaker-info">
				    <h3>adidas Yeezy Foam RNNR</h3>
            <p>Stone Sage</p>
        </div>
				<button class="add-to-cart">Купить</button>
		</div>
</main>

Установка слушателей событий `addEventListener` на кнопку для отслеживания клика и нажатия клавиши клавиатуры выглядит следующим образом 👇🏻

// Находим кнопку на HTML-странице
const button = document.querySelector('.add-to-cart')

// Описываем функцию для реакции на нажатую клавишу клавиатуры
function handleKeyDown () {
	console.log('Нажали на клавиатуру');
}

Функцию для выполнения реакции на событие можно передать просто названием `button.addEventListener('keydown', handleKeyDown)`👇🏻

// Устанавливаем слушатель для обработки событий с клавиатуры
button.addEventListener('keydown', handleKeyDown)

Либо можно описать функцию внутри параметров `addEventListener`👇🏻

// Устанавливаем слушатель на клик
button.addEventListener('click', function () {
  console.log('Произошёл клик по кнопке');
})

Теперь ты знаешь про события, как их отслеживать и реагировать на них, давай применим эти знания к части проекта про синтезатор.

Порядок действий простой:

- находим клавишу, на которую нужно нажимать для воспроизведения музыки - записываем функцию, которая воспроизводит мелодию - устанавливаем слушатель событий на клавишу и привязываем к событию `click` запуск функции воспроизведения мелодии

Так это выглядит в коде 👇🏻

// Находим клавишу на HTML-странице
let key = document.querySelector('.key');

// Функция для воспроизведения мелодии
function playSound() {
    let audio = new Audio('path_to_sound.mp3');

    if (audio) {
        audio.play();
    }
}

// Устанавливаем слушатель на клик
key.addEventListener('click', playSound)

Поздравляем, вечеринка почти спасена, совсем скоро у нас будет виртуальный музыкальный инструмент прямо из клавиатуры и экрана!

Именно так! В общем, мастерски устанавливая слушатели событий на элементы HTML-страницы, ты сможешь отслеживать любые действия пользователя и реагировать на них, делая страницу по-настоящему динамичной и интерактивной.
