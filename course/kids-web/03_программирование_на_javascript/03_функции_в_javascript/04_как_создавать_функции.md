# Как создавать функции

![](https://pictures.s3.yandex.net:443/resources/Untitled_Artwork_564_1_1701437170.png)

Для того чтобы собрать наш синтезатор, нам нужно написать команды, которые будут сообщать компьютеру, что нужно делать при нажатии на клавиши. Поэтому в этом уроке мы вернёмся к функциям — и ты напишешь функцию для воспроизведения аудио.  

Ранее мы уже обсуждали, что такое функции и как их вызывать (можешь перечитать соответствующий урок прошлой недели). Но в том уроке мы не обсуждали, как создавать функции самостоятельно, — поговорим об этом сейчас. 

Создание функции называют «объявлением функции»: мы даём ей имя, параметры и пишем команды, которые она должна выполнять. Сейчас рассмотрим объявление функции внимательнее и обсудим каждый шаг. 

Есть несколько способов объявить функцию:

```javascript
/* Классическое объявление функции */
function makeSomething() { /*Тело функции*/ }

/* Функциональное выражение */
const makeSomethingElse = function () { /*Тело функции*/ }

/* Стрелочная функция */
const makeSomeOtherThing = () => { /*Тело функции*/ }
```

Если будет интересно узнать об их разнице, посмотри статью в [Доке](https://doka.guide/js/function/){target="_blank"}, а пока просто запомни, как они выглядят, чтобы суметь опознать функцию в коде. В наших уроках чаще всего будет использоваться вариант `function makeSomething() {}`

У каждой функции есть название, по которому ты её вызываешь. Функции желательно называть так, чтобы было понятно, что она делает. Обычно это значит, что в начале названия будет стоять какой-нибудь глагол. Например, если наша функция высчитывает случайное число, то неплохим вариантом будет что-то вроде `getRandomNumber()`

Мы вернёмся к нашему примеру `собакаПринесиМяч` из прошлого урока о функциях, но назовём функцию так, чтобы в теории её можно было использовать в настоящем JS-коде. 

```javascript
function bringBall() {}
```

Надеемся, с прошлого разговора о функциях ты помнишь, что им можно передавать **параметры** (в примере с собакой — цвет мяча или персонаж). Параметры перечислены в круглых скобках после имени функции. А в фигурных скобках (в теле функции) ты описываешь действие, которое необходимо совершить. 

```javascript
function bringBall(color, name) {}
```

В функции `bringBall` мы ждём получения результата работы (строка о том, что мяч донесён). Чтобы получить `"мяч"`, тебе нужно вернуть результат работы функции. Если мы попробуем записать в переменную результат работы функции, не вернув его, то получим значение `undefined`

```javascript
function bringBall(color, name) {
	let ball = "";
	ball = "Собака принесла " + color + " мяч " + name;
}

const yellowBall = bringBall("жёлтый", "Аски");
console.log(yellowBall); // Тут будет показано значение "undefined"
```

Для возвращения результата надо использовать слово `return`

```javascript
function bringBall(color, name) {
	let ball = "";
	ball = "Собака принесла " + color + " мяч " + name;
	return ball
}

const yellowBall = bringBall("жёлтый", "Аски");
console.log(yellowBall); // Тут будет показано 
//"Собака принесла жёлтый мяч Аски"
```

Теперь в переменной `yellowBall` будет записана строка, получившаяся в результате выполнения функции `bringBall()`

У тебя может возникнуть вопрос: почему мы не можем создать переменную `ball` внутри тела функции и обратиться к ней ниже? Как в примере:

```javascript
function bringBall(color, name) {
	let ball = "";
	ball = "Собака принесла " + color + " мяч " + name;
}

console.log(ball); // будет ошибка, говорящая, что такой переменной не существует
```

Переменные, созданные в теле функции, доступны только внутри своей **области видимости**. В примере у переменной `ball` область видимости ограничена телом функции `bringBall`

Внутри тела функции можно работать с переменными, которые были созданы не в функции, потому что они находятся в одной области видимости:

```javascript
/* Область видимости 1. Начало */
let color = "жёлтый";
let name = "Аски";

function bringBall() {
	/* Область видимости 2. Начало */
	let ball = "";
	ball = "Собака принесла " + color + " мяч " + name;
	return ball;
	/* Область видимости 2. Конец */
}

const yellowBall = bringBall();
console.log(yellowBall); // Тут будет показано "Собака принесла жёлтый мяч Аски"
/* Область видимости 1. Конец */
```

Вот чек-лист, что нужно сделать для записи функции: 

- объявить функцию с помощью ключевого слова `function`
- назвать функцию таким образом, чтобы было понятно, какое действие она выполняет
- прописать круглые скобки, в которые, если необходимо, ты передашь параметры функции
- написать тело функции (если нужно, чтобы функция возвращала результат своей работы, используй `return`)

Теперь, когда ты знаешь, как писать свои функции, время вспомнить о предстоящей тусовке — перейдём к нашему синтезатору.

Сейчас твоих знаний достаточно, чтобы собрать функцию, необходимую для воспроизведения звуков. Попробуем пошагово написать её, а в следующих уроках вернёмся к проекту и соединим функцию с нажатиями на клавиши компьютера.

### Шаг 1: Основа функции

Начнём с создания функции, которая будет воспроизводить звук в зависимости от переданного ей кода клавиши.

### Шаг 2: Добавление логики выбора звука в `playSound`

С названием определились! 

В нашей функции `playSound` мы хотим воспроизвести звук в зависимости от того, какая клавиша была нажата. Для этого мы используем уже готовую функцию JavaScript — команду `new Audio()`. Это как поставить пластинку в виниловый проигрыватель. Представь, что каждый раз, когда ты нажимаешь клавишу, компьютер достает звук из нашей цифровой библиотеки и загружает его в проигрыватель, но пока ещё не проигрывает. 

```javascript
// Функция для воспроизведения звука в зависимости от кода клавиши
function playSound(keyCode) {
    let audio;

    if (keyCode === '65') { // Если это клавиша A
        audio = new Audio('path_to_sound_for_A.mp3');
    } else if (keyCode === '83') { // Если это клавиша S
        audio = new Audio('path_to_sound_for_S.mp3');
    } else if (keyCode === '68') { // Если это клавиша D
        audio = new Audio('path_to_sound_for_D.mp3');
    }
}

```

### Шаг 3: Воспроизведение звука

Теперь реализуем воспроизведение звука, когда соответствующий аудиофайл найден (готов к воспроизведению).

Для этого прописываем команду `audio.play()` — это кнопка Play ▶️ на нашем плеере. 

```javascript
// Если аудиофайл определен, воспроизводим его
if (audio) {
    audio.play();
}
```

### Итоговая функция

Ура, теперь у нас готова функция для воспроизведения звука! Вот как она выглядит:

```javascript
// Функция для воспроизведения звука в зависимости от кода клавиши
function playSound(keyCode) {
    let audio;

    if (keyCode === '65') { // Если это клавиша A
        audio = new Audio('path_to_sound_for_A.mp3');
    } else if (keyCode === '83') { // Если это клавиша S
        audio = new Audio('path_to_sound_for_S.mp3');
    } else if (keyCode === '68') { // Если это клавиша D
        audio = new Audio('path_to_sound_for_D.mp3');
    }
    // Если аудиофайл определён, воспроизводим его
    if (audio) {
        audio.play();
    }
}

```

Теперь ты знаешь, как писать свои функции, как их правильно определять, как возвращать результат работы функции, что такое область видимости. И работа над музыкальным проектом тоже продвинулась.
