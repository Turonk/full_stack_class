# Приглашение на вечеринку

Дорогие герои, кажется, нет смысла переживать! У вас же есть компьютер Аски, а с помощью JavaScript мы в два счёта превратим его в музыкальный синтезатор. 

Ладно, не в два счёта, а за одну неделю.

Вторая неделя модуля будет про управление HTML-тегами с помощью JavaScript, а также про события, вроде кликов пользователя, и функции (о которых поговорим подробнее, чем на прошлой неделе).

В итоге ты (с нашими героями заодно):

- научишься описывать логику действия нужной функции
- узнаешь, что такое событие и как с его помощью добавлять интерактив на страницу
- а еще поймёшь, как обрабатывать данные из HTML и при чём тут DOM

Проект недели — музыкальный синтезатор, работающий в браузере. Делается нехитро: к клавиатуре компьютера привяжем звуки с помощью функций, событий и звуков. Закодим вместе поэтапно, на каждый этап свои уроки на неделе.

![](https://pictures.s3.yandex.net:443/resources/Untitled_Artwork_549_2_1701418138.png)

1-2. Первые два урока посвящены работе с DOM (узнаешь, что это). Благодаря этим урокам ты сможешь сделать виртуальные кнопки синтезатора, которые будут дублировать кнопки клавиатуры.

1. Потом в уроке про создание функций сконструируем механизм музыкального плеера, поможет функция `play()`
2. В уроке про браузерные события свяжем кнопки клавиатуры с с функцией `play()`
3. В предпоследнем уроке объединим то, чему научились на прошлых уроках и сделаем так, чтобы нажатие на клавишу вызывало функцию для проигрывания аудио.
4. В последнем уроке соберем весь код для синтезатора вместе и поиграем мелодии на вечеринке.

Куда без этого, Ящерка!
