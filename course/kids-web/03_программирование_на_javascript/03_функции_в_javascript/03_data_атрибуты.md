# Data-атрибуты

Ты уже умеешь искать элементы с помощью JS, но иногда функция `querySelector` может вернуть не тот элемент, что нам нужен, даже если ты ищешь по классам, ведь одинаковых классов в коде тоже бывает много.

Отделить важные для нас элементы среди изобилия однотипных (например, среди карточек с кроссовками из прошлого модуля), сделать их более уникальными можно с помощью разных атрибутов. 

Но некоторые атрибуты могут совпадать у одинаковых элементов, поэтому нам на помощь приходят `data-`**атрибуты.** Это пользовательские атрибуты, которые можно настраивать как угодно. Они позволяют придать уникальности HTML-элементам и, кроме того, хранить в них дополнительную информацию.

### Как пользоваться data-атрибутами

Пользовательские атрибуты — это нестандартные атрибуты, которые используются для передачи пользовательских данных из HTML в JavaScript или для того, чтобы помечать HTML-элементы для JavaScript. Чтобы избежать совпадения имён для атрибутов и других конфликтов, принято записывать пользовательские атрибуты, начиная с `data-`. После дефиса можно записывать произвольное слово либо несколько, используя **camelCase-**нотацию.

`data-`атрибуты часто используют при тестировании веб-проектов, когда необходимо добавить вспомогательную техническую информацию элементам, не относящуюся к содержанию веб-страницы. Также ты можешь встретить их использование при создании подсказок на HTML-элементах. При наведении курсора всплывающая подсказка описывает элемент страницы — эту информацию удобно хранить в атрибуте элемента. 

Так, в сайте с кроссовками можно было помечать новые и старые коллекции:

```html
<! -- Используя data-атрибуты, можно добавить дополнительную информацию элементам страницы -->
<div data-model="new">adidas Ozweego</div>
<div data-model="old">adidas Yeezy Boost 380</div>
<div data-model="old">adidas F/1.3 LE</div>
```

В нашем проекте с синтезатором в `data-`атрибутах мы будем хранить код клавиш клавиатуры, чтобы правильно обрабатывать пользовательские нажатия. 

Имена пользовательских атрибутов можно также передавать в уже известные тебе функции: `querySelector` и `querySelectorAll` 

Например, найдём только новые модели кроссовок:

```javascript
const newModelItem = document.querySelector('[data-model="new"]')// Выведет <div data-model="new">adidas Ozweego<div>
```

Получив доступ к HTML-элементу при помощи JS, мы можем:

1. **Читать/менять контент**
Например, получив доступ к кнопке покупки товара на сайте, мы можем получить текст внутри и изменять его. Например, при клике на кнопку изменить текст «Купить» на «В корзине».
2. **Читать/менять классы**
Мы можем узнать, какие классы установлены на элемент, либо изменять их (удалять/добавлять) — это позволяет динамически стилизовать элементы и применять различные анимации.
3. **Читать/менять атрибуты**
В атрибутах элементов хранится много полезной информации, JS помогает работать с этой информацией: можно заменять пути к файлам, изменять инлайн-стили, изменять пользовательские данные и много другое.
4. **Добавлять дочерние элементы**
Можно добавлять новые элементы в вёрстку напрямую из JS.

Кажется, Собака намекает, что пора бы эту теорию применить к нашей проблемке с отсутствием музыки на вечеринке.

### **Про синтезатор и клавиши**

Как и у реальных музыкальных инструментов, у нашего компьютерного синтезатора будут клавиши. Для воспроизведения музыки при нажатии на кнопки синтезатора нам нужно показать JS, какой функционал принадлежит каждой кнопке. 

Сперва давай найдём все клавиши в программе. В HTML-файле клавиши имеют подобную вёрстку:

```html
<button data-key="65" class="key">A</button>
<button data-key="83" class="key">S</button>
<button data-key="68" class="key">D</button>
```

Хоть клавиш и много, у них установлен одинаковый класс `.key`, по которому мы можем их выделить среди других HTML-элементов на странице. И чтобы установить для каждой клавиши функцию по воспроизведению звука, предварительно сохраним их в переменную `keys`

```javascript
let keys = document.querySelectorAll('.key');
```

Более того, мы можем использовать составные селекторы. Это работает так же, как в CSS: 

```css
button {
	/* стили для тега button */
}

button .key {
	/* стили для кнопок с классом key */
}
```

Передавая в функцию `querySelector` параметры класса и `data-`атрибута, мы можем не только выбирать специфические элементы, но и динамически подбирать конкретный в зависимости от других переменных. 

Мы заранее не знаем, какой код клавиши использует пользователь. Для формирования параметра для функции мы можем воспользоваться сложением строки с названием атрибута и его значением: `'[data-key="' + event.keyCode + '"]'`

В результате после выбора кнопки с `keyCode = 65` мы динамически сформируем строчку `data-key="65"`. Так, в зависимости от выбора пользователя, JS будет выбирать разные HTML-элементы страницы:

```javascript
let keyElement = document.querySelector('[data-key="' + event.keyCode + '"]');
```
