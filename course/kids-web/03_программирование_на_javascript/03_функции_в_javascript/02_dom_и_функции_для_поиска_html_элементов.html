DOM и функции для поиска HTML-элементов

Что такое DOM и почему его называют деревом

JavaScript не умеет работать напрямую с HTML. Чтобы их подружить, придумали переменную **DOM** (Document Object Model). В неё буквально дублируется информация обо всех HTML-тегах веб-страницы, включая классы, атрибуты и прочие характеристики.

Структура у переменной такая же, как у разметки самого сайта. Если в HTML-коде одни теги вкладываются в другие, то в DOM одни элементы становятся дочерними по отношению к другим. В итоге получается дерево.

Вот, сравни на знакомой вёрстке, как выглядит дерево элементов (слева), соответствующее самому коду (справа):

![](https://pictures.s3.yandex.net:443/resources/Frame_1352_5_1701175539.png)

В JavaScript все эти элементы, а также дополнительные функции для взаимодействия с ними записаны в переменную `document`

Для работы с переменной `document` код JavaScript должен быть написан в отдельном файле, который подключается к HTML-документу с помощью тега `script`:

<script src="main.js"></script>

`script` является двойным тегом (помнишь, открывающий `<script>` и закрывающий `</script>` теги?). Это позволяет вставлять JavaScript-код непосредственно в HTML-документ между этими тегами. Кроме того, атрибут `src` используется для подключения внешних скриптов, как показано в примере выше.

Такое подключение JavaScript-файла к HTML-странице обеспечивает доступ к DOM данной страницы, включая переменную `document` с её элементами и функциями.

Аски, Собаку и другие элементы всегда можно найти с помощью JS. Сейчас расскажем.

Как с помощью JavaScript найти HTML-элемент на странице

Сейчас научимся искать элементы на странице — это понадобится, когда будем оживлять клавиши синтезатора с помощью JS (да, для оживления их надо будет сначала уметь быстро найти).

В JavaScript нам понадобятся две **функции**, которые принимают **аргументом** **селектор** нужного элемента. Удобно, что аргументы нужно писать так же, как в CSS:

- `querySelector` Позволяет искать один (первый) элемент страницы соответствующего селектора. Функции `querySelector` можно передать класс `.list__item` как аргумент, в таком случае она вернёт первый элемент с этим классом на странице, начиная с верха страницы:

    // Для выбора элемента по идентификатору
    let container = document.querySelector('#container');
    
    // По имени класса
    let list = document.querySelector('.list');
    
    // Найдёт первый элемент на странице с классом .list__item
    let listItem = document.querySelector('.list__item');
    console.log(listItem) // Выведет <li class="list__item"></li>

![](https://pictures.s3.yandex.net:443/resources/Frame_1356_3_1701418216.png)

- `querySelectorAll` Позволяет найти несколько элементов страницы с указанным селектором. Если в функцию передать класс `.list__item` как аргумент, она вернёт все подходящие под селектор элементы:

let listItems = document.querySelectorAll('.list__item');
console.log(listItems) // Выведет все элементы с классом .list__item

Итого: вызываешь функцию, передаёшь ей класс, и она находит тебе элемент.

![](https://pictures.s3.yandex.net:443/resources/Frame_1357_3_1701418226.png)

Вот и конец урока, давай подытожим:

- теперь ты знаешь, что такое DOM (интерфейс, позволяющий JS работать с разметкой документа) и переменная `document` (хранит всю информацию о HTML страницы и полезные функции) - а ещё умеешь находить элементы HTML-страницы, используя функцию `querySelector` для поиска одного элемента и `querySelectorAll`, если нужно найти несколько с одинаковыми значениями
