# Перебор массива. Методы forEach() и map()

Это правда, но раньше мы перебирали элементы массива с помощью циклов, а эта конструкция довольно громоздкая: много символов, нужно не запутаться с индексом `i` 👇🏻

```javascript
let array = ["джинсы", "шарфы", "шорты"];

for (let i = 0; i < array.length; i++) {
	console.log(array[i]);
} // джинсы шарфы шорты
```

Сейчас научим иначе!

У массивов есть методы `forEach()` и `map()`, позволяющие перебрать каждый элемент и обработать его по отдельности. Эти методы применяются при декларативном стиле написания кода и часто используются в библиотеках и фреймворках 👇🏻

```javascript
let array = ["джинсы", "шарфы", "шорты"];

array.forEach(item => console.log(item)); // джинсы шарфы шорты
```

## Метод `forEach()`

Метод `forEach()` используют для перебора элементов массива. Как и метод `find()`, он принимает в аргумент функцию. 

Этой функции доступны три аргумента:

- первый аргумент (`item`) — элемент массива, до которого в данный момент добрался метод `forEach()`
- второй аргумент (`index`) — индекс элемента в массиве
- третий аргумент (`array`) — весь массив, по которому пробегает метод `forEach()`

Функция будет вызвана для каждого элемента массива. При этом второй и третий аргументы используются редко, в таком случае их можно опустить, но помнить про них нужно.

Давай выведем в гардеробную консоль Цэ-эс-эсочки элементы массива и разложим их по пакетам, добавив эмодзи👇🏻

```javascript
let array = ["джинсы", "топы", "шорты"];

// С обычной функцией
array.forEach(function (item) {
    console.log(item + '🛍'); 
}); // джинсы 🛍 топы 🛍 шорты 🛍

// С использованием стрелочной функции
array.forEach(item => console.log(item + '🛍')); // джинсы 🛍 топы 🛍 шорты 🛍
```

Внутрь метода `forEach()` мы передаём функцию. Она вызывается для каждого элемента массива, который впоследствии попадает в аргументы этой функции. Именно поэтому `item` — это текущий элемент массива.

## Метод `map()`

Метод `map()` создаёт новый массив, аналогичный существующему, но заполняет его изменёнными элементами. В качестве аргумента `map()`, как и `forEach()`, принимает функцию. Только эта функция обязательно должна вернуть значение, именно оно станет новым элементом для нового массива.

На словах понять это сложно, давай рассмотрим пример. 

Допустим, у нас есть массив чисел и нам нужен новый массив, в котором будут элементы из исходного массива, но умноженные на два. Вызовем метод `map()` и передадим функцию, в которой будем умножать элемент массива на два и возвращать его из функции ключевым словом `return`. Так как метод `map()` создаст новый массив, результат работы метода сохраним в переменную `result` 👇🏻

```javascript
const numbers = [0, 1, 2, 3, 4, 5];

const result = numbers.map(function (item) { // Берём каждый элемент массива
  return item * 2; // Умножаем элемент на два
})

console.log(numbers); // [0, 1, 2, 3, 4, 5]
console.log(result); // [0, 2, 4, 6, 8, 10]

// Вариант со стрелочной функцией
const result = numbers.map(item => item * 2);
```

Этот метод часто используют для изменения массивов с данными. А если не указать, какое значение должно вернуться, `map()` подставит значение `undefined` 👇🏻

```javascript
const numbers = [0, 1, 2, 3, 4, 5];

const transformed = numbers.map(function(number) {
  if (number < 3) {
    return "Меньше трёх"
  }
  // Для чисел больше двух нет возвращаемого значения, поэтому увидим undefined
})
console.log(transformed)
// ['Меньше 3-х', 'Меньше 3-х', 'Меньше 3-х', undefined, undefined, undefined]
```

## Отличия между `forEach()` и `map()`

Оба метода перебирают массив и выполняют переданную функцию для каждого элемента, но:

- метод `forEach()` используют, когда нужно что-то сделать для каждого элемента массива, **не изменяя сам массив;**
- метод `map()` используют, когда нужно **создать новый массив из старого** и **преобразовать его элементы.** В результате остаётся исходный массив и рождается новый с изменёнными элементами
