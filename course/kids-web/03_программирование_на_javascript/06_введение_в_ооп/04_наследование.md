## Наследование

У классов в JS есть особый механизм — **наследование.** По нему можно создать новый класс на основе старого класса-шаблона, чтобы расширить его функционал, а потом создавать сколько угодно экземпляров уже более прокачанного класса. И все эти объекты будут обладать всеми улучшениями по сравнению со старым классом. Этот подход позволяет избежать дублирования кода — в итоге работать с таким проектом проще.

О, Аски, ты как раз кстати. Начнём разбираться с наследованием на примере карточки рыцаря. В наследовании класс `Hero` называют **родительским,** а класс `Knight` — **дочерним.**

Опишем в классе `Knight` уникальные особенности рыцаря так, чтобы внутри этого класса осталось описание игрового персонажа из класса `Hero`. Чтобы дочерний класс унаследовал свойства родителя, тебе понадобится ключевое слово `extends`. После него и указывается имя класса, от которого происходит наследование.

```javascript
//Дочерний класс героя-рыцаря
class Knight extends Hero {
	// Описание класса
}
```

Теперь нужно определить, какие свойства и методы будут в дочернем классе. 

В классе `Hero` есть свойства: `name`, `level`, `healthPoints`, `stats`. Рыцарю `Knight` добавим способность танцевать танго на коне `isHorseTango` и уровень энергии `energy`

Используем функцию `constructor()`. В скобках перечисляем свойства и из родительского класса, и новые, уникальные для рыцаря. Ниже в коде пишем ключевое слово `super` — ссылку на родительский класс. Там в скобках мы перечисляем свойства из родительского класса. Ниже определяем новые свойства `isHorseTango` и `energy` 👇🏻

```javascript
// Дочерний класс героя-рыцаря
class Knight extends Hero {
	// Конструктор дочернего класса
	constructor(name, level, healthPoints, stats, isHorseTango, energy) {
        super(name, level, healthPoints, stats);
        this.isHorseTango = isHorseTango; // Может танцевать танго на коне
        this.energy = energy; // Показатель уровня энергии героя
    }
}
```

Итак, сейчас ты умеешь прокачивать свойства родительского класса внутри дочернего. Но можно прокачивать не только свойства, но и методы класса.

У класса `Hero` есть метод, который выводит информацию о персонаже в консоль `displayHero()`. Так как в дочернем классе информации стало больше, давай расширим этот метод, чтобы он показывал и информацию о новых свойствах класса. 

Для этого сделаем так, чтобы метод `displayHero()` выводил информацию о свойствах:

- из родительского класса,
- из дочернего класса.

Чтобы показывать информацию из родительского класса, не надо ничего придумывать, просто вызовем метод `displayHero()`, а ключевым словом `super` покажем, что этот метод работает так, как описано в классе-родителе.

Новую информацию о свойствах дочернего класса выведем отдельно. Ниже в коде выведем значения для `energy` и `isDoubleSword` с помощью обычного метода `console.log()` 👇🏻

```javascript
// Дочерний класс героя-рыцаря
class Knight extends Hero {
	// Конструктор дочернего класса
	constructor(name, level, healthPoints, stats, isHorseTango, energy) {
	  super(name, level, healthPoints, stats);
    this.isHorseTango = isHorseTango; // Может танцевать танго на коне
    this.energy = energy; // Показатель уровня энергии героя
  }

	// Метод, расширяющий метод базового класса
  displayHero() {
		super.displayHero();
		console.log(`Энергия: ${this.energy}`)

		if (this.isHorseTango === "true") {
		  // Если в момент создания класса Knight
			// передать true в аргумент isHorseTango, будет выведено сообщение:
		  console.log("Этот герой может танцевать танго на коне")
    }
  }
}
```

Ну вот и всё, мы прокачали класс обычного персонажа до уровня рыцаря, который может танцевать танго на коне и полон энергии!

Да, Цэ-эс-эсочка, для тебя тоже обязательно нужно создать свой дочерний класс `Mage`

Супер! Тогда самостоятельно добавь магу зелье для тектоника `hasTectonicPotion` и уровень маны `mana`. Не забудь расширить метод `displayHero()` из родительского класса, чтобы он показывал эти значения.

```jsx
// Дочерний класс героя-мага
class Mage extends Hero {
	// Конструктор дочернего класса
	constructor(name, level, healthPoints, stats, hasTectonicPotion, mana) {
	  super(name, level, healthPoints, stats);
		this.hasTectonicPotion = hasTectonicPotion; // Зелье для тектоника
    this.mana = mana; // Мана мага
  }

	// Метод, расширяющий метод базового класса
  displayHero() {
    super.displayHero();
		console.log(`Мана: ${this.mana}`)

    if (this.hasTectonicPotion === "true") {
		  // Если в момент создания класса Mage
			// передать true в аргумент hasTectonicPotion, будет выведено сообщение:
			console.log("Есть зелье для тектоника!")
    }
  }
}
```

Что ж, в проекте этой недели уже созданы подвиды персонажей: рыцарь и маг. Все их характеристики и особенности тебе пригодятся для создания небольшой игры. А о чём будет игра и какую механику нам предстоит реализовать, ты узнаешь в следующем уроке.
