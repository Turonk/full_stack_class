# Что дальше?

Всё правильно, теперь ты владеешь основными навыками создания любого интерактивного сайта. Знать вышеперечисленное необходимо просто для того, чтобы код работал.

На самом деле, основная и самая сложная часть работы разработчика — это не просто написать работающий код, а **организовать код** так, чтобы его мог понять любой другой разработчик и сайт бы не ломался при дальнейшей доработке проекта и добавлении новых фич.

Именно про это мы и поговорим в оставшихся уроках второго модуля.

Всегда пожалуйста.

На предстоящей неделе ты узнаешь, как классы и новые для тебя функции (`find`, `map`, `filter`) позволяют по-разному подходить к организации кода проекта. 

Кстати, помимо теории, тебе предстоит пройти два тренажера. Если что-то не будет получаться, проси совета в чате или у наставника — важно пройти дальше, потому что в конце будет решающий урок модуля.

Да-да, это сдача финального проекта.

![](https://pictures.s3.yandex.net:443/resources/cssochka_schedule__1705246652.png)

Отличная идея, ведь сроки очень сжатые и важно всё успеть.

Исправляемся!

Для зачёта достаточно собрать воедино весь проект веб-сайта `Heroes Dance Battle`, который мы подробно описывали на прошлых неделях. 

### Минимальные требования к проекту

В твоём коде реализована базовая механика игры:

- Одна карточка персонажа заполняется информацией от пользователя, которую тот вводит через форму на сайте.
- Вторая карточка персонажа заполняется информацией о рандомном герое из списка, который пришёл с сервера.
- Реализована логика вычисления сильнейшего из двух персонажей.
- Результат вычислений выводится в консоль.

Если же это покажется слишком простым и скучным, можешь выполнять дополнительные задания, это позволит тебе ещё больше прокачать навыки использования JS.

### Дополнительные задания

- Добавить методы в классы `Mage` и `Knight`, которые могли бы учитывать дополнительные особенности каждого класса и давать им уникальные способности (например, для мага — увеличивать значение очков здоровья за счёт маны героя, а для рыцаря — увеличивать значение ловкости за счёт очков энергии).
- Усовершенствовать определение победителя, сделать более умный, интересный расчёт с учётом особенностей героев.
- Заменить вывод информации в консоль о ходе баттла на отображение данных на странице сайта в окне браузера.
- Добавить анимации для карточек и изменять их вид в ходе баттла для визуализации процесса.
