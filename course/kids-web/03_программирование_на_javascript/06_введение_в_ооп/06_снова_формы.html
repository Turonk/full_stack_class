Шаг 2. Решаем проблему с числами

На этом этапе сталкиваемся с маленькой проблемой. До этого нам надо было просто отображать в карточках значения силы или ловкости, не думая, в каком виде это значение к нам пришло. А теперь мы планируем вычитать и складывать эти числа, чтобы вычислять победителя. А для математических операций тип данных важен — иначе возможны ошибки при расчётах.

Что данные о числах, которые приходят через формы или от сервера, лучше переводить в числовой тип данных.

Наглядный пример: если бы на кассе супермаркета вдруг начали складывать цены, которые записаны в виде строк в памяти программы, то при покупке чипсов за `"80"` рублей и напитка за `"150"` рублей результат сложения цен получился бы `"80150"` рублей.

Именно! Рассказываем, как избежать подобного в проекте.

Чтобы привести что-то к числу, в JS существует функция `Number()`👇🏻

Number("80") // Приводит к числу 80
console.log(Number("80") + Number("150")) // Выведет число 230

Если тебе любопытно, то есть разные способы приводить к другим типам данных, подробнее читай в [Доке](https://doka.guide/js/typecasting/){target="_blank"}, а мы продолжим работать над проектом.

Добавляя характеристики силы, интеллекта и ловкости в объект `heroStats`, их нужно конвертировать в число 👇🏻

Шаг 3. Устанавливаем запрет на супермощных персонажей

В прошлом уроке мы создали два объекта, `gameParameters` и `gameClasses`, чтобы сделать игру более честной. Пришла пора их применить.

План такой: если пользователь ввёл значение более высокое, чем установлено в правиле, то запишем персонажу максимально допустимое значение. Это число хранится в объекте `gameParameters` как значение `MAX_STAT`👇🏻

// Получаем информацию о герое игрока
sendToBattleButton.onclick = () => {
    const heroName = document.getElementById("name").value;
    if (heroName !== "") {
        const heroClass = document.querySelector('input[name="class"]:checked').value;
        const heroLevel = document.getElementById("level").value;
        const heroStats = {};
        const additionalAbility = document.querySelector('input[name="additionalAbility"]:checked').value;
        const additionalStat = document.getElementById("additionalStat").value;

        // Если введённое значение параметра больше максимального, устанавливаем максимальное
        heroStats.str = Number(document.getElementById("strength").value);
        if (heroStats.str > gameParameters.MAX_STAT) {
            heroStats.str = gameParameters.MAX_STAT
        }
        heroStats.int = Number(document.getElementById("intelligence").value);
        if (heroStats.int > gameParameters.MAX_STAT) {
            heroStats.int = gameParameters.MAX_STAT
        }
        heroStats.agi = Number(document.getElementById("agility").value);
        if (heroStats.agi > gameParameters.MAX_STAT) {
            heroStats.agi = gameParameters.MAX_STAT
        }
    } else {
        alert("Добавьте герою имя!")
    }

}

Теперь ограничим классы персонажей только магом и рыцарем. Получив значение выбранного класса `Mage` или `Knight`, нужно создать соответствующий экземпляр класса персонажа, передать ему характеристики и сохранить в переменную `playerHero`. Для этого используем условие👇🏻

sendToBattleButton.onclick = () => {

        // Если введённое значение параметра больше максимального, устанавливаем максимальное
        heroStats.str = Number(document.getElementById("strength").value);
        if (heroStats.str > gameParameters.MAX_STAT) {
            heroStats.str = gameParameters.MAX_STAT
        }
        heroStats.int = Number(document.getElementById("intelligence").value);
        if (heroStats.int > gameParameters.MAX_STAT) {
            heroStats.int = gameParameters.MAX_STAT
        }
        heroStats.agi = Number(document.getElementById("agility").value);
        if (heroStats.agi > gameParameters.MAX_STAT) {
            heroStats.agi = gameParameters.MAX_STAT
        }

        const additionalAbility = document.querySelector('input[name="additionalAbility"]:checked').value;

Что мы имеем: в функцию аргументом передаётся экземпляр класса персонажа, в нём хранятся характеристики персонажа и метод для отображения данных карточки. Давай просто вставим каждый параметр в соответствующий HTML-тег и вызовем метод класса 👇🏻

// Выводим героя игрока на экран
function displayPlayerHero(hero) {
    document.getElementById("playerHeroClass").innerHTML = gameClasses[hero.constructor.name];
    document.getElementById("playerHeroName").innerHTML = hero.name;
    document.getElementById("playerHeroLevel").innerHTML = hero.level;
    document.getElementById("playerHeroHp").innerHTML = hero.healthPoints;
    document.getElementById("playerHeroStrength").innerHTML = hero.stats.str;
    document.getElementById("playerHeroIntelligence").innerHTML = hero.stats.int;
    document.getElementById("playerHeroAgility").innerHTML = hero.stats.agi;

    hero.displayHero();
}

Чтобы не запутаться, можешь вывести в консоль приходящий аргумент функции `console.log(hero)` — так ты наглядно поймёшь, где в объекте `hero` лежат необходимые свойства.
