Вызываем соперника на баттл

Действительно, баттл без соперника никакой не баттл. Поэтому в этом уроке мы реализуем получение случайного противника с сервера. Для этого придётся вспомнить про запросы к серверу и как получать рандомные числа в JS.

Кстати, противниками в этой танцевальной дуэли будут 20 случайных персонажей из всех тех, что были созданы студентами этого курса. Так что челлендж урока — научиться их получать и отображать их характеристики в карточке проекта.

Получение противника

Шаг 1. Запрашиваем всех возможных врагов

В прошлых уроках мы уже сохранили в переменную `getEnemyButton` кнопку для получения соперника. Осталось на неё установить обработчик события клика `onclick`👇🏻

 // По аналогии напишем анонимную функцию для получения оппонента
getEnemyButton.onclick = () => {
    // Тут будем запрашивать данные о персонаже с сервера
};

Напишем запрос на сервер с карточками. Чтобы получить информацию, нам понадобится обычный GET-запрос. Его поможет выполнить функция `fetch()` и ссылка для получения всех персонажей 👇🏻

getEnemyButton.onclick = () => {
    // Получаем героя оппонента с сервера
    fetch(`https://api-code.practicum-team.ru/heroes`)
				// Обрабатываем ответ сервера
        .then((response) => response.json())
        .then((data) => {
						// Смотрим на данные в консоли
            console.log(data);
        })
				// В случае ошибки запроса выводим сообщение об ошибке в консоль 
        .catch((error) => console.error("Ошибка:", error));
};

Шаг 2. Выбираем случайного соперника

Получить данные обо всех персонажах — это половина успеха. Нужно найти случайного оппонента и отобразить его в интерфейсе игры.

От сервера приходит массив героев, из этого массива мы выбираем по индексу одного из них. Чтобы при каждом нажатии на кнопку `ПОЛУЧИТЬ ГЕРОЯ` нам подбирался новый случайный герой, напишем код для получения случайного элемента массива.

В JS существует объект `Math`, он позволяет выполнять различные математические операции. В предыдущем проекте мы уже обращались к нему для получения случайного предсказания, сейчас `Math` пригодится нам вновь.

Вот две очень полезные `Math`-функции в программировании:

- `Math.floor()` помогает округлить в меньшую сторону то число, которое передали в качестве аргумента - `Math.random()` возвращает случайное число (подробнее [по ссылке](https://developer.mozilla.org/ru/docs/Web/JavaScript/Reference/Global_Objects/Math/random){target="_blank"})

Чтобы получить случайный индекс массива `data`, мы:

1. Умножим случайное число на длину массива 2. Округлим полученное значение

Полностью запись выглядит вот так 👇🏻

Math.floor(Math.random() * data.length) // Случайный элемент от 0 до длины массива data.length

Шаг 3. Сохраняем данные о сопернике

Сохраним выбранного персонажа в переменную `randomEnemy` 👇🏻

getEnemyButton.onclick = () => {
	// Получаем героя оппонента с сервера
    fetch(`https://api-code.practicum-team.ru/heroes`)
			// Обрабатываем ответ сервера
      .then((response) => response.json())
      .then((data) => {
				// Смотрим на данные в консоли
        console.log(data);
				let randomEnemy = data[Math.floor(Math.random() * data.length)]; // Получаем случайного героя оппонента
        console.log(randomEnemy); // Выводим героя оппонента в консоль
      })
			// В случае ошибки запроса выводим сообщение об ошибке в консоль 
      .catch((error) => console.error("Ошибка:", error));
};

В переменной `randomEnemy` хранится объект из прошлого проекта. Адаптируем его к актуальному проекту, создав экземпляр класса `Hero` с информацией из объекта `randomEnemy`, и запишем его в переменную `enemyHero`👇🏻

getEnemyButton.onclick = () => {
	// Получаем героя оппонента с сервера
	  fetch(`https://api-code.practicum-team.ru/heroes`)

      .then((response) => response.json())
      .then((data) => {
			// Смотрим на данные в консоли
	      console.log(data);
				let randomEnemy = data[Math.floor(Math.random() * data.length)]; // Получаем случайного героя оппонента
        console.log(randomEnemy); // Выводим героя оппонента в консоль

        // Создаём экземпляр класса героя оппонента 
				// и сохраняем его в переменную enemyHero
        enemyHero = new Hero(
	        randomEnemy.title, // Имя героя
          Math.floor(Math.random() * 10) + 1, // Уровень героя
          randomEnemy.hp, // Запас сил героя
	          {
	            str: randomEnemy.str,
              int: randomEnemy.int,
              agi: randomEnemy.agi,
            }
          ); // Параметры героя
			// В случае ошибки запроса выводим сообщение об ошибке в консоль 
      .catch((error) => console.error("Ошибка:", error));
};

В функцию аргументом передаётся экземпляр класса персонажа, в нём хранятся характеристики персонажа и метод. Давай просто вставим каждый параметр в соответствующий HTML-тег и вызовем метод класса 👇🏻

function displayEnemyHero(hero) {
	document.getElementById("enemyHeroClass").innerHTML = gameClasses[hero.constructor.name];
  document.getElementById("enemyHeroName").innerHTML = hero.name;
  document.getElementById("enemyHeroLevel").innerHTML = hero.level;
  document.getElementById("enemyHeroHp").innerHTML = hero.healthPoints;
  document.getElementById("enemyHeroStrength").innerHTML = hero.stats.str;
  document.getElementById("enemyHeroIntelligence").innerHTML = hero.stats.int;
  document.getElementById("enemyHeroAgility").innerHTML = hero.stats.agi;

  hero.displayHero();
}

Чтобы не запутаться, можешь вывести в консоль приходящий аргумент функции `console.log(hero)` — так ты наглядно поймёшь, где в объекте `hero` лежат необходимые свойства.
