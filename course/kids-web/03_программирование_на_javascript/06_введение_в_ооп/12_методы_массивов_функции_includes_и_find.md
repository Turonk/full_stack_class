# Методы массивов. Функции includes() и find()

## Метод `includes()`

Метод `includes()` есть у массивов и строк:

- в массиве проверяет, существует ли искомый элемент внутри массива
- в строках определяет, есть ли искомая подстрока (часть строки) в основной строке

В данный метод необходимо передать искомое значение и вызвать его в массиве или строке. После чего он вернёт `true`, если искомый элемент нашёлся, и `false` — если нет.

Рассмотрим сперва на массиве: у нас как раз завалялся один с названиями фильмов в переменной `movies`. Вызовем на этом массиве метод `includes()` и передадим в качестве аргумента искомое название `'Барби'`, а затем `'Бойцовский клуб'`, запишем результаты в переменные и выведем в консоль 👇🏻

```javascript
const movies = [ 'Барби', 'Джон Уик 4', 'Интерстеллар']

const isBarbie = movies.includes('Барби')
console.log(isBarbie); // true

const isFightClub = movies.includes('Бойцовский клуб');
console.log(isFightClub); // false
```

А теперь посмотрим, как поиск происходит на строках. Запишем в переменную `text` предложение и затем проверим методом `includes()`, есть ли в предложении искомые слова 👇🏻

```javascript
const text = 'Сегодня хочу посмотреть дораму!';
console.log(text.includes('дораму')); // true
console.log(text.includes('боевик')); // false
```

## Метод `find()`

Метод `find()` используется в работе с массивами и возвращает значение **первого** найденного в массиве элемента, подходящего под условие поиска. А если ни одного подходящего элемента нет, возвращает `undefined`

В аргумент метода нужно передавать функцию 👇🏻

```javascript
array.find(function(item, index, arr) {
    // Условие
});
```

Функция внутри `find()` принимает три аргумента:

- первый аргумент (`item`) — элемент массива, до которого в данный момент добрался метод `find()`
- второй аргумент (`index`) — индекс элемента в массиве `array`
- третий аргумент (`arr`) — весь массив `array`, по которому пробегает `find`

Метод `find()` часто используют с массивами, где элементы — это объекты. Давай снова посмотрим на кинопримере: у нас есть список фильмов, у каждого из которых уникальный номер `id`, жанр `genre` и имя `name` 👇🏻

```javascript
const movies = [
	{id: 1, genre: 'comedy', name: 'Барби'}, // Жанр: комедия
  {id: 2, genre: 'action', name: 'Джон Уик 4'}, // Жанр: боевик
  {id: 3, genre: 'fiction', name: 'Интерстеллар'} // Жанр: фантастика
];

const fiction = movies.find(function(item, index, arr) {
	// Тут указываем условие: нужно вернуть элемент,
	// в ключе name которого будет название 'Интерстеллар'
  return item.name === 'Интерстеллар';
});

console.log(fiction); // {id: 3, genre: 'fiction', name: 'Интерстеллар'}
```

Мы тут! 

В коде выше в аргумент метода `find()` передана функция. Эта функция вернёт `true`, если в свойстве `item.name` будет значение `'Интерстеллар'`

Метод `find` перебирает элементы массива `movies` и для каждого запускает переданную функцию, которая должна вернуть `true/false`. Как только функция вернёт `true`, перебор элементов массива останавливается и метод возвращает найденный элемент. В этом примере найденный элемент сохраняется в переменную `fiction`

А вот что происходит, если функция не находит элемент, удовлетворяющий условию 👇🏻

```javascript
const movies = [
	{id: 1, genre: 'comedy', name: 'Барби'}, 
  {id: 2, genre: 'action', name: 'Джон Уик 4'},
  {id: 3, genre: 'fiction', name: 'Интерстеллар'} 
];

const fantasy = movies.find(function(item, index, arr) {
  return item.name === 'Гарри Поттер';
});

console.log(fantasy); // Undefined
```

Сейчас мы передавали в метод целую функцию с тремя аргументами. В современной же разработке для подобных методов чаще используют стрелочные функции, они позволяют делать запись короче. Так будет выглядеть пример с фильмами, если использовать стрелочную функцию (заметь ещё, что второй и третий аргументы не пригодились, поэтому можем их опустить) 👇🏻

```javascript
const movies = [
	{id: 1, genre: 'comedy', name: 'Барби'}, 
  {id: 2, genre: 'action', name: 'Джон Уик 4'}, 
  {id: 3, genre: 'fiction', name: 'Интерстеллар'} 
];

const fiction = movies.find(item => item.name === 'Интерстеллар');

console.log(fiction); // {id: 3, genre: 'fiction', name: 'Интерстеллар'}
```

Вот именно. Логика при этом осталась прежняя, но, за счёт использования стрелочных функций, кода стало меньше и читается он лучше.
