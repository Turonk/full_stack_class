Функция filter()

Согласны! Тем более, если присмотреться к нашей повседневности, в интернете мы постоянно всё фильтруем — ищем ли на маркетплейсе товар определённого бренда, или читаем статьи по конкретной теме. За любой такой наш выбор на разных сайтах отвечает фильтрация. А у массивов есть встроенный метод `filter()`

Лови!

Не так давно мы рассказывали тебе про метод `find()`, который аргументом получает функцию. Эта функция должна содержать условие и возвращать `true` или `false`. Как только условие будет положительное, метод `find()` останавливает перебор массива и возвращает искомый элемент.

Так вот — метод `filter()` очень похож на метод `find()`, но разница в том, что `filter()` не останавливает перебор массива, а собирает все элементы, удовлетворяющие условию, в новый массив.

{video:https://code.s3.yandex.net/kids-web/Untitled_Artwork_27.mp4}

Отличная идея, тем более что на стриминговых платформах пользователи постоянно прибегают к фильтрам.

Вот как выглядит фильтрация массива фильмов по жанру 👇🏻

const movies = [
	{id: 1, genre: 'comedy', name: 'Барби'}, // Жанр: комедия
  {id: 2, genre: 'action', name: 'Джон Уик 4'}, // Жанр: боевик
  {id: 3, genre: 'fiction', name: 'Интерстеллар'}, // Жанр: фантастика
	{id: 4, genre: 'fantasy', name: 'Гарри Поттер'}, // Жанр: фэнтези
	{id: 5, genre: 'fantasy', name: 'Властелин колец'} // Жанр: фэнтези
];

const fantasy = movies.filter(function(item, index, arr) {
	// Тут указываем условие: нужно вернуть элемент,
	// в ключе genre которого будет название 'fantasy'
  return item.genre === 'fantasy';
});

console.log(fantasy); 
// [
//   {id: 4, genre: 'fantasy', name: 'Гарри Поттер'},
//   {id: 5, genre: 'fantasy', name: 'Властелин колец'}
// ]

Функция внутри `filter()` принимает три аргумента:

- первый аргумент (`item`) — элемент массива, до которого в данный момент добрался метод `filter()` - второй аргумент (`index`) — индекс элемента в массиве - третий аргумент (`arr`) — весь массив, по которому пробегает `filter()`

Метод `filter()` перебирает элементы массива и для каждого запускает переданную функцию, которая должна вернуть `true` или `false`. Как только функция вернёт `true`, метод добавляет найденный элемент в новый массив. Именно поэтому найденные фильмы в примере выше сохраняются в переменную `fantasy`

Используя стрелочные функции, код из примера выше можно записать компактнее 👇🏻

const fantasy = movies.filter(item => item.genre === 'fantasy');

В примерах выше функции, которые использует метод `filter()`, написаны непосредственно в самом методе в виде анонимных функций. Так делать удобно, когда подобные функции больше нигде не встречаются.

Но в больших проектах блоки кода часто выносят в отдельные функции, если подобный код нужно переиспользовать в разных частях программы. Поэтому давай разберём ещё один пример с фильтрацией массива с числами. Только в этом примере опишем функцию для фильтрации отдельно и передадим в метод `filter()` ссылку на неё, передав имя функции в метод в виде аргумента 👇🏻

// Опишем отдельно функцию, которая аргументом получает число 
// и возвращает результат сравнения числа с четвёркой
function moreThan4(number) {
  if (number > 4) {
    return true
  }
  return false
}

const numbers = [1, 2, 3, 4, 5, 6, 7, 8]

// Передадим функцию moreThan4 в метод
numbers.filter(moreThan4) // [5, 6, 7, 8]

Метод `filter()` вызывает для каждого элемента в массиве `numbers` функцию `moreThan4()`. Так как функция в методе первым аргументом получает сам элемент массива, выходит, что в качестве `number` в функции `moreThan4()` попадает число из массива. Оно сравнивается с четвёркой, и по результатам сравнения формируется новый массив с числами, для которых сравнение вернуло `true`
