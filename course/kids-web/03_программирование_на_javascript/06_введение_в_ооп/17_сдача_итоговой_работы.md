### Минимальные требования к проекту

В твоём коде реализована базовая механика игры:

- Одна карточка персонажа заполняется информацией от пользователя, которую тот вводит через форму на сайте.
- Вторая карточка персонажа заполняется информацией о рандомном герое из списка, который пришёл с сервера.
- Реализована логика вычисления сильнейшего из двух персонажей.
- Результат вычислений выводится в консоль.

Если это покажется слишком простым и скучным, можешь выполнить дополнительные задания, это позволит тебе ещё больше прокачать навыки использования JS.

### Дополнительные задания

- Добавить методы в классы `Mage` и `Knight`, которые могли бы учитывать дополнительные особенности каждого класса и давать им уникальные способности (например, для мага — увеличивать значение очков здоровья за счёт маны героя, а для рыцаря — увеличивать значение ловкости за счёт очков энергии).
- Усовершенствовать определение победителя, сделать более умный, интересный расчёт с учётом особенностей героев.
- Заменить вывод информации в консоль о ходе баттла на отображение данных на странице сайта в окне браузера.
- Добавить анимации для карточек и изменять их вид в ходе баттла для визуализации процесса.
