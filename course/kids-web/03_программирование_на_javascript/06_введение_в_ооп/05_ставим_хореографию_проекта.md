# Ставим хореографию проекта

Присоединяемся к радостному приветствию! В этом уроке мы наконец начнём разработку интерактивной логики на JavaScript для игры. В ней мы задействуем все твои навыки с прошлых уроков: создание классов, функций, циклов, условий и запросов к серверу.

Для начала определимся с механикой игры. Пусть это будет `Dance Battle` между двумя персонажами. Одного персонажа мы создаём через форму на сайте, а второй приходит к нам с сервера. 

Затем карточки обоих персонажей с их характеристиками отображаются на странице сайта, появляется кнопка `НАЧАТЬ БАТТЛ!`. При нажатии на эту кнопку запускается вычисление, какой персонаж более выносливый и лучше танцует. Результат вычисления отображается в консоли.

По умолчанию интерфейс будет выглядеть так:

![](https://pictures.s3.yandex.net:443/resources/Snimok_ekrana_2023-12-29_v_20.33.04_1704912423.png)

Кажется, работа предстоит масштабная, но давай двигаться постепенно. В этом уроке мы создадим проект и настроим форму, чтобы пользователь мог взаимодействовать с ней, а в следующих разберёмся с выводом информации о танцорах в карточках и логикой игры.

В прошлых уроках мы создавали персонажей трёх видов: `Hero`, `Knight`, `Mage`. У них были параметры интеллекта, силы и так далее. Теперь важно добавить пару переменных, в которые запишем ограничения параметров персонажей. Так игра будет честнее и никто не сможет создать слишком сильного героя. 

Переменная `gameParameters` ограничит характеристики персонажей, а `gameClasses` — их разнообразие:

```javascript
// Объект с настройками игры
const gameParameters = {
    MAX_LEVEL: 10, //Максимальный уровень героя
    MAX_STAT: 99, //Минимальный уровень параметра героя
		MIN_STAT: 10, //Минимальный уровень параметра для умения
}

// Объект классов игры
const gameClasses = {
    Mage: "Маг",
    Knight: "Рыцарь",
    Hero: "Класс"
}
```

Далее объявим переменные для игроков `Heroes Dance Battle`. В переменной `playerHero` будет персонаж, созданный через форму на сайте. В переменной `enemyHero` — персонаж оппонента, который приходит с сервера:

```javascript
// Объявление героя игрока
let playerHero = null;

// Объявление героя оппонента
let enemyHero = null;
```

Пока запишем в значения переменных `null` — это означает, что данные не определены (ведь мы ещё никого не создали и ничего не получили с сервера). Как только пользователь создаст героя и мы подберём ему соперника, в этих переменных появится соответствующая информация.

Теперь найдём все интерактивные кнопки в проекте и сохраним их в переменные. Процесс тебе уже знаком: объявляем переменную и записываем в неё то, что вернёт функция `getElementById()` с соответствующим `id` в виде строки. Поиск элементов происходит по DOM-дереву. Оно хранится в объекте `document` 👇🏻

- кнопку отправки на танцпол можно найти так:

    ```javascript
    // Добавление героя игрока на экран
    const sendToBattleButton = document.getElementById("sendToBattleButton");
    ```

- кнопку подбора противника в карточке `Герой оппонента` — так:

    ```javascript
    // Вывод героя оппонента на экран
    const getEnemyButton = document.getElementById("getEnemyButton");
    ```

- кнопку использования дополнительного умения персонажа в карточке `Ваш герой` — так:

    ```javascript
    // Действие героя игрока
    const doSkillButton = document.getElementById("doSkillButton");
    ```

- а кнопку `НАЧАТЬ БАТТЛ!` под карточками персонажей — так:
    
    ```javascript

    ```

На странице проекта есть форма 👇🏻

![](https://pictures.s3.yandex.net:443/resources/Snimok_ekrana_2023-12-29_v_20.39.49_1704912713.png)

Пользователь, заполняя поля формы, формирует данные карточки своего персонажа. А далее тебе нужно их обработать. Для этого установим слушатель на событие клика по кнопке.

### Установка слушателя события `click`

В прошлых уроках для отслеживания событий клика по элементу мы использовали метод `onclick`. Раньше ему просто присваивали именованную функцию (то есть функцию с именем; о том, какие бывают ещё, расскажем ниже). Для кнопки `sendToBattleButton` это выглядело бы так:

```javascript
function logClick() {
  console.log("Произошёл click");
}

sendToBattleButton.onclick = logClick;
```

Но сейчас мы тебе расскажем об очень крутой фишке в JS, которая позволит написать этот код короче и без использования отдельных функций как `logClick()`

В коде на прошлых неделях можно было заметить **стрелочные функции** (функции с особым синтаксисом), одна из них выглядела так:

```javascript
const makeSomeOtherThing = () => { /*Тело функции*/ }
```

Главные её отличия от классической функции — отсутствие ключевого слова `function` и добавленная стрелка после списка аргументов.

Так выглядит функция сложения элементов `a` и `b`:

```javascript
const sum = (a, b) => a + b;
```

А так — получение первого элемента массива:

```javascript
const getFirstElemOfArray = array => array[0];
```

В примерах выше стрелочная функция сохранена в переменную. Но если нам нужно вызывать функцию в методе или в слушателе событий, мы можем описать её прямо внутри метода или слушателя. Указатель в виде переменной или названия функций в таком случае не нужны. 

Может показаться сложным, но на самом деле мы уже так делали в уроке про запросы к серверу:

```javascript
fetch(`https://api-code.practicum-team.ru/heroes`)
    .then((response) => response.json());
    .then((data) => console.log(data));
// В этой части кода мы получали ответ от сервера 
// и аргументом в функцию then передавали стрелочную функцию для обработки ответа
```

В JS функции, которые не имеют имени, называются **анонимными**. Получается, что стрелочные функции могут быть анонимными. Подробно про разновидности функций, как всегда, читай в [Доке](https://doka.guide/js/function/){target="_blank"}.

Давайте применим новые знания в нашем проекте. Установим слушатель события `click` на кнопку `sendToBattleButton` при помощи метода `onclick` , которому присвоим анонимную стрелочную функцию. Позже в ней мы опишем логику добавления персонажа пользователя:

```javascript
// Получение информации героя игрока
sendToBattleButton.onclick = () => {
 // Обработка формы 
}
```

Выносить функцию обработки клика в отдельный блок необязательно, нам не потребуется переиспользовать её где-то ещё. Поэтому описать функцию будет удобно и правильно только там, где она вызывается — в обработчике клика у кнопки `sendToBattleButton`. К тому же стрелочные функции иначе работают с `this`, поэтому их удобно использовать внутри методов объектов или слушателей.
