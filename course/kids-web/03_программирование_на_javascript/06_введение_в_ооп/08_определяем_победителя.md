# Определяем победителя

А пока давай синхронизируемся.

В прошлых уроках мы получили из формы на странице персонажа пользователя. Объект с характеристиками сохранён в переменной `playerHero`. Запрос на сервер приносит нам список всех героев, из которого мы получаем случайного противника — объект в переменной `enemyHero`

Теперь по клику на кнопку `ОТПРАВИТЬ НА ТАНЦПОЛ` наша программа должна определять победителя. Для этого реализуем две функции:

- первая будет подсчитывать сумму характеристик персонажа
- вторая с помощью вывода в консоль `console.log()` будет информировать о ходе баттла и выбирать победителя

Мы пройдём все шаги написания кода вместе, чтобы объяснить базовую функциональность. Но, если захочется проверить свои силы в настоящем испытании, в конце урока тебя ждёт квест уровня `hard`

## Подсчёт характеристик

Что в танцевальном баттле важнее всего?

Не поспоришь! Признаем, для наших персонажей танцы не основной вид деятельности: рыцари участвуют в сложных походах за новыми технологиями, маги создают волшебные библиотеки и блоки кода. У всех персонажей есть общий набор характеристик: сила, ловкость, интеллект и количество очков здоровья. Давай просто сложим эти показатели. Это можно сделать всего за два шага.

### Шаг 1

Создадим функцию `countStatsSum`, которая будет принимать в качестве аргумента объект персонажа `hero`, а в теле функции создадим переменную для суммы характеристик `statsSum`. В самом начале она будет равна нулю 👇🏻

```javascript
function countStatsSum(hero) {
    let statsSum = 0;
}
```

### Шаг 2

Теперь мы пройдём по характеристикам силы, ловкости, интеллекта и здоровья персонажа `hero` и суммируем их с переменной `statsSum`

Чтобы получить значение здоровья персонажа, необходимо обратиться через точку по соответствующему ключу в объекте, вот так — `hero.healthPoints`

Остальные характеристики лежат в объекте `stats` внутри `hero`

Ну и не забываем про синтаксис сложения. Если мы хотим прибавить к переменной значение и тут же его присвоить, можно использовать символы `+=`👇🏻

```javascript
function countStatsSum(hero) {
  let statsSum = 0;
	// Последовательно прибавляем в переменную statsSum значения характеристик из объекта hero
  statsSum += hero.stats.str;
  statsSum += hero.stats.int;
  statsSum += hero.stats.agi;
  statsSum += hero.healthPoints;

  return statsSum;
}
```

В конце обязательно указываем ключевое слово `return` и название переменной `statsSum`. Это позволит функции `countStatsSum` не только сложить все характеристики, но и вернуть результат расчёта. Это тебе понадобится для определения более стойкого персонажа. 

Теперь пора писать функцию определения победителя!

## Расчёт победителя и вывод результата

Пропишем код для сравнения рассчитанных характеристик и для вывода оповещений о ходе баттла в консоль. В этот раз за четыре шага.

### Шаг 1

Танцевальный баттл обычно проходит на сцене либо в специальном зале. Из-за особенностей наших персонажей, а именно рыцаря, который может танцевать танго на коне, назовём наш танцпол ареной. Так же назовём и функцию. Она будет принимать аргументом двух персонажей: `firstHero` и `secondHero`

Для начала сообщим, между кем проходит баттл👇🏻

```javascript
function arena(firstHero, secondHero) {
  console.log(
    `Да начнётся танцевальный баттл между ${firstHero.name} и ${secondHero.name}!`
  );
}
```

### Шаг 2

Теперь создадим переменные, необходимые для расчёта победителя, и выведем суммарные значения характеристик в консоль.

Объявим:

- переменную `winner` со значением `null` (в начале функции она будет пустая, но после всех вычислений запишем в неё победителя)
- переменную `fistHeroSum`, в которую сохраним сумму характеристик первого героя (чтобы её получить, воспользуемся ранее записанной функцией, передав аргументом первого персонажа `countStatsSum(firstHero)`)
- переменную `secondHeroSum`, куда сохраним сумму характеристик второго персонажа, которые вернёт функция `countStatsSum(secondHero)`

И выведем в консоль значения характеристик для персонажей 👇🏻

```javascript
function arena(firstHero, secondHero) {
  console.log(
    `Да начнётся танцевальный баттл между ${firstHero.name} и ${secondHero.name}!`
  );

  let winner = null;

  let fistHeroSum = countStatsSum(firstHero);
  let secondHeroSum = countStatsSum(secondHero);

  console.log("Сумма значений параметров первого героя: ", fistHeroSum);
  console.log("Сумма значений параметров второго героя: ", secondHeroSum);
}
```

Осталось только сравнить характеристики персонажей и сообщить о более стойком герое!

### Шаг 3

Для вычисления победителя используем давно знакомую тебе конструкцию условий — `if … else if …`. В ней сравним значения сумм характеристик `fistHeroSum`, `secondHeroSum` и запишем в переменную `winner` того персонажа, у которого значение окажется больше.

Во втором условии проверим, записан ли в переменную `winner` какой-либо герой. Если в `winner` сохранён герой, выведем поздравление с именем персонажа победителя. Если в `winner` всё ещё остался `null` — это означает, что характеристики персонажей равны и в данном баттле победила дружба. Выведем и эту информацию — и в консоль, и уведомлением на странице 👇🏻

```javascript
function arena(firstHero, secondHero) {
  console.log(
    `Да начнётся танцевальный баттл между ${firstHero.name} и ${secondHero.name}!`
  );

  let winner = null;

  let fistHeroSum = countStatsSum(firstHero);
  let secondHeroSum = countStatsSum(secondHero);

  console.log("Сумма значений параметров первого героя: ", fistHeroSum);
  console.log("Сумма значений параметров второго героя: ", secondHeroSum);

	if (fistHeroSum > secondHeroSum) {
	  winner = firstHero;
  } else if (fistHeroSum < secondHeroSum) {
    winner = secondHero;
  }

  if (winner) {
    console.log(`Ритмично чествуем победителя: ${winner.name}`);
    alert(`Ритмично чествуем победителя: ${winner.name}`);
  } else {
    console.log("В танцевальном баттле победила дружба!");
    alert("В танцевальном баттле победила дружба!");
  }
}
```

Вот и вся логика определения победителя. Осталось только запускать её при каждом клике кнопки `startBattleButton`

### Шаг 4

Для запуска функции-арены достаточно записать в метод `onclick` анонимную стрелочную функцию, где мы будем вызывать функцию `arena`, и передать в неё два аргумента — персонажей `playerHero` и `enemyHero` 👇🏻

```javascript
startBattleButton.onclick = () => {
    arena(playerHero, enemyHero);
};
```

Теперь наша игра готова 🥳

В ней мы устраиваем баттл между героями, которых получаем из формы на странице и сервера. Весь баттл — это расчёт характеристик и вывод всех этапов расчётов в консоль.

// Метод лечения героя у класса Mage

	  console.log(this.name + " продлевает танец " + hero.name + " на " + healAmount + " единиц.");
	
		// Трата маны пропорционально уровню героя

	} else {
    alert("Недостаточно маны...");
  }
}

// Метод увеличения ловкости героя у класса Knight
gainAgility(hero) {
	if (this.energy > gameParameters.MIN_STAT) {
	  // Количество увеличения ловкости

    // Если при увеличении значение ловкости не превысит максимальное,
    // увеличиваем ловкость,
    // иначе устанавливаем максимальное значение

    if (hero.stats.agi + gainAmount < gameParameters.MAX_STAT) {
	    hero.stats.agi += gainAmount;
      console.log(this.name + " увеличивает ловкость " + hero.name + " на " + gainAmount + " единиц.");
    } else {
      hero.stats.agi = gameParameters.MAX_STAT;
    }

    // Уменьшение энергии пропорционально уровню героя
    const energyAmount = (gainAmount * 10) / this.level;
    if (this.energy - energyAmount > gameParameters.MIN_STAT) {
	    this.energy -= energyAmount;
    } else {
      this.energy = gameParameters.MIN_STAT;

    displayPlayerHero(playerHero);
