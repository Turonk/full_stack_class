Классы и конструктор объектов

Аски, ты прав! В JavaScript есть специальный инструмент, который играет роль такого шаблона, — это **классы**. В этом уроке мы научимся описывать с их помощью типовые объекты.

{video:https://code.s3.yandex.net/kids-web/Untitled_Artwork_24.mp4}

Работа с классами чем-то напоминает работу с уже знакомыми тебе функциями. Ты же помнишь, что функцию надо сначала объявить, потом описать, что она будет делать, а потом вызывать в самом коде. С классами похожий алгоритм: сперва создаёшь класс, а потом — **экземпляр** класса. Экземпляром класса называют созданный с помощью класса объект.

Чтобы описать класс, нужно написать ключевое слово `class`, его название и фигурные скобки (в которых как раз будем описывать свойства создаваемых объектов).

Начнём создавать класс для базовой карточки любого героя нашей игры. Обычно классы принято называть существительным, поэтому мы назовём его `Hero` 👇🏻

class Hero {}

Теперь создать нового героя по шаблону из класса мы можем, используя ключевое слово `new` и название класса с круглыми скобками после него 👇🏻

let newHero = new Hero();

Отлично, мы уже создали шаблон карточки персонажа и саму карточку, но пока что они пусты. Давай посмотрим, как использовать класс `Hero`, чтобы превратить в шаблон наш объект из прошлой темы.

let newHero = {
	title: titleInput.value,
	description: descriptionInput.value,
	str: strInput.value,
	agi: agiInput.value,
	hp: hpInput.value,
	int: intInput.value,
	studentEmail: studentEmail
}

Если мы попробуем добавить данные так же, как со знакомыми тебе объектами, то вернётся ошибка👇🏻

class Hero {
	title: "Цэ-эс-эсочка",
	description: "Лунная призма, дай мне сил, пожалуйста.",
	str: 30,
	agi: 99,
	hp: 99,
	int: 99,
	studentEmail: "student@yandex.ru"
}

let CSSchan = new Hero(); // Будет ошибка

Всё дело в том, что при создании классовых объектов для указания их свойств нужно воспользоваться функцией-конструктором, она так и называется: `constructor()`. А записывать данные в создаваемый объект нужно, используя ключевое слово `this` (`this` переводится «здесь» и в конструкторе класса указывает на класс, в котором мы записываем свойства). Вот как это выглядит 👇🏻

class Hero {
	constructor() {
		this.title = "Цэ-эс-эсочка";
		this.description = "Лунная призма, дай мне сил, пожалуйста.";
		this.str = 30;
		this.agi = 99;
		this.hp = 99;
		this.int = 99;
		this.studentEmail = "student@yandex.ru";
	}
}

let CSSchan = new Hero();

console.log("Описание Цэ-эс-эсочки: " + CSSchan.description);
// "Описание Цэ-эс-эсочки: Лунная призма, дай мне сил, пожалуйста."

Данные в ней будут такими же, как мы указали в нашем шаблоне — функции-конструкторе.

let ASCIIsan = new Hero();
console.log("Описание Рыцаря Аски: " + ASCIIsan.description);
// "Описание Рыцаря Аски: Лунная призма, дай мне сил, пожалуйста."

Поняли-приняли. Чтобы иметь возможность передавать другие данные при создании нового объекта с помощью класса, нужно указать их как параметры в функции-конструкторе. Вот так 👇🏻

class Hero {
  constructor(title, description, str, agi, hp, int, studentEmail) {
    this.title = title;
    this.description = description;
    this.str = str;
    this.agi = agi;
    this.hp = hp;
    this.int = int;
    this.studentEmail = studentEmail;
  }
}

let CSSchan = new Hero(
  "Цэ-эс-эсочка",
  "Лунная призма, дай мне сил, пожалуйста.",
  30,
  99,
  99,
  99,
  "student@yandex.ru"
);

let ASCIIsan = new Hero(
  "Рыцарь Аски",
  "Мои доспехи ведут к успеху.",
  99,
  30,
  99,
  99,
  "student@yandex.ru"
);

console.log("Описание Цэ-эс-эсочки: " + CSSchan.description);
// "Описание Цэ-эс-эсочки: Лунная призма, дай мне сил, пожалуйста."
console.log("Описание Рыцаря Аски: " + ASCIIsan.description);
// "Описание Рыцаря Аски: Мои доспехи ведут к успеху."

Ура, мы получили две карточки персонажей с разными данными, созданными по одному шаблону.
