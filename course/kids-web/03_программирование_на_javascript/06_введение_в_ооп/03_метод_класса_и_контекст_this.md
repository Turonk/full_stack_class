## Методы

Методы — это функции, их отличие только в том, что они находятся внутри классов и могут взаимодействовать со свойствами класса. 

Допустим, у нас есть класс, описывающий котика:

```javascript
class Cat {
	constructor(name, age, color) {
		this.name = name;
    this.age = age;
    this.color = color;
	}
};
```

Действительно, Аски. 

Давайте-ка научим его мяукать, для этого добавим в объект метод `makeMew` (обрати внимание, что, в отличие от объявления обычной функции, мы не будем использовать ключевое слово `function`)👇🏻

```javascript
class Cat {
	constructor(name, age, color) {
		this.name = name;
    this.age = age;
    this.color = color;
	}
	// Тут не нужно использовать ключевое слово function, так как это метод объекта
	makeMew() { // Мяукнуть 
		console.log('Мяу-мяу');
	}
};

// Создадим объект (кота Барни) — экземпляр класса Cat
const catBarni = new Cat("Барни", 7, "чёрно-белый");
```

Мы можем обращаться к свойствам класса через точку, чтобы получать значения этих свойств или перезаписывать их. Вызов метода выполняется также через точку 👇🏻

```javascript
// Выведем в консоль имя кота
console.log(catBarni.name) // "Барни"
// Обращаться к методам объекта также можно через точку 
catBarni.makeMew() // Выведет в консоль "Мяу-мяу"
```

Без проблем, можем добавить метод `sayAge()` , чтобы кот мог мяукнуть столько раз, сколько ему лет. Но для этого поговорим поподробнее о `this`

## Немного о `this`

Чтобы кот научился рассказывать о своём возрасте, надо в методе `sayAge()` обратиться к свойству `age` — для этого необходимо использовать ключевое слово `this` 👇🏻

```javascript
class Cat {
	constructor(name, age, color) {
		this.name = name;
    this.age = age;
    this.color = color;
	}
	
	makeMew() { 
		console.log('Мяу-мяу');
	}
	
	sayAge() {
    console.log("Мяукнуть " + this.age +" раз");
  }
};

// Создадим объект (кота Барни) - экземпляр класса Cat
const catBarni = new Cat("Барни", 7, "чёрно-белый");
catBarni.sayAge() // Команда выведет в консоль "Мяукнуть 7 раз"
```

С помощью `this` можно обращаться к любым свойствам и методам текущего класса. Значение `this` — это объект перед точкой, который используется для вызова метода.

```javascript
// Во время выполнения catBarni.sayAge() значением this будет являться 
// объект catBarni, поэтому this.age вернёт то же значение, как catBarni.age
cat.sayAge() // "Мяукнуть 7 раз"
```

Это удобно, потому что значение `this` вычисляется во время выполнения кода и зависит от места вызова. Если у нас есть два разных экземпляра класса с одинаковым методом, то в каждом случае результат вызова метода будет отличаться. Это значительно практичнее, чем указывать фиксированную переменную в методе.

```javascript
class Cat {
	constructor(name, age, color) {
		this.name = name;
    this.age = age;
    this.color = color;
	}
	
	makeMew() { 
		console.log('Мяу-мяу');
	}
	
	sayAge() {
    console.log("Мяукнуть " + this.age +" раз");
  }
};

// Создадим объект (кота Барни) - экземпляр класса Cat
const catBarni = new Cat("Барни", 7, "чёрно-белый");
// Создадим объект (кошку Булочку) - экземпляр класса Cat
const catBulochka = new Cat("Булочка", 5, "коричневый");

// В зависимости от экземпляра класса, в значении this будут разные объекты 
// и, соответственно, разный возраст животного
catBarni.sayAge() // "Мяукнуть 7 раз"
catBulochka.sayAge() // "Мяукнуть 5 раз"
```

## `class Hero` и его метод `displayHero()`

В проекте есть класс — шаблон, который позволяет создавать персонажей для проекта. И мы уже создали два объекта с персонажами `CSSchan` и `ASCIIsan` на его основе 👇🏻

```javascript
class Hero {
	constructor(name, level, healthPoints, stats) {
	  this.name = name; //имя
    this.level = level; //уровень
    this.healthPoints = healthPoints; //жизненные силы
    this.stats = stats; //параметры
  }
}

let ASCIIsan = new Hero(
  "Рыцарь Аски",
	100,
	100,
	{
		str: 100,
		int: 30,
		agi: 100
	}
);

let CSSchan = new Hero(
  "Цэ-эс-эсочка",
	100,
	100,
	{
		str: 30,
		int: 100,
		agi: 100
	}
);
```

Теперь давай добавим классу `Hero` метод `displayHero()`, который будет выводить основные характеристики героя в консоль. 

В этой функции ты соберёшь характеристики из объекта героя при помощи ключевого слова `this` в шаблонную строку и отобразишь её в консоли при помощи `console.log()`👇🏻

```javascript
class Hero {
	constructor(name, level, healthPoints, stats) {
	  this.name = name; //имя
    this.level = level; //уровень
    this.healthPoints = healthPoints; //жизненные силы
    this.stats = stats; //параметры
  }
	// Метод, отвечающий за вывод информации о герое в консоль
  displayHero() {
		// С помощью шаблонной строки соберём характеристики героя в строку
    const heroInfo =
			// this.name выведет значение имени героя у объекта
			// "\n" - символ, позволяющий перенести текст на новую строку 
      `Имя: ${this.name}` + 
      `\nУровень: ${this.level}` +
      `\nЖизненные силы: ${this.healthPoints}` +
      `\nСила: ${this.stats.str}` +
      `\nИнтеллект: ${this.stats.int}` +
      `\nЛовкость: ${this.stats.agi}`;
			// Вывод информации в консоль
      console.log(heroInfo);
    }
}
```
