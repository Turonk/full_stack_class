В этом уроке хотим познакомить тебя поближе с JS, показать несколько вдохновляющих примеров проектов, написанных на этом языке, и даже предложить тебе пару весёлых заданий.

**Что такое JavaScript**

JS — это современный язык программирования, который выделяется своей визуальностью и интерактивностью. Если на сайте что-то двигается, меняется или реагирует на клики и нажатия клавиш, скорее всего, это работа JavaScript.

Разработчики JavaScript часто тесно сотрудничают с дизайнерами. Некоторые, набираясь опыта, даже приобретают навыки дизайнера. Кстати, редкость представляют собой люди, которые владеют и кодингом, и дизайном, — их называют «единорогами», и они особенно ценятся в стартапах 🦄

HTML, который уже занимает почётное место в списке твоих умелок, это язык разметки — рассказывали тебе в первом модуле. С его помощью можно сделать пару симпатичных страниц для простенького сайта, но, чтобы бахнуть мощный сложный веб-сервис типа «ВКонтакте» или запилить компьютерную игру, потребуется инструмент помощнее — как раз такой, как JS.

Тебе не показалось!

Многочисленные возможности JavaScript в сочетании с современными браузерами и мощными устройствами позволяют работать с 3D-графикой и создавать мультиплеерные игры. И всё это может работать на любом устройстве без установки — настоящая магия!

Ну ладно: делу — время, потехе — час. Погнали посмотрим, как вообще выглядит код на JS.

// 1. Создаём переменную с массивом из персонажей Доты
let dotaHeroes = ["Пудж", "Инвокер", "Фантомный Убийца", "Снайпер", "Джаггернаут"];

// 2. Создаём переменную с массивом из персонажей аниме 
let animeCharacters = ["Наруто", "Гоку", "Сайтама", "Луффи", "Лайт Ягами"];

// Функция для выбора случайного героя из массива
function chooseRandomHero(heroesArray) {
    let randomIndex = Math.floor(Math.random() * heroesArray.length);
    return heroesArray[randomIndex];
}

// 3. Создаём команду для битвы, выбирая случайных героев
let battleTeam = [
    chooseRandomHero(dotaHeroes),
    chooseRandomHero(dotaHeroes),
    chooseRandomHero(animeCharacters),
    chooseRandomHero(animeCharacters)
];

// 4. Печатаем список команды для битвы в консоль
console.log("Команда для битвы: " + battleTeam.join(", "));

Это королевская битва с персонажами из Доты и аниме. Но прежде всего это программа, написанная на JS. Обещаем, к концу недели ты уже будешь понимать, что тут и для чего, а пока держи первое задание:

1. Скопируй блок кода выше. 2. Запусти его в браузере (ниже объясним, как это сделать без VSCode). 3. Получи свою команду героев.

В течение этого модуля ты будешь работать как в песочницах внутри уроков, так и самостоятельно в редакторе кода VSCode. И в обоих случаях тебе поможет твой новый лучший друг в мире веб-разработки 👇🏻

Консоль браузера и console.log()

Для того чтобы протестировать код, проверить ошибки в нём, да и просто пообщаться с браузером с помощью кода, существует консоль (нет, не которая плейстейшен) браузера.

Вызвать её проще всего кнопкой F12 (на маке fn + F12), дальше нажать на вкладку Console. Сделать это можно на любом сайте, даже сейчас на уроке Практикума.

![](https://pictures.s3.yandex.net:443/resources/Screenshot_2023-11-09_at_23.13.03_1699636250.png) *Вкладка Console подсвечена синим в нижней части инструментов разработчика*

Если получилось открыть, вставляй скопированный код в поле ввода в консоли (>) и нажимай Enter. Итогом будет твоя суперкоманда персонажей.

Как можно было понять из кода, за вывод сообщения в консоль отвечает команда `console.log` — без неё программа не выдала бы тебе героев.

// Печатаем список команды для битвы в консоль
console.log("Команда для битвы: " + battleTeam.join(", "));

По-русски читается «консоль лог». Помимо помощи в поиске ошибок, разработчики любят использовать эту команду для оставления пасхалок своим коллегам, ведь только программисты смотрят консоль. Одна такая есть на сайте Практикума.

![](https://pictures.s3.yandex.net:443/resources/Screenshot_2023-11-09_at_23.31.09_1699636285.png)

Кстати, существует стереотип, что разработчики чаще общаются с кодом, чем со своими друзьями. Доля правды в этом есть: сообщения оставляют в консоли, а ещё в комментариях…

Не, прямо в коде!

Комментарии в коде

// Привет, это я, твой прошлый ты. Я оставил тебе этот комментарий, чтобы 
// напомнить, что мы вместе должны пофиксить тут ошибку. Так что давай не подведём нас обоих, окей?

Комментарии в коде — это сообщения, которые программисты оставляют в коде программы. Зачастую ради объяснения логики работы программы другим разработчикам, включая будущее «я» автора. Они не влияют на исполнение программы, браузер их попросту игнорирует.

Комментарии могут служить различным целям:

1) Объяснять функционал определённого участка кода.

2) Оставлять напоминания о необходимости исправления или доработки.

3) Быть средством коммуникации между членами команды.

В этом модуле мы будем постоянно использовать комментарии в примерах кода в уроках. Писать их очень просто, в JS они начинаются с `//` в начале строки. Всё, что после на этой строке, браузер не читает и игнорирует.
