# Вкусный заход

Для этого предстоит подключить его к API. 

Ты уже знаешь про работу с API на JavaScript, теперь добавим щепотку React и Next.

После этого останется только шлифовка и сонастройка компонентов друг с другом.

Инфы будет много, рассчитываем на твой аппетит к новым знаниям.

![](https://pictures.s3.yandex.net:443/resources/Worn-Ass-Semi-Gloss_50_1708522230.jpg)

В меню:

- Начнём с завтрака. Кто у нас кормит завтраками и обещаниями (промисами)? Правильно, твоя старая знакомая — функция `fetch`. Писать её можно по-разному, а ещё она умеет работать на сервере и на клиенте. Познакомимся ближе.
- Следом получим суп данных `GET`-запросом — упоминали его во втором модуле, но теперь воспользуемся на React и Next. Попутно разберёмся, как надёжнее запрашивать данные снаружи.
- Основное блюдо темы — авторизация. Это `POST`-запросы, которые ты тоже уже знаешь поверхностно. Научимся запоминать пользователя, если он авторизован, чтобы повторное посещение сайта происходило без ввода логина и пароля (наш инструмент для этого — `JWT`).
- Ну и на десерт — голосование за игру. Используем для реализации `PUT`-запросы.

Не будем юлить — тема действительно сложная, впереди много работы с кодом, но и результат обещаем вкусный!

Но добавим, что, пока не получишь зачёт от наставника по заданию этой темы, не сможешь загрузить финальную работу модуля на проверку.
