## Идея условного рендеринга

Примеры выше наглядно показывают, как работает **условный рендеринг**. Он даёт нам возможность настраивать компоненты или менять их в зависимости от передаваемых параметров.

![](https://pictures.s3.yandex.net:443/resources/Frame_1465_1_1706890915.png)

Перед тем как изменять компоненты, сначала нужно научиться проверять **props** (аргументы), которые мы в них передаём. 

Давай разберёмся, как это можно сделать.

### Тернарный оператор

Для проверки условий мы обычно пользуемся конструкцией `if...else`. Она удобна, но не работает внутри JSX-компонентов. В мире React на её замену приходит **тернарный оператор.** Он предлагает нам более краткий способ написания условий в JavaScript. 

Его структуру просто описать по следующей схеме 👇🏻

```javascript
const result = условие ? действие_если_истина : действие_если_ложь
```

Тернарный оператор как бы задаёт вопрос условию «Это правда или ложь?». 

Если правда, можно совершить определённое действие после символа `?`, а если ложь — выполнить что-то другое после символа `:`

Всегда за!

Проверим переменную `isStock`: если товар в наличии, выведем в кнопку надпись `Купить`, а если `isStock` окажется ложной и товара в наличии нет, выведем надпись `Нет в наличии` 👇🏻

```javascript
const isStock = true;
const button = document.querySelector("button")

// Используем "if - else"
if (isStock) {
	button.textContent = "Купить"
} else {
	button.textContent = "Нет в наличии"
}

// Используем тернарный оператор
button.textContent = isStock ? "Купить" : "Нет в наличии"
```

У нас есть поле для ввода числа. При помощи условия `input.value % 2 === 0` мы проверяем, чётное число или нет. Перепиши проверку, используя тернарный оператор.

```javascript
input.value % 2 === 0 ? status.textContent = "Число чётное" : status.textContent = "Число нечётное";
```

### Конструкция `"&&"`

**Конструкция `"&&"`** (`"И"`) уже знакома тебе из модуля «Основы JavaScript». 

Часто мы используем этот оператор, когда нужно проверить два условия и выполнить определённое действие в том случае, если оба верны. Но это не всё, на что он способен. 

`"&&"` может заменить конструкцию `"if"` в ситуациях, когда блок `"else"` не требуется. Такой подход делает проверку условий более компактной, улучшая читаемость кода.

```javascript
const products = 5;

// Используем конструкцию "if"
if (products > 0) {
	console.log(`Всего товаров: ${products}`);
}

// Используем конструкцию "&&"
products > 0 && console.log(`Всего товаров: ${products}`);
```

В этом примере оба подхода приведут к одному и тому же результату — выводу количества товаров, если они есть. Но использование оператора `"&&"` сделает код легче и гораздо понятнее, а также сэкономит ресурсы браузера на его выполнение.

У нас есть форма с несколькими полями. При клике на кнопку `Отправить` мы используем цикл с проверкой заполненности полей. Если любое из полей пустое, появляется сообщение с ошибкой.

## **Условный рендеринг в JSX**

После изучения основных идей условного рендеринга в обычном JavaScript давай перенесём наши знания в мир React. Здесь мы часто используем тернарный оператор и конструкцию `"&&"` для удобного управления отображением компонентов.

### Тернарный оператор в JSX

Вспомним, что тернарный оператор позволяет нам сократить условную проверку до одной строчки кода. Рассмотрим пример, где мы изменим не только текст кнопки, но и её стиль 👇🏻

```javascript
import Styles from './Button.module.css'

export function Button (props) {
  return (
    <button className={props.isStock ? Styles['green'] : Styles['gray']}>
      {props.isStock ? 'Купить' : 'Нет в наличии'}
    </button>
  )
}
```

В этом компоненте мы используем тернарный оператор для динамического изменения класса в зависимости от переменной `isStock`. Если товар в наличии (`isStock === true`), мы присваиваем класс `Styles['green']` для стилизации кнопки зелёным цветом и устанавливаем текст `Купить`. В противном случае кнопка получает класс `Styles['gray']` и отображает текст `Нет в наличии`

Тернарный оператор может выполнять и более сложные задачи. Кроме изменения текста и стилей мы можем менять и сами компоненты. 

Посмотрим на примере приложения `Погода`👇🏻

```javascript
export function WeatherDisplay (props) {
  return (
    <div className="container">
      <h1>Погода сегодня</h1>
      <div className="icon">
        {props.temperature < 0 ? <SnowyIcon /> : <SunnyIcon />}
      </div>
    </div>
  )
}
```

В этом примере компонент `WeatherDisplay` принимает аргумент `temperature`, представляющий текущую температуру. Используя тернарный оператор, мы решаем, какую иконку погоды отобразить в зависимости от температуры.

Если температура меньше нуля, отображается компонент `<SnowyIcon />` — иконка снежной погоды. Если температура выше нуля, выводим компонент `<SunnyIcon />` — иконку тёплой погоды.

У компонента `Alert` есть параметр `isError`, который определяет, произошла ли ошибка. 

Если `isError` равен `"true"` — компонент отображает ошибку. 

Если `isError` равен `"false"` — компонент отображает сообщение об успехе.

**Для отображения сообщения с ошибкой:**

- Класс `"error"`
- Заголовок `"Проблемка"`
- Параграф `"Кажется, что-то пошло не так!"`

**Для отображения успешного сообщения:** 

- Класс `"success"`
- Заголовок `"Успешно"`
- Параграф `"Всё просто замечательно!"`

Реализуй изменение компонента, проверяя `isEerror`. Используй тернарный оператор.

```javascript
const Alert = (props) => {

      <p>{props.isError ? "Кажется, что-то пошло не так!" : "Всё просто замечательно!"}</p>
    </div>

```

### Конструкция `"&&"` в JSX

Давай посмотрим на пример использования оператора `"И"` в JSX. 

Представим большой баннер со скидкой для новых покупателей. Если покупатель ещё не успел применить скидку, нам нужно отобразить этот компонент 👇🏻

```javascript
export function Home (props) {
  return (
		<div className="container">
			{props.isNewUser && <Banner />}
		</div>
	)
}
```

В этом примере, благодаря оператору `"И"`, компонент `<Banner/>` будет отображаться только при условии, что `isNewUser` правдиво. 

Если `isNewUser` со значением `"false"` — баннер отображаться не будет.

На странице есть компонент `Card`, который принимает параметр `props.rating`

Мы хотим проверить, что значение параметра больше нуля. Если это условие выполняется, нужно вывести параграф с текстом `"Рейтинг:"` и самим рейтингом, используя конструкцию `"&&"`

{iframe:https://sandbox-teens.practicum-team.ru/tasks/03-framework/03-data-flow/0302-conditional-rendering/task-04/pre/|minWidth:400px|minHeight:600px}

```javascript
const Card = (props) => {
  return (
    <div className="card">
      <img src="ball.png" alt="Мячик" />
      <h4>Баскетбольный мячик</h4>
      {props.rating > 0 && <p>Рейтинг: {props.rating}</p>}
    </div>
  );
};
```

Отличная идея!

## Работа над Pindie

Откроем проект и посмотрим на главную страницу — компонент `<Home/>`

```javascript
<CardsList id="popular" title="Популярные">
	<PopularCardsFragment />
</CardsList>
<CardsList id="new" title="Новинки">
	<NewCardsFragment />
</CardsList>
```

Здесь мы используем компонент `<CardsList/>` несколько раз, отображая разные вложенные фрагменты. Предлагаем улучшить это место, чтобы отрисовка фрагментов зависела от передаваемых аргументов `"props"`

Выполнив четыре шага ниже, ты сможешь добиться этого результата:

1. В качестве маяка, указывающего на нужный фрагмент, используй значение `"props.id"`. Этот аргумент принимает два возможных значения — `popular` или `new`
2. На странице `<Home/>` убери фрагменты списков и просто передай аргументы, вызывая `<CardsList/>` для отображения популярных и новых игр. 
3. Внутри компонента списка импортируй фрагменты `PopularCardsFragment` и `NewCardsFragment`, они нам скоро понадобятся.
4. Проверь значение аргумента `"props.id"`, используя тернарный оператор или конструкцию `"&&"`. При значении `props.id === "popular"` отображай фрагмент с популярными играми, а при значении `props.id === "new"` — фрагмент с новыми играми.
