Работа со списками

В проекте Pindie все карточки одинаковые. В мире React-разработки это означает, что карточка — отдельный компонент. Сейчас это не так. Карточки объединены в группы внутри фрагментов.

Именно так! Чтобы это реализовать, прокачаем навыки управления данными, узнаем, как можно использовать списки в мире JSX-компонентов. Да, списки в React создают по-особенному. С них и начнём.

Но перед этим давай вспомним, что такое списки.

![](https://pictures.s3.yandex.net:443/resources/Untitled_Artwork_684_1707135551.png)

Списки в HTML

**Списки** — это наборы элементов.

Представим список с именами друзей 👇🏻

<ul>
	<li>Собака</li>
	<li>Аски</li>
	<li>Цэ-эс-эсочка</li>
</ul>

Это простой пример списка в HTML, где каждый пункт `<li>…</li>` содержит одно имя. Похоже на записную книжку, в которой хранятся имена друзей, следуя одно за другим.

Списки в JavaScript

Мы много раз работали с JavaScript и создавали разметку прямо внутри JS-файлов.

Вот как будет выглядеть список друзей на JavaScript 👇🏻

const names = ['Собака', 'Аски', 'Цэ-эс-эсочка']; // Имена друзей

const list = document.querySelector('ul'); // Тело списка

for (let i = 0; i < names.length; i++) {
	const li = createElement('li');
	li.textContent = names[i];
	list.append(li);
}

Используя цикл для перебора имён друзей, мы можем динамически добавлять новые пункты списка, изменяя только данные внутри массива.

Такой подход помогает нам отделить данные от разметки.

Если у нас появится новый друг, мы просто добавим его в массив `names`, а остальную работу с формированием списка JS сделает за нас.

Списки в React

В мире React у нас появляется более продвинутый способ создания списков. Вместо простого перечисления данных мы можем использовать целые компоненты.

Рассмотрим пример 👇🏻

<ul>
	<li><FriendCard/></li>
	<li><FriendCard/></li>
	<li><FriendCard/></li>
</ul>

Теперь мы не ограничены простым текстом — каждый компонент внутри себя может содержать картинки, кнопки и даже другие компоненты, создавая более сложные и интересные элементы списка.

Важно отметить, что эти компоненты могут иметь параметры (`props`).

Давай посмотрим, как будет выглядеть список друзей, где каждый компонент принимает разные параметры 👇🏻

<ul>
	<li><FriendCard name="Собака" image="jav-jav.png"/></li>
	<li><FriendCard name="Аски" image="aski.png"/></li>
	<li><FriendCard name="Цэ-эс-эсочка" image="cssochka.png"/></li>
</ul>

Здесь мы используем компонент `<FriendCard/>` для отображения разных друзей. Каждый раз, когда мы создаём новый пункт списка, мы передаём данные через параметры компонента.

![](https://pictures.s3.yandex.net:443/resources/Frame_1466_1707135600.png)

Это значит, что мы можем адаптировать внешний вид компонента под конкретного друга, не создавая отдельный компонент для каждого.

Разделение ответственности

В примере со списком друзей есть такой код 👇🏻

const App = () => {
	return (
		<ul>
			<li><FriendCard name="Jav-Jav" image="jav-jav.png"/></li>
			<li><FriendCard name="Аски" image="aski.png"/></li>
			<li><FriendCard name="Цэ-эс-эсочка" image="cssochka.png"/></li>
		</ul>
	);
};

И следующий логичный шаг — это не прописывать каждый элемент отдельно, а создать массив и пройтись по нему.

Мы взяли имена персонажей и отделили их от разметки в массив `names`👇🏻

const names = ['Jav-Jav', 'Аски', 'Цэ-эс-эсочка']; // Имена друзей

Для отображения карточек с разными параметрами в прошлом модуле мы использовали цикл `for`. Он перебирал каждый элемент массива и создавал пункт списка `<li>` с уникальным именем 👇🏻

const list = document.querySelector('ul'); // Тело списка

for (let i = 0; i < names.length; i++) {
	const li = createElement('li');
	li.textContent = names[i];
	list.append(li);
}

Круто было бы использовать такой подход внутри JSX-компонентов, но, к сожалению, работать он не будет.

Цикл `for` позволяет нам пройти по каждому элементу списка и выполнить нужные действия. Важно заметить, что `for` не создаёт новые элементы, а изменяет уже существующие. В разработке **безопаснее** работать **с** **копиями данных**, чтобы сохранить исходные данные без изменений и обращаться к ним при необходимости. Для этого используются более аккуратные методы, с одним из которых мы сейчас тебя познакомим.

Методы массивов

Существует множество методов, которые упрощают работу с массивами в JavaScript.

С некоторыми мы тебя уже знакомили:

- Метод `map` для преобразования одного массива в другой - Метод `filter` для фильтрации - Метод `find` для поиска

![](https://pictures.s3.yandex.net:443/resources/Frame_1468_1707135796.png)

И это далеко не всё!

В следующих уроках мы подробнее рассмотрим их применение, а сейчас разберём использование метода `map` в React.

`Map` позволяет нам взять каждый элемент массива, выполнить нужные действия и получить новый массив с изменёнными элементами. В отличие от `for`, он не изменяет исходные данные, а создаёт их копию. Именно поэтому метод `map` полюбили все веб-разработчики.

Давай посмотрим, как работать с этим методом 👇🏻

const массив = [...элементы_массива];

const новый_массив = массив.map(function(элемент_массива, индекс, массив) {
	... какие-то действия с элементом массива
	return изменённый_элемент
})

Здесь мы создаём копию массива, чтобы не изменять оригинальные данные.

Затем метод `map` принимает в себя функцию, которая выполняется для каждого элемента массива. Результат выполнения этой функции становится новым элементом в массиве.

Обрати внимание на первый аргумент функции — это элемент массива, и он обязателен, в отличие от остальных параметров, которые могут быть не указаны.

Примеры есть в уроке «Перебор массива. Методы `forEach()` и `map()`» (тема «Введение в ООП»).

Ловушки маппинга и важность ключей

Разберёмся с предупреждением в консоли, которое мы видели в предыдущем примере. Это предупреждение связано с важной деталью при использовании метода `map`, которую легко упустить — **ключами (keys)**.

Дело в том, что для создания списков в React библиотеке важно знать, какие элементы уникальны и как они могут отличаться друг от друга. Это позволяет эффективнее обновлять и перерисовывать компоненты при изменении данных.

Вернёмся к примеру со списком друзей 👇🏻

<ul>
	{friendNames.map((name) => (
		<li>
			<FriendCard name={name} />
    </li>
	))}
</ul>

На первый взгляд всё хорошо, но React требует от нас больше информации. Без явно указанных ключей ему тяжело отследить, какой элемент изменился, переместился или был удалён. Это может привести к неожиданным багам и ошибкам.

Когда мы используем `map`, нам предоставляется второй аргумент — индекс элемента в массиве, другими словами — его порядковый номер. В обычном JavaScript этот индекс необязателен. Когда мы работаем с React, важно указывать уникальные индексы, которые и становятся нашими ключами.

Добавим ключи в список 👇🏻

<ul>
	{friendNames.map((name, index) => {
		<li key={index}>
			<FriendCard name={name} />
    </li>
	))}
</ul>

Здесь мы явно указали ключи для каждого пункта списка. Теперь React может точно отслеживать изменения и управлять обновлениями компонентов.

Не забывай добавлять ключи при использовании метода `map`, чтобы избежать возможных ошибок. Модифицируем каталог

В прошлом уроке мы использовали условный рендеринг для отображения разных каталогов в зависимости от передаваемого параметра.

Давай посмотрим на `<CardsList/>` и вспомним, как это было 👇🏻

export const CardsList = (props) => {
  return (
    <section className={Styles['list-section']}>
      <h2 className={Styles['list-section__title']} id={props.id}>
        {props.title}
      </h2>
      <ul className={Styles['cards-list']}>
        {props.id === 'popular' && <PopularCardsFragment />}
        {props.id === 'new' && <NewCardsFragment />}
      </ul>
    </section>
  );
};

Пришло время перейти к более современному подходу и использовать метод `map` для перебора массива игр и их отображения.

Но сперва нужно решить, какой из массивов использовать.

Для этого создай новую переменную `targetArray`, которая будет выполнять роль условного рендеринга. Она принимает параметр `props.id` и выбирает нужный массив 👇🏻

const targetArray = props.id === "popular" ? popularGames : props.id === "new" && newGames;

Но проще использовать конструкцию `if…else` 👇🏻

let targetArray;

if (props.id === "popular") {
	targetArray = popularGames;
}
if (props.id === "new") {
	targetArray = newGames;
}

Оба варианта выполняют одну и ту же задачу, выбирая массив в зависимости от параметра `props.id`.

Размести один из них прямо внутри компонента после массивов с данными, чтобы переменная `targetArray` имела доступ к параметрам, которые мы передаём.

Теперь модифицируй компонент `<CardsList/>` — добавь метод `map`, который будет перебирать `targetArray` и отображать карточки игр, используя новый компонент `<Card/>` 👇🏻

<section className={Styles["list-section"]}>
	<h2 className={Styles["list-section__title"]} id={props.id}>{props.title}</h2>
	<ul className={Styles["cards-list"]}>
		{targetArray.map((item) => {
			return (
				<li className={Styles["cards-list__item"]} key={item.id}>
					<a href={item.link} target="_blank" className={Styles["card-list__link"]}>
						<Card {...item} />
					</a>
				</li>
			);
		})}
	</ul>
</section>

Ниже объясним, что происходит в обновленном компоненте:

1. При переборе массива с играми мы захватываем каждую игру в переменную `item` и создаём пункт списка `<li>`. Этот тег принимает ключ с уникальным `id` каждой игры. 2. Для создания ссылки на игру мы использовали тег `<a>`. Здесь в атрибут `href` мы передаём реальную ссылку из массива, обращаясь к параметру `item.link` 3. Внутри тега `<a>` вызываем компонент `<Card/>`, передавая в него все остальные параметры игры.

Этот инструмент позволяет нам передать все свойства объекта `item` в виде отдельных параметров. Другими словами, это сокращенный вариант передачи данных, который делает код более компактным. {/quiz-task}
