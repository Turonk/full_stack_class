## Аналогия с нативным JavaScript и DOM API

Прежде чем говорить о работе с React-компонентами, давай посмотрим, как бы мы работали, используя только JS. 

Представим, что в интерфейс нашего приложения мы хотим добавить кнопку при помощи нативного JavaScript и DOM API.

```javascript
// Создаём функцию, которая вернёт нам разметку кнопки
const createButton = function(buttonText) {
	const myButton = document.createElement("button");
	myButton.textContent = buttonText;
	return myButton;
}

// Выбираем, в какой элемент страницы вставить кнопку
const banner = document.querySelector('.banner');
// Вставляем кнопку
banner.append(createButton('Подробнее'))

const productCard = document.querySelector('.product-card');
productCard.append(createButton('Купить'))
```

Обрати внимание, как в данном фрагменте кода вызывается функция `createButton`: мы передаём в неё аргумент — текст, который будет отображён в кнопке. Благодаря аргументу мы можем использовать одну функцию `createButton` для элементов `banner` и `productCard` с разным текстом кнопки. Такой подход применим не только к кнопке, но и к другим, более сложным компонентам: карточкам, баннерам с похожим оформлением, но разным текстом внутри.

## Что такое `props` и свойство `children`

В примере выше мы использовали функцию, в которой через DOM API создаётся элемент. Поскольку в React компоненты — это тоже функции, в них так же можно передавать аргументы. 

В этом разделе мы покажем примеры, как можно в React-компонент передавать аргументы. В процессе держи в голове дополненное определение React-компонента: **это функция, которая принимает на вход данные, а возвращает JSX-разметку.** 

Рассмотрим пример в песочнице. 

У нас есть компонент списка `ListComponent`, компонент `ItemsFragmentOne` с содержимым для этого списка, а также страница `Page`, в которой используются все эти компоненты.

{iframe:https://sandbox-teens.practicum-team.ru/tasks/03-framework/03-data-flow/0301-props/example-01/pre/|minWidth:400px|minHeight:600px}

Функция компонента `ListComponent` принимает единственный аргумент под названием `props`

`props` — это JavaScript-объект, внутрь которого складываются данные**, которые будут использоваться в самом компоненте. Внутри `ListComponent` мы логируем этот объект в консоль, чтобы вы могли увидеть, из чего он состоит. Дополнительно прикладываем скринкаст 👇🏻

{video:https://code.s3.yandex.net/kids-web/vids/Screen_Recording_2024-01-09_at_18.41.57.mp4|controls:true|autoplay:0|pip:false|controlsList:nodownload}

Сейчас объект `props` выглядит так 👇🏻

```javascript
{
  children: ...
}
```

В `props` лежит единственное свойство `children` — это специальное поле, которое добавляет сам React. Значением этого поля будут компоненты, которые были обёрнуты в компонент `ListComponent`. В данном случае значением свойства `children` будет являться компонент `ItemsFragmentOne`, потому что в странице `Page` этот компонент лежит внутри `ListComponent`

Попробуем внутри компонента `ListComponent` воспользоваться свойством `children` из объекта `props` 

Добавь в песочницу выше в `ListComponent` строку `{props.children}` так, чтобы код этого компонента выглядел следующим образом 👇🏻

```javascript
const ListComponent = function(props) {
  console.log(props);
  return (
    <div>
      <h2>Заголовок списка</h2>
      <ul>
        {props.children} // Добавляем использование свойства children из props
      </ul>
    </div>
  )
}
```

Ты сразу заметишь, что на экране кроме заголовка отобразится ещё и список из двух пунктов.

## Передача свойств через атрибут JSX-тега

Кроме свойства `children`, которое React добавляет в объект `props`, разработчик может передавать дополнительные свойства через атрибуты JSX-тега.

Вернёмся к нашей песочнице выше и обратим внимание на то, что в компоненте `ListComponent` есть фиксированный текст для заголовка: `<h2>Заголовок списка</h2>`. Получается, сейчас `ListComponent` не является универсальным компонентом.

Изменим код так, чтобы передавать текст для заголовка как аргумент в функцию. Тогда в разных местах, где может использоваться `ListComponent`, мы сможем получать список с соответствующим заголовком. 

Как это можно сделать, показано в песочнице ниже — это тот же пример, что мы уже видели, только с новыми доработками.

{iframe:https://sandbox-teens.practicum-team.ru/tasks/03-framework/03-data-flow/0301-props/example-02/pre/|minWidth:400px|minHeight:600px}

Разберём подробнее пример из этой песочницы.

Сначала посмотрим, как выглядит интерфейс страницы. Она состоит из двух списков: в первом списке указаны приветствия на испанском и английском языках, а во втором — на немецком и французском.

Теперь обратим внимание на код страницы `Page`. Для отображения двух списков используется один компонент `ListComponent`, внутрь которого в обоих случаях передаётся разное содержимое списка, а именно `ItemsFragmentOne` и `ItemsFragmentTwo`. Внутри кода функции самого `ListComponent` это содержимое используется с помощью `{props.children}`, с этим мы уже знакомы.

Для того чтобы один компонент `ListComponent` мог отображать разный текст заголовка, мы задаём ему атрибут `listTitle` таким образом 👇🏻

`<ListComponent listTitle={firstListTitle}>`

В качестве значения атрибута присваиваются переменные `firstListTitle` и  `secondListTitle` с разным текстом заголовка. Внутри кода функции самого `ListComponent` этот атрибут используется как свойство объекта `props`, а именно так — `{props.listTitle}`

Здесь важно понимать, что атрибут `listTitle` — это придуманный нами как разработчиками атрибут компонента `ListComponent`. Это значит, что в коде функции любого другого компонента свойство `listTitle` в объекте `props` будет отсутствовать, пока мы явно не передадим этот атрибут так же, как мы это сделали с `ListComponent`

        ❗ Снова обратим внимание на синтаксис JSX. Если в качестве значения атрибута в JSX-теге мы хотим использовать переменную (в нашем случае это `firstListTitle` и  `secondListTitle`), её необходимо обернуть в скобки `{}`
{/quiz-task}

Стоит отметить, что для компонента можно указывать неограниченное количество атрибутов, которые могут иметь любые значения, все они будут доступны внутри кода функции компонента через объект `props`

В качестве примера приведём песочницу со списком разных приветствий, каждое из которых передаётся через атрибуты компонента `ItemsFragmentOne`👇🏻

## Передача атрибутов сверху вниз

В разработке на React применяется компонентный подход: это значит, что один компонент в своей JSX-разметке может вызывать другие компоненты. 

До этого момента в наших примерах только компонент страницы `Page` в своей JSX-разметке вызывал другие, созданные нами компоненты — `ListComponent` и `ItemsFragmentOne`

Давай выделим в отдельный компонент заголовок списка и будем вызывать его в JSX-разметке `ListComponent`. Пусть новый компонент будет называться `Header`. Таким образом, нам надо получить цепочку, как на схеме 👇🏻

![](https://pictures.s3.yandex.net:443/resources/Frame_1462_1706861135.png)

Спасибо за рыцарский вопрос, Аски!

Ответ: точно так же — через атрибут компонента. 

Пусть компонент `Header` будет иметь атрибут `headerText` для передачи текста заголовка, внутри JSX-разметки значение атрибута будет доступно, как обычно, из объекта `props`, а именно `props.headerText`

В JSX-разметке `ListComponent` компонент `Header` вызывается так: `<Header headerText={props.listTitle}/>`

Тут отметим, что значением атрибута `headerText` является свойство `listTitle` из объекта `props` компонента `ListComponent`

## Работа над Pindie 

Как справедливо подсветил Аски, в нашем приложении есть два почти идентичных компонента списка — `PopularCardsList` и `NewCardsList`, отличаются они только тремя моментами:

1. Значением атрибута `id` в теге заголовка `h2` (а именно `id="popular"` и `id="new"`)
2. Текстом заголовка списка (а именно `Популярное` и `Новинки`)
3. Компонентами с содержимым списков (а именно компонентами `PopularCardsFragment` и `NewCardsFragment`)

#### **Задание 1**

Создай универсальный компонент списка и передай в него нужные атрибуты и `children` так, как мы уже делали в примерах выше. 

Для этого нужно выполнить следующие шаги:

1. Создай в папке `app/components/CardsList` файл `CardsList.jsx`
2. Внутри этого файла создай функцию-компонент `CardsList`, которая будет принимать в качестве аргумента объект `props` (внутри `props` и будут лежать значения свойств, которыми отличаются два существующих компонента `PopularCardsList` и `NewCardsList`)
3. Новая функция-компонент `CardsList` должна возвращать JSX-разметку — скопируй её из `PopularCardsList` или `NewCardsList`
4. В скопированной JSX-разметке замени:
    a. значение атрибута `id` в теге заголовка `h2` на `{props.id}`
    b. текст заголовка списка на `{props.title}`
    c. содержимое списка (вместо `PopularCardsFragment` или `NewCardsFragment` используй `{props.children}`)

После выполнения этих четырёх шагов получится универсальный компонент `CardsList`

#### **Задание 2**

Теперь вызови `CardsList` в компоненте страницы `Page` в файле `page.js`

Чтобы это сделать, замени в JSX-разметке `Page` компоненты `PopularCardsList` и `NewCardsList` на наш новый компонент `CardsList`, в который будешь передавать значения атрибутов `id` и `title`

В качестве `children` (то есть вложенных компонентов нижнего уровня) нужно использовать компоненты с содержимым наших списков, а именно `PopularCardsFragment` и `NewCardsFragment`

Показываем, как можно заменить компонент `PopularCardsList` на наш новый компонент списка `CardsList` 

Вместо `<PopularCardsList />` нужно вставить такой код 👇🏻

```javascript
<CardsList id="popular" title="Популярные">
    <PopularCardsFragment />
</CardsList>
```
