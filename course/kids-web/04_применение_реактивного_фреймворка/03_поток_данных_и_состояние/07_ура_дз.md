## План действий

**Часть 1. Единый источник данных (подробнее — в пятом уроке этой недели)**

- Скачай файл с данными. Его можно найти по [этой](https://gist.github.com/pa7lux/c1cb9b5be2f53bed84785147f70f483a){target="_blank"} ссылке. Назови файл `data.js` и положи его в папку `data`. Путь к нему будет таким: `/app/data/data.js`
- В файле `/app/data/data-utils.js` создай функцию `getGamesByCategory`, которая будет фильтровать данные по категории.
- В файле `/app/page.js` создай константы `popularGames` и `newGames`. Сохрани туда результат работы функции `getGamesByCategory` с нужным названием категории. Так ты разделишь данные из общего источника по категориям.

**Часть 2. Компонент карточки Card (подробнее — во втором уроке этой недели)**

- Создай папку `/Card` в `app/components`
- В этой папке создай файл `Card.jsx`
- В этой же папке создай файл `Card.module.css` и перенеси в него стили карточки из файла `CardsList.module.css` (перечитай урок про модульный CSS с прошлой недели, если чувствуешь необходимость освежить в памяти инфу по этой теме).
- Создай компонент `Card`. Каждая карточка — элемент списка игр. Можешь скопировать один из таких элементов из компонента `PopularCardsFragment` или `NewCardsFragment`
- Используй `props`, чтобы передавать данные в карточку. 
Вот что нужно поменять:
    
    а) атрибут `href` в элементе `<a>` — `{props.link}`
    
    b) ссылка на изображение игры — `{props.image}`
    
    c) текст заголовка игры — `{props.title}`
    
    d) текст описания игры — `{props.description}`
    
    e) имя автора — `{props.developer}`
    
    f) количество голосов — `{props.users.length}`

**Часть 3. Компонент CardsList (подробнее — во втором уроке этой недели)**

- Создай в папке `components/CardsList` файл `CardsList.jsx`
- Создай компонент `CardsList`. Его разметку можно взять у компонента `PopularCardsList` или `NewCardsList`
- Вставь два компонента `CardsList` в `app/page.js`. Передай спискам соответствующие данные через `props` (укажи нужные `id`, `title` и `data`).
- Используй `props`, чтобы получить данные в компоненте `CardsList`
Вот что нужно поменять:
    
    а) значение атрибута `id` в теге заголовка `h2` на `{props.id}`
    
    b) текст заголовка списка на `{props.title}`
    
- Данные для списка передаются в компонент как `{props.data}`. Содержимое списка должно составляться с помощью метода `map()` и компонента `Card`

## Требования

- Все данные хранятся в файле `data.js` в папке `data`
- Есть отдельная функция, которая фильтрует данные по категории из `data`
- На главной странице из этой функции получаются данные по категориям `Популярные` и `Новые`
- Эти данные передаются через параметр `data` в `props` компоненту `CardsList`
- `Card` — отдельный компонент, данные карточки попадают в него через `props`. Компонент находится тут: `app/components/Card/Card.jsx`. Модульные стили карточки находятся тут: `app/components/Card/Card.module.css`
- Компонент `CardsList` — отдельный компонент. Он находится тут: `app/components/CardsList/CardsList.jsx`. Модульные стили списка должны быть тут: `app/components/CardsList/CardsList.module.css`
- Компонент `CardsList` использует метод `map()`, чтобы отобразить карточки (компоненты `Card`) на странице.
- Перед отправкой работы удали папки `node_modules` и скрытую папку `.next`
Чтобы увидеть скрытые папки на macOS нажми комбинацию горячих клавиш «cmd+shift+.», на Windows — смотри [инструкцию](https://hi-tech.mail.ru/news/47521-kak-pokazat-skrytye-papki/){target="_blank"}. Проверь, чтобы файлы `package.json` и `package-lock.json` были на месте, а папка с проектом весит не более 10 Мб.
