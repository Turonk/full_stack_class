Вывод данных на основе динамического роутинга

Работа над Pindie

Вот как сейчас устроена работа с данными в Pindie:

1. На главной странице есть карточки с играми. Этот список формируется на основе данных из `data.js` 2. У каждой карточки есть значение `id` — значит, можно сделать так, чтобы при нажатии на карточку открывалась отдельная страница об этой игре. Для этого используем динамический роут, о котором говорили в прошлом уроке. 3. Мы сможем передавать `id` нужной карточки на страницу, где будем вызывать функцию для поиска данных об игре в файле `data.js`

![](https://pictures.s3.yandex.net:443/resources/Frame_1524_2_1708349033.png)

**Шаг 1**

Открой файл `app/data/data-utils.js`, где мы записываем вспомогательные функции для работы с данными (этот файл мы создали в уроке «Единый источник данных. Поток данных»).

**Шаг 2**

В этом файле напиши функцию для поиска данных об игре по `id` — `getGameById`. Эта функция должна с помощью метода `find` находить в `data` нужную игру.

export const getGameById = (id) => {
  return data.find((game) => game.id === Number(id));
}

{quiz-task} background: | #f1f1ef content: | ❗ О методе `find` мы подробно говорили в уроке «Единый источник данных. Поток данных». Он позволяет найти в списке нужный элемент, если переданная функция проверки условия возвращает `true`. Мы переводим параметр `id` в число, потому что `id` игр — число, а значением `props.params.id` (параметр динамического роута) получаем строку. {/quiz-task}

**Шаг 3**

Теперь добавь вёрстку страницы игры. Мы снова подготовили её для тебя заранее, вот [ссылка](https://github.com/Yandex-Practicum/pindie-prebuild-components/tree/main/GameDetailPage){target="_blank"}.

Открой файл `/app/games/[id]/page.js`, который мы создали в прошлом уроке, и вставь разметку на страницу, а ещё скопируй целиком CSS-модуль и положи рядом.

Это страница со вписанными заранее данными, а нам нужно отображать данные об игре на основе параметра динамического роута. Ниже опишем, что для этого нужно сделать.

**Шаг 4**

Получить данные об игре ты можешь, используя функцию `getGameById`. Импортируй её и запиши данные игры в константу `game` в начале файла.

Вот что тебе нужно заменить в разметке, чтобы всё работало как надо:

- Атрибут `src` у элемента `<iframe>` — должен быть `game.link` - Заголовок — `game.title` - Описание — `game.description` - Автор — `game.developer` - Количество голосов за игру — `game.users.length` - Атрибут кнопки голосования — `onClick={() => {}}` (обработка нажатия на кнопку — задача со звёздочкой в домашнем задании)

Это правда.

Дело в том, что нужная игра не находится в списке по `id` и константе `game` задаётся значение `undefined`. Нужно уметь отлавливать такие моменты.

Мы можем сделать проверку, при которой на странице появится сообщение об отсутствии игры с таким `id`, если константа `game` не содержит информации об игре. Сделать это поможет условный рендеринг, о котором мы рассказывали в одноимённом уроке.

Вот что у тебя должно получиться 👇🏻

{
	game ? (
		<>
		  <section className={Styles['game']}>
		    <iframe className={Styles['game__iframe']} src={game.link}></iframe>
		  </section>
		  <section className={Styles['about']}>
		    <h2 className={Styles['about__title']}>{game.title}</h2>
		    <div className={Styles['about__content']}>
		      <p className={Styles["about__description"]}>{game.description}</p>
		      <div className={Styles["about__author"]}>
		        <p>Автор: <span className={Styles["about__accent"]}>{game.developer}</span></p>
		      </div>
		    </div>
		    <div className={Styles["about__vote"]}>
		      <p className={Styles["about__vote-amount"]}>За игру уже проголосовали: <span className={Styles["about__accent"]}>{game.users.length}</span></p>
		      <button onClick={() => {}} className={`button ${Styles["about__vote-button"]}`}>Голосовать</button>
		    </div>
		  </section>
		</>
	) : (
		<section className={Styles['game']}>
			<p>Такой игры не существует 😢</p>
		</section>
	)
}

Для начала можешь просто добавить текст `Такой игры не существует`, а сверстать свой компонент `Не найдено` для страницы с несуществующей игрой — задача со звёздочкой для тебя.
