Минимальные требования (необходимо для зачёта)

Тебе нужно соблюсти в проекте следующее:

1. Активный пункт меню подсвечивается, и через меню можно переходить на страницы разделов. 2. На самих страницах разделов отображаются списки с карточками определённой категории. 3. Роутинг настроен так, что клики по карточкам ведут на детальные страницы карточек, где выводится информация о конкретной игре и в неё можно играть.

Чек-лист по минимальным требованиям

- Каждый раздел меню в шапке сайта должен открывать страницу по соответствующему роуту. Для этого нужно:

1. Создать роуты для страниц: `Новинки`, `Популярные`, `Шутеры`, `Ранеры`, `Пиксельные` и `TDS`. В конце урока «Роут в Next.js» есть конкретные названия роутов и пошаговая инструкция, как создать сам роут. Также в этом уроке лежит скринкаст с наглядным примером. 2. Добавить ссылки на созданные роуты в соответствующие разделы меню в шапке Pindie, используя компонент `Link`. В уроке «Компонент Link» есть пошаговый пример, как добавить ссылку на роут `/new` в раздел меню `Новинки`

- Каждая страница раздела должна содержать список карточек соответствующей категории. Для этого необходимо использовать уже знакомую тебе функцию `getGamesByCategory`. Как заполнить страницу карточками с нужными играми, мы показали на скринкасте в уроке «Роут в Next.js». - При нажатии на карточку игры пользователь должен попадать на страницу этой игры. Для этого нужно создать динамический роут `/games/[id]` , где `id` — это идентификатор игры. Как сделать такой роут, обсуждали в уроке «Динамические роуты». - На странице отдельной игры, компонент которой лежит [тут](https://github.com/Yandex-Practicum/pindie-prebuild-components/blob/main/GameDetailPage/page.js){target="_blank"}, необходимо выводить всю информацию об этой игре и предоставлять пользователю возможность поиграть в неё. Для этого нужно:

1. Научить проект получать `id` — идентификатор игры из динамического параметра роута `/games/[id]`. Как это сделать, показывали в уроке «Динамические роуты». 2. Научить проект получать информацию о нужной игре из хранилища данных `app/data/data-utils.js` на основе динамического параметра `id`. Для этого нужно воспользоваться функцией `getGameById`, которую мы реализовали в уроке «Вывод данных на основе динамического роутинга». 3. В компоненте страницы игры использовать HTML-тег `iframe`, которому в атрибут `src` вставлять ссылку на игру. Таким образом, пользователь получит возможность поиграть в игру прямо на сайте Pindie. - Когда пользователь находится на странице со списком игр определённой категории, соответствующий ей пункт меню в шапке сайта должен подсвечиваться. Для этого нужно воспользоваться хуком `usePathname` и CSS-стилем `menu__link_active`. Пример того, как можно сделать такой визуальный эффект, показывали в уроке «Хуки роутинга и навигации».

Pindie на максималках (по желанию)

Чтобы максимально прокачать проект, используя новые знания, нужно соблюсти следующее:

1. Если ввести адрес несуществующей карточки, покажется красивый компонент с сообщением об ошибке. 2. Если кликнуть на кнопку `Проголосовать`, отправишься на отдельную страницу с формой авторизации. 3. Логотипы в шапке и подвале — это ссылки, но только на внутренних страницах, а не на главной.

Чек-лист для задач со звёздочкой

- Если перейти по роуту `/games/[id]`, где вместо `[id]` подставить несуществующий идентификатор игры, должна открыться страница, на которой будет выведено сообщение о том, что такой игры не существует. Мы уже начали выполнять с тобой эту задачу в уроке «Вывод данных на основе динамического роутинга», где в зависимости от результата работы функции `getGameById` показывали соответствующую вёрстку. По желанию можешь использовать готовый [компонент](https://github.com/Yandex-Practicum/pindie-prebuild-components/blob/main/GameNotFound/GameNotFound.jsx){target="_blank"}. - На сайте Pindie есть логотип в шапке и подвале. Когда пользователь находится на любом роуте, кроме `/`, эти логотипы должны быть ссылками на главную страницу. Когда пользователь находится на главной странице (на роуте `/`), логотипы не должны быть ссылками. Чтобы это реализовать, воспользуйся хуком `usePathname`, за подсказкой беги в урок «Хуки роутинга и навигации». - По клику на кнопку `Проголосовать` пользователь должен попадать на страницу с формой авторизации. Чтобы это случилось, нужно:

1. Сделать роут, по которому будет открываться страница — название роута придумай самостоятельно. 2. Показывать на странице форму авторизации. Можно использовать для этого готовый [компонент](https://github.com/Yandex-Practicum/pindie-prebuild-components/tree/main/AuthForm){target="_blank"}. 3. Воспользоваться хуком `useRouter`, который мы рассматривали в уроке «Хуки роутинга и навигации», для перенаправления пользователя на страницу с формой авторизации. В этом же уроке есть пример, где мы решали подобную задачу навигации на определённую страницу по нажатию на кнопку.
