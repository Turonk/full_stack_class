## Как создать роут в Next.js

В прошлом уроке мы упомянули библиотеку App Router, которая реализует маршрутизацию в приложениях на Next.js. Работа этой библиотеки основана на {{файловой системе}}[web_teens_M3T5_3_файловой_системе].

Для того чтобы создать новый роут, необходимо:

1. В папке `app` создать ещё одну папку, имя которой будет полностью совпадать с именем будущего роута.
2. В этой новой папке создать файл `page.js`. Из него должен экспортироваться компонент страницы, который будет отображаться при переходе пользователя на новый роут.

В этом уроке мы с тобой создадим новый роут `/new` в проекте Pindie.

![](https://pictures.s3.yandex.net:443/resources/Frame_1512_1_1708328633.png)

Обрати внимание, в папке `app` также присутствует файл `page.js`. Компонент страницы из этого файла отображается, когда пользователь попадает на корневой роут, то есть на `/`. Здесь важно провести в голове прямую аналогию между тем, как разработчик ищет файл с компонентом нужной страницы в проекте, и тем, как приложение на `Next.js` ищет, какой компонент страницы отобразить на нужный роут.

![](https://pictures.s3.yandex.net:443/resources/Frame_1511_1708328660.png)

Именно!

Можно создавать и более длинные роуты. Предположим, мы хотим создать роут `/new/shooters`. Для этого по аналогии нужно в папке `app/new` создать папку `shooters` с файлом `page.js`. Таким образом пользователь, попадая на роут `/new/shooters`, будет видеть на экране компонент из `app/new/shooters/page.js`

Конечно! Лови скринкаст.

{video:https://code.s3.yandex.net/kids-web/vids/Простои_роут_в_Next.js._ск1.mp4|controls:true|autoplay:0|pip:false|controlsList:nodownload}

Заметь, когда мы перешли по адресу `/new`, на странице появился не только заголовок `Страница для новых игр`, но ещё и точно такие же шапка и подвал, как на главной странице по адресу `/`

Так происходит, потому что в папке `app` есть файл `layout.js`. Из данного файла экспортируется `RootLayout` — компонент-каркас для всех страниц, которые лежат в папке `app` (он содержит в себе те элементы интерфейса приложения, которые должны отображаться на всех страницах). `Next.js` через `children` передаёт в `RootLayout` компонент страницы из файла `page.js`, и в результате пользователь видит общие элементы интерфейса для всего приложения из `RootLayout` и специфичные элементы из `page.js` соответствующей страницы.

## Рисуем список новых игр

Когда пользователь переходит на роут `/new`, должна отобразиться страница со списком карточек новых игр. У нас уже есть компонент списка карточек `CardsList`, который мы используем на главной странице, когда переходим на роут `/`. А также есть функция `getGamesByCategory`, которая позволяет получить данные для карточек, относящихся к определённой категории. Воспользуемся этими компонентом и функцией для того, чтобы на новой странице отображать список карточек с новыми играми.

## Домашка

По образцу роута `/new` сделай несколько новых роутов и страниц, которые будут открываться по ним:

1. `/popular` — роут, по которому должна открываться страница со списком игр, относящихся к категории `popular`
2. `/shooters` — роут, по которому должна открываться страница со списком игр, относящихся к категории `shooter`
3. `/runners` — роут, по которому должна открываться страница со списком игр, относящихся к категории `runner`
4. `/tds` — роут, по которому должна открываться страница со списком игр, относящихся к категории `TDS` 
5. `/pixel-games` — роут, по которому должна открываться страница со списком игр, относящихся к категории `pixel`

Для каждого нового роута нужно выполнить те же самые шаги, что мы уже выполняли для роута `/new`:

1. В папке `app` создай папку с таким же именем, как у планируемого роута.
2. В этой новой папке создай файл `page.js`, из которого при помощи `export default` экспортируй компонент страницы.
3. В jsx-разметке компонента страницы воспользуйся компонентом `CardsList`, чтобы показать список карточек.
4. Чтобы достать данные карточек определённой категории, используй функцию `getGamesByCategory`, передав ей в аргумент название необходимой категории.

Для самопроверки в адресную строку браузера введи роут, как мы это делали на последнем скринкасте, и нажми `enter` на клавиатуре — если всё правильно, должна открыться страница со списком соответствующих карточек.
