# Динамические роуты

Простой роутинг — это когда мы вручную прописываем, какой будет ссылка. Но если на сайте тысячи страниц? Точно невозможно справиться с такой задачей, если не научиться автоматически создавать ссылки, подставляя в них параметры. 

В уроке ниже мы научимся этому.

## Динамические роуты

Посмотрим, что за динамические роуты, на примере [Доки](https://doka.guide/){target="_blank"}. Перед тобой статья [«Спред-синтаксис…»](https://doka.guide/js/spread/){target="_blank"}.

![](https://pictures.s3.yandex.net:443/resources/Frame_1515_2_1708348099.png)

Её адрес — [https://doka.guide/js/spread/](https://doka.guide/js/spread/){target="_blank"}. 

Он состоит из трёх частей:

- адрес сайта [https://doka.guide](https://doka.guide/js/spread/){target="_blank"}
- роут `js`
- роут `spread`

Откроем [другую статью](https://doka.guide/js/ternary-operator/){target="_blank"} раздела о JavaScript.

![](https://pictures.s3.yandex.net:443/resources/Frame_1516_1708348150.png)

Её адрес уже иной — [https://doka.guide/js/ternary-operator/](https://doka.guide/js/ternary-operator/){target="_blank"}.

Изменение последней части адреса привело к тому, что и содержание страницы поменялось, хотя разметка идентична. Страницы со статьями в Доке формируются динамически в зависимости от последней части адреса. Таким образом, страница с путём `spread` открывает статью о спред-синтаксисе, а с путём `ternary-operator` — о тернарном операторе. 

Эта изменяющаяся часть адреса хранит параметр, в зависимости от которого подгружается нужная информация. В Next.js-приложениях роуты, которые позволяют добавлять такой параметр, называют **динамическими.**

![](https://pictures.s3.yandex.net:443/resources/Frame_1517_1_1708348184.png)

## Динамические роуты в Pindie

Используя динамические роуты, нам предстоит сделать отдельные страницы для каждой игры в проекте Pindie.

У любой игры, данные о которой мы получаем, есть `id` — мы можем использовать это значение как параметр в динамическом роуте. То есть у каждой игры будет роут вида `/games/[id]`. Так, `/games/1` будет указывать на страницу игры со значением `id` 1.  

Динамические роуты в Next.js можно сделать, создавая в папке `app` новую папку с названием в квадратных скобках, в которой будет лежать новый файл `page.js`. Вот как это выглядит на примере адреса `games/[id]` 👇🏻

![](https://pictures.s3.yandex.net:443/resources/Frame_1518_1708348242.png)

Вот так это выглядит для разных страниц в проекте:

Давай для наглядности создадим файл `/app/games/[id]/page.js` и выведем что-нибудь простое на сайте по пути `/games/[id]`. Например, `Привет!`

```javascript
export default function GamePage() {
  return (
    <main className="main">
      <h1>Привет!</h1>
    </main>
  );
}
```

Теперь по пути `/games/[id]` мы будем видеть заголовок `Привет!`. Вот как это выглядит, если перейти по адресу `/games/1` 👇🏻

![](https://pictures.s3.yandex.net:443/resources/Frame_1519_1708348514.png)

То же самое будет и на страницах с другими значениями `id` — то есть по адресу `/games/42` мы увидим этот же заголовок. 

Теперь поговорим о том, как получить динамический параметр из роута. 

Объект, содержащий параметры страницы, будет доступен в знакомом тебе объекте `props` как `props.params` (обновить в памяти эту инфу можно в уроке «Отсыпаем propsы»). Вот как его получить и вывести в консоль 👇🏻

```javascript
"use client"
export default function GamePage(props) {
  const params = props.params;
  console.log(params)
  return (
    <main className="main">
      <h1>Привет!</h1>
    </main>
  );
}
```

![](https://pictures.s3.yandex.net:443/resources/Frame_1520_1708348530.png)

Соответственно, мы можем вывести на страницу, например, её `id` 

```javascript
"use client";
export default function GamePage(props) {
  const params = props.params;

  return (
    <main className="main">
      <h1>Привет! Это страница {params.id}</h1>
    </main>
  );
}
```

{quiz-task}
    background: |
        #f1f1ef
    content: |
        ❗ Ты можешь называть динамический параметр не только `id`. Например, если хочешь назвать этот параметр `slug` (часто эту часть адреса называют именно так), то папка, где будет храниться код страницы, будет называться `[slug]`. Соответственно, и в `props.params` будет такой объект: `{ slug: ‘1’ }`
{/quiz-task}

Всё верно, и это уже попахивает домашкой.

## Домашка

Открой файл `/app/components/CardsList/CardsList.jsx`

Сейчас карточки ведут на страницу игры и ссылка выглядит так 👇🏻

```javascript
<a href={item.link} target="_blank" className={Styles["card-list__link"]}>
  <Card
    {...item}
  />
</a>
```

Сделай так, чтобы ссылки вели на страницу `/games/[id]`, для этого:

- Замени тег `<a>` на `<Link>`
- Убери атрибут `target` (нам ведь не надо будет переходить на другую страницу в новой вкладке, мы остаёмся в Pindie)
- Замени `href`: вместо `item.link` нужно использовать `item.id`. Имей в виду, тебе нужно указать адрес, учитывая роут `/games/`. Чтобы сделать всё правильно, можешь передать адрес шаблонной строкой, вот так: ``/games/${item.id}``
    
    Должно получиться так:

    ```javascript
    <Link href={`/games/${item.id}`} className={Styles["card-list__link"]}>
      <Card
        {...item}
      />
    </Link>
    ```
