Как добавить ссылку в Next.js

Есть два простых способа добавить ссылку в Next.js, рассмотрим оба из них 👇🏻

Тег `<a>`

Используя тег `<a>`, добавим ссылку на роут `/new`, который мы сделали в прошлом уроке, в меню в шапке сайта.

{video:https://code.s3.yandex.net/kids-web/vids/Компонент_Link._ск_1.mp4|controls:true|autoplay:0|pip:false|controlsList:nodownload}

В компонент `Header` (отвечает за отображение меню в шапке сайта) мы добавили новый роут `/new`. Теперь при нажатии на кнопку `новинки` пользователь автоматически переходит по ссылке `http://localhost:3000/new` и попадает на страницу с карточками новых игр.

Казалось бы, мы добились желаемого результата. Но при таком способе добавления ссылки на кнопку сайт будет работать не так быстро, как мог бы.

Обрати внимание, когда мы переходим по ссылке, HTML-вёрстка на мгновение пропадает, а затем появляется вновь. Этот эффект говорит о том, что браузер полностью перерисовал весь интерфейс страницы с чистого листа. Таким образом, браузер выполняет лишнюю работу, ведь компонент `Header` можно не перерисовывать, так как он не меняется от страницы к странице, потому что его вызов происходит в файле `layout.js` (о нём рассказывали в прошлом уроке).

Полная перерисовка страницы браузером происходит потому, что он воспринимает переход по роуту `/new`, который мы указали в теге `<a>`, как открытие совершенно нового сайта `http://localhost:3000/new`, не имеющего отношения к тому, на котором мы сейчас находимся.

Напрашивается вывод: тег `<a>` не подходит для переходов по роутам того же сайта, где этот тег используется. Зато годится, чтобы добавлять ссылки на внешние ресурсы — другие сайты.

Компонент `Link` в Next.js

Правильный способ добавить ссылку в элемент интерфейса — использовать компонент `Link`, который нам предоставляет `Next.js`

Для наглядности задействуем его в Pindie 👇🏻

{video:https://code.s3.yandex.net/kids-web/vids/Компонент_Link._ск2.mp4|controls:true|autoplay:0|pip:false|controlsList:nodownload}

В видео мы:

1. Импортировали компонент `Link` с помощью `import Link from 'next/link';` 2. Заменили тег `<a>` на `Link`

Когда мы переходим по роуту `/new`, браузер не перерисовывает всю страницу целиком с нуля, он перерисовывает только содержимое страницы между шапкой с меню и подвалом. Это можно видеть по тому, как в консоли с HTML-вёрсткой страницы **не** пропадает на мгновение тег `<header>`

Иными словами, при переходе на роут в приложении будут перерисованы только `children` из `RootLayout`, так как в `RootLayout` в качестве `children` наш `Next.js` передаёт компонент страницы `New` 👇🏻

export default function RootLayout({ children }) {
  return (
    <html lang="ru">
      <body>
        <Header />
        {children}
        <Footer />
      </body>
    </html>
  )
}

Компонент `Link` позволяет браузеру не выполнять лишнюю работу, не загружать и не перерисовывать всю страницу с нуля. Именно такой подход используют SPA-приложения.

{quiz-task} background: | #f1f1ef content: | ❗ Кстати, несмотря на то, что мы в JSX-разметке использовали `Link` , в HTML-вёрстке в браузере всё равно отображается тег `<a>`. Это вполне нормально, компонент `Link` внутри себя использует тег `<a>`, но при этом делает так, чтобы переход по нему не перезагружал всю страницу целиком. {/quiz-task}

Домашка

Опиши все пути в шапке и подвале сайта Pindie через компонент `Link`, чтобы основная навигация заработала.

Ссылки на социальные сети в подвале оставь тегами `<a>`, потому что компонент `Link` не подходит для перехода на внешние ресурсы.
