# Хуки роутинга и навигации

![](https://pictures.s3.yandex.net:443/resources/Worn-Ass-Semi-Gloss_48_1708349473.jpg)

Бывают ситуации, когда пользователь совершает действие, после которого нам надо переместить его на другую страницу. К примеру, перемещение юзера на главную страницу после авторизации на сайте. 

Или нам может понадобиться покрасить ссылку с адресом текущей страницы в хедере. Так часто делают, чтобы пользователь не терялся на сайте. На скриншоте видно, как это выглядит на сайте [Next.js](https://nextjs.org/){target="_blank"} — в хедере цветом выделена ссылка [Docs](https://nextjs.org/docs){target="_blank"}, поскольку мы находимся в документации фреймворка.

![](https://pictures.s3.yandex.net:443/resources/Frame_1529_1708349507.png)

Для решения таких задач в Next.js существуют встроенные **хуки роутинга и навигации**. 

## Хук `useRouter`

Начнём с хука `useRouter` — он даёт средства для того, чтобы с помощью JS менять роуты на сайте. Проще говоря, перемещать пользователя между страницами программно. Сейчас в Pindie нет задач, для которых этот хук необходим (кроме задачи со звёздочкой в домашнем задании), но вообще такое приходится делать достаточно часто. Поэтому давай посмотрим на простом примере, как использовать этот хук 👇🏻

```javascript
'use client'
 
import { useRouter } from 'next/navigation'
 
export default function Page() {
  const router = useRouter()
 
  return (
    <button type="button" onClick={() => router.push('/about')}>
      Нажми на меня и окажешься на странице about!
    </button>
  )
}
```

Вначале мы создаём объект `router`. В нём записываются методы, благодаря которым мы и можем осуществлять навигацию:

- `router.push()` — перемещает пользователя на другую страницу;
- `router.replace()` — перемещает пользователя на другую страницу, не записывая перемещение в историю браузера;
- `router.back()` — перемещает пользователя на прошлую страницу.

Подробнее остановимся на первом из методов — `router.push()`. В примере выше видно, как он работает: в круглых скобках передаётся строка с нужным адресом страницы, на которую нужно перенести пользователя. При нажатии на кнопку пользователя перенесёт в начало страницы `/about`. Можно передать этой функции и объект, который будет указывать, что не нужно возвращаться в начало страницы — вот как это будет выглядеть: `router.push('/about', {scroll: false})`

## Хук `usePathname`

Теперь поговорим о хуке `usePathname` — знания о нём понадобятся для работы над Pindie. 

Вот небольшой пример кода с ним 👇🏻

```javascript
"use client";

import { usePathname } from "next/navigation";

export const Header = () => {
	const pathname = usePathname();

	console.log(pathname);

	return <header></header>
}
```

В константу `pathname` записывается адрес, на котором пользователь сейчас находится. Например, если пользователь находится на главной странице, то в `pathname` будет записано `'/'`. Так же и с остальными страницами сайта. `pathname` будет очищен от лишней информации: например, в адресе `/games/1?game=true` есть дополнительные параметры, но в `pathname` всё равно запишется строка `"/games/1"`

## Работа над Pindie

В Pindie нужно обозначать ссылку, на которой ты находишься. Такие ссылки называют активными. 

Вот чего мы хотим добиться 👇🏻

![](https://pictures.s3.yandex.net:443/resources/Frame_1530_1708349617.png)

Давай сделаем это пошагово!

**Шаг 1**

Ниже CSS-код для активной ссылки. Вставь его в `Header.module.css` и не забудь, что `menu__link_active` должен располагаться после описания `.menu__link`, иначе стили будут конфликтовать. 

```css
.menu__link_active {
  background-color: #ffff00;
  pointer-events: none;
}
```

**Шаг 2**

Теперь открой файл с компонентом-хедером — `app/components/Header/Header.jsx`. Сделай так, чтобы у компонентов `Link` в меню менялся стиль в случае, если открытая страница соответствует адресу этого `Link`. Это можно сделать с помощью шаблонных строк и тернарного оператора. 

Например, для ссылки на страницу с новинками это будет выглядеть так 👇🏻

```javascript
<Link
  href="/new"
  className={`${Styles["menu__link"]} ${
    pathname === "/new" ? Styles["menu__link_active"] : ""
  }`}
>
```

**Шаг 3**
