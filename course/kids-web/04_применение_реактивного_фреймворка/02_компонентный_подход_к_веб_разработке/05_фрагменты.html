		<li>Какао</li>

Элементы из списка Аски можно перенести в компонент `<ListItems />`, используя средство, которое помогает в таких ситуациях.

Вот что получится 👇🏻

export function ListItems() {
	return (
		<>
			<li>Чай</li>
			<li>Кофе</li>
			<li>Какао</li>
		</>
	)
}

Видишь символы `<>` в начале и `</>` в конце компонента?

Они как раз и обозначают упомянутый Собакой **JSX-фрагмент.** JSX-фрагменты позволяют группировать элементы, если им не нужна обёртка (как в примере с чаем, кофе и какао). Фрагменты не влияют на вёрстку приложения, потому что при их использовании не создаётся новых элементов.

Теперь, если ты вставишь компонент `<ListItems />` в компонент `<List />` вот так…

export function List() {
	return (
		<ul>
			<ListItems />
		</ul>
	)
}

… результатом будет идеальный HTML 👇🏻

<ul>
	<li>Чай</li>
	<li>Кофе</li>
	<li>Какао</li>
</ul>

Тогда попрактикуйся в песочнице, которую мы для тебя подготовили.
