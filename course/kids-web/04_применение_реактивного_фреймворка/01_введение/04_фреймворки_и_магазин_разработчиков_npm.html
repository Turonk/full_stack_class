Фреймворки и магазин разработчиков NPM

Штука, о которой повествует Собака, называется **фреймворк.** Фреймворк — это конструкция (так и переводится с английского), в которой библиотеки уже сонастроены друг с другом под типовые задачи (добавление новых страниц, оптимизация изображений, работа с API).

Абсолютно все современные разработчики программируют именно так, а самый популярный фреймворк, с которым предстоит работать и тебе, называется Next.js.

Но для того, чтобы запустить его у себя на компе, придётся познакомиться с npm и Node.js.

![](https://pictures.s3.yandex.net:443/resources/Untitled_Artwork_661_1_1706023129.png)

Магазин разработчиков

В мире разработки есть свой аналог магазина приложений типа App Store или Google Play, но в нём вместо игр, редакторов видео и прочих приколюх — список библиотек. Называется этот магазин [**npm**](https://www.npmjs.com/){target="_blank"} (сокращение от Node Package Manager — **«**пакетный менеджер **Node.js»**).

Давай не будем вдаваться в подробности и делать тебе больно большим количеством технической инфы. Главное сейчас, что, установив Node.js, ты автоматически установишь и нужный нам npm, а значит, приблизишься к использованию заветного фреймворка.

Поэтому ниже пошагово разберём, как добавить Node.js на твой комп.

Node.js — среда выполнения JavaScript-кода. Она позволяет выполнять JS-код не только в браузере, но и на твоём компьютере или на сервере.

Веб-сервер, который ты запустишь в проекте модуля, будет локальным. Это значит, что ты сможешь тестировать проект, над которым работаешь, на своём компьютере, но никто из внешнего мира посмотреть на него не сможет.

Ещё подробнее, как всегда, в [Доке](https://doka.guide/tools/nodejs/){target="_blank"}.

Установка Node.js

1. Зайди на сайт [Node.js](https://nodejs.org/en){target="_blank"}.

![](https://pictures.s3.yandex.net:443/resources/Frame_1410_1_1706023291.png)

2. Перед тобой две зелёные кнопки. Кнопка слева (с подписью Recommended For Most Users) начнёт скачивание стабильной версии Node.js — нажимай на неё и жди загрузки файла. 3. После загрузки файла открой его — установщик Node.js будет показывать, что нужно делать для установки. 4. Чтобы проверить, всё ли установилось, зайди в консоль и введи команду `node -v`. Там высветится, какая версия Node.js установлена на твоём компьютере.

![](https://pictures.s3.yandex.net:443/resources/Frame_1412_1_1706023330.png)

Как устроен npm

Теперь, когда у тебя на компьютере есть Node.js, мы можем внимательнее изучить [npm](https://www.npmjs.com/){target="_blank"}. Переходи по активной ссылке на сайт магазина и найди там страницу уже знакомого React через поисковую строку.

![](https://pictures.s3.yandex.net:443/resources/Frame_1413_2_1_1706023397.png)

Не теряйся в информации, сейчас быстренько сориентируем, что тут где.

Слева — заметка с коротким описанием библиотеки, пример кода и документация. В случае с этой страницей — ссылка на документацию на официальном сайте.

Справа — команда для установки библиотеки, ссылка на репозиторий с кодом библиотеки, сайт, количество установок (почувствуй мощь комьюнити), актуальная версия и другие технические данные.

Чтобы установить библиотеку React, надо выполнить команду (она как раз указана справа) `npm i react` в папке, где ты будешь собирать свой проект. Обычно это делают через консоль. А чтобы удалить React, нужно ввести `npm rm react`

Фреймворк Next.js

Для React есть несколько крупных фреймворков, самый популярный из них — Next.js (именно он идёт первым в [инструкции](https://react.dev/learn/start-a-new-react-project#nextjs){target="_blank"} по созданию React-приложений на сайте React).

Для того чтобы создать Next.js-приложение, тебе нужно ввести в терминале `npx create-next-app`. В консоли будут появляться вопросы — на них нужно ответить так же, как на скриншоте ниже

{quiz-task} background: | #f5f6f7 content: | Обрати внимание, «No» на все, кроме `Would you like to use App Router?` — тут тебе надо ответить «Yes», чтобы использовать новую структуру Next.js-приложения. {/quiz-task}

![](https://pictures.s3.yandex.net:443/resources/Frame_1400_1_1706023553.png)

Напиши там же следующей строкой `npm install npm -g`. После этого ещё раз установи проект.

После этого у тебя появится практически пустое Next.js-приложение с минимумом дополнительных библиотек.

Ниже посмотрим на содержимое проекта и разберёмся, что в него входит.

Твоё первое Next.js-приложение

Чтобы увидеть проект, выполни два шага:

1. Перейди в папку со своим проектом командой `cd имя-проекта` (имя было первым вопросом при создании приложения). 2. Введи команду `ls -a` — так ты сможешь увидеть содержимое папки в терминале, в том числе скрытые файлы (те названия, которые начинаются с `.` — они не отображаются при вызове обычной команды `ls`).

Это значит, что надо скачать специальную программу Git Bash для работы с терминалом на ОС Windows. Как это сделать — смотри в нашем [дополнительном материале](https://extra.students-projects.ru/tools/gitbash-tools){target="_blank"}.

Когда программа Git Bash будет установлена, запусти её и введи там команду `ls -a`. Всё получится.

![](https://pictures.s3.yandex.net:443/resources/Frame_1407_1_1706023656.png)

В файле `package.json` есть информация о проекте: название, версия, доступные команды и информация о библиотеках, которые нужны для работы приложения. Список библиотек можно увидеть в `dependencies`

Например, на скрине ниже видно, что для работы Next.js нужны библиотеки `react`, `react-dom` и `next`. После названия записана версия библиотеки, которая нужна приложению 👇🏻

![](https://pictures.s3.yandex.net:443/resources/Frame_1414_1_1706023685.png)

Чтобы установить библиотеки, которые указаны в `package.json`, нужно ввести команду `npm install`. Она загрузит код нужных библиотек и сохранит его в папку `node_modules` (именно для таких быстрых махинаций мы скачивали Node.js).

В `scripts` записаны команды, которые ты можешь вызвать в консоли. Чтобы это сделать, нужно ввести в терминале следующее 👇🏻

npm run <название нужной команды>

В файле `package-lock.json` находится более подробная информация о библиотеках, которые используются в проекте. Но сейчас тебе не понадобится работать с этим файлом, поэтому не трогай его, чтобы ничего не сломалось.

В папке `node_modules` хранится код всех библиотек, которые используются в твоём проекте. Обычно эта папка весит ОЧЕНЬ много. Поэтому важно отправлять проект на ревью наставнику и в Git без этой папки 😬

Все необходимые библиотеки можно будет переустановить вызовом команды `npm install` — как раз для этого список библиотек и данных о них есть в `package.json` и `package-lock.json`

Отличная новость: при создании пустого приложения с помощью `create-next-app` создаётся файл `.gitignore`, где перечисляются файлы и папки, которые не следует добавлять в GitHub. Всё, что перечислено в `.gitignore` (в том числе и папка `node_modules`), не будет добавлено в коммит. О коммитах ты можешь вспомнить, заглянув в урок про систему контроля версий Git (опять же в теме первого модуля «Основы Git»).

![](https://pictures.s3.yandex.net:443/resources/Frame_1415_1_1706023728.png)

Когда создашь проект, запусти его командой `npm run dev` — он должен запуститься по адресу [localhost:3000](http://localhost:3000){target="_blank"}. По этому адресу откроется приложение, которое Next.js собирает по умолчанию 👇🏻

![](https://pictures.s3.yandex.net:443/resources/Frame_1416_1_1706023808.png)
