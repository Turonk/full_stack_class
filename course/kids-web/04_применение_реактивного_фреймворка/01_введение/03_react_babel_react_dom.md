## React

Ты уже знаешь, что **React** — библиотека на языке JavaScript. В React ты как раз можешь разделить приложение на множество компонентов, которые взаимодействуют друг с другом.

Сейчас продемонстрируем.

В прошлом уроке мы создали шапку сайта, используя функцию `createHeader`. В React можно создавать элементы более продвинутым способом, вставляя в функцию нечто похожее на HTML. Вот так 👇🏻

```javascript
function Header () {
    return (
        <header>
            <img src="logo.png"/>
        </header>
    )
}
```

Если код тебе кажется необычным, не удивляйся — это действительно другой язык разметки, специально разработанный командой React. Он называет **JSX** (или **JavaScriptXML**). В итоге, мы пишем на привычном JavaScript, но можем вставлять разметку, похожую на HTML, которая живёт по своим правилам.

Но в первозданном виде браузер не может прочитать и понять этот JSX.

## Переводчик Babel

Язык JavaScript постоянно дорабатывается. Почти каждый год создатели языка выпускают обновления, где показывают новые фичи и крутые возможности.

Многие разработчики хотят использовать эти новшества, но сталкиваются с проблемой: в старых браузерах, которые давно не обновлялись, эти фичи могут не работать.

Проблему решает **Babel** — переводчик в мире JavaScript. Эта библиотека превращает код современной версии JS в код, который будут понимать все браузеры.

Посмотрим, как он работает.

## Библиотеки-отрисовщики

Правила React гласят, что его элементы могут использоваться **в любом месте и на любой платформе**.

Без проблем!

![](https://pictures.s3.yandex.net:443/resources/Untitled_Artwork_658_1706022040.png)

Для этого мы создадим собственную библиотеку, как в прошлом уроке, и назовём её `reactTerminal`. Она будет использоваться для отображения нашего каталога на терминале, где нет браузера.

Каждая подобная библиотека предназначена для своего уникального устройства — терминала, дисплея в самолёте или умного холодильника. Но когда мы говорим о создании сайтов, на помощь приходит конкретная библиотека и наша следующая остановка — **React DOM 🚌**

### Как работает React DOM

React DOM превращает JavaScript-код в HTML-разметку и отображает её на странице сайта.

Аски, тогда с гордостью слушай, как происходит этот процесс.

Babel перевел код в знакомый браузеру JS, наступает очередь React DOM. Он уже знает, что нужно нарисовать наш сайт, но пока не знает где.

Для этого нам нужно создать контейнер. Обычно это просто тег `<div>` с каким-то идентификатором 👇🏻

```javascript
<div id="root">
```

Теперь мы должны указать React DOM на этот контейнер. 

Командой `getElementById` получим этот элемент, а используя `createRoot`, скажем библиотеке, что здесь будет контент сайта. Последней командой `render` превратим наш JavaScript-код в HTML-страницу, заполнив контейнер созданными элементами 👇🏻

```javascript
const rootElement = document.getElementById("root");
const root = ReactDOM.createRoot(rootElement);
root.render(<Component />);
```

### Шаг 1

В файле `index.html` создаём корневой элемент `<div id="root"></div>` для отображения нашего React-приложения. 

```javascript
<div id="root"></div>
```

### Шаг 2

Затем подключаем библиотеки к сайту по ссылке. 

С этим способом мы успели познакомиться ещё в первом модуле, подключая шрифты через Google Fonts. В конце тела страницы подключаем `script.js`, который содержит наш React-код.

```javascript
<script crossorigin src="https://unpkg.com/react@18/umd/react.development.js"></script>
<script crossorigin src="https://unpkg.com/react-dom@18/umd/react-dom.development.js"></script>
<script crossorigin src="https://unpkg.com/@babel/standalone/babel.min.js"></script>

// Наш код React
<script src="script.js">
```

### Шаг 3

Далее в файле `script.js` мы описали функцию для создания элемента, который назвали `Cat`. В мире React такие элементы как раз называются **компонентами**. 

Наш код компонента, используя функцию, создаёт Котика-Компонента!

```javascript
const Cat = () => {
  return (
    <img src="kitty.png" alt="Котик-Компонент!"/>
  );
};
```

### Шаг 4

После создания компонента, получаем корневой элемент из `index.html` командой `document.getElementById`

Используя команду `ReactDOM.createRoot`, мы сообщаем библиотеке React DOM, что именно внутри этого элемента должны отображаться все компоненты, которые мы создали при помощи библиотеки React и языка JSX.

```javascript
const rootElement = document.getElementById("root");
const root = ReactDOM.createRoot(rootElement);
```

### Шаг 5

Babel трансформирует наш JSX-код в обычный JavaScript, понятный браузеру. 

А затем с помощью метода `root.render(<Cat/>)` мы говорим React DOM о том, что нужно нарисовать компонент. Другими словами, **отрендерить** его.

```javascript
root.render(<Cat/>)
```
