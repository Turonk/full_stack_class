Шаг 1. Создаём и запускаем приложение

В прошлом уроке мы подробно обсудили, что нужно сделать для создания Next.js-приложения. Лови короткий чек-лист, чтобы освежить в памяти знания — а если приложение у тебя уже создано, переходи сразу к пункту три:

1. Вызови команду `npx create-next-app` в консоли. 2. Ответь на вопросы, которые появляются в консоли. Отвечай «нет» на все вопросы, кроме вопроса про App Router — там ответь «да». 3. Запусти приложение командой `npm run dev`. Оно будет доступно по адресу [localhost:3000](http://localhost:3000){target="_blank"}

В прошлом уроке мы подробно обсудили, что такое файлы `package.json` (там хранятся информация о проекте, списки библиотек и доступных команд), `package-lock.json` (подробная информация о библиотеках, нужных для проекта) и папка `node_modules` (папка, в которую сохраняется код библиотек).

Сейчас посмотри на структуру Next.js-приложения ещё раз: в ней увидишь две папки, о которых поговорим ниже, — `public` и `app`

Шаг 2. Переносим неизменяемые файлы в папку `public`

Папка `public` — место, где будут храниться неизменяемые штуки (такие, как шрифты или картинки), которые нам понадобятся на сайте.

Картинки, которые мы положим в эту папку, в коде можно будет получить так 👇🏻

<!-- 
	Например, здесь мы указываем, что изображение example.jpg лежит 
	по адресу /public/images/example.jpg
-->
<img alt="пример" src="/images/example.jpg" />

В проекте, который мы переносим на Next.js, изображения и шрифты хранятся в папках `images` и `fonts`. Перенеси обе папки в папку `/public`

Посмотрим, что изменится в путях к изображениям, на примере логотипа сайта. Вот как он выглядит в HTML 👇🏻

<img class="logo__image" src="./images/logo.svg" alt="Логотип Pindie">

После переноса изображений в папку `public` нам нужно будет указывать абсолютный путь к файлу в папке `public`. То есть логотип теперь будет доступен по адресу `/images/logo.svg`

<img class="logo__image" src="/images/logo.svg" alt="Логотип Pindie" />

Чтобы понять разницу в абсолютных и относительных путях (а это знание тебе пригодится в дальнейшем), смотри наш дополнительный материал по [ссылке](https://extra.students-projects.ru/general/absolute-and-relative-path){target="_blank"}.

Шаг 3. Переносим вёрстку и стили в папку `app`

Теперь загляни в папку `app`  — там хранится основной код твоего приложения.

![](https://pictures.s3.yandex.net:443/resources/Frame_1399_1706083948.png)

Обрати своё внимание на три файла в папке: `layout.js`, `globals.css` и `page.js`, чтобы перенести вёрстку и стили, нужно поработать именно с ними.

**Шаг 3.1. Файл layout.js — «обёртка» сайта**

В файле `layout.js` описываются неизменяемые части сайта. Например, теги `<html>` и `<body>` будут одинаковыми на всех страницах приложения и записаны именно здесь.

Мы перенесём в этот файл шапку и подвал сайта. Но чтобы проект работал как надо, сначала тебе нужно внести в `layout.js` эти изменения:

1. Удали строчки с подключением шрифта Inter 👇🏻

    // Здесь в проект добавляется ненужный тебе шрифт 
    import { Inter } from 'next/font/google'
    
    // И эта строка – тоже ненужный тебе шрифт
    const inter = Inter({ subsets: ['latin'] })

2. Удали у `body` атрибут `className` 3. Замени атрибут `lang` у `<html>` на `"ru"`

Отлично! Теперь сюда можно копировать элементы `<header>` и `<footer>`

Сейчас ты видишь, что функция в файле выглядит так 👇🏻

export default function RootLayout({ children }) {
  return (
    <html lang="ru">
      <body>{children}</body>
    </html>
  )
}

Тебе нужно расположить элементы `<header>` и `<footer>` внутри тега `<body>`, но `<header>` — перед `{children}`, а `<footer>` — после.

Обязательно объясним, откуда они тут взялись, но несколько позже 🌝

Теперь в этом файле ты можешь заменить стандартные метатеги Next.js. Метатеги нужны для того, чтобы хранить дополнительную информацию о сайте. На них ориентируются поисковые системы, а ещё название сайта показывается на вкладке браузера, так что задавать их важно. Они записываются в `<head>`

Вот как выглядят теги `<title>` и `<meta name="description">`, которые создаёт Next.js по умолчанию 👇🏻

![](https://pictures.s3.yandex.net:443/resources/Frame_1412_1_1_1706084026.png)

Метатеги хранятся в объекте `metadata`. `title` — заголовок страницы, `description` — описание. Вот так они выглядят по умолчанию 👇🏻

export const metadata = {
  title: 'Create Next App',
  description: 'Generated by create next app',
}

Если выполнить все шаги верно, получится такой код 👇🏻

import './globals.css'

export const metadata = {
  title: 'Pindie',
  description: 'Портал инди-игр от студентов Яндекс Практикума',
}

export default function RootLayout({ children }) {
  return (
    <html lang="ru">
      <body>
				<header>{/* Содержание шапки */}</header>
				{children}
				<footer>{/* Содержание футера */}</footer>
			</body>
    </html>
  )
}

Да! В JSX комментарии оформляются так: `{/* коммент */}`. Запомни, как это выглядит, они с нами надолго.

Пора!

**Шаг 3.2. Файл `globals.css` — стили страницы**

В файле `globals.css` записаны основные стили страницы. Он тоже подключался в самом начале `layout.js`

Для начала удали стандартные стили приложения.

Пока что мы разместим стили шрифтов в этом файле. Скопируй содержание файла `fonts.css` (сейчас он должен быть в `/public/fonts/fonts.css`) сюда. Замени пути к шрифтам на абсолютные. Получится так (на примере одного из шрифтов) 👇🏻

@font-face {
    font-family: 'Anonymous Pro';
		/* 
		Путь к шрифту до изменения был таким:
			src: url(./anonymouspro-regular.woff);
		*/
    src: url(/fonts/anonymouspro-regular.woff);
    font-weight: normal;
    font-display: swap;
}

Затем скопируй в `globals.css` все подготовленные нами CSS-стили из файла `styles/style.css`. Позже мы научимся дробить один большой CSS-файл на множество мелких.

{quiz-task} background: | #f5f6f7 content: | Помни, если в CSS тебе встречаются относительные пути до изображений, тебе нужно менять их на абсолютные пути от папки `public`, в которой они должны храниться. {/quiz-task}

Тогда мы добрались до начинки 🍰

**Шаг 3.3. Файл `page.js` — начинка главной страницы сайта**

В файле `page.js` будет находиться разметка главной страницы нашего проекта. Как видишь, по сути, в этом файле записана функция, которая возвращает разметку сайта. Но вместо HTML тут используется JSX, о котором мы уже говорили ранее 👇🏻

export default function Home() {
  return (
		// Тут будет вёрстка твоей страницы
	)
}

Удали разметку стандартного приложения Next.js. Надо сделать так, чтобы приложение возвращало разметку нашей главной страницы.

Нам нужно содержание элемента `<body>` (как помнишь, сам элемент `<body>` был описан в `layout.js` как один из неизменяемых элементов сайта). В нём была та самая запись `{children}`, вокруг которой мы располагали шапку и подвал. Как раз здесь и будет храниться элемент `main`, который мы вставляем в функцию в этом файле 👇🏻

export default function Home() {
  return (
		<main></main>
	)
}

Мы почти закончили, но чтобы успешно перевести HTML в JSX, добавим несколько дополнительных штрихов:

1. Нужно упомянуть, что функция может возвращать только один корневой элемент. Поэтому, например, такой код не заработает 👇🏻

    // Такой вариант не будет собран — выдаст ошибку
    export default function Home() {
      return (
    		<div></div>
    		<main></main>
    		<div></div>
    	)
    }

Проверь, чтобы оставался только один корневой элемент.

2. В JSX для того, чтобы задать элементу класс, используется атрибут `className` (а не привычный тебе `class`). Дело в том, что JSX — расширение JavaScript, где ключевое слово `class` используется для других целей (вернись к нашим урокам про объектно-ориентированное программирование, если не помнишь, для чего именно). Такая же ситуация и с HTML-атрибутом `for` — его нужно заменить на `htmlFor`

{quiz-task} background: | #f5f6f7 content: | Ты можешь заменить все `class` на `className` **автоматически**. В VSCode меню автоматической замены открывается нажатием на клавиши `Ctrl + Shift + H` (или `Cmd + Shift + H` на macOS). {/quiz-task}

3. Все теги в JSX должны быть закрытыми. Посмотри на пример тега `<img>` 👇🏻

    <!-- Незакрытый тег <img> – он валиден в HTML, но в JSX не сработает -->
    <img alt="Пример" src="/example.jpg">
    <!-- Мы добавили / в конце тега <img> – теперь он считается закрытым -->
    <img alt="Закрытый тег" src="/example.jpg" />

Так закрывать нужно только одиночные теги.

А вот такие закрывать не нужно, они закрываются вторым специальным тегом 👇🏻

    <p>Я параграф с закрывающим тегом</p>

Проверь, все ли теги в твоей JSX-разметке закрываются.

{quiz-task} background: | #f5f6f7 content: | Здесь тоже можешь использовать автоматическую замену: многие теги изображения в проекте заканчиваются на `className="card__image">`. Введи эту строку в меню поиска, а в меню замены напиши `className="card__image" />`. Останется только вручную поработать с изображением `className="promo__image">`. Закрой этот тег самостоятельно. {/quiz-task}

4. И, конечно, все пути до картинок должны быть абсолютными: проверь, прописаны ли пути к ним от папки `public`

Чек-лист

- папка `images` перенесена в папку `public` - папка `fonts` перенесена в папку `public` - относительные пути к изображениям заменены на абсолютные - шрифты подключены в файле `global.css` - вёрстка шапки и подвала сайта хранится в `layout.js` - стили проекта перенесены в файл `globals.css` - функция `Home` в файле `page.js` возвращает вёрстку элемента `<main>` нашего сайта
