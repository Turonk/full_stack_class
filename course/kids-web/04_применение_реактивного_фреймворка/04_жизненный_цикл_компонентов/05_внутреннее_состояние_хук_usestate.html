Внутреннее состояние

Практически в каждом сайте засветился король всех хуков — `useState`. Этот встроенный хук из библиотеки React очень популярен среди разработчиков и в нашем курсе тоже будет встречаться довольно часто.

`useState` перед использованием в компоненте, как и все другие React-хуки, нужно импортировать из библиотеки 👇🏻

'use client';
import {useState} from 'react';

{quiz-task} background: | #f1f1ef content: | ❗ Ты уже знаешь ключевую фразу перед импортом — `'use client'`. Это правило возникло неспроста. Изначально библиотека React помогала создавать интерфейсы для браузера, взаимодействовать с его инструментами. Чаще всего обновления элементов страницы — это результат действий пользователя, они тесно связаны с жизненным циклом компонентов, именно поэтому использование хуков уместно **только на клиентских компонентах** в браузере пользователя. {/quiz-task}

Хук `useState` помогает работать с внутренним состоянием функционального компонента.

Сейчас объясним!

Чтобы быть по-настоящему интерактивным, интерфейс сайта должен изменяться, давать обратную связь на действия пользователя. Например, при перемещении товаров в корзину на маркете текст в кнопке должен меняться с `'Купить'` на `'В корзине'`

В компонентах часто необходимо хранить данные (промежуточные расчёты и значения, другую специфичную информацию). Раньше для этого мы использовали переменные, а если эти значения нужно было отображать, то обращались к DOM-элементу и меняли в нём содержимое.

Если сохраним значение — число `1` — в переменную `buttonText` и передадим её в JSX, то оно отобразится на странице 👇🏻

const Button = () => {
	let buttonText = 1;

	return <button>{buttonText}</button>
}

А если мы будем менять этот текст в переменной по клику или любым другим способом, то значение в самой переменной поменяется, но вот в интерфейсе всё останется прежним (при клике на кнопку обрати внимание на консоль) 👇🏻

{iframe:https://sandbox-teens.practicum-team.ru/tasks/03-framework/04-life-cycle/04-useState/example-04/pre/|minWidth:400px|minHeight:600px}

В React-компонентах хранение данных реализовано немного иначе.

Хранить данные в обычных переменных можно, но стоит учитывать пару особенностей:

- Если значение переменной нужно отобразить на странице, при изменении значения в локальной переменной интерфейс не обновится и будет отображать неактуальное значение. - Локальные переменные не сохраняются между перерисовками — при повторном отображении компонента они создаются с нуля и игнорируют прошлые изменения в переменных. Причём через хук `useRef`, который мы разбирали ранее, эту задачу тоже не решить. Он выводит значение в консоль, не показывает изменения на странице сразу при обновлении `ref.current`

Данные, которые могут храниться внутри компонента и влиять на его поведение, называют **внутренним (локальным)** **состоянием компонента**.

Переменные состояния недостаточно просто сохранять. Нам предстоит изменять их значения, а изменяя внутреннее состояние компонента, мы используем стадию жизненного цикла обновления (`update`), благодаря чему React понимает, что компонент необходимо перерисовать.

Взглянем на хук `useState` поближе.

Хук `useState`

Хук `useState` — это специальная функция, помогающая сохранить и изменять внутреннее состояние компонента. При вызове он возвращает массив с двумя элементами:

1. Текущее значение переменной состояния. 2. Функция, с помощью которой его можно изменить.

// При вызове хука useState в переменную myState запишется массив
const myState = useState()
// Первый элемент массива myState - текущее значение переменной состояния
const currentState = myState[0]
// Второй элемент массива myState - функция, изменяющая значение переменной состояния
const setCurrentState = myState[1]

Чтобы удобнее записать создание переменных и присвоение в них значений, можно воспользоваться следующей конструкцией 👇🏻

const [currentState, setCurrentState] = useState()

Оба варианта записи выше равнозначны.

В момент монтирования (создания компонента) хук `useState` сохраняет в нём изначальное значение для переменной состояния 👇🏻

const [currentState, setCurrentState] = useState(0)
console.log(currentState) // 0

Используя функцию `setCurrentState` с новым значением в качестве аргумента, можно изменить значение переменной состояния 👇🏻

const [currentState, setCurrentState] = useState(0)
setCurrentState(1)
console.log(currentState) // 1

При изменении состояния React обновляет значение в своём хранилище и инициирует перерисовку компонента. При этом повторный вызов хука `useState` возвращает уже другой массив, первым элементом которого будет новое значение переменной состояния (а функция останется прежней).

Так, в примере с покупкой на сайте мы можем использовать локальное состояние для хранения переменной с текстом кнопки. Добавим хук `useState` и передадим в него аргументом строку `'Купить'` 👇🏻

const [buttonText, setButtonText] = useState('Купить')

При первой отрисовке компонента в переменной `buttonText` будет храниться начальное значение `'Купить'`. Её можно использовать в JSX-разметке 👇🏻

'use client';
import {useState} from 'react';

const Button = () => {
	const [buttonText, setButtonText] = useState('Купить')

	return <button>{buttonText}</button>
}

Смена состояния обычно происходит по событию. В прошлом уроке мы уже научились обрабатывать события в React. Передадим в свойство `onClick` на кнопке функцию-обработчик клика, в которой будем менять состояние компонента с помощью `setButtonText` и нового значения 👇🏻

{iframe:https://sandbox-teens.practicum-team.ru/tasks/03-framework/04-life-cycle/04-useState/example-01/pre/|minWidth:400px|minHeight:600px}

Как только мы поменяем состояние компонента функцией `setButtonText('В корзине')`, React выполнит повторную перерисовку компонента и отобразит уже новое значение в разметке.

Сейчас мы меняем состояние один раз, что неудобно для настоящей кнопки покупки товара. Добавив условие тернарным оператором, ты сможешь проверять текущее состояние кнопки и в зависимости от его значения менять состояние на противоположное 👇🏻

Время практики

В песочнице уже есть компонент `Input`, тебе нужно:

- правильно передать состояние со значением текста в параграф — тег `<p>` - вызвать и передать функцию, изменяющую состояние.

{iframe:https://sandbox-teens.practicum-team.ru/tasks/03-framework/04-life-cycle/04-useState/example-03/pre/|minWidth:400px|minHeight:600px}

// В компоненте Input уже записан хук useState

// 1. Передай начальное значение состояния в тег <p> для отображения текста
// 2. Используй функцию изменения состояния в обработчике handleInputChange

const Input = () => {
  const [inputValue, setInputValue] = React.useState("тут будет текст");

  const handleInputChange = (e) => {
    // Передай значение из e.target.value в функцию, изменяющую состояние
    setInputValue(e.target.value)
  };

  return (
    <div className={"text__block"}>
      <input
        type="text"
        placeholder={"Введите текст"}
        // В свойство onChange передай ссылку на функцию-обработчик handleInputChange
        onChange={handleInputChange}      
      />
      <p>{inputValue}</p>
    </div>
  );
};

const rootElement = document.getElementById("root");
const root = ReactDOM.createRoot(rootElement);
root.render(<Input />);

Хук `useState` самый востребованный при создании интерфейсов. С помощью него можно создавать сколько угодно подобных состояний у компонента и хранить в них различные значения. Это позволяет не только работать с текстом или данными внутри компонента, но и управлять отображением других компонентов.

Рассмотрим популярный элемент интерфейса `PopUp` — подобный элемент можно встретить практически на каждом сайте (это всплывающее окно, которое отображается поверх веб-страницы в браузере). Его чаще всего используют для вывода сообщений с важной информацией (подтверждение действий на сайте, регистрация или вход в личный кабинет). На сайте Яндекс Практикума ты можешь встретить его при переходе по модулям курса.

![](https://pictures.s3.yandex.net:443/resources/Frame_1491_1707841262.png)

Контент в нём может быть разный, а вот реализация обычно похожа.

В React-приложениях `PopUp` часто находится в родительском компоненте, например на странице сайта.

В компоненте страницы `Page` существует состояние, которое отвечает за отображение `PopUp` 👇🏻

// Компонент PopUp получает функцию для закрытия извне через props
const PopUp = (props) => {
	return (
		<div className="popup">
			<p>текст</p>
			// Получаем из параметров props-обработчик, закрывающий PopUp
			<button onClick={()=>{props.closePopUp}}>Закрыть</button>
		</div>
	)
}

// В компоненте Page, в котором располагается PopUp, существует состояние, 
// отвечающее за отрисовку PopUp 
const Page = () => {
	// Состояние isPopUpOpened хранится в boolean-типе
	const [isPopUpOpened, setIsPopUpOpened] = useState(false);
	
	// Обработчик, который закрывает PopUp, необходимо также передать через props
	// дочернему компоненту PopUp
	const handlePopUp = () => {
		setIsPopUpOpened(!isPopUpOpened);
	}

	return (
		<div>
			// Если isPopUpOpened равен true, отобразится компонент PopUp
			{isPopUpOpened && <PopUp closePopup={handlePopUp}/>}
			<button onClick={handlePopUp}>Открыть попап</button>
		</div>
	)
}

Для изменения состояния используется обработчик `handlePopUp`. В нём используется функция `setIsPopUpOpened` и текущее значение состояния `isPopUpOpened`. За счёт логического оператора **НЕ** (`!`) при каждом вызове `handlePopUp` меняется логическое значение состояния `isPopUpOpened`: с `false` в `true` и наоборот.

Обработчик `handlePopUp` понадобится в компоненте `Page` на кнопке `Открыть PopUp`, а также в самом компоненте `PopUp`, чтобы его закрывать.

Передать обработчик `handlePopUp` в дочерний компонент можно через параметры `props` таким образом 👇🏻

<PopUp closePopup={handlePopUp}/>

Получается, что мы можем передавать состояние и функцию для его изменения из хука `useState` в дочерние элементы через параметры `props` так же, как обычные значения и переменные.

![](https://pictures.s3.yandex.net:443/resources/Frame_1492_1707841285.png)

Для отображения `PopUp` в родительском компоненте `Page` достаточно воспользоваться условной отрисовкой компонента 👇🏻

{isPopUpOpened && <PopUp closePopup={handlePopUp}/>}

Такая конструкция позволяет отрисовать компонент `PopUp` только при условии, когда состояние `isPopUpOpened` хранит значение `true`

Работа над Pindie

Одна из основных идей проекта — это голосование за игры на сайте. Пользователю нужно авторизоваться, чтобы его голос учитывался.

Сделаем окно авторизации в виде `PopUp`, который будет открываться по клику на кнопку `Войти` в шапке сайта (компонент `Header`).

{video:https://code.s3.yandex.net/kids-web/vids/Запись_экрана_2024-01-29_в_16.51.29.mp4}

`PopUp` часто состоит из нескольких компонентов:

- Компонент подложки Это серый фон, который перекрывает веб-страницу в момент отображения всплывающего окна. Этот фон интерактивный, по клику на него `PopUp` должен закрываться. - Компонент всплывающего окна Небольшой блок, в котором отображается контент: сообщения с кнопками или (как в нашем случае) вёрстка для авторизации пользователя. - Компонент контента Это то, что мы хотим отобразить внутри всплывающего окна. В нашем случае вёрстка и всё необходимое для авторизации пользователя. Компонент контента необходимо передать внутрь компонента всплывающего окна в качестве `children`

Для этого тебе понадобятся три компонента `Overlay`, `Popup`, `AuthForm` из репозитория по ссылке ниже:

Стили и основная вёрстка готовы, надо только написать логику по взаимодействию с окном авторизации.

Начнём с добавления новых компонентов в папку `components`

**Шаг 1.** Внеси изменения в компонент `Header` , чтобы добавить окно авторизации. Для этого:

- Создай папку `Popup` в папке `components` и перенеси в неё JSX- и CSS-файлы компонента `Popup` - Создай папку `Overlay` в папке `components` и перенеси в неё JSX- и CSS-файлы компонента `Overlay` - Создай папку `AuthForm` в папке `components` и перенеси в неё JSX- и CSS-файлы компонента `AuthForm` - Сделай компонент `Header` клиентским и импортируй хук `useState` в компонент `Header` - Внутри компонента `Header` вызови хук `useState` с изначальным значением состояния `false`. Хук `useState` должен вернуть две переменные, назови их `popupIsOpened` и `setPopupIsOpened` - Опиши две функции: 1) Функция `openPopup` изменяет состояние `popupIsOpened` в значение `true` 2) Функция `closePopup` изменяет состояние `popupIsOpened` в значение `false` - В компоненте `Header` на кнопку `Войти` установи обработчик клика, который будет открывать `Popup`

    <div className={Styles["auth"]}>
    	<button className={Styles["auth__button"]} onClick={openPopup}>
    		Войти
    	</button>
    </div>

- По клику на кнопку `Войти` нужно отображать три компонента: `Overlay`, `Popup` и `AuthForm`. `Overlay` (это серый фон за всплывающим окном `Popup`) положи на одном уровне с компонентом `Popup`. Компонент `AuthForm` расположи внутри компонента `Popup`, для этого вложи его внутрь `Popup` вот так 👇🏻

        // Код компонента Header...
        </nav>
        <Overlay />
        <Popup>
            <AuthForm />
        </Popup>
    </header>

- Параметрами `props` пропусти в компоненты `Overlay` и `Popup` значение состояния `popupIsOpened` и функцию `closePopup`, чтобы закрыть `Popup`

**Шаг 2.** Добавь возможность закрывать окно авторизации и правильно отображать компоненты `Overlay` и `Popup`. В них нужно использовать переданные параметры `props`. Для этого:

- В компоненте `Popup` отобрази класс `"popup_is-opened"` по условию, используя конструкцию с использованием значения переданного состояния из `props`

    className={`${Styles["popup"]} ${props.isOpened && Styles["popup_is-opened"]}`}

- Аналогично поступи с классом `"overlay_is-opened”` в компоненте `Overlay` - Организуй закрытие `Popup` либо по клику на кнопку в компоненте `Popup`, либо по серому фону — а именно компоненту `Overlay`, для этого:

1) В компоненте `Popup` добавь `onClick` на тег `<button>` и передай в него функцию, закрывающую `Popup` из `props`

2) В компоненте `Overlay` передай такую же функцию в `onClick` на тег `<div>`

В этом компоненте есть тег `<button>`

Сделаем так, чтобы по клику на кнопку `Получить код` отображался промокод вместо текста кнопки. А спустя несколько секунд промокод будет исчезать, возвращая надпись `Получить код`

Лови пошаговую инструкцию 👇🏻

- Для переменной состояния `codeIsVisible` используй хук `useState` с изначальным значением состояния `false` - Для обработки клика запиши функцию `handleButtonClick`, которая будет устанавливать переменную `codeIsVisible` в `true`, если она изначально была `false` - Добавь `onClick` на тег `<button>` и передай в него функцию `handleButtonClick` - Внутри тега `<button>` вместо обычного текста `Получить код` сделай условную отрисовку: - Если переменная `codeIsVisible` в значении `true`, пусть отрисовывается следующее 👇🏻

    <span className={Styles["promo-code"]}>WEBTEENS10</span>

- Если переменная `codeIsVisible` в значении `false`, пусть отрисовывается `Получить код`

Эти шаги помогут по клику менять отображение кнопки в компоненте `Promo`
