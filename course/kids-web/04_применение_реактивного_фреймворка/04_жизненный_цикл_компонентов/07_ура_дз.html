Часть 1. Всплывающее окно

{quiz-task} background: | #f1f1ef content: | 📌 Урок «Внутреннее состояние. Хук `useState`» облегчит создание всплывающего окна в проекте. {/quiz-task}

- Скачай компоненты `Popup` , `Overlay` и `AuthForm` из репозитория. Его можно найти по [этой ссылке](https://github.com/Yandex-Practicum/pindie-prebuild-components){target="_blank"}. - Создай три отдельные папки внутри папки `app/components` для каждого компонента и перенеси JSX- и CSS-файлы в каждую из них. - Импортируй новые компоненты в файл `Header.jsx` - Используй хук `useState` в компоненте `Header`, чтобы создать состояние `popupIsOpened` с булевым значением. По умолчанию значение состояния — `false` - Создай две функции на верхнем уровне компонента для открытия и закрытия всплывающего окна — `openPopup` и `closePopup` - В функции `openPopup` необходимо менять состояние `popupIsOpened` с `false` (закрыто) на `true` (открыто). - В функции `closePopup` необходимо менять состояние `popupIsOpened` с `true` (открыто) на `false` (закрыто). - Добавь обработчик события `onClick`, передав функцию `openPopup` кнопке `Войти`. Так при клике на кнопку будет вызываться функция открытия всплывающего окна. - Добавь компонент `Overlay` в JSX-разметку после блока навигации (`<nav/>`):

1) Передай состояние `popupIsOpened` в компонент через параметр `isOpened`

2) Передай функцию закрытия `closePopup` через параметр `close`

- Добавь компонент `Popup` в JSX-разметку после компонента `Overlay`:

1) Передай состояние `popupIsOpened` в компонент через параметр `isOpened`

2) Передай функцию закрытия `closePopup` через параметр `close`

- Добавь компонент `AuthForm` в JSX-разметку внутри компонента `Popup` как его дочерний элемент.

Часть 2. Отображение промокода

{quiz-task} background: | #f1f1ef content: | 📌 После урока «Внутреннее состояние. Хук `useState`» ты сможешь легко добавить промокод внутрь кнопки. А урок «Всевидящий хук `useEffect`» поможет скрыть его через пять секунд после появления, вернув кнопке прежний вид. {/quiz-task}

- Используй хук `useState` в компоненте `Promo`, чтобы создать состояние `codeIsVisible` с булевым значением. По умолчанию значение состояния — `false` - Создай функцию `handleButtonClick` на верхнем уровне компонента. Функция должна проверять состояние `codeIsVisible` и, если его значение `false`, менять состояние на `true`. Для этого лучше использовать логическое отрицание `!` и оператор `&&` - Используй условный рендеринг внутри кнопки `Получить код`, чтобы проверить состояние `codeIsVisible`:

1) Если состояние `codeIsVisible` со значением `true` — должен выводиться элемент `<span>` с модульным стилем `promo-code` и текстом `WEBTEENS10` внутри.

2) Если состояние `codeIsVisible` со значением `false` — должен выводиться обычный текст `Получить код`

- Добавь обработчик события `onClick`, передав функцию `handleButtonClick` для кнопки `Получить код`. Так при клике на эту кнопку будет вызываться функция смены состояния и внутри появится промокод. - Используй хук `useEffect` в компоненте `Promo`, чтобы создать таймер обратного отсчёта и восстановления прежнего состояния кнопки. Для этого:

1) Создай пустую локальную переменную `timeout`

2) Реализуй проверку состояния `codeIsVisible`. Только когда состояние со значением `true` — присвой переменной `timeout`-таймер, используя `setTimeout`

3) Внутри таймера (функции `setTimeout`) необходимо менять состояние `codeIsVisible` на значение `false`

4) Время таймера (функции `setTimeout`) установи со значением `5000`, что соответствует пяти секундам.

5) В функции очистки хука `useEffect` используй `clearTimeout` и передай в него таймер (переменную `timeout`). Функция будет удалять таймер после его работы.

6) В массиве зависимостей хука `useEffect` укажи состояние `codeIsVisible`. Так компонент будет обновляться каждый раз при изменении значения состояния.

Чек-лист с требованиями

- Появляется всплывающее окно (компоненты `Popup` и `Overlay`) при клике на кнопку `Войти` в шапке сайта. - Всплывающее окно исчезает при клике на кнопку-крестик внутри него. - При клике на кнопку `Получить промо` внутри неё появляется `<span>` с промокодом. - Промокод исчезает через пять секунд после появления, а текст кнопки возвращается обратно. - Перед отправкой работы удали папки `node_modules` и скрытую папку `.next` Чтобы увидеть скрытые папки на macOS нажми комбинацию горячих клавиш «cmd+shift+.», на Windows — смотри [инструкцию](https://hi-tech.mail.ru/news/47521-kak-pokazat-skrytye-papki/){target="_blank"}. Проверь, чтобы файлы `package.json` и `package-lock.json` были на месте, а папка с проектом весит не более 10 Мб.
