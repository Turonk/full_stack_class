## Хуки

Хуки — это специальные функции, которые можно использовать для интерактивности только в функциональных компонентах. Обычно хуки возвращают данные и функции для их обработки. Ты можешь использовать встроенные в библиотеку React хуки либо комбинировать их и создавать свои. 

Именно с помощью хуков можно управлять жизненным циклом функционального компонента, сохранять различную информацию внутри компонентов, оптимизировать расчеты данных и получать доступ к DOM-элементам. 

Ниже создадим свой собственный хук с именем `useConsoleLog`, который будет сохранять сообщение в переменную и иметь возможность выводить её значение в консоль 👇🏻

```javascript
// Хук - это функция, которая начинается с use...
function useConsoleLog() {
	// Для сообщений нам понадобится переменная text
  let text = '';
	// Опишем две функции:
	// Функция setText будет сохранять сообщение в переменную text
  const setText = function(newText) {
    text = newText;
  }
	// Функция toConsole будет выводить сообщение в консоль
	const toConsole = function() {
		console.log(`Ваш текст: ${text}`)
	}
	// Чтобы использовать хук в компоненте, вернём из него два метода
	return {setText, toConsole}
}
```

Один хук и уже несколько действий для компонента! 

Теперь сделаем так, чтобы они срабатывали интерактивно. В этом нам помогут события — ты уже умеешь обрабатывать их в JavaScript: `submit`, `click`, `keydown`, — но с React-элементами это происходит немного иначе.

## Особенные события

Для обработки событий в браузере есть слушатель событий `addEventListener` — универсальный способ отслеживать различные пользовательские события. Также он может устанавливать несколько обработчиков на один DOM-элемент. В прошлых проектах мы использовали такие свойства DOM-элементов, как `onclick`, `onkeydown`, `onsubmit` — они помогали обработать одноимённые события. Правда, для этого мы каждый раз обращались к реальным DOM-элементам. 

React же, чтобы интерфейс сайта работал молниеносно, старается лишний раз не тревожить реальные DOM-элементы. Все изменения изначально выполняются на React-элементах, и только затем фреймворк сравнивает их с DOM-элементами и оптимально применяет все изменения. 

Таким образом, для работы с React-элементами нужны особенные события — `SyntheticEvent` (с английского — «синтетические события»). Они также имеют ряд оптимизаций, чтобы быть универсальными для разных браузеров. 

Сейчас главное — запомнить, что обработка событий в React так же проста, как и с обычными DOM-элементами, достаточно использовать подходящие свойство: `onClick`, `onKeydown`, `onSubmit`

Но есть и несколько отличий:

- События в React именуются в стиле camelCase вместо нижнего регистра.
- В JSX ты передаёшь саму функцию-обработчик в фигурных скобках, а `handleClick` передаётся как ссылка.

Самостоятельно сравни код ниже, чтобы понять, о чём речь.

HTML 👇🏻

```html
<button onclick="handleClick()">
  Кликнуть по кнопке
</button>
```

React 👇🏻

```javascript
<button onClick={handleClick}>
  Кликнуть по кнопке
</button>
```

Чтобы передать параметры обработчику события, обернули вызов в стрелочную функцию 👇🏻

```javascript
<button onClick={() => handleClick(arg)}>
  Кликнуть по кнопке
</button>
```

## Используем хуки

Используем созданный выше хук `useConsoleLog`, который выводит сообщение в консоль.

Для этого обратимся к нему внутри функционального компонента и с помощью деструктуризации получим две функции, которые он вернёт. Сохраним их в одноимённые переменные `setText` и `toConsole` 👇🏻

```javascript
function useConsoleLog() {
  let text = '';
  const setText = function(newText) {
    text = newText;
  }
	const toConsole = function() {
		console.log(`Твой текст: ${text}`)
	}
	return {setText, toConsole}
}

// Применяем хук useConsoleLog внутри функционального компонента
function Component = (props) => {
	const {setText, toConsole} = useConsoleLog();
	
	return (
		<button>В консоль</button>
	)
}
```

Теперь добавим действие для кнопки: по клику на неё будем использовать хук для вывода в консоль сообщения `'Привет, мир!'`

Чтобы передать сообщение и вывести его в консоль, нужно для начала вызвать `setText('Привет, мир!')` и только затем `toConsole`. Обернём это всё в функцию-обработчик `handleClick`. Останется только обработать событие клика с помощью `onClick` 👇🏻

```javascript
function useConsoleLog() {
  let text = '';
  const setText = function(newText) {
    text = newText;
  }
	const toConsole = function() {
		console.log(`Твой текст: ${text}`)
	}
	return {setText, toConsole}
}

function Component = (props) => {
	const {setText, toConsole} = useConsoleLog();
	// Создаём функцию-обработчик
	const handleClick = () => {
		setText('Привет, мир!');
		toConsole();
	}
	return (
	// Обрабатываем событие клика
		<button onClick={handleClick}>В консоль</button>
	)
}
```

Сейчас текст сообщения записывается внутри обработчика `handleClick`

Если мы хотим в обработчик передавать текст аргументом, то в свойстве `onClick` используем стрелочную функцию. Рассмотрим на примере `handleClick2` 👇🏻

```javascript
function useConsoleLog() {
  let text = '';
  const setText = function(newText) {
    text = newText;
  }
	const toConsole = function() {
		console.log(`Твой текст: ${text}`)
	}
	return {setText, toConsole}
}

function Component = (props) => {
	const {setText, toConsole} = useConsoleLog();
	
	const handleClick = () => {
		setText('Привет, мир!');
		toConsole();
	}
	// Создаём обработчик, который получает сообщение извне аргументом
	const handleClick2 = (message) => {
		setText(message);
		toConsole();
	}

	return (
		<button onClick={handleClick}>В консоль</button>
		// Для вызова с аргументом обернём handleClick2 в стрелочную функцию
		<button onClick={()=>handleClick2("клик-клик")}>Клик в консоль</button>
	)
}
```

Кастомный хук `toConsole` — первый шаг в знакомстве с React-хуками.

Разные хуки скрывают разные возможности. Взглянем на встроенный в React хук `useRef`

## Хук useRef

Хук `useRef` возвращает объект со свойством `current`. В него записывается значение любого типа, переданное в `useRef` аргументом. Интересной особенностью является то, что при следующих перерисовках компонента `useRef` возвращает тот же объект с записанным значением. Таким образом, в нём можно хранить информацию между повторными перерисовками, что невозможно в случае обычных переменных внутри компонента, которые сбрасываются при каждой перерисовке компонента. 

Если с помощью компонента с хуком `useRef` мы создаём несколько React-элементов, то для каждого элемента будет создан свой персональный объект, в котором можно сохранять данные.

Создав один компонент счётчика и сохраняя в объекте хука `useRef` текущее количество кликов, мы сможем в интерфейсе программы создать несколько разных счётчиков с независимыми данными о количестве кликов на каждый из них 👇🏻

```javascript
'use client';
// Импортируем хук из библиотеки React
import { useRef } from 'react';

function Counter() {
	// Создаём объект с изначальным значением, равным - {current: 0}
  let ref = useRef(0);

	const handleClick = () => {
		// Увеличиваем значение на один
    ref.current = ref.current + 1;
    alert('На кнопку кликнули ' + ref.current + ' раз!');
  }

  return (
    <button onClick={handleClick}>
      Кликни на меня!
    </button>
  );
}
```

Компонент `Counter` использует объект, возвращаемый хуком `useRef`, для отслеживания количества нажатий на кнопку.

При работе с библиотекой React нам не нужно каждый раз взаимодействовать с DOM для обновления элемента, получения или изменения его данных. React берёт эту задачу на себя и максимально оптимизирует этот процесс. Но существуют исключения, когда в компоненте может понадобиться прямой указатель на реальный DOM-элемент:

- управление фокусом, выделение текста или воспроизведение медиа
- вызов анимаций
- взаимодействие со сторонними DOM-библиотеками

Для вышеперечисленных целей в функциональных компонентах можно использовать хук `useRef`. Он возвращает объект, который с помощью JSX-атрибута `ref` можно присвоить любому элементу, чтобы получить доступ к нему. Именно в поле `current` React запишет указатель на DOM-элемент, когда будет формировать DOM-дерево.

Например, так можно выводить в консоль в режиме реального времени ввод символов в `Input` 👇🏻

```javascript
'use client';
// Импортируем из библиотеки React
import {useRef} from 'react';

const Input = () => {
	// Записываем объект, возвращаемый хуком, в переменную
	const myInput = useRef(null);
	const handleInput = () => {
		// Вызвав myInput.current.value, можно получить текущее значение элемента ввода
		console.log(myInput.current.value);
	}
	// Присваиваем в атрибут ref объект myInput для доступа к DOM-элементу
	return <input type="text" ref={myInput} onInput={handleInput}/>
};
```

Выше перечислены только некоторые возможные применения хука `useRef`, а комбинируя его с другими хуками, можно создавать более сложные элементы программы. 

Хуки существуют для различных задач, поэтому нет единого правила, как именно применять их в программе, но есть общие правила оформления.

## Правила хуков

Хуки — не простые функции. 

Для их корректной работы в React-компонентах нужно соблюдать несколько правил:

- Хуки используются только в клиентских компонентах
В Next.js такие компоненты нужно обозначать с помощью ключевой фразы `'use client'` в начале файла с кодом компонента.
- Имена хуков начинаются с `use` (`useRef`, `useState`, `useEffect`)
- Хуки можно вызвать только в функциональных компонентах или других хуках
- Хуки нельзя вызывать условно, в циклах или вложенных функциях
- Для React важен порядок вызова
