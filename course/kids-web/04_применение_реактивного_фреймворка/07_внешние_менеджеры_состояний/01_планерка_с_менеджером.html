Планёрка с менеджером

![](https://pictures.s3.yandex.net:443/resources/IMG_4704_1709218087.jpg)

В одном из последних уроков мы уже подсветили тебе проблему рассинхронности в Pindie: счётчик голосов на главной странице и детальных страницах каждой игры на данный момент показывает разные цифры. В этой теме пофиксим проблему.

За синхронизацию всех изменений в приложении отвечает его **состояние**. Такой главный источник истины для всех составных частей системы. В грядущих уроках будешь разбираться с подходами и способами работы с состоянием. В результате научишь все компоненты слушать одного командира — **менеджера глобального состояния приложения**.

В этой теме будет задание, но не будет окошка для сдачи ДЗ. Но выполнение этого задания сильно ускорит сдачу финального проекта модуля по React. Уже на следующей неделе тебе надо будет сдать наставнику архив с кодом Pindie, который мы рука об руку разрабатывали всё это время.

Мы откроем урок для сдачи финального проекта **18 марта**.
