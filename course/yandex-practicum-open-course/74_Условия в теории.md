# Условия в теории

Если за окном дождь, возьмите зонт. Если в баке осталось мало бензина, остановитесь на заправке. Если есть в кармане пачка — ну, вы поняли. Мы постоянно действуем на основе условий: `если` такие-то `условия`, то `делаем вот так`.

Такой способ принимать решения заложен и во многие программы. Если бензина осталось мало, надо зажечь сигнал «Мало бензина». Если пользователь кликнул по кнопке, открой всплывающее окно. Если прокрастинаторский совет слишком длинный и в экран не помещается, то надо уменьшить шрифт:

JAVASCRIPT

```
если (надпись длиннее 40 символов) {
    уменьшить размер надписи до 32px
} 
```

Но что, если надпись не такая длинная, а размер шрифта почему-то маленький? Стоит перестраховаться:

JAVASCRIPT

```
если (надпись длиннее 40 символов) {
    уменьшить размер надписи до 33px
} иначе {
    установить обычный размер в 42px
} 
```

![](https://pictures.s3.yandex.net:443/resources/Untitled_4_1714119689.png)

Такой код называется псевдокодом. Как это записать на JavaScript? Разберём на простом примере:

JAVASCRIPT

```
if (age >= 18) {
    console.log('добро пожаловать на выборы');
}

// выведет надпись в консоль, если число в переменной age (возраст) больше или равно 18;
// иначе ничего не произойдёт, JavaScript не пойдёт внутрь фигурных скобок 
```

Более сложная конструкция:

JAVASCRIPT

```
if (age >= 18) {
    console.log('добро пожаловать на выборы');
} else {
    console.log('вам голосовать ещё рано');
}

// выведет надпись в консоль, если число в переменной age (возраст) больше или равно 18;
// во всех иных случаях сделает другое действие 
```

Проверяя выполнение условия, JavaScript отвечает на вопрос, равно ли оно `true` или `false`:

JAVASCRIPT

```
let age = 24;
console.log(age > 21); // вернёт ответ true 
```

По традиции осталось применить знания на практике.

JAVASCRIPT

```
let age = 24;
console.log(24 > age); 
```

Что попадёт в консоль?

`true`

`false`

`24`
