# Мысли о стилях. CSS

Если HTML сообщает браузеру о содержании веб-страницы, то CSS — о том, как её элементы выглядят и где расположены. Если нужно сделать ссылку розовой и большой, это описывают на CSS.

![](https://pictures.s3.yandex.net:443/resources/css_style_1672240705.gif)

У нашей кнопки белый текст и серый фон. В CSS так и написали:

CSS

```
button {
  color: white;
  background-color: grey;
} 
```

Такой код пишут в отдельном файле, обычно его называют `style.css`. Теперь попробуйте написать код сами.

Посмотрите на демо с примером несколькими абзацами ниже. Перед вами файл `style.css` (окей, не совсем перед вами, а во второй вкладке, после `index.html`). В нём написаны стили для кнопки. В окне результата справа видно, что сейчас у кнопки серый фон и белый цвет текста.

Добавим немного индивидуальности. Поменяйте фон кнопки с серого цвета (`grey`) на чёрный (`black`). Цвет текста менять не нужно, оставьте его белым (`white`).

Главное, не удаляйте двоеточие и точку с запятой. Без них всё сломается.

А теперь время для творчества. Если бы вы были кнопкой, то какой? Выберите любой цвет или цвета из таблицы в статье про [цвета в вебе](https://doka.guide/css/web-colors/#nazvanie-cveta) и поменяйте значение. Восхищайтесь результатом!

После экспериментов верните фону кнопки чёрный цвет, а тексту — белый.
