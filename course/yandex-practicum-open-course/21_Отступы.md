Отступы
=======

Почему вокруг текста обложки пустота?

Андрей

Почему вокруг текста обложки образовались произвольные пустоты?

Браузер назначил элементам отступы — так происходит по умолчанию, пока веб-разработчики не возьмут управление стилем на себя.

Теорию и принципы работы отступов изучим чуть позже, сейчас предлагаем скорее доделать плейлист. Для этого достаточно знать, что внешний отступ от элемента (поле) в CSS называется `margin`. Это свойство создаёт пустое пространство между элементом и его соседями.

![](https://pictures.s3.yandex.net:443/resources/Untitled_100_1672324543.png)

Отступы можно задавать отдельно для верхней, правой, нижней или левой сторон. Тогда имя свойства обозначается не просто `margin`, а соответственно `margin-top`, `margin-right`, `margin-bottom` или `margin-left`.

Если написать `margin: 20px`, отступы в 20 пикселей появятся со всех четырёх сторон, а если `margin-left: 20px` — только слева.

Так, надо потренироваться

Андрей

Так, надо потренироваться

Сократите до минимума расстояние между заголовками `<h1>` и `<h2>` и между параграфами. Обнулите нижний отступ для селектора `h1` и верхний для селектора `h2`. Для селектора `p` обнулите и нижний, и верхний отступы.

Кстати, значение `0` в CSS можно указывать и без `px`. Потому что ноль — это просто ноль.

В `style.css` для селектора `h1` надо дописать `margin-bottom: 0;`, для селектора `h2` — `margin-top: 0;`, а для селектора `p` — и `margin-top: 0;`, и `margin-bottom: 0;`.

Готово!

Андрей

Готово!

Чтобы продолжить работу с отступами, очистим пространство: описание плейлиста перенесём под обложку (тем более что в референсе так и было).

Вынесите элементы `<p>` вместе со всем содержимым из элемента `<div>` — поместите их сразу после закрывающего тега `</div>`.

Кажется, становится похоже… на что-то

Андрей

Кажется, становится похоже… на что-то

Обложка, как скульптура в работе, становится всё изящнее.

Другое быстрое улучшение — разместить название и картинку по центру обложки. Задайте селектору `div` CSS-свойство `text-align` со значением `center`.

Теперь всё по центру

Андрей

Теперь всё по центру

Ого! Оцените удобство объединения в общем контейнере. Вы задали свойство только для одного `<div>` — и все дочерние элементы к нему прислушались.

Пора разобраться с верхним отступом. Почему мы ещё не написали `margin-top` для элемента `h1`?

Есть проблема: `margin-top` первого дочернего элемента будет отодвигать не элемент от верхней границы родителя, а самого родителя от вышестоящего элемента.

То есть дело обстоит так:

Скопировать код

HTML

    <div>
        <!-- margin-top для h1 сдвинет вниз весь div -->
        <h1></h1>
        <!-- margin-top для p отодвинет p от h1 -->
        <p></p>
    </div> 

Вместо того чтобы делать отступ наружу, отступим от границы элемента `h1` внутрь. Для элемента `h1` обнулите `margin-top` и назначьте `padding-top` со значением `45px`.

Теперь над обложкой нет большого отступа

Андрей

Теперь над обложкой нет большого отступа

Есть! Отступы работают — вы заменили внешний отступ `margin` на внутренний `padding`. Запомните эти свойства, они вам пригодятся.

Для заголовка `h2` не установлен нижний отступ: там действует загадочный отступ по умолчанию. Задайте этому элементу предсказуемое поведение: установите для `h2` нижний внешний отступ `margin-bottom` размером `35px`.

А много ещё?

Андрей

А много ещё?

Внешне изменилось мало, зато ситуация с отступами теперь под вашим контролем. Обложка почти готова, ещё немного — и можно отправлять работу на тестирование. Настало время восхищаться собой!

Пойду повосхищаюсь!

Андрей

Пойду повосхищаюсь!

Вы заметили, что вокруг заголовка `<h1>` есть пустое пространство, хотя вы не добавляли отступы в CSS. Почему так происходит?

Это баг браузера, который нужно исправлять

Браузер назначает некоторым элементам отступы по умолчанию

Элемент `<h1>` автоматически получает внутренний отступ (`padding`)

Пустое пространство — это фон родительского элемента
