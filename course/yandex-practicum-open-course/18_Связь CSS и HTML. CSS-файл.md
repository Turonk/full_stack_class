# Связь CSS и HTML. CSS-файл

Продолжим раздавать стиль!

Второй способ подключения стилей — через отдельный файл. Разработчики предпочитают этот способ, когда объём написанного CSS-кода превышает 30–40 строк.

В этом случае файлы с расширением .`html` хранят HTML-код, а файлы с расширением .`css` — код на CSS.

Когда стили выносят в отдельный CSS-файл, HTML-страница связывается с ним тегом `<link>`:

HTML

```
<head>
  <!-- здесь что-то про кодировку, заголовок, фавиконку -->
  <link rel="stylesheet" href="style.css" />
</head> 
```

Вспомним: у тега `<link>` атрибут `rel` указывает на предназначение подключаемого файла. Значение `stylesheet` сообщает браузеру, что передаются именно стили. Второй атрибут, `href`, указывает адрес CSS-файла.

Перенесём код стилей из HTML-файла в файл `style.css`.

Посмотрите в верхнюю левую часть песочницы. Рядом с вкладкой index.html появилась вкладка style.css. Весь код между тегами `<style>` и `</style>` перенесите в эту вкладку. Сами теги копировать не нужно. После этого удалите элемент `<style>` из `<head>` вместе со всем содержимым.

Работать с CSS-кодом в отдельном месте приятнее — и технически, и визуально. Задайте всем текстовым элементам то же семейство шрифтов, что и в референсе.

💡 _Примечание:_ названия подключаемых шрифтов рекомендуется брать в кавычки. Для однословных названий это технически необязательно, но является лучшей практикой для надёжности и единообразия кода. Родовые семейства ( `serif`, `sans-serif` ) кавычками **не** оборачивают.

Для заголовков первого уровня укажите правило: `font-family: 'William', serif;`. Для заголовков второго уровня и абзацев — `font-family: 'Inter', sans-serif;`.

Добавляйте новые свойства в правила, размещённые в файле `style.css`:

CSS

```
h1 {
  /* уже заданные свойства */
  font-family: 'William', serif; /* добавить эту строку */
}

h2 {
    /* уже заданные свойства */
    font-family: 'Inter', sans-serif; /* и эту строку */
}

/* и добавить стиль для абзаца */
p {
    font-family: 'Inter', sans-serif;
} 
```

Именно так работа со стилями выглядит в реальном мире. Писать CSS в отдельном файле приятнее, но это не значит, что жизнь станет проще. Наоборот, теперь пришло время зарубиться по профессиональной вёрстке. А пока полюбуйтесь результатом ваших трудов!

Превратим навык в привычку. Вы создали файлы `index.html` и `styles.css`, оба лежат в папке с плейлистом. Подключите файл стилей к `index.html` так, чтобы он заработал.

```
|-папка с кодом проекта
--|-index.html
--|-styles.css 
```

Правильный ответ

`<link rel="stylesheet" href="styles.css" />`

Верно! Файлы лежат рядом, поэтому ничего дополнительно указывать не нужно.

`<link rel="stylesheet" href="папка с кодом проекта/styles.css" />`

`<link rel="icon" href="styles.css" />`
