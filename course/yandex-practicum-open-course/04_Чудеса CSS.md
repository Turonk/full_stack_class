# Чудеса CSS

Когда мы нажимаем на кнопку, обычно что-то происходит (если только она не сломалась). Появляется всплывающее окно, товар добавляется в корзину или включается анимация. Мы уже создали саму кнопку, перевели текст и покрасили её в нужный цвет. Осталось придумать какое-то действие.

За большинство действий на сайтах отвечает JavaScript. Но это отдельный язык программирования и изучать его лучше после того, как вы станете крутыми верстальщиками. К тому же современные HTML и CSS тоже способны на многое!

На наш взгляд, самое впечатляющее во всём вебе — это анимации. Давайте сделаем так, чтобы по нажатию на кнопку проигрывался небольшой мультик.

Создание анимаций обычно требует довольно много кода. Здесь мы не будем останавливаться и подробно объяснять, как он работает.

Мы добавили в проект картинки, которые будут анимироваться, когда вы зажмёте кнопку. Осталось добавить код анимации. Мы написали его за вас. Так часто бывает в команде — кто-то пишет одну часть кода, пока другой работает над чем-то ещё. Файл с анимациями называется _animations.css,_ и мы уже подключили его к HTML-странице с помощью тега `<link>`. Взгляните на строчку под номером 9. Позже вы тоже научитесь так делать.

Вам осталось только «включить» анимацию для кнопки. Скопируйте код ниже и вставьте в файл `styles/style.css` (в файле будет комментарий на соответствующей строке, где нужно будет вставить этот код). А потом запаситесь попкорном и нажимайте на кнопку – анимация будет проигрываться, пока вы её удерживаете!

CSS

```
animation: change-bg 10s step-end infinite; 
```

_Продолжайте держать кнопку нажатой, чтобы увидеть всю анимацию!_
