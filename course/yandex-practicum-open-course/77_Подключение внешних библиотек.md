## Урок 15: Подключение внешних библиотек

Судя [по документации](https://code.s3.yandex.net/web-code/smoothly/basic-usage.html), библиотека предоставляет нам функцию `smoothly`. Эта функция принимает три аргумента — элемент страницы, свойство элемента, которое мы хотим изменить, и новое значение этого свойства. Вот пример использования функции из документации:

Скопировать код

JAVASCRIPT

```
const element = document.querySelector('.element');
smoothly(element, 'textContent', 'Новое содержимое'); 
```

Средствами `smoothly` сделайте так, чтобы текст внутри элемента `phrase` плавно изменялся на случайный текст из массива.

То есть, раньше мы добавляли текст на страницу вот так: `phrase.textContent = randomElement.text`, а теперь нужно это сделать с помощью функции `smoothly`, передав в качестве аргументов элемент `phrase`, свойство `'textContent'` и новый текст `randomElement.text`.
