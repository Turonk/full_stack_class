# Абзац

Основная часть текста на сайте состоит из абзацев. Их заключают в специальные теги `<p>`.

![](https://pictures.s3.yandex.net:443/resources/20_1710842290.png)

_Вот какой пример создатель языка HTML Тим Бернерс-Ли приводил в первом руководстве для разработчиков._

После заголовков добавьте абзац с текстом о плейлисте:

```
Плейлист для беспечного занятия кодингом 
```

Теперь после первого абзаца добавьте ещё один:

```
Один раз послушал — семь раз покодил. 
```

В итоге у вас получилось два заголовка, а под ними — два абзаца текста. Проверьте, всё ли в порядке.
