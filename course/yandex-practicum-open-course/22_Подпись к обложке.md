# Подпись к обложке

Для плейлиста осталось доделать несколько важных деталей. Перед началом работы ещё раз сверимся с референсом: 

Обложке не хватает подписи с годом и автором плейлиста. После кода изображения в HTML-файл добавьте элемент `<h3></h3>`.

А в него добавьте год, допустим `2022`, и псевдоним автора, например `Liza G.`.

Теперь слушатели знают, кого благодарить за музыкальную подборку.

Имя и дата появились на обложке, но браузер установил свои отступы и начертания шрифта. Исправьте это.

В файле стилей создайте правило с селектором `h3` и набором свойств:

CSS

```
font-family: Inter, sans-serif;
margin: 0;
font-size: 16px;
text-transform: uppercase;
line-height: 18px;
font-weight: normal; 
```

Вы назначили для `h3` семейство шрифта `Inter`, убрали отступы, задали размер шрифта `16px` и перевели символы в верхний регистр, задали высоту строки `18px` и ликвидировали «врождённую» жирность шрифта для заголовков. Так гораздо лучше.

Сделайте первый заголовок «нормальным» по толщине, как вы уже делали в предыдущем задании для элемента `h3`.

Отодвиньте подпись от изображения: добавьте селектору `img` свойство `margin-bottom` со значением `80px`.

Почти готово.

Эстетический штрих. Селекторам элементов `h1`, `h2` и `h3` добавьте свойство `color: white;` — текст на обложке должен стать белым.

И последнее — чтобы стало ещё красивее.

Для солидности предлагаем поместить обложку и текст по центру: добавьте две строчки в `style.css`.

Селектору `div` пропишите `margin: 0 auto 20px;`. Это незнакомое заклинание поместит `div` по центру по горизонтали и немного отодвинет описание вниз. Так как `div` — не текст, то `text-align` здесь не сработает.

Зато сработает для подписи под альбомом. Добавьте соответствующий `text-align` cелектору `p`.
