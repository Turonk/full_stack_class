# Прозрачность

Прозрачность важна не только когда дело касается выхода компании на IPO или коммуникации на работе, но и когда мы что-то верстаем.

Представьте, что между фоновым изображением и текстом стоит полупрозрачное стекло тёмного оттенка. Такой приём часто используют, чтобы усилить контраст и увеличить читаемость текста поверх изображения.

Аналог тёмного стекла в вебе — элемент с частично прозрачной заливкой цветом. Цвет можно сделать прозрачным, дополнив RGB-палитру альфа-каналом, который устанавливает прозрачность:

CSS

```
/* rgb без альфа-канала, просто цвет */
rgb(115 170 200);
/* rgb c альфа-каналом, цвет + прозрачность 50% */
rgb(115 170 200 / 0.5); 
```

Величина прозрачности меняется от `1` до `0`. Единица — это на 100% непрозрачное состояние, как закрашенное плотным однородным цветом оконное стекло. Ноль — это 0% цвета, как будто вы только что помыли окна (а дождя ещё не было).

Если голубому фону с цветом `rgb(8 130 255)` нужно увеличить прозрачность в пять раз, то мы напишем `rgb(8 130 255 / 0.2)`. Значение `0.2` сообщает браузеру, что у фона должно быть 20% цвета и 80% прозрачности.

![](https://pictures.s3.yandex.net:443/resources/Untitled_-_2022-12-29T182935.371_1672327782.png)

Десятичная дробь в CSS и во многих других языках пишется с точкой, а не с запятой, как в школьной тетради. Дробь можно писать без нуля.

CSS

```
/* один и тот же цвет */
rgb(115 170 200 / 0.5);
rgb(115 170 200 / .5); 
```

Чтобы опробовать прозрачность, внутри входной секции `header`, рядом с `h1`, создайте элемент `div`. В стилях определите для него размер `250px` на `250px` и белый фоновый цвет — `rgb(255 255 255)`.

Следующий шаг — белый квадрат станет туманным квадратом.

Задайте фону элемента `div` 30% цвета и 70% прозрачности.

Вместо `rgb(255 255 255)` укажите `rgb(255 255 255 / 0.3)` либо `rgb(255 255 255 / .3)`.

Спасибо альфа-каналу — теперь сквозь блок будет видно, что под ним.

А теперь переделайте цвет `#3fb` в rgb, потому что вам нужно сделать его полупрозрачным (50% цвета). Найдите любой конвертер из HEX в RGB, определите правильное значение цвета и добавьте ему прозрачность. Впишите сюда результат, используя полную запись вместе с названием функции `rgb` и показателем прозрачности, указанным через `/` (обратите внимание, что синтаксис функции rgb не предполагает использование запятых при указании прозрачности). Формат ответа: `rgb(000 000 000 / 0.0)`.
