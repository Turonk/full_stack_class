Тень — полезный инструмент дизайна. За её создание отвечает свойство `box-shadow`.

Свойство передаёт браузеру информацию о том, с какой стороны относительно элемента нарисовать тень, следует ли сделать её побольше или поменьше и какого она цвета. В коде это выглядит так:

CSS

```
div {
    box-shadow: -2px 2px 5px #FD6969;
  /* сдвинута на 2px влево, на 2px вниз */
  /* радиус размытия — 5px */
    /* цвет красноватый, #FD6969 */
} 
```

Последовательность значений, которые описывают тень:

*   горизонтальный сдвиг (отрицательное значение помещает тень левее элемента, положительное — правее);
*   вертикальный сдвиг (отрицательное значение помещает тень выше элемента, положительное — ниже);
*   радиус размытия (чем значение больше, тем тень шире и бледнее);
*   цвет (задаётся так же, как цвет текста или фона).

Иногда тень не нужно сдвигать, достаточно только размытия. В этом случае указывают, что первые два значения равны `0`.

![](https://pictures.s3.yandex.net:443/resources/18_1673888496.png)

Тень можно создавать не только для границ элемента, но и для текста. В этом случае используют свойство `text-shadow`. Оно работает аналогично.

Прежде чем добавлять карточкам тень, перекрасьте их границы и границы картинок в чёрный цвет `black`.

Посмотрите, как выглядят карточки — совсем простые, ничего, кроме содержимого. По виду и не скажешь, сколько кода за этим кроется.

Сделайте карточкам тень, которая выделит их на фоне страницы деликатнее, чем черный `border`. Элементам с классом `card` укажите тень со сдвигом вправо на `4px`, сдвигом вниз также на `4px`, размытием `0` и цветом `black`.

Без тени сомнения заявляем: то, что у вас получается, — действительно круто!
