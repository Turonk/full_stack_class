# Позиция, размер, повтор фона

Чаще всего для управления фоновым изображением хватает трёх свойств: `background-size`, `background-repeat` и `background-position`.

Размеры фонового изображения определяет `background-size`:

![](https://pictures.s3.yandex.net/resources/ft361background-size_1731525780.png)

CSS

```
/* cover (англ. «накрыть») сожмёт или растянет картинку */
/* так, чтобы занимала всю поверхность */
/* сохранит пропорции */
background-size: cover;

/* contain (англ. «содержать») сделает так, чтобы вся картинка уместилась */
/* сохранит пропорции */
background-size: contain;

/* можно указать размер в пикселях */
/* первое значение — ширина, второе — высота */
background-size: 220px 400px; 
```

Если картинка меньше блока, то по умолчанию она будет повторяться, чтобы заполнить всё пространство. Значение `background-repeat` может отменить повтор изображения.

![](https://pictures.s3.yandex.net:443/resources/Untitled_1_1710842548.png)

CSS

```
/* так отменяется повтор изображения */
background-repeat: no-repeat;

/* изображение повторяется только по вертикали */
background-repeat: repeat-y; 
```

Положением фона управляет `background-position`:

![](https://pictures.s3.yandex.net/resources/ft363background-position_1747318613.png)

CSS

```
/* по центру — сразу по горизонтали и по вертикали */
background-position: center;

/* по горизонтали к правому краю, по вертикали — к нижнему */
background-position: right bottom;

/* можно указать сдвиг в пикселях */
/* по горизонтали сдвиг на 150px вправо от левого верхнего угла блока */
/* по вертикали — на 50px вниз*/
background-position: 150px 50px; 
```

Достаточно экспериментов. Пора доработать изображение.
