# Классы

Теперь представьте: нужно не два, а десять разных `<div>`. Тогда CSS-селектор `div` навяжет полупрозрачный фиолетовый фон всем десяти.

На выручку приходят атрибуты `class`. Классы задают каждому элементу именной ярлык. Так, `<div class="card"></div>` позволит обращаться в стилях к конкретному элементу по селектору `.card`, не затрагивая свойства других элементов с тем же тегом.

Один и тот же класс можно присвоить любому количеству элементов. Например, класс `white-text` — всем элементам с текстом белого цвета.

HTML

```
<h1 class="white-text">Откуда к нам пришла зима</h1>
<p class="white-text">Не знаешь ты, никто не знает</p>
<!-- в HTML название класса указывается в кавычках атрибута class --> 
```

Текст будет белым, если в стилях прописано правило для класса:

CSS

```
.white-text { 
    color: #fff; 
} 
/* в стилях селектор класса начинается с точки */ 
```

Только элементы с классом `white-text` получат белый текст.

Имена классов пишут латиницей, без пробелов, начиная с букв, а не цифр или спецсимволов. Такой способ определения стилей надёжен и точен. В дальнейшем рекомендуем задавать стили для классов и свести к минимуму использование имён элементов в качестве селекторов.

В открывающий `<div>` внутри `<header>` добавьте атрибут `class` со значением `overlay`. Значение укажите в кавычках — двойных или одинарных, но одинаковых с обеих сторон.

Словом `overlay` в веб-разработке называют дополнительный слой поверх чего-то, в переводе с английского это «наложение» или «перекрытие». Теперь, когда элемент отмечен классом, можно адресовать стили только ему.

Во вкладке `styles/style.css` в правиле для `div` замените селектор на `.overlay` — не пропустите точку перед названием класса.

Теперь для `<div>` внутри `<section>` не определено ни одного свойства.

Да и не только для него: селектора `div` в `style.css` больше нет. Каждому блоку предстоит получить свой стиль.

Задайте класс `card` тому `<div>`, который задуман как карточка с правилами веб-дизайна. Тогда этот блок станет карточкой и по названию.

Открывающему тегу `<div>` внутри `<section>` добавьте атрибут `class` со значением `card`.

Имена классов пишут латиницей. Лучше, если имя передаёт смысл блока — так легче понять, к чему вы обращаетесь. Если `card`, значит, к карточке.

Во вкладке `styles/style.css` создайте правило для всех карточек. Пусть они будут шириной `360px`, с бледно-синим фоном для «подсветки» — `#e3f3ff`.

Создайте правило с селектором `.card` и свойствами: для ширины — `width: 360px`, для фона — `background-color: #e3f3ff`.

Классы вы будете писать везде и всегда. Проскролльте вниз — карточка обрела очертания и площадь.
