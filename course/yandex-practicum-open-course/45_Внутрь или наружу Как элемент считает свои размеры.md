# Внутрь или наружу? Как элемент считает свои размеры

Ранее вы указали ширину `350px` для карточки — как на макете. Но после манипуляций с внутренними отступами и границей, которые увеличили элемент, его ширина уже не та.

Чтобы не считать вручную, воспользуемся свойством `box-sizing` — оно определяет поведение границ и внутренних отступов. По умолчанию для всех элементов действует правило `box-sizing: content-box`, границы и внутренний отступ расширяют элемент. Многие корифеи интернета жалуются, что выбрать именно такое поведение по умолчанию было ошибкой. Но что сделано, то сделано, приходится с этим жить.

Установив для `box-sizing` значение `border-box`, вы измените способ расчёта размеров элемента: границы и внутренние отступы отрисуются внутрь. Общая ширина будет равна значению `width`. Довольно интуитивное поведение, поэтому нормальная практика — задать значение `box-sizing` сразу для всех элементов на странице.

![](https://pictures.s3.yandex.net:443/resources/Untitled_12_1672406950.png)

Чтобы задать правило не только для `.card` и не прописывать `box-sizing` вручную для всех элементов, познакомьтесь с универсальным селектором `*`. Он передаёт свойства напрямую каждому элементу на странице. Так как `*` — очень общий селектор, его нужно задавать в самом начале CSS.

Перед сбросом стилей для `body, h1, h2, h3, h4, p` создайте CSS-правило для селектора `*`.

Такой селектор устанавливает законы, а законы для всех одинаковые. Не злоупотребляйте этим, поскольку элементов много, браузеру придётся работать с каждым из них. Правоприменение — штука дорогая.

Измените принцип расчёта размеров всех элементов — в том числе карточек — на внутренний. Для селектора `*` укажите `box-sizing` с нужным значением.

С новыми знаниями вы вернули карточки к былым размерам. Все элементы сфокусировались внутри границ.

Какое значение у `box-sizing` по умолчанию?

`content-box`

`border-box`

`none`
