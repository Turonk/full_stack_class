Личные?

Это тоже важно, но сначала разберёмся с границами элементов. Они находятся между `margin` и `padding`. В стилях границы определяют свойствами группы `border`:

CSS

```
border-color: #000; /* цвет границы */
border-width: 1px; /* толщина границы в px */
border-style: solid; /* начертание границы (см. картинку) */ 
```

![](https://pictures.s3.yandex.net:443/resources/Untitled_11_1672392420.png)

Опять же — вместо написания трёх свойств по отдельности, разработчики применяют краткую форму. Значения `width`, `style` и `color` указывают внутри одного короткого свойства (шортката) через пробел:

CSS

```
/* непрерывная граница чёрного цвета толщиной 3px */
border: 3px solid #000; 
```

Посмотрите, как работает граница элемента. Задайте классу `card` и классу `card-image` границу-пунктир со значением `dashed` и толщиной `5px`. Цвет границы пусть будет `rgb(250 50 50 / .4)` — заодно вспомните про альфа-канал.

Пунктирная граница прозрачного ярко-красного цвета толщиной `5px` — всё, как вы задали. Кстати, граница тоже увеличивает элемент, он стал больше на пять пикселей с каждой стороны.

Пунктирные границы в дизайне используют редко, тем более такого цвета. Сделайте границы менее вычурными: поменяйте начертание на `solid`, а толщину сократите до одного пикселя.

Если ваш внутренний колорист переживает за сочетания цветов, можете его успокоить — позже вы уберёте и цвет фона, и цвет границы. Пока вы учитесь новому, они напоминают вам, как устроен элемент.
