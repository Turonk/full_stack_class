Неправильный ответ

`font-family`

`font-style`

Какой тег надо переставить, чтобы ссылка оказалась внутри абзаца?

HTML

```
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>The Life of Coder</title>
</head>
<body>
  <h1>The Life of</h1>
    <h2>Coder</h2>
        <a href="https://www.noisli.com" target="_blank"><p>Плейлист</a> 
        для беспечного занятия кодингом. Один раз послушал — семь раз покодил.
        </p>
</body>
</html> 
```

`<h1>`

`</a>`

Правильный ответ

`<p>`

Точно! Открывающий тег абзаца почему-то попал внутрь ссылки, хотя должен быть перед ней.

`</body>`

`</p>`
