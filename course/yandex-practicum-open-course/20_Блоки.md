Тогда приступим. В этом уроке поговорим про блоки.

Веб-страница и внешне, и технически, в коде, делится на блоки из HTML-элементов. Например, каждая карточка на сайте про Блока (который поэт) — это единый блок. Он состоит из картинки, названия раздела, заголовка, даты и текста.

![](https://pictures.s3.yandex.net/resources/PRACTICUMFB-10619_1731525580.png)

Чтобы объединить сразу несколько HTML-элементов в один общий блок, в коде их нужно отделить от остального контента. Это делает универсальный строительный элемент `<div>`.

Любой элемент с открывающим и закрывающим тегами в HTML устроен как коробка. Особое предназначение `<div>` — быть абстрактной пустой коробкой, куда можно положить что-то ещё. Без содержимого и стилей для `<div>` пользователь может даже не увидеть его физически.

HTML

```
<!-- родительский элемент -->
<div>
      <!-- дочерние элементы -->
      <h2>Дом стоит, свет горит.</h2>
      <p>Из окна видна даль.</p>
</div> 
```

Как дом из кирпичей, страница складывается из блоков. Элемент `<div>` эти блоки создаёт и позволяет CSS управлять сразу всем набором элементов, которые оказались между `<div>` и `</div>`.

Вкладывая один элемент внутрь другого, смещайте вложенные элементы на два пробела вправо (или клавишей Tab). Когда кода станет намного больше, вы заметите разницу: читать код с такой разметкой намного проще, а исправлять — быстрее.

![](https://pictures.s3.yandex.net:443/resources/Untitled_99_1672324347.png)

Наша задача — создать квадратную форму и цветную основу для обложки. Нужно поместить в неё написанные элементы, задать размеры «коробки» и цвет фона.

То, что находится между `<body>` и `</body>`, скопируйте и удалите из кода. Создайте на этом месте элемент `<div>` и вложите в него всё скопированное. В идеале — не забудьте про отступ.

Ничего не изменилось. Без дополнительных стилей `<div>` незаметен: это невидимая коробка и всё.

Скоро вы увидите этот мистический `<div>`.

В файле `style.css` задайте элементу `<div>` фоновый цвет. За это отвечает свойство `background-color`. В качестве значения предлагаем `deepskyblue`.

Чтобы увидеть реакцию, химики добавляют в колбу вещества-индикаторы. В CSS работу селектора обнаружить проще: добавьте в правило цвет фона.

Продолжим?

По умолчанию `<div>` занимает всю ширину своего родителя — `<body>`. Поэтому цвет заполнил всю горизонталь (кроме краёв, там какие-то отступы). Не слишком похоже на обложку плейлиста.

Имеет смысл ограничить размеры блока. Сделайте из элемента квадрат `500` на `500` пикселей, задав CSS-свойства `width` и `height`.
