## Урок 17: Циклы

В теле цикла команду `console.log` замените командой `smoothly`. Причём эта команда должна помещать в DOM-элемент `phrase` текст из элемента массива с индексом `i`.

Напомним, функция `smoothly` принимает три аргумента, поэтому внутри цикла нужно написать так:

Скопировать код

JAVASCRIPT

```
smoothly(phrase, 'textContent', /* здесь текст из элемента по индексу i */; 
```
