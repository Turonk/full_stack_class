# Связь CSS и HTML. Тег <style>

Зоны ответственности HTML и CSS надо научиться разделять. Стили можно задавать как в самом HTML-документе, так и в отдельном файле.

В первом случае внутри элемента `<head></head>` создаётся элемент `<style>`. Пространство между тегами `<style></style>` — это зона языка CSS.

![](https://pictures.s3.yandex.net:443/resources/PWD-138-10_1713254619.png)

Не размещайте `<style>` внутри элемента `<body>`, держите его в `<head>`. Стиль — это закон для всей веб-страницы, а законы должны быть в голове.

Наша задача — перенести инлайновые стили в `<head>`. После добавления фавикон-картинки и перед закрывающим тегом `</head>` создайте элемент `<style>`.

Перед закрывающим тегом `</head>` вставьте теги `<style> </style>` .

Вы создали зону стилей там, где принято, — в самом конце компонента `head`. Это делают, чтобы стили бросались в глаза.

Между тегами элемента `<style>` создайте пустую строчку:

HTML

```
<head>
    <!-- заголовок, фавикон, метаданные -->
    <style>

    </style>
</head> 
```

Затем между тегами `<style> </style>` напишите селектор `h1` и комплект фигурных скобок:

Браузер видит в зоне `<style>` правило для заголовков первого уровня. Но пока там пусто, он берёт CSS-свойства из тега `<h1>` в компоненте `<body>`. Туда вы сейчас и отправитесь.

Перенесите содержимое атрибута `style` из открывающего тега `<h1>` в созданное вами пустующее правило. Разместите свойства между фигурными скобками, каждое — на отдельной строке. Покажем на примере первого свойства:

HTML

```
<head>
    <!-- заголовок, фавикон, метаданные -->
    <style>
        h1 {
            font-size: 31px;
            <!-- остальные свойства из атрибута style тега h1 перенесите сами -->
        }
  </style>
</head> 
```

Когда закончите переносить все свойства, не забудьте убрать атрибут `style` со всеми свойствами из тега `<h1>`:

Ваше первое правило готово! Стили заголовка — как на ладони.

Проделайте всё то же самое для элемента `<h2>`: пусть его стили тоже задаёт правило.

В зоне `<style>` компонента `<head>` напишите селектор `h2`. В фигурные скобки этого правила перенесите свойства инлайновых стилей из тега `<h2>`. Потом удалите атрибут `style` из тега элемента `<h2>` вместе со всеми инлайновыми стилями (или с тем, что от них осталось).

Вы создали первую таблицу стилей — так называется набор правил CSS. Можно вообще убрать стили из тела страницы и вынести их в отдельный файл. Этим и займёмся.
