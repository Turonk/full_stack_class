# Наследование

Мы уже говорили о запутанных семейных связях. Теперь пора разобраться в них получше. Ведь стиль родительских элементов оказывает влияние на стиль дочерних.

HTML

```
<!-- родительский -->
<div>
    <!-- дочерний -->
  <p>Задача веб-дизайна — сделать не только красиво.</p>
</div> 
```

Например, если абзацу `p` не задан конкретный размер шрифта, цвет текста или выравнивание, абзац будет «прислушиваться» к родителю, то есть к стилю элемента `div`.

И если для `div` определить свойство `font-size: 40px`, высота символов во вложенном элементе `p` тоже станет `40px`. Установите для `div` выравнивание по центру `text-align: center` — и текст абзаца `p` выровняется по центру.

Это называется наследованием и работает с большинством CSS-свойств. Например, цвет, шрифт, размер текста — наследуемые свойства. Они применяются ко всем вложенным элементам. Но если дочернему элементу установить собственное конкретное значение, то свойство наследоваться не будет.

Проверьте, что наследование работает. Задайте для `header` выравнивание текста по центру.

Теперь дочерний элемент `h1` имеет одновременно и родительский стиль (выравнивание по центру), и свой собственный (белый текст и размер шрифта `74px`).

Странице нужно задать новый шрифт. Чтобы не писать свойства для каждого элемента по отдельности, можно сказать что-то сразу всему документу. Для этого обращаются к элементу `body`, ведь он — корневой родительский элемент для всех видимых элементов на HTML-странице.

Сразу после правила для `body, h1` найдите селектор `body` и присвойте ему свойство `font-family: 'Open Sans', 'Arial', sans-serif`.

Оно задаст всей странице шрифт `Open Sans`. Если такого шрифта нет на устройстве пользователя, браузер попробует использовать `Arial`. Если нет и `Arial` — браузер задействует системный шрифт без засечек.

Дочерние элементы безропотно заимствуют родительский стиль, пока не обзаведутся собственными правилами.

Элемент `body` — главный родитель на веб-странице. Не пишите лишнего в правилах для него (и держите их повыше в коде, сразу после сброса и обнуления стилей браузера).

Предположим, вы хотите поменять шрифт в заголовке и выровнять его по центру. Ваши действия?

`font-family: 'название шрифта', 'Arial', sans-serif`; `margin: auto`

`font-family: 'название шрифта', 'Arial', sans-serif`; `text-align: center`

`font-family: 'название шрифта'`; `text-align: left`
