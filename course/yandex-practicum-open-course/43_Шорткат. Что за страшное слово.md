# Шорткат. Что за страшное слово?

С урока кройки и шитья перенесёмся на урок английского. Есть более короткий и быстрый способ установить отступы для одного элемента с разных сторон. CSS позволяет записывать свойство в одну строку без уточнений стороны — такое свойство называется шорткат.

![](https://pictures.s3.yandex.net:443/resources/Untitled_10_1672392227.png)

CSS

```
/* направление расстановки — по часовой стрелке, начиная сверху */

/* 4 значения */
/* для каждой стороны – своё значение */
padding: 20px 15px 30px 15px;

/* 3 значения */
/* верх — 10px, по бокам — 20px, низ — 30px */
padding: 10px 20px 30px;

/* 2 значения */
/* верх и низ — 10px, по бокам — 20px */
padding: 10px 20px;

/* 1 значение */
/* 10px со всех сторон */
padding: 10px; 
```

Работает как для `margin`, так и для `padding`.

Вместо четырёх строк кода в правиле для селектора `.card` напишите одну так, чтобы сохранить внутренние отступы.

Изящное решение — задействовать три значения `padding: 25px 25px 30px`. Если чувствуете дискомфорт (это нормально), выбирайте самый простой и понятный способ — перечисление размеров для каждой стороны: `padding: 25px 25px 30px 25px`.

Результат тот же, но в четыре раза короче.

Краткость решения подчёркивает его красоту. Сокращайте и оптимизируйте повторяющийся код.
