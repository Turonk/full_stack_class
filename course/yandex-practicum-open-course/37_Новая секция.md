# Новая секция

Вы уже реализовали входную секцию сайта с помощью возможностей CSS: фона, цвета, размеров, свойств шрифтов и текстов. В этой теме вы доделаете сайт и узнаете ещё больше правил и трюков.

Ближайший шаг — сразу после входного экрана создать секцию с основным контентом сайта. Туда попадут карточки с правилами дизайна, которые актуальны и для разработчиков.

Схема сайта станет такой:

![](https://pictures.s3.yandex.net:443/resources/Untitled_6_1672390250.png)

Начнём с контейнера для карточек: заодно узнаете новый элемент `<section>`.

Рекомендуем почаще переключаться в режим просмотра — для этого есть кнопки «результат» и «в новой вкладке».

Для создания секций и разделов применяют элемент `<section>`. Он ведёт себя как `<div>`, но сразу сообщает браузеру о своём предназначении — так поисковики качественнее прочитают сайт.

После тега `<header>` добавьте новый пустой раздел с помощью парного тега `<section>`: сначала напишите `<section>`, затем — `</section>`. Не вставляйте туда никакой текст или другие элементы.

Контейнер для подзаголовка и карточек создан. Пока его не видно, потому что внутри нет никакого контента.

Сделайте карточку — контейнер `<div>`, куда вы положите изображение, подзаголовок и текст. Создайте его внутри `<section></section>`.

Да, но каркас секции и карточки уже создан. Их не видно, потому что внутри пока пусто.

Напишите заголовок карточки и описание. Заголовком сделайте `<h3>` с содержимым `Пустота`; ниже поместите текст `Простое правило, которое часто нарушают: ставить рядом элементы с похожим смыслом и окружать их пустым пространством. Пустота — мощное средство воздействия.` в абзац `<p>`_._ Всё это должно происходить внутри элемента `<div>`.

Текстовое содержимое карточки здесь. В смысле, под входной секцией — скролльте туда.

Откуда там фиолетовый фон? Что происходит? 🧐

Всё логично.

Ранее внутри `<header>` вы поставили `<div>` как полупрозрачное стекло между текстом и изображением. Написали для него правила в `styles.css` — они действуют для всех `<div>` на странице.

Карточка — ещё один `<div>`. Элемент `<section>` получил размеры из-за вложенного текста, `<div>` забрал размеры `<section>` и получил цвет фона. Это не ошибка, всё в порядке.

Что нужно сделать, чтобы сайт стал похож на референс, расскажем в следующем уроке.

Назовите ещё один аналог `<div>`, который можно применять везде, а не только в шапке.
