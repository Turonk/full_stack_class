# Типографика

С фоном, цветами и даже c тонированными окнами разобрались. Теперь перейдём к тому, что на этом фоне находится.

Текст имеет много настроек, в CSS их можно разбить на две группы. За сам шрифт отвечает группа `font`, за поведение текстовых элементов — группа `text`. За оформление шрифта и текста в графическом дизайне отвечает отдельная область — типографика.

Из группы `font` популярны такие свойства:

CSS

```
font-size /* размер шрифта */ 
font-weight /* «вес» шрифта, толщина (отношение ширины штриха к высоте буквы) */ 
font-family /* семейство шрифта */ 
font-style /* стиль шрифта, например, italic — курсивный шрифт */ 
```

Из группы `text` вам знакомо свойство `text-align` — выравнивание. Часто используют правило `text-decoration: underline` (подчёркнутый текст) или `text-decoration: none` (убирает подчёркивание; например, заданное по умолчанию для ссылок). Регистром букв управляет `text-transform`.

![](https://pictures.s3.yandex.net:443/resources/Untitled_-_2023-07-12T185300.037_1689177252.png)

Ещё для текста можно установить высоту строки свойством `line-height` — это называется интерлиньяж. Свойство `letter-spacing` определяет расстояние между символами в тексте.

Переведите заголовок в верхний регистр, применив свойство `text-transform`.

В правило для элемента `h1` добавьте выражение `text-transform: uppercase`.

Это очень удобно. Для посетителей сайта визуально вы трансформируете буквы, но для поисковиков предпочтительна обычная форма текста, которую они и видят между `<h1>` и `</h1>`.

Толщину шрифта можно указывать словами, например, `bold` или `normal`. Более точная настройка осуществляется числами, вернее, сотнями в диапазоне от `100` (очень тонкое начертание) до `900` (ультрамассивное начертание).

Присвойте заголовку `font-weight` значение `800`, чтобы получить начертание шире, чем `bold`.

Теперь вы отлично умеете настраивать ширину шрифта. Кстати, если у шрифта всего два или три начертания, для них не будет иметь значения, что вы указали в коде — `100` или `200`.

Отодвиньте заголовок от верхнего края, задав для `h1` отступ свойством `padding-top` со значением `270px`.

Входной экран готов, вы неплохо потрудились! Дальше будет ещё интереснее!

Как стилизовать текст ниже? Обратите внимание, что текст всегда должен быть с маленькой буквы.
