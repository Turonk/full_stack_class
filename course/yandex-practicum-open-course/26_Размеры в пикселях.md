# Размеры в пикселях

Видели макет?

Да, одной интуицией уже не обойтись. Предстоит разобраться в фундаментальных вопросах, первый из которых — размеры.

Вы уже встречались с ними, когда верстали обложку плейлиста. Чаще всего размеры даются в фиксированной величине — в пикселях. Например, `200px`.

Слово «пиксель_»_ (pixel) возникло в 1965 году, когда межпланетные станции начали передавать фотографии поверхности Марса и Луны по одной точке. Самый маленький неделимый элемент изображения надо было как-то назвать. Остановились на комбинации pix и el.

Теперь так называют самые маленькие точки экрана, для которых можно установить цвет и силу свечения. Сочетание этих точек создает итоговое изображение. Пиксель обозначается буквами `px`. Между числом и единицами измерения пробел не ставится.

Отличный настрой!

В файле `index.html` создана базовая структура и подключён файл стилей. Ваша задача — создать прототип входного экрана страницы о четырёх правилах вёрстки. Между тегами `<body>` добавьте парный тег `<header>`.

Он ведёт себя так же, как и `<div>`, но браузеру, поисковым системам и скринридерам по такому названию проще понять, где находится входная секция сайта.

Да, всё в порядке. Мы пока создаём _коробки_, но ещё не написали контент, который можно увидеть.

В HTML несколько десятков элементов, знать наизусть и использовать их все необязательно. Самые полезные будем постепенно вводить в употребление.

Элемент для входного экрана создан — надо что-то сделать с его размером. В файле `styles.css` сделайте `header` прямоугольником размерами `width: 500px;` и `height: 500px;`.

Помните, что нужно расположить нужные свойства внутри фигурных скобок.

CSS

```
header {
    /* каждое свойство должно быть на отдельной строке */
} 
```

Указание размеров — первый шаг к визуальному воплощению элемента. Элемент уже есть, хоть и бесцветный.

Кстати, по числу пикселей первая телевизионная картинка обратной стороны Луны превосходила ваш прямоугольник всего лишь в 4 раза.

Чтобы `header` стал заметен, задайте ему цвет фона `forestgreen`.

Помните, какое свойство отвечает за фоновый цвет?

Это свойство `background-color`. Впишите его ниже свойств ширины и высоты.

Получилось. Цветовой фон понадобится в процессе разработки, чтобы видеть сам элемент.

Размеры работают не только для высоты и ширины. В `<header>` вложите заголовок первого уровня (это `<h1>`, если вдруг забыли) с текстом `Четыре правила вёрстки`. В файле `styles.css` напишите CSS-правило для `h1`, задайте размер шрифта `74px`.

Запомните этот авангард. Скоро CSS изменит его до неузнаваемости.

Каким тегом лучше задавать «шапку» для сайта?

<h1>

<div>

<header>
