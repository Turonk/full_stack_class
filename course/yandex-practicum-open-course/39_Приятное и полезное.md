# Приятное и полезное

Сейчас после каждого обновления результата нужно проскроллить `<header>`, чтобы увидеть изменения. Это отвлекает, раздражает и усложняет восприятие. Вот бы этот `<header>` убрать на время, но не удалять.

Андрей

А так можно было?

Можно. Комментарии в коде нужны не только для информативных заметок, но и чтобы временно отключить строки кода, не удаляя их. В каждом языке комментарии оформляются по-своему.

HTML

```
<!-- в HTML-коде комментарий окружён такими символами -->
<!-- <p>невидимый пользователю абзац</p> --> 
```

CSS

```
/* в CSS — такими */
/* p {
    color: white;
} */ 
```

Браузер игнорирует комментарии и не отрисовывает то, что в них написано.

Используйте новое знание во благо. Прямо перед `<header>` напишите `<!--`, а сразу после — `-->`. Входной экран будет «закомментирован» в коде, и браузер перестанет отрисовывать его.
