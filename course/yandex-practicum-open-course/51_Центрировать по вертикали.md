# Центрировать по вертикали

Вы уже сталкивались с такой задачей, когда нужно было центрировать надпись «Четыре правила вёрстки» по вертикали. Тогда вам пришлось устанавливать внутренний отступ в пикселях, чтобы подвинуть текст в нужное место.

Способ простой, но работает не всегда. Значение `100px` на маленьком устройстве — это уже треть экрана, а на большом мониторе — почти незаметно. Поэтому не подгоняйте пиксели только под ваш экран, подумайте о посетителях сайта.

Но неужели сегодня, когда учёные уже всерьёз планируют полёт на Марс, в вебе до сих пор нет способа автоматически поставить элемент по центру?

Способ есть. Для уже изученного свойства `display`, помимо `block`, `inline` и `inline-block`, есть особое значение `flex`:

CSS

```
display: flex;
/* *flex* переводится как «гибкий» */ 
```

Элемент с таким свойством становится флекс-контейнером и — как супергерой — получает сверхспособности. Например, внутри него `margin: auto` работает не только по горизонтали! Невероятно, но это так. Чтобы запомнить, решите задачу центрирования для подвала.

![](https://pictures.s3.yandex.net:443/resources/Untitled_15_1672409086.png)

CSS

```
/* PS >
О полном спектре возможностей *flex* мы рассказываем в платной части профессии. */ 
```

Чтобы поставить текст об авторстве по центру подвала, элемент с классом `footer` сделайте флекс-контейнером. После этого селектору `.footer-author` добавьте свойство `margin: auto` — оно разместит текст по центру обеих осей родительского элемента.

Такая комбинация входит в золотую коллекцию веб-разработчиков, поскольку автоматически размещает элемент по центру родительского. Стройное решение без лишних подсчётов и ухищрений.

Чтобы применить это решение и для шапки, и убрать прежний способ центрирования, удалите символы, которые превращают код элемента `<header>` в комментарий.

Раскомментировать — так разработчики называют действие, обратное комментированию.

При небольшой ширине окна что-то может не вмещаться и отображаться некорректно, поэтому обязательно взгляните на сайт в режиме просмотра — он впервые показан полностью, со всеми секциями.

Элемент `overlay` сделайте флекс-контейнером. В свойствах для селектора `h1` пропишите `margin: auto` взамен `padding-top`.

Теперь и главный заголовок оказался по центру — вне зависимости от размеров экрана пользователя, можно выводить даже на табло в аэропорту.

Страница выглядит профессионально, а вот код ещё не вполне. Он станет красивее, если вы избавитесь от обращения к селекторам `header` и `h1` и будете обращаться к классам.

Элементу `<header>` присвойте одноимённый класс `header`, элементу `<h1>` — класс `header-title`. В селекторах замените обращения по названию элемента на обращения к его классу.

Ничего не должно поменяться, кроме красоты и стройности кода. Порядок вовне начинается с порядка внутри.

Перед тем как сдавать страницу, давайте ещё раз взглянем на неё внимательно — всё ли ок?

Что задать блоку, чтобы поставить его по центру не только по горизонтали, но и по вертикали?

`display: block`, `margin: 0 auto`

`display: flex`, `margin: auto`

`display: flex`, `margin: 0 auto`
