# Один тег в другом. Родители и дети

В элементы можно вкладывать не только текст, но и другие элементы. Элемент, который лежит внутри, называется дочерним. Тот, в который вложен дочерний, называется родительским.

Тогда познакомимся с одной из фич платформы, которая вам сильно поможет в обучении. И это — поиск. В основном курсе мы часто будем ссылаться на какую-то информацию или говорить, что что-то мы рассмотрим подробнее позже, поэтому полезно научиться находить нужные термины или код. Например так:

Поиск работает по всему тексту: названиям тем, урокам, заданиям. Искать в тексте гораздо удобнее, чем искать нужный кусок видео, поэтому мы пишем уроки, а не записываем на камеру. Причём, поиск работает не только для пройденных тем, но и для предстоящих уроков. Например, вы можете посмотреть, как часто вам будет встречаться новый термин. Слова можно вводить с ошибками и опечатками, поиск вас поймёт.

В нашем случае тег `<p>` является родительским по отношению к тегу `<a>`. А тег `<a>` будет дочерним для тега `<p>`.

Окей, распутаем эти семейные связи

Важно уметь правильно вкладывать теги друг в друга. Тут есть несложное правило: дочерний элемент всегда должен завершаться раньше, чем родительский.

Посмотрим на примере. На музыкальных фестивалях обычно выступает несколько групп (будем честны, все приходят ради последней — хедлайнера). Их выступления проходят в один день. То есть «фестиваль» окружает «хедлайнеров» примерно так: `<фестиваль> <выступление> </выступление> </фестиваль>`.

Бывают музыкальные фестивали, которые длятся несколько дней. В этом случае процесс выглядит так:

HTML

```
<фестиваль> 
    <день-1> </день-1> 
    <перерыв> </перерыв>
    <день-2> </день-2>
</фестиваль> 
```

Так и в HTML: у одного родительского элемента бывает несколько дочерних. Важно, чтобы открывающий тег родителя шёл раньше всех, а закрывающий — после всех тегов дочерних элементов.

Перед тем как снова пойти верстать, выберите вариант, в котором соблюдены правила вложенности:

HTML

```
<p><a href="https://arcticmonkeys.com"></p></a> 
``` 

HTML

```
</p></h1><h1><p> 
``` 

Правильный ответ

HTML

```
<p>
    <a href="https://kraftwerk.com">Афиша группы</a>
    <a href="https://arcticmonkeys.com">Ещё афиша группы</a>
</p> 
``` 

Всё верно! Тут разметка правильная. Внутри абзаца вложена ссылка, а за ней ещё одна ссылка.
