## Урок 14: Объекты

Кроме фраз, на сайте должны меняться картинки. Вот первая из них:

Скопировать код

```
https://code.s3.yandex.net/web-code/procrastinate/1.gif 
```

Чтобы было ясно, к какой фразе она относится, картинку и текст лучше хранить вместе в объекте следующего вида:

Скопировать код

JAVASCRIPT

```
{ text: 'отправить другу смешную гифку', image: 'https://code.s3.yandex.net/web-code/procrastinate/1.gif' } 
```

Подставьте этот объект взамен `'отправить другу смешную гифку'` . Так первый элемент массива `phrases` превратится в объект.
