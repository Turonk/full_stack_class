## Урок 5: Математика ниже плинтуса

Всё работает, но есть нюанс. Если копирайтер пришлёт больше вариантов, код по-прежнему будет выбирать только среди первых 6 элементов. Придётся руками лезть в скрипт и править длину массива.

Джаваскрипт может лучше. Будем умножать не на конкретное число `6`, а на длину массива. В этом случае, если в массиве окажется больше вариантов, то его длина тоже увеличится и код останется актуальным. Здесь у массива есть свойство `length`, оно хранит его длину. Чтобы её получить, нужно написать имя массива, поставить точку и написать `length`:

Скопировать код

JAVASCRIPT

```
console.log(aliExpress.length) // покажет длину массива 
```

Замените цифру `6` в коде на длину массива `phrases`.
