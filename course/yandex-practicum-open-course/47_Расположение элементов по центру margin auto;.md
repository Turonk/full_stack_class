# Расположение элементов по центру: margin: auto;

Секция, в которую завёрнуты карточки, ведёт себя как блочный элемент, занимает всю родительскую ширину. А теперь проведём мысленный эксперимент: как бы вы разместили карточки посередине экрана?

Свойство `text-align` не поможет: оно действует только на текст. Можно на глаз задать количество пикселей для `margin-left` первой карточки, пока правила не окажутся в центре. Но такой способ сработает только на вашем компьютере, а для экрана другого размера потребуется другое число пикселей.

С центрированием блочных элементов работает особое значение `auto`. Оно автоматически устанавливает максимально возможный отступ по горизонтали. Если задать свойствам `margin-left` и `margin-right` значение `auto`, получатся максимальные отступы с обеих сторон и элемент встанет по центру своего родителя.

![](https://pictures.s3.yandex.net:443/resources/Untitled_14_1672407993.png)

Сдвигать карточки в центр вы будете не по отдельности, а вместе с родителем. Подсветите его, чтобы наблюдать изменения — укажите для класса `content` фоновый цвет со значением `#8aafcf`.

Теперь вы можете увидеть подлинные размеры элемента `<section>`. Так как этот сайт вы делаете для больших экранов, полезно взглянуть на него в полноэкранном режиме.

Пока `<section>` с классом `content` упирается в края экрана, центрировать его не получится. Сократите ширину элемента до `770px`.

Контейнер принял заданную ширину. Если окно просмотра по ширине меньше `770px`, появится горизонтальный скролл — чтобы пользователи могли посмотреть на всю секцию с карточками, которые стоят в одном ряду. В этом случае увеличьте окно нажатием кнопки в правом верхнем углу или передвиньте границы окна.

При ширине окна просмотра более `770px` правее секции с классом `content` появляется свободное от цвета пространство.

Поставьте элемент `<section>` в центр экрана, задайте ему внешний отступ со значением `auto` слева и справа. Сделайте это всего одним свойством, отступам сверху и снизу можно указать значение `0`.

Значение `auto` задало максимально возможный размер правого и левого полей. Результат — равновесие: блок встаёт по центру и никуда оттуда не денется на любом экране шире, чем сама секция.

Секция по ширине равна `770px`, две карточки внутри — это `720px`. Остаётся `50px` свободного пространства, место которому — между карточками.

Классу `card` укажите внешний отступ справа размером `50px`.

Дааа, карточки с правилами вновь попали на разные строки.

Обе карточки имеют одинаковый класс и отступы по `50px`, но второй карточке не хватило места. Пора узнать, как задавать элементу больше одного класса, чтобы обратиться только ко второй карточке и обнулить её правое поле. Поговорим об этом в следующем уроке!
