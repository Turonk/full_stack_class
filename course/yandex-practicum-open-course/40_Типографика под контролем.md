# Типографика под контролем

Отступы вокруг заголовка карточки вы не заказывали. Браузер установил их без вашего ведома.

Верстальщики должны контролировать поведение элементов. Так что в этом уроке мы сбросим все «заводские настройки» браузера, а затем зададим стили для текстов внутри карточек.

Уберите заданные по умолчанию отступы и размеры. Скоро вы создадите их самостоятельно, без базовых настроек браузера.

Сбросьте всё сразу для нескольких элементов. В селектор `body, h1` через запятую добавьте `h2, h3, h4, p`.

Отступ сброшен, надо сбросить и размеры шрифта.

Для этого воспользуйтесь комбинацией `font-size: 100%; font-weight: normal`. Первое свойство установит единый размер шрифта для всех элементов. Второе — задаст толщину шрифта со значением `normal`.

Добавьте свойства в селектор с запятыми, чтобы применить сброс сразу ко всем указанным элементам.

Вы отсекли лишнее. Разница размеров и толщины шрифта обнулена, внешние отступы сброшены — остался чистый холст.

Это полезно делать в самом начале работы. Теперь переходите к самостоятельной настройке.

Чтобы адресно задавать изменения подзаголовку и тексту, элементу `<h3>` присвойте класс `card-title`, абзацу `<p>` — класс `card-text`.

Задав разные классы, можно задавать и разные стили.

Сделайте текст на карточке таким же, как в макете. Для селектора класса `.card-title` задайте размер шрифта `31px`, толщину шрифта `800`, переведите заголовок в верхний регистр, применив свойство `text-transform`, и выровняйте текст по центру с помощью `text-align`. Элементу с классом `card-text` укажите размер шрифта `18px`.

Насладитесь результатом и ещё раз внимательно просмотрите код 😊
