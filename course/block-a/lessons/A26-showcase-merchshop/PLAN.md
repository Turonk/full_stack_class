# Урок 26 · Showcase MerchShop

Паспорт защиты. Проект: [MerchShop](../../projects/05-merchshop/PROJECT.md). После [CSS-оформление](../A25-shop-css/PLAN.md).

- Группа ≤10 · 120 минут
- Это не новый концепт. Это публичная проверка цепочки «каталог → корзина → заказ → polish».

## Результат

Каждый ученик запустил сервер и за ≤6 минут показал: каталог, корзину, заказ, CSS. Сосед по рубрике отмечает зачёт или дыру.

## Тайминг

| Мин | Фаза | Действие |
| --- | --- | --- |
| 0–10 | Правила | Порядок из 6 шагов и рубрика |
| 10–70 | Питчи | ≤6 мин × ученик |
| 70–90 | Ревью | Пара проходит чек-лист |
| 90–110 | Правка | Только провал зачёта |
| 110–120 | Закрытие | Мост: завтра склейка Hub + Shop |

## Порядок одного питча

1. Открыть `/shop` — каталог товаров.
2. Добавить 2 товара в корзину.
3. Перейти на `/cart` — таблица, сумма, удаление.
4. Оформить заказ — flash-подтверждение.
5. Показать Hub-маршруты (`/game`) — по-прежнему работают.
6. Открыть `/fake` — свой 404.

## Рубрика

| Критерий | Не зачёт | Зачёт | Сильно |
| --- | --- | --- | --- |
| Корзина | Не добавляется | Товары в `session`, сумма считается | Может добавить qty |
| Форма | Не валидируется | Пустое имя → ошибка | Красивые сообщения |
| Связь с Hub | Два проекта | Один `app.py` | Единый `base.html` |
| Авторство | Тексты стенда | Свои товары, цены | Рассказывает архитектуру |
