# Схема демо (4 шага)
1. Экран целиком — что за хаб
2. Прогон ширин **360 → 720 → 1200**
3. `:root` — смена акцента одной строкой вживую
4. Один приём спринта своими словами (10–20 строк)

Живой UI: hover · Tab · пульс. Баг — назвать самому.
