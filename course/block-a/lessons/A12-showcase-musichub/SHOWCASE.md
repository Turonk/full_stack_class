# Showcase A12 · MusicHub

Продукт: [`../../projects/02-musichub/etalon/`](../../projects/02-musichub/etalon/)

## Обязательные кадры демо

1. Прогон ширин: **360px → 720px → 1200px** — сетка перестраивается, горизонтального скролла нет.
2. Hover карточки — поднимается плавно (transition точечный, не `all`).
3. Смена `--accent` в `:root` одной строкой — сайт перекрашивается вживую.
4. Пульс бейджа «В ЭФИРЕ» + `prefers-reduced-motion` не ломает страницу (анимация отключается, контент на месте).
5. Плеер sticky — виден при любой прокрутке, последняя карточка не перекрыта.
