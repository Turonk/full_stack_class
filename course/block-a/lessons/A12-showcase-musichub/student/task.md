# A12 · Твоя задача: подготовить демо MusicHub

Сегодня ты показываешь свой MusicHub залу. **6 минут на сцене.**

## Сценарий демо (4 шага — отрепетируй вслух с таймером)

1. **Экран целиком.** Что это за хаб, какая у него тема, кто в эфире. Одно предложение.
2. **Прогон ширин.** DevTools → режим устройства: 360px → 720px → 1200px. Колонки перестраиваются на глазах — твой главный вау-момент.
3. **Система.** Открой `:root` в styles.css → поменяй `--accent` на другой цвет → сайт перекрасился одной строкой. Скажи вслух, сколько мест правил бы без переменных.
4. **Один приём — одна история.** Выбери ОДИН кусок кода (10–20 строк) и объясни своими словами:
   - sticky-плеер («HUD сайта»), или
   - grid + mobile-first («одна база, медиазапросы добавляют»), или
   - clamp/шкала rem («размеры со шкалы, а не на глаз»), или
   - пульс + reduced-motion («движение сообщает, защита обязательна»).
