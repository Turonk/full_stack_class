# A13 Checks · Приёмка проектов

## Обязательные чекпоинты питча (Стоп-краны)

1. **Стоп-кран 1 (Адресная строка):**
   - Если сайт открыт через `file:///...` — выступление останавливается. Преподаватель помогает запустить `flask run`, и только после этого питч продолжается.

2. **Стоп-кран 2 (Данные не из Python):**
   - Если в `catalog.html` обнаружены скопированные вручную 10 карточек без цикла `{% for %}` — критерий «Модель данных» не засчитывается, отправляется на доработку в фазе 90–110 мин.

3. **Стоп-кран 3 (Живая форма):**
   - Проверяющий из зала диктует произвольное название (например, «Ночной экспресс»).
   - Спикер отправляет форму.
   - Трек обязан появиться на странице каталога.
   - По нажатию F5 не должно появляться окно повторной отправки.

4. **Стоп-кран 4 (Проверка 404):**
   - Спикер открывает адрес `http://127.0.0.1:5000/not-found-test`.
   - Должен отобразиться фирменный шаблон `404.html` с рабочей ссылкой домой.
