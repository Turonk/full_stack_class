# Рубрика оценки проекта
- **Сервер:** запущен Flask, ассеты со статусом 200 OK
- **Данные:** карточки выводятся из Python через Jinja `{% for %}`
- **Интерактив:** форма POST + валидация + Post/Redirect/Get
- **Ошибки:** фирменный `404.html` на любой неизвестный URL
- **Инженерия:** спикер понимает архитектуру своего кода
