# Урок 13 · Showcase серверного хаба

Паспорт защиты. Полный пакет слайдов ещё не собран. Проект и рубрика: [хаб 2.0](../../projects/01b-flask-hub/PROJECT.md). После [урока 12](../A12-flask-error404-polish/PLAN.md).

- Группа ≤10 · 120 минут
- Это не новый концепт. Это публичная проверка цепочки «запрос → маршрут → данные → ответ».

## Результат

Каждый ученик запустил свой сервер и за ≤6 минут показал: главную, каталог из `ITEMS`, одну карточку, добавление карточки из зала, свой 404. Сосед по рубрике отмечает зачёт или дыру. Преподаватель не принимает питч с адресом `file://`.

## Тайминг

| Мин | Фаза | Действие |
| --- | --- | --- |
| 0–10 | Правила | На слайде порядок из пяти шагов и рубрика. Серверы поднимаются до вызова к экрану |
| 10–70 | Питчи | ≤6 мин × ученик. При группе меньше 10 минуты не растягивать: лучше короче и с живой формой |
| 70–90 | Ревью | Пара проходит чек-лист проекта по экрану соседа, без переписывания кода |
| 90–110 | Правка | Только провал зачёта: сервер не поднимается, каталог не из цикла, форма портит список, 404 — белая страница Flask |
| 110–120 | Закрытие | Что остаётся в коде после перезапуска, а что нет. Следующий спринт — интерфейс этих же страниц, не новый сайт |

Если гостей пускают только на питчи, разбор багов до их прихода не выносить. Это правило уже есть в [RHYTHM.md](../../../teacher/RHYTHM.md).

## Порядок одного питча

1. Адресная строка `/`: это ответ сервера.
2. Показать `ITEMS` и ту же карточку в `/catalog`.
3. Открыть `/item/<id>` по ссылке.
4. Гость диктует название. Форма `/suggest`. Карточка находится в каталоге.
5. Открыть `/item/not-a-real-id` или другой пустой путь. Свой 404, ссылка домой.

Кто не успел форму к уроку, делает шаги 1–3 и 5. Шаг 4 закрывает дома скрином. В рубрике форма тогда «не зачёт», остальные строки ставятся честно.

## Что говорит ведущий, если питч буксует

- Сайт открыт с диска — остановить рассказ, запустить `flask run`, только потом продолжить.
- Карточки зашиты в HTML — попросить показать цикл. Нет цикла: зачёт по данным не ставить, чинить в блоке правки.
- Форма добавляет пустую карточку — это провал проверки, не «мелочь оформления».
- После питча сервер можно оставить включённым до ревью и затем остановить, чтобы порт 5000 не мешал следующему, если показывают по очереди с одного проектора. Со своего ноутбука ученик показывает сам.

## Не делать на этом уроке

Не вводить JSON, `fetch`, базу и логин. Не переносить сайт в новый дизайн. Не сравнивать красоту проектов между собой: рубрика про механизм.
