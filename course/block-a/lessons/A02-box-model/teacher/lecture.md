## Открытие · 2 мин

**Сказать:**

> Вчера баннер зажил. Сегодня сцена другая: карточка трека. Вы написали `width: 300px`. На экране — шире. Класс бормочет: «я написал 300, а карточка шире».

> Виновата не магия. Виновата **коробка**. У каждого элемента невидимая упаковка из четырёх слоёв. Кто понял слои — двигает карточку осознанно. Кто не понял — тыкает padding наугад и злится на браузер.

## Блок 1 · Четыре слоя · 5 мин

**Сказать:**

> Представьте коробку наушников с маркетплейса.

> **Content** — сами наушники. Текст, картинка, кнопка.  
> **Padding** — пузырчатая плёнка *внутри* коробки. Воздух между товаром и картонной стенкой.  
> **Border** — сам картон, рамка.  
> **Margin** — щель до соседней коробки на полке. Снаружи. Улица между домами.

> В CSS у каждого блока те же роли. Текст не должен липнуть к рамке — это padding. Карточки не должны слипаться — это margin (или gap во flex, но база — margin).

**Спросить:** Padding — внутри рамки или снаружи?  
**Ждём:** внутри.

**Спросить:** Margin — внутри или снаружи?  
**Ждём:** снаружи.

**Сказать:**

> Если перепутать, получится «я отодвинул текст, а соседу стало тесно» или наоборот. На курсе якорь: **ковёр / улица**. Padding = ковёр в комнате. Margin = улица. Кадр: добавили padding — текст отлип от края, сосед ещё не сдвинулся.

## Блок 2 · Почему 300 превращается в 344 · 6 мин

**Сказать:**

> Вернёмся к реплике: «я написал 300». Вот ловушка старого мира:

```css
.card {
  width: 300px;
  padding: 20px;
  border: 2px solid #2ee6a6;
}
```

> Мозг думает: «карточка 300». Браузер в режиме **content-box** думает иначе: «300 — только внутренности. Плёнку и картон добавлю сверху».

> Считаем вслух. Padding слева 20 + справа 20 = 40. Border 2 + 2 = 4. Итого на экране: **300 + 40 + 4 = 344**.

**Спросить:** Кто уже ловил «чуть шире, чем просил»?  
**Ждём:** кивки / истории.

**Сказать:**

> Режим **border-box** говорит: «width — это вся коробка целиком, включая padding и border. Воздух съедает место у content изнутри». Тогда при width 300 на экране честно **300**.

> Почти весь современный веб начинает так:

```css
*, *::before, *::after {
  box-sizing: border-box;
}
```

> Это не школьная прихоть. Это договорённость, чтобы колонки не разъезжались. Discord, GitHub, ваш будущий магазин — все живут в border-box.

**Спросить:** content-box при тех числах даёт сколько? border-box?  
**Ждём:** **344** и **300**. Это checkpoint. Без хора дальше не идём.

**Сказать:**

> Кадр после правила: поставили border-box — Computed показывает 300. «Я написал 300» наконец совпало с экраном.

**Факт на 30 секунд — схлопывание margin:**

> Два соседних блока: у первого `margin-bottom: 30px`, у следующего `margin-top: 20px`. Между ними будет не 50px, а **30px** — больший побеждает. Не баг, а модель: соседние margin не складываются, а схлопываются. Знать — значит не удивляться. У `gap` во flex/grid такого нет — воздух всегда честный, ещё один повод любить gap.

## Блок 3 · DevTools — не чит, а рентген · 4 мин

**Сказать:**

> Глазами вы ширину угадаете плохо. В DevTools есть схема коробки — «пончик»: content, padding, border, margin с цифрами.

> ПКМ по карточке → Inspect → смотрите Computed / box model. Если пончика не видите — вы гадаете, не дебажите.

> Сегодня на стенде специально потрогаем: поставим content-box, раздуем padding, увидим рост общей ширины. Вернём border-box — ширина стабильна, текст чуть сжался внутри. Вот куда «делись» пиксели: их съел padding у content.

**Спросить:** Зачем тогда вообще знать content-box, если все ставят border-box?  
**Ждём:** чтобы читать чужой код / понимать баги старых примеров / не паниковать.

## Блок 4 · Карточка как смысл · 3 мин

**Сказать:**

> На PulseDeck будет карточка **квеста** — учебный пример, зелёная обводка. В радио у вас — карточка **трека**: название, исполнитель, позже обложка.

> В HTML лучше `article.card`, а не безымянный серый `div` на всё. `article` — кусок смысла, который можно вынуть и показать отдельно. Как объект в Python: у него есть данные и границы.

> Radius, фон, тонкая рамка — это уже вкус. Но без padding карточка всегда выглядит «школьной»: текст липнет к краю, глаз устаёт. Сцена «липнет» → правило «нужен ковёр» → кадр с padding.

## Шпаргалка терминов

| Термин | Одной фразой |
| --- | --- |
| content | товар внутри |
| padding | ковёр, внутри рамки |
| border | стены |
| margin | улица снаружи |
| content-box | width только content, снаружи растёт |
| border-box | width = вся коробка |
| схлопывание margin | соседи 30 и 20 дают 30, не 50 |
| Computed | правда в пикселях |
