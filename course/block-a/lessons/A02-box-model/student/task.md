# A02 · Задача ученика

Собери **карточку трека** в Pulse FM.

**Зачем:** чтобы «я написал 300» совпало с экраном и текст трека не лип к краю карточки.

## Сделай
1. Блок с названием трека и исполнителем.
2. Padding и border так, чтобы текст не лип к краю.
3. В CSS: `box-sizing: border-box` (на `*` или на карточке).
4. Проверь ширину в DevTools Computed.

## Готово, когда
- [ ] Карточка визуально «с воздухом»
- [ ] Ты можешь объяснить, зачем border-box
- [ ] Не путаешь padding и margin
