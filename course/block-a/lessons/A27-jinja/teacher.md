## Новая тема

- templates/ папка.
- {% extends %}, {% block %}.
- {{ variable }}.
- {% for t in tracks %}.
- Данные живут в Python, HTML их показывает.

1. base.html nav.

## Частые ошибки 12–14 лет

- {{ }} внутри {% %}.
- Безопасность: не учим |safe на пользовательском вводе.
