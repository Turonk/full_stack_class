# A11 · Checks (стоп-краны)

## Retrieval (0–5)
**Q1:** Три ручки иерархии?
**Ожидание:** размер, вес, цвет.

**Q2:** Что делает `clamp(1.8rem, 5vw, 2.4rem)`?
**Ожидание:** резиновый размер между полом и потолком.

**Q3:** Роли шрифтов?
**Ожидание:** Syne — заголовки (плакатный), IBM Plex Sans — текст (интерфейсный).

## Predict (5–15, до кода)
**Q:** Как помочь тем, кого укачивает от анимаций, не лишая остальных пульса?
**Ожидание:** системная настройка «уменьшить движение» + `prefers-reduced-motion` в CSS.
**Mist:** «кнопка выключить» → «полумера: её надо найти. Система уже умеет — CSS её слышит».

## Checkpoint mid (55–60, порог 7/10)
**Q1:** Чем `transition` отличается от `@keyframes`?
**Ожидание:** transition — два состояния по событию, один раз; keyframes — сценарий по шагам, сам, можно зациклить.

**Q2:** Что делает `prefers-reduced-motion: reduce`?
**Ожидание:** отключаем анимации для тех, кто попросил систему убрать движение; контент остаётся.

**Mist majority:** игра «лифт или стиральная машина» на стенде — класс распределяет примеры. Не пускать в You do.

## You do · критерий «готово» (65–100)
- [ ] бейдж пульсирует спокойно (2–3s)
- [ ] одна зацикленная анимация на экран
- [ ] reduced-motion глушит пульс и transitions
- [ ] hover/focus-visible живы (A05)
- [ ] дешёвые свойства (transform/opacity/filter/box-shadow)

**Mist «keyframes есть, движения нет»:** «Сценарий не подключён: `animation: pulse …` написан? Имя по буквам совпадает?»
**Mist «стробоскоп»:** «Дыхание или паника? 2–3 секунды.»
**Mist «рябит»:** «Новогодняя ёлка. Одна на экран — выбирай лучшую.»

## Gallery (100–110)
**Формат:** пульс → эмуляция reduce (DevTools → Rendering) → hover/Tab.
**Mist:** нет защиты → не позорим; «три строки до стандарта» — фикс первым делом дома.

## Exit (110–120)
Термин (transition / keyframes / reduced-motion) + скрин/видео пульса. **Анонс A12:** сценарий демо 360→1200→`:root`→один приём; репетиция вслух с таймером 6 минут.
