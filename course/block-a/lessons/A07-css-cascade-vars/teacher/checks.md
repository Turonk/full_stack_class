# A07 · Checks (стоп-краны)

## Retrieval (0–5)
**Q1:** `width: 300px` + `padding: 20px` + `border: 2px`, режим по умолчанию. Ширина на экране?
**Ожидание:** 344px.
**Mist:** «300» → вспомнить border-box; «ставим `box-sizing` первой строкой каждого проекта».

**Q2:** Padding vs margin?
**Ожидание:** ковёр внутри / улица снаружи.

**Q3:** Карточка «подпрыгивает» на hover — какие свойства?
**Ожидание:** `transform` + `transition` (+ `box-shadow`).

## Predict (5–15, до кода)
**Q:** Два правила `.card { background: … }` — тёмное выше, фиолетовое ниже. Цвет карточки?
**Ожидание:** фиолетовый — при равной силе побеждает нижнее.
**Mist:** «верхнее» → показать на стенде, поменять порядок строк местами вживую.

**Q (ловушка рангов, показывать в §4):** `.title { color: red }` ниже, `.card .title { color: white }` выше. Цвет заголовка в карточке?
**Ожидание:** белый — ранг 0-2-0 бьёт 0-1-0, порядок не важен.
**Mist:** «красный, он же ниже» → пересчитать ранги вслух: два класса против одного.

## Checkpoint mid (55–60, порог 7/10)
**Q1:** Два правила одинаковой силы спорят. Кто победил?
**Ожидание:** написанное ниже.

**Q2:** Где живёт цвет акцента и как его достать?
**Ожидание:** `--accent` в `:root`; в правилах — `var(--accent)`.

**Mist majority:** возврат на We do — прогнать ещё один круг «порядок правил» на стенде, затем снова check. Не пускать в You do.

## You do · критерий «готово» (65–100)
- [ ] Live Server, экран тёмный
- [ ] в стартерском хаосе не осталось ни одного hex вне `:root`
- [ ] три карточки, воздух внутри и между
- [ ] нет `!important`, нет id в стилях
- [ ] проверка «заказчик»: смена `--accent` перекрашивает весь сайт

**Mist «hex в правилах»:** вопрос «заказчик попросил розовый — сколько мест править?» → перенести цвет в `:root`.
**Mist «опечатка в имени переменной»:** «CSS молча игнорирует — читай по буквам, смотри DevTools».

## Gallery (100–110)
**Формат:** экран целиком → открыть `:root` → перекрасить акцент за 5 секунд вживую.
**Mist:** у ученика нет переменных → не позорим, хвалим экран, фикс — в ДЗ.

## Exit (110–120)
Термин своими словами (каскад / специфичность / переменная CSS) + скрин в чат. Нет скрина → прислать до следующего урока.
