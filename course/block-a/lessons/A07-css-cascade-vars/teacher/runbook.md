## Реплики-якоря

- «Каждый цвет — из `:root`. Руками hex в правила не пишем.»
- «Класс сильнее тега. Id — для JavaScript, не для стилей.»
- «`!important` — крик вместо очереди. Сегодня под запретом.»
- «CSS не ругается на опечатку — он молча игнорирует. Проверяй глазами и DevTools.»
