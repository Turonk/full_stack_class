# Каскад — три ступеньки
1. Откуда правило (браузер < автор)
2. Специфичность — ранги: `button` 0-0-1 < `.class` 0-1-0 < `#id` 1-0-0
3. Порядок: при равных — **нижнее** побеждает

---

# Переменные — тема в одном месте
```css
:root { --accent: #7C5CFF; }
.btn  { background: var(--accent); }
```
Одна строка → весь сайт перекрашен
`!important` — **не начинать им день**
