## Новая тема

- style vs файл css.
- Специфичность: тег < класс < не дерите !important.
- :root --bg --text --accent.
- Наследование цвета и шрифта.

## Практика в классе

1. styles.css + link.
2. Переменные из STYLE.md.
3. body фон и шрифт.
4. header padding.
5. Цвет ссылок через var.

## Частые ошибки 12–14 лет

- CSS внутри каждой карточки дублируется.
- Опечатка в имени переменной.
- Подключили файл не из той папки.
