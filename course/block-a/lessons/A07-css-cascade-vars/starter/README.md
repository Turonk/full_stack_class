# A07 · Стартер: MusicHub с хаосом цветов

Скелет уже собран — но цвета в `styles.css` продублированы руками: один и тот же `#7C5CFF` живёт в нескольких местах.

## Задача дня

1. Найди глазами все места, где повторяется акцентный цвет. Посчитай вслух.
2. Объяви `:root` с переменными: `--bg`, `--bg-elev`, `--text`, `--muted`, `--accent`.
3. Замени **каждый** hex в правилах на `var(…)`.
4. Дострой три карточки треков (названия свои).
5. Проверка «заказчик»: поменяй `--accent` — весь сайт перекрасился одной строкой?
