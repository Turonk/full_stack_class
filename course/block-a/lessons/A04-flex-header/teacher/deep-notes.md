## 1. Схема осей (показывать на слайде/доске)

```
              главная ось → (row)
┌────────────────────────────────────────────┐
│  [Logo]          [Эфир] [Треки] [Клуб]      │
│  ↑ поперечная ось → align-items (по высоте) │
└────────────────────────────────────────────┘
```

- `justify-content` — вдоль главной оси (в ряд).
- `align-items` — поперёк (по высоте шапки).
- Жест руками: ряд — горизонтальная ладонь; высота — вертикальная.

## 2. I do · live-coding на стенде (для подготовки дома)

Готовим: открыт [`demo/index.html`](../demo/index.html) и `styles.css`, Live Server.

1. **Было: столбик** — убрать `display: flex` с `.bar` (или показать без него). Ссылки падают в столбик — «инвентарь сваленный».
2. **Разметка бара**:
   ```html
   <header class="bar">
     <p class="mark">PulseDeck</p>
     <nav>
       <a class="on" href="#play">Play</a>
       <a href="#friends">Друзья</a>
       <a href="#shop">Магазин</a>
     </nav>
   </header>
   ```
   - `nav` — роль «навигация» для скринридера, не просто набор ссылок.
3. **Flex по одному свойству** — после каждого шага спросить «Что изменилось?»:
   ```css
   .bar {
     display: flex;                    /* 1) дети в ряд */
     justify-content: space-between;   /* 2) края к стенкам */
     align-items: center;              /* 3) на одну полку по высоте */
     gap: 16px;                        /* 4) воздух между детьми */
     padding: 14px 24px;
     background: #0d1322;
   }
   nav { display: flex; gap: 20px; }   /* 5) ссылки в ряд внутри правой зоны */
   ```
4. **Состояния ссылок** — подсветка активного, hover, focus:
   ```css
   nav a { color: #8b95ad; text-decoration: none; }
   nav a.on, nav a:hover, nav a:focus-visible { color: #2ee6a6; }
   ```
5. **Сузить окно** — ряд живёт; полный перенос витрины будет на A05.

- «Сейчас `flex-start`. Нажимаю. Что изменится при `center`?»
- «Теперь `space-between`. Куда уедут крайние дети?»
- «Один ребёнок тянется на 100% ширины — каково соседям?» (жадный ребёнок выталкивает остальных — сегодня не нужно).

## 4. FAQ преподавателя

- **Почему не float?** Float — обтекание картинок текстом; шапки на нём собирали с костылями-«очистками». Flex — договорённость браузеров для панелей.
- **Почему не пробелы/`&nbsp;`?** Сменился шрифт или ширина — всё поехало. Раскладкой управляет родитель.
- **flex на ссылку или на родителя?** Только на родителя. Дети сами ряд не включают.
- **`space-between` и `margin-left: auto` — это одно?** Почти: auto — частный приём на одном ребёнке; space-between — свойство контейнера для всех детей.

## 5. Частые ошибки 12–14 лет

| Симптом | Фикс за 15 сек |
| --- | --- |
| Flex на `<a>`, не на шапке | Перенести на `.top` / `.bar` |
| Ссылки столбиком справа | `nav { display: flex; gap: 20px; }` |
| Один ребёнок + space-between | Нужны два ребёнка (бренд и nav) |
| Скопированы «Друзья/Магазин» | Заменить на эфирные ярлыки |
| Якорь не прыгает | Проверить `id` у секции-цели |

## 6. Отстаёт / Опережает

- **Отстаёт:** только `display: flex` + `space-between` (шаги 1–4 task.md). `align-items`, gap, состояния ссылок — на дом.
- **Опережает:** `nav { display: flex; gap }`; `focus-visible`; `is-current` на «Эфир»; заглушка аватара 32px.
