## Реплики-якоря

- «Flex — режим родителя: дети в ряд и по командам.»
- «`space-between` — первый к краю, последний к краю, воздух между.»
- «`align-items` — как поставить детей на одну полку по высоте.»
- «Раскладкой управляет родитель, не пробелы.»

## Стоп-кран

Если на checkpoint <7/10 верно → We do с тремя коробками-детьми на demo (эталон deep-notes §2), предсказываем крайних игроков вслух → снова check.

## Отстаёт / Опережает

- **Отстаёт:** только `display: flex` + `justify-content: space-between` на шапке (шаги 1–4 task.md). `align-items` и gap — допилить дома.
- **Опережает:** `nav { display: flex; gap: 20px; }` внутри правой зоны; `focus-visible` на ссылках меню; `is-current` подсветка активного раздела.
