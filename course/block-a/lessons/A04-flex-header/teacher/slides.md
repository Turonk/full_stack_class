# Flex · две оси
```
              главная ось (row) →
┌────────────────────────────────────────┐
│  [д1]   [д2]   [д3]                    │
│  ↑ поперечная ось (align-items)        │
└────────────────────────────────────────┘
```
`display: flex` — режим **родителя**.

---

# justify-content
- `flex-start` — кучкой к началу
- `center` — кучкой к центру
- **`space-between`** — первый к краю, последний к краю
