# Домашка A04 · 40–55 минут

Доведи шапку своего Pulse FM и убедись, что якоря работают.

## Сделай

1. Шапка: `display: flex`, `justify-content: space-between`, `align-items: center`.
2. Слева — название радио, справа — три ссылки меню с `gap`.
3. Ссылки ведут на секции страницы (якоря `#...`, у секций есть `id`).
4. Убедись, что баннер, карточка и обложка прошлых уроков живы.

## Критерии приёмки

- [ ] Шапка в один ряд, бренд слева, меню справа
- [ ] Горизонтального скролла из-за меню нет
- [ ] Клик по «Треки» прыгает к карточке
- [ ] Фокус с клавиатуры (Tab) по ссылкам меню виден

## Сдать

Скрин шапки + `index.html` + `styles.css`.

## Если не получилось

- Ссылки столбиком → проверь, что `display: flex` стоит на шапке, а не на ссылке.
- Меню прижалось к лого → добавь `justify-content: space-between` на шапку.
- Якорь не прыгает → сверь `#имя` в ссылке и `id="имя"` у секции.
