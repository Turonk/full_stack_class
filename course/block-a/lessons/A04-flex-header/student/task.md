# A04 · Задача ученика

Собери **шапку** Pulse FM.

**Зачем:** чтобы пульт эфира читался сразу — бренд слева, меню справа, без столбика ссылок по центру.

## Сделай
1. Контейнер шапки: `display: flex`.
2. Слева — название радио.
3. Справа — ссылки: Эфир / Треки / Клуб (якоря `#` пока ок).
4. `justify-content: space-between` и `align-items: center` + `gap` по вкусу.

## Готово, когда
- [ ] Элементы в один ряд у краёв
- [ ] Можешь предсказать, что сделает `center` vs `space-between`
