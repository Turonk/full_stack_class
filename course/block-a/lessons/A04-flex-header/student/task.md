# A04 · Задача ученика

Собери **шапку** Pulse FM: бренд слева, меню справа — в один ряд.

**Зачем:** глаз привык к зонам: слева — кто ты, справа — что можно нажать. Столбик ссылок по центру выглядит как несобранный пульт.

## Сделай

1. На контейнере шапки поставь `display: flex`.
2. Слева — название радио.
3. Справа — меню: Эфир / Треки / Клуб (пока можно ссылки-якоря `#`).
4. Добавь `justify-content: space-between` — первый элемент к левому краю, последний к правому.
5. `align-items: center`, чтобы все встали на одну полку по высоте.
6. `gap` — воздух между элементами.

## Готово, когда

- [ ] Все элементы в один ряд у краёв
- [ ] Бренд слева, меню справа
- [ ] Можешь предсказать, что сделает `center` вместо `space-between`
- [ ] Шапка не ломает баннер и карточку прошлых уроков

## Не делай

- Не ставь flex на отдельную ссылку — включай на родителе
- Не расставляй ссылки пробелами в HTML
- Не копируй слова лаунчера (Play / Друзья / Магазин)
