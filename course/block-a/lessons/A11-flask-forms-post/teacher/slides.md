# GET против POST
| Метод | Назначение | Где лежат данные? |
| --- | --- | --- |
| **GET** | Безопасное чтение | В адресной строке URL |
| **POST** | Создание / изменение | Внутри тела HTTP-запроса |

Для форм создания используем **POST**!

---

# HTML-форма: атрибут name
Сервер видит поле только по его атрибуту `name`:

```html
<form method="post" action="{{ url_for('suggest') }}">
  <label for="title">Название трека:</label>
  <input type="text" id="title" name="title" required>

  <label for="img">Обложка:</label>
  <select name="img">
    <option value="pixel.svg">Неон Pixel</option>
    <option value="bell.svg">Школа</option>
  </select>

  <button type="submit" class="btn">Отправить</button>
</form>
```

# Обработка POST во Flask
Один маршрут принимает оба метода:

```python
@app.route("/suggest", methods=["GET", "POST"])
def suggest():
    if request.method == "POST":
        title = request.form.get("title", "").strip()
        if not title:
            flash("Название не может быть пустым!")
            return redirect(url_for("suggest"))
        
        ITEMS.append({"id": "...", "title": title, ...})
        flash("Трек добавлен в эфир!")
        return redirect(url_for("catalog"))
    
    return render_template("suggest.html")
```

# Ловушка F5: паттерн PRG
Что если на POST просто вернуть страницу?
- Пользователь жмет F5 -> повторная отправка формы!
- В каталоге появляется дубликат!

**Паттерн Post / Redirect / Get:**
1. Браузер шлет **POST**
2. Сервер сохраняет данные
3. Сервер шлет **Redirect** на каталог
4. Браузер делает чистый **GET** каталога

F5 теперь полностью безопасен!
