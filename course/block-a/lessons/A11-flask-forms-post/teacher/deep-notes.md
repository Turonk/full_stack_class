# A11 Deep Notes · Подготовка преподавателя

## Техническая модель урока
1. `Методы HTTP: GET vs POST`:
   - `GET` — идемпотентный и безопасный метод для запроса данных. Параметры передаются в строке запроса (Query String) после знака `?`.
   - `POST` — метод для изменения состояния сервера. Данные передаются в теле запроса (Request Body) в формате `application/x-www-form-urlencoded`.
2. `Объект request во Flask`:
   - `request.method` хранит текущий метод запроса строкой в верхнем регистре (`"GET"`, `"POST"`).
   - `request.form` — словарь типа `ImmutableMultiDict`, содержащий пары ключ-значение из полей формы с атрибутом `name`.
3. `Паттерн Post/Redirect/Get (PRG)`:
   - Если сервер отвечает `200 OK` напрямую на POST-запрос, в истории переходов браузера последним остаётся POST. Нажатие F5 повторяет последний запрос, приводя к дублированию записей или двойным транзакциям.
   - Ответ `302 Found` (вызываемый через `redirect()`) заставляет браузер выполнить новый `GET` на указанный URL, очищая контекст отправки формы.
4. `Flash-сообщения`:
   - Работают через подписанный сессионный cookie. Требуют установленного `app.secret_key`. Без него вызов `flash()` приведёт к `RuntimeError: The session is unavailable because no secret key was set`.

## Частые ошибки 12–14 лет
| Симптом | Причина | Исправление |
| --- | --- | --- |
| `RuntimeError: The session is unavailable...` | Забыли объявить `app.secret_key` | Добавить в начале файла: `app.secret_key = "любая-строка"` |
| `request.form.get("title")` возвращает пустую строку | В `<input>` написали `id="title"`, но забыли `name="title"` | Обязательно добавить атрибут `name="title"` |
| Браузер отправляет GET вместо POST | В теге формы написали `method="GET"` или пропустили атрибут | Написать: `<form method="post" action="...">` |
| По нажатию F5 сайт переспрашивает отправку | В POST-ветке написали `return render_template(...)` | Заменить на `return redirect(url_for('catalog'))` |

## Дифференциация темпа
- **Если отстает:** в форме оставить только одно обязательное поле `title` и выпадающий список `img`. Поля `subtitle` и `blurb` заполнять дефолтными строками.
- **Если опережает:** добавить валидацию минимальной длины названия (не менее 3 символов) и очистку от лишних спецсимволов.
