## Почему это занятие длится ровно 120 минут
Связка «HTML-форма -> HTTP POST -> Python request.form -> валидация -> список в памяти -> flash -> redirect» — это первый настоящий fullstack-сценарий в жизни ребят. Они пишут код и на клиенте (верстка формы и инпутов), и на сервере (обработка входящих данных). Забытый атрибут `name="title"` или отсутствие `app.secret_key` — стандартные поводы для пошаговой командной отладки.
