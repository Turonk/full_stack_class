# Урок 11 · Форма POST и ответ без повторной отправки

Паспорт. Полный пакет ещё не собран. Проект: [хаб 2.0](../../projects/01b-flask-hub/PROJECT.md). После [урока 10](../A10-jinja-inheritance-routes/PLAN.md).

- Группа ≤10 · 120 минут
- Один концепт: форма отправляет данные на сервер методом POST, сервер меняет список и отвечает перенаправлением.

## Результат

На `/suggest` форма с полями `title`, `subtitle`, `blurb` и выбором уже лежащей обложки. После отправки браузер оказывается на `/catalog`, новая карточка в списке, сверху короткое сообщение. Пустое название не добавляется. Повторное обновление каталога не создаёт вторую такую же карточку.

Список по-прежнему в памяти: перезапуск сервера его очищает от добавленных в рантайме карточек. Это проговаривается.

## Не входит

Загрузка файла с компьютера, база, логин, JSON, `fetch`. Красивый 404 для неизвестного адреса — следующий урок. Пустой `id` карточки на этом уроке уже не должен падать.

## Теория

В форме `method="post"` и `action="{{ url_for('suggest') }}"`. У каждого поля есть `name`. Без `name` сервер поле не увидит. Текст кнопки на сервер не обязателен.

Один обработчик на оба метода:

```python
@app.route("/suggest", methods=["GET", "POST"])
def suggest():
    if request.method == "POST":
        title = request.form.get("title", "").strip()
        if not title:
            flash("Нужно название")
            return redirect(url_for("suggest"))
        ITEMS.append({...})
        flash("Карточка в эфире")
        return redirect(url_for("catalog"))
    return render_template("suggest.html")
```

`app.secret_key = "dev-only"` включается до маршрутов. Для урока это ключ подписи cookie с flash-сообщениями, не пароль пользователя. Произнести это одной фразой.

В `base.html`:

```html
{% for message in get_flashed_messages() %}
<p class="flash">{{ message }}</p>
{% endfor %}
```

`id` новой карточки не вводит ученик руками в форме. Учитель даёт готовую функцию «название → id» и проверку дубля `-2`. Группа её использует, не изобретает транслит.

Обложки: `<select name="img">` с двумя-четырьмя именами файлов, которые уже лежат в `static/img/`.

## Практика

1. Шаблон `suggest.html` на своём `base.html`.
2. Пункт меню «Предложить».
3. Обработчик GET/POST по образцу стенда.
4. Пустое название возвращает на форму с сообщением.
5. Успех открывает каталог, карточка видна.
6. Обновить каталог. Вторая копия не появляется.

## Ошибки

| Симптом | Куда смотреть |
| --- | --- |
| Поля пустые, хотя их заполнили | Нет `name` или форма осталась `method="get"` без чтения `request.form` |
| `KeyError` / flash молчит | Нет `secret_key` |
| После F5 браузер спрашивает «отправить форму снова» | Нет `redirect`, ответ POST нарисован на той же странице |
| В каталог попала пустая карточка | Проверка `title` стоит после `append` |
| Картинка новой карточки сломана | В `select` значение не совпадает с именем файла |
