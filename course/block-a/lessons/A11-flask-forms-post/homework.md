# Домашка A11 · 45–70 минут

1. Добавить в форму `/suggest` выпадающий список `<select name="img">` с выбором одной из ваших реальных картинок.
2. Проверить, что отправленная через форму карточка корректно отображает выбранную картинку в каталоге.
3. Добавить на детальную страницу `/item/<id>` кнопку «← Назад в каталог».

## Критерии приёмки
- [ ] Форма успешно добавляет новую карточку с картинкой
- [ ] Сервер валидирует пустые названия
- [ ] F5 в каталоге не отправляет форму повторно

## Формат сдачи
Два скриншота:
1. Заполненная форма на `/suggest`.
2. Каталог после редиректа с зеленым уведомлением `flash` и новой карточкой.
