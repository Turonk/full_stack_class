# Домашка A05 · 50–70 минут

Доведи витрину из трёх карточек. Это заготовка к завтрашнему showcase.

## Результат

Три разных трека. Мышь и Tab поднимают карточку. На 360px страница не уезжает вбок. `transition` ~0,2 с только на `transform` и `box-shadow`.

## Сделай

1. Три разных трека: названия, исполнители, обложки (cover из A03).
2. Контейнер `.row`: flex + `flex-wrap: wrap` + `gap`.
3. Внутри каждой карточки — ссылка «Открыть».
4. Hover поднимает карточку; Tab тоже — через `:focus-within` на `.card`.
5. `transition` только на transform/box-shadow, ~0,2 с.
6. Шапка с A04 на месте.
7. Скрин 360px: ничего не вылезло за край. Если вылезло — уменьши min-width / проверь wrap.

## Критерии приёмки

- [ ] Три разных трека
- [ ] Отклик мыши и клавиатуры (`:hover` + `:focus-within`)
- [ ] На 360px нет скролла вбок
- [ ] `transition` не `all`
- [ ] Баннер, карточка, обложка, шапка прошлых уроков живы

## Сдать

Скрин витрины (широкий + 360px) + `index.html` + `styles.css`.

## Если не получилось

- Карточка не поднимается → проверь `:hover` именно на `.card`, а не на `img`.
- Нет отклика с Tab → добавь ссылку внутрь карточки и `:focus-within` на `.card` (не `:focus-visible` на `article`).
- Съезжает вбок → `flex-wrap: wrap` на контейнере, убери фиксированные ширины больше экрана.
