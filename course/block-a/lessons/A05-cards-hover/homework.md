# Домашка A05 · 50–70 мин

Доведи витрину из трёх карточек. Это заготовка к завтрашнему showcase.

## Критерии

- Три разных трека
- Flex + wrap + gap
- Hover поднимает карточку
- Focus с клавиатуры виден
- Шапка с A04 на месте
- Скрин 360px ширины (DevTools): ничего не вылезло за край — если вылезло, уменьши min-width карточки
