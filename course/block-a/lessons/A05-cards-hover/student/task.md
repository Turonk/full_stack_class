# A05 · Задача ученика

Собери **витрину из трёх треков** — с откликом на мышь, Tab и узкий экран.

## Результат

К концу работы у тебя:

1. карточка поднимается от мыши;
2. при Tab поднимается вся карточка (фокус на ссылке внутри);
3. на ширине 360px страница не уезжает вбок.

Переход ~0,2 с только для `transform` и `box-shadow`.

## Сделай

Стартер: одна карточка `.card`, фиксированная `width: 280px`, ссылки внутри нет. Эталон разметки — у учителя в `solution/`.

1. В `index.html`: три разных трека в контейнере `.row`. Внутрь каждой карточки — ссылка «Открыть» (класс `card-link`).
2. В `styles.css`: у `.row` — `display: flex`, `flex-wrap: wrap`, `gap: 16px`.
3. У `.card`: убери жёсткую `width`, поставь `flex: 1 1 200px` и `max-width: 280px`.
4. Hover и клавиатура:
   ```css
   .card {
     transition: transform 0.2s ease, box-shadow 0.2s ease;
   }
   .card:hover,
   .card:focus-within {
     transform: translateY(-4px);
     box-shadow: 0 0 0 1px #7c5cff, 0 18px 40px rgba(124, 92, 255, 0.25);
   }
   ```
5. Проверь DevTools → **360px** — страница не уезжает вбок.

## Готово, когда

- [ ] Три разных трека
- [ ] Мышь и Tab поднимают карточку
- [ ] На 360px карточки переносятся, без скролла вбок
- [ ] Шапка с A04 и обложка с A03 на месте
- [ ] `transition` не `all`

## Не делай

- Не пиши `transition: all` — перечисляй свойства
- Не ставь `:focus-visible` на сам `article` — фокус получает ссылка внутри; подъём даёт `:focus-within`
- Не копируй названия игр из лаунчера PulseDeck
