# A05 · Задача ученика

Собери **витрину из трёх треков**.

**Зачем:** чтобы карточки отвечали как живой плеер — мышью, клавиатурой и на узком экране без скролла вбок.

## Сделай
1. Три карточки в flex-контейнере с `gap` и `flex-wrap: wrap`.
2. Hover: лёгкий подъём или тень (~0.2s).
3. Focus: кольцо при Tab (`:focus-visible`).
4. Проверь ширину **360px** в DevTools.

## Готово, когда
- [ ] Три карточки отвечают мыши и клавиатуре
- [ ] На узком экране не ломают страницу
- [ ] Готов показать это завтра на showcase
