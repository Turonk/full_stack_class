# A05 · Лекция вслух · Витрина и состояния

---

## Открытие · 2 мин

**Сказать:**

> Сцена: три карточки треков. Курсор наезжает — тишина. Класс: «трек без реакции плеера». Мозг ждёт отклик примерно за **200 миллисекунд** — не ноль и не полсекунды.

> Завтра showcase. Сегодня плитки должны **отвечать**: мышью и клавиатурой. Три карточки. Перенос на узком экране. Плавный transition только на нужных свойствах. Без JavaScript: браузер сам знает `:hover` и `:focus`.

## Блок 1 · Состояния UI · 5 мин

**Сказать:**

> У интерактивного элемента есть жизни: обычное состояние, наведение, фокус с клавиатуры, иногда disabled. Если сделали только hover — человек с Tab ходит вслепую. Клавиатура — тоже геймпад сайта.

```css
.card:hover,
.card:focus-visible {
  transform: translateY(-4px);
  box-shadow: 0 12px 24px rgba(0, 0, 0, 0.35);
}
```

> `:focus-visible` — кольцо, когда фокус пришёл с клавиатуры, а не после каждого клика мыши. Уважение к обоим мирам. Правило: **мышь и Tab оба должны видеть отклик**.

**Спросить:** Почему мало одного `:hover`?  
**Ждём:** Tab / доступность / не все с мышью.

**Сказать:**

> Кадр: навели — карточка чуть поднялась. Нажали Tab — кольцо. Плеер снова живой.

## Блок 2 · transition без жадности · 4 мин

**Сказать:**

> `transition: all 0.2s` кажется удобным. На деле анимирует всё подряд, иногда тормозит и сюрпризит. Лучше перечислить:

```css
transition: transform 0.2s ease, box-shadow 0.2s ease;
```

> 0.15–0.25s — сладкая зона отклика. Полсекунды — уже «плывёт». Ноль — дёргается. Сцена «плывёт полсекунды» → правило «только нужные свойства, ~0.2s».

**Спросить:** Какие два свойства мы трогаем для «подпрыгнула карточка»?  
**Ждём:** transform и/или box-shadow (не width).

---

## Блок 3 · wrap на 360px · 4 мин

**Сказать:**

> Три карточки в `display: flex` с `gap` красивы на широком. На телефоне 360px они не обязаны давиться в один ряд до горизонтального скролла всей страницы. Класс: «страница уехала вбок».

```css
.shelf {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}
```

> `flex-wrap: wrap` — «не влезло — перенеси». Checkpoint: DevTools → 360px → витрина жива, страница не едет вбок.

**Спросить:** Что хуже для родителя на демо — чуть перенос или горизонтальный скролл?  
**Ждём:** скролл хуже.

**Сказать:**

> Кадр на 360: карточки перенеслись. Эфир на телефоне не ломается.
