## FAQ преподавателя

- **Почему ~200 мс?** Мгновенно выглядит дёргано, полсекунды — слишком медленно. Steam / Epic / Spotify держатся около 0,15–0,25 с.
- **Почему не `transition: all`?** Анимируется всё подряд — дороже и с рывками. Перечисляем transform и box-shadow.
- **`focus-within` vs `focus-visible`?** `focus-within` — фокус *внутри* элемента (карточка со ссылкой): поднимаем всю карточку. `focus-visible` — кольцо у самой ссылки, когда фокус пришёл с клавиатуры.
- **Зачем ссылка внутри карточки?** `article` с Tab не получает фокус. Ссылка внутри — естественный путь Tab без `tabindex` на article.
- **Почему не `:focus-visible` на `.card`?** Карточка — `article`. Псевдокласс на ней не сработает от Tab, пока фокус не на самой карточке. Подъём даёт `:focus-within`.

## Частые ошибки 12–14 лет

| Симптом | Фикс за 15 сек |
| --- | --- |
| `transition: all` | Только transform и box-shadow |
| Hover только на img | Перенести на `.card` |
| Три одинаковых трека | Разные названия |
| Класс `.tile` в радио | Переименовать в `.card` |
| Нет отклика с Tab | Ссылка внутри + `:focus-within` |
| `:focus-visible` на `article` | Убрать; оставить на ссылке / браузерное кольцо |

## Отстаёт / Опережает
