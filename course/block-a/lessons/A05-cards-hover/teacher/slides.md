# Состояния
```
default ── :hover ── :active
   │
   └── :focus-within (фокус внутри карточки)
         └── ссылка: :focus-visible (Tab)
```
Мышь **и** клавиатура видят отклик.

# transition: правильно и нет
Плохо: `transition: all 0.2s`
Хорошо: `transition: transform 0.2s, box-shadow 0.2s`
0,15–0,25 с — комфортный отклик.

# Факт IT · :focus-visible
caniuse.com/css-focus-visible
- Chrome: с 2020
- Safari: 15.4 · март 2022
