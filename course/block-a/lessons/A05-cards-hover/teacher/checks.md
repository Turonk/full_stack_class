# A05 · Checks

## Retrieval
**Q:** Зачем в шапке был `justify-content: space-between`?
**Ожидание:** лого слева, меню справа, края к стенкам.
**Mist:** «не помню» → слайд A04 на 10 секунд, один ответ вслух, дальше.

## Predict (5–15)
**Q:** Только `:hover`, без отклика с клавиатуры. Что увидит человек, который ходит по сайту через Tab?
**Ожидание:** ничего / не поймёт, где он / карточка не поднимается.
**Mist:** «не знаю» → быстрая демонстрация: Tab по ссылке без `:focus-within` на карточке — подъёма нет.

## Checkpoint mid (обязательный)
**A. Tab:** фокус на ссылке внутри карточки; карточка поднимается (`:focus-within`); у ссылки видно кольцо (`:focus-visible`).
**B. 360px:** карточки переносятся, нет горизонтального скролла всей страницы.
**Mist A:** только `:hover` → добавить ссылку внутрь + `.card:focus-within` (или `.tile` на стенде). Если поставили `:focus-visible` на сам `article` — убрать: `article` с Tab не получает фокус.
**Mist B:** фиксированные ширины без wrap → `flex-wrap: wrap` + меньший min-width / `flex: 1 1 …`, повторить в DevTools.

## Pre-showcase spot
Тёмный холст, шапка A04 жива, ≥3 карточки с откликом мыши и Tab, на 360px нет скролла вбок.
**Mist:** карточка без отклика → `:hover` + `:focus-within` + transition на transform/box-shadow.

## Exit
**Q:** Скрин витрины + одно свойство transition назвать вслух.
**Ожидание:** экран без скролла вбок, назван transform или box-shadow.
**Mist:** `transition: all` → переписать на transform + box-shadow и прислать скрин.
