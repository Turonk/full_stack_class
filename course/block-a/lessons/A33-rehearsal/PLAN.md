# Урок 33 · Репетиция: финальные правки

Паспорт защиты. Проект: [MediaGameHub v1](../../projects/06-final/PROJECT.md). После [Showcase MediaGameHub](../A32-showcase-final/PLAN.md).

- Группа ≤10 · 120 минут
- Один концепт: репетиция — проверка чек-листа, не новый код.

## Результат

Каждый ученик проходит полный чек-лист. Все маршруты работают, сервер запускается, README содержит команды. Финальные правки перед защитой.

## Тайминг

| Мин | Фаза | Действие |
| --- | --- | --- |
| 0–10 | Правила | Чек-лист защиты, что проверять |
| 10–50 | You do | Ученик проходит чек-лист, чинит провалы |
| 50–80 | Ревью | Сосед проходит чек-лист по экрану |
| 80–100 | Правка | Только критические провалы |
| 100–110 | Репетиция питча | 2 минуты на каждого |
| 110–120 | Закрытие | Завтра защита. Серверы поднять до вызова |

## Чек-лист защиты

- [ ] Сервер запускается: `flask --app app run --debug`
- [ ] Единая навигация: Hub · Shop · Game · Cart
- [ ] `/catalog` — каталог через `fetch("/api/items")`
- [ ] `/shop` — товары через `fetch("/api/shop")`
- [ ] `/cart` — корзина через `fetch("/api/cart")`
- [ ] `/game` — игра работает, счёт в localStorage
- [ ] `/suggest` — форма добавления карточки
- [ ] `/api/items` — JSON в браузере
- [ ] `/fake` — свой 404
- [ ] CSS-токены: нет жёстких цветов
- [ ] README: команды запуска

## Практика

Пройти чек-лист и чинить только проваленные пункты. Не начинать новую страницу.

Отдельно проверить:
- `/no-such-page`
- `/item/no-such-id`
- форма с пустым названием
- форма с нормальным названием
- исходный код 404: статус 404

## Ошибки

| Симптом | Куда смотреть |
| --- | --- |
| Белый экран на кривом URL | Нет `errorhandler(404)` |
| Красивая страница, но статус 200 | Забыли `, 404` |
| Форма добавляет пустую карточку | Проверка стоит после `append` |

## Домашка · 45–70 мин

Закрыть красные пункты чек-листа. Прислать скрин: `/catalog`, `/shop`, `/game`.

## Мост к A34

Завтра защита блока. Серверы поднять до вызова к экрану.
