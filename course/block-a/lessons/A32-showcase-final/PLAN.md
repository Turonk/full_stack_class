# Урок 32 · Showcase MediaGameHub v1

Паспорт защиты. Проект: [MediaGameHub v1](../../projects/06-final/PROJECT.md). После [CSS-токены](../A31-css-tokens/PLAN.md).

- Группа ≤10 · 120 минут
- Это не новый концепт. Это публичная проверка всего блока: сервер → JS → API → fetch → CSS.

## Результат

Каждый ученик запустил сервер и за ≤6 минут показал: Hub, Shop, Game, API, fetch, CSS. Сосед по рубрике отмечает зачёт или дыру.

## Порядок одного питча

1. Открыть `/` — единая навигация, герой.
2. Показать `/api/items` — JSON в браузере.
3. Открыть `/catalog` — каталог через `fetch`.
4. Открыть `/shop` — товары через `fetch`.
5. Перейти на `/game` — сыграть раунд.
6. Добавить товар в корзину, перейти на `/cart`.
7. Открыть `/fake` — свой 404.

| Критерий | Не зачёт | Зачёт | Сильно |
