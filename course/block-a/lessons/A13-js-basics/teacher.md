## Новая тема

- script defer vs в конце body.
- let/const, не var.
- number, string, boolean.
- function declaration и вызов.
- console.log как рентген, не как продукт.

## Практика в классе

1. app.js + defer.
2. const MAX_LIVES = 3.
3. let score = 0.
4. function addScore(n).
5. Вызвать дважды, логи.

## Частые ошибки 12–14 лет

- script в head без defer — не находит DOM потом.
- Сравнение = вместо ===.
- Боятся консоли.
