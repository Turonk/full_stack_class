# Домашка A08 · 45–70 минут

Завершить перенос всех обложек и медиафайлов своего сайта на сервер Flask.

## Критерии приёмки
- [ ] Сервер запускается по `http://127.0.0.1:5000/`
- [ ] Все картинки карточек перенесены в `static/img/` и открываются без ошибок
- [ ] В HTML нет старых относительных путей `src="src/..."`
- [ ] В консоли DevTools Network отсутствуют ошибки 404

## Формат сдачи
Два скриншота:
1. Главная страница в браузере с адресной строкой `127.0.0.1:5000`.
2. Вкладка DevTools Network со списком запросов (HTML, CSS, картинки) — все со статусом 200.
