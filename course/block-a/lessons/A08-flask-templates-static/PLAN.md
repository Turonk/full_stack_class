# Урок 8 · Шаблоны и статика

Паспорт. Полный пакет (слайды, стенд, стартер) ещё не собран. Проект: [хаб 2.0](../../projects/01b-flask-hub/PROJECT.md). Предыдущий урок: [клиент и сервер](../A06b-flask-client-server/README.md).

- Группа ≤10 · 120 минут
- Один концепт: HTML и CSS лежат в файлах проекта, но браузер получает их только как ответ сервера.

## Результат

Свой сайт спринта 1 открывается на `http://127.0.0.1:5000/`. Видны свой CSS и свои картинки. Рядом на диске страница больше не открывается как «главный способ» смотреть сайт: рабочий адрес — `http://`, не `file://`.

## Не входит

Jinja-циклы, `base.html`, несколько маршрутов сверх `/`, формы, 404. Карточки пока можно оставить скопированными в HTML. Данные вынесутся на уроке 9.

## Теория, которую надо произнести

`render_template` ищет файл только в `templates/`. Функция маршрута возвращает уже собранный HTML. Файл шаблона сам по себе браузер не открывает.

`url_for("static", filename="css/style.css")` строит адрес вида `/static/css/style.css`. Flask отдаёт файл из папки `static/`. Относительный `src/pic.jpg` на вложенном пути ищется не там: браузер прибавляет его к текущему URL. На уроке 8 страница одна, но привычку ставим сразу, до урока 10.

Имя `filename` — путь внутри `static/`, без слова `static` в начале.

## Live-coding на стенде

Код держать коротким. Стенд — не сайт ученика.

```python
from flask import Flask, render_template

app = Flask(__name__)

@app.route("/")
def home():
    return render_template("index.html")
```

В шаблоне:

```html
<link rel="stylesheet" href="{{ url_for('static', filename='css/style.css') }}">
<img src="{{ url_for('static', filename='img/cover.jpg') }}" alt="Обложка стенда">
```

Показать исходник страницы: в атрибутах уже обычные URL `/static/...`, фигурных скобок нет. Потом открыть этот URL отдельно: браузер получает файл.

## Практика ученика

1. Рядом с своим сайтом завести приложение Flask с тем же `requirements.txt`, что на уроке 7.
2. Скопировать свой `index.html` в `templates/index.html`.
3. Скопировать свой CSS в `static/css/style.css`.
4. Картинки — в `static/img/`. В разметке заменить `src="src/..."` и `href="style.css"` на `url_for`.
5. Запустить сервер и открыть только `http://127.0.0.1:5000/`.

Аудио, если оно было, кладётся в `static/music/`, но плеер не чинится: достаточно, чтобы файл открывался по своему URL.

## Если не успевает

Оставить одну страницу, один CSS и одну картинку. Остальные карточки можно временно скрыть. Цель дня — путь через сервер, не полнота каталога.

## Если успевает раньше

Поднять второй маршрут `/about` через второй шаблон. Цикл не начинать.

## Ошибки

| Симптом | Куда смотреть |
| --- | --- |
| `TemplateNotFound` | Файл не в `templates/` или опечатка в имени |
| Страница без стилей | В ссылке нет `url_for`, либо CSS не в `static/css/` |
| Картинка сломана | В `filename` остался старый `src/` или лишний `static/` |
| Открыт красивый старый сайт | Адрес `file://`. Закрыть вкладку и открыть `127.0.0.1:5000` |

## Домашка · 45–70 мин

Добить перенос своих обложек. Прислать скрин `127.0.0.1:5000` и скрин одного адреса `/static/img/...`, где картинка открыта отдельно.
