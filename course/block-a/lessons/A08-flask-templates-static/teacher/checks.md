# A08 Checks · Контрольные точки

## Retrieval
**Q:** Почему большие страницы не возвращают строкой из `return`?  
**Ожидание:** код становится нечитаемым, легко ошибиться в кавычках, нет разделения логики и верстки.  
**Mist:** «потому что Python медленный» -> показать, что дело в поддержке кода разработчиком (Separation of Concerns).

## Checkpoint mid (обязательный)
**Действие:** открыть DevTools -> вкладку Network. Нажать Ctrl+R на главной странице `http://127.0.0.1:5000/`.  
**Q:** Сколько запросов сделал браузер и откуда он взял файл `styles.css`?  
**Ожидание:** браузер сделал несколько HTTP-запросов (HTML + CSS + картинки). Стили получены сервером по URL `/static/css/styles.css`.  
**Mist:** в Network красная строка `404` на CSS -> проверить путь в `url_for('static', filename=...)` и реальное имя файла в `static/css/`.

## Контроль практики (You do)
**Критерий:**
1. Адрес в строке браузера — `http://127.0.0.1:5000/` (не `file://`).
2. Присутствуют фирменные стили и шрифты сайта ученика.
3. Все обложки треков / карточки загрузились без битых иконок.
4. В коде шаблона `index.html` все ссылки на ассеты обернуты в `{{ url_for('static', filename=...) }}`.
