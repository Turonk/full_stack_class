# A08 Deep Notes · Подготовка преподавателя

## Техническая модель урока
В уроке A08 происходит переход от возврата сырого строкового HTML к стандартной архитектуре Flask:
1. `templates/` — шаблоны Jinja2. По умолчанию Flask ищет шаблоны в подпапке `templates` того модуля, где создан `app = Flask(__name__)`.
2. `render_template(template_name)` загружает шаблон, выполняет предварительный парсинг Jinja-тегов и формирует результирующую строку ответа с заголовком `Content-Type: text/html; charset=utf-8`.
3. `static/` — встроенный endpoint статики во Flask. По умолчанию Flask автоматически регистрирует внутренний маршрут `/static/<path:filename>`, который отдаёт файлы из директории `static/`.
4. `url_for('static', filename='...')` генерирует абсолютный URL от корня приложения (например, `/static/css/styles.css`). Это критически важно для предотвращения поломки относительных путей при появлении динамических маршрутов вроде `/item/<item_id>` на уроке 10.

## Типичные ошибки подростков 12–14 лет
| Симптом | Причина | Исправление за 15 секунд |
| --- | --- | --- |
| `TemplateNotFound: index.html` | Папка названа `template` (без s) или лежит не рядом с `app.py` | Переименовать в `templates` и проверить расположение |
| Стили не применились, страница белая | В `<link>` остался старый относительный путь `href="style.css"` или опечатка в пути | Проверить `href="{{ url_for('static', filename='css/styles.css') }}"` |
| Лишнее слово static в filename | Написали `filename='static/css/styles.css'` | Убрать `static/`, аргумент `filename` считается **внутри** папки static |
| Картинка не открывается (404) | Опечатка в регистре или расширении (`.jpg` vs `.png` vs `.jfif`) | Сверить имя файла в `static/img/` символ в символ |
| Двойные скобки видны прямо на сайте | Открыли `index.html` двойным щелчком по `file://` | Закрыть вкладку, открыть `http://127.0.0.1:5000/` |

## Дифференциация темпа
- **Если отстает:** перенести только каркас, `styles.css` и 2 главные картинки. Остальные карточки временно закомментировать в HTML, чтобы успеть проверить связку `render_template + url_for`.
- **Если опережает:** перенести аудиофайлы в `static/music/`, проверить тег `<audio src="{{ url_for('static', filename='music/track.mp3') }}">`, добавить второй маршрут `@app.route("/about")` и шаблон `templates/about.html`.
