# A08 · Задача ученика

Переведи свой сайт из Спринта 1 на сервер Flask: разложи файлы по структуре `templates/` и `static/` и настрой все пути.

## Результат
К концу урока твой сайт открывается по адресу [http://127.0.0.1:5000/](http://127.0.0.1:5000/).
Все твои цвета, шрифты и картинки отображаются корректно.

## Шаги выполнения

1. В папке со своим проектом Flask создай структуру папок:
   - `templates/` — для HTML-страниц
   - `static/css/` — для стилей
   - `static/img/` — для картинок и обложек
2. Перемести свой файл верстки в `templates/index.html`.
3. Перемести файл стилей в `static/css/styles.css`.
4. Скопируй все свои картинки из старой папки `src/` в `static/img/`.
5. В `app.py` импортируй `render_template` и напиши обработчик:
   ```python
   @app.route("/")
   def home():
       return render_template("index.html")
   ```
6. В файле `templates/index.html` замени пути к стилям и картинкам:
   - Стили: `<link rel="stylesheet" href="{{ url_for('static', filename='css/styles.css') }}">`
   - Картинки: `<img src="{{ url_for('static', filename='img/имя_твоей_картинки.расширение') }}" alt="...">`
7. Запусти сервер командой:
   ```powershell
   .\.venv\Scripts\python.exe -m flask --app app run --debug
   ```
8. Открой `http://127.0.0.1:5000/`, открой DevTools (F12) -> Network и убедись, что нет красных статусов 404.

## Готово, когда
- [ ] Адресная строка браузера показывает `http://127.0.0.1:5000/` (не `file://`)
- [ ] Все твои фирменные стили и шрифты применились
- [ ] Все обложки загрузились без ошибок
- [ ] В коде `index.html` все ссылки на ассеты обернуты в `url_for('static', ...)`
