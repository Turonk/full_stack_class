# Урок 34 · Защита блока

Паспорт защиты. Проект: [MediaGameHub v1](../../projects/06-final/PROJECT.md). После [Репетиция](../A33-rehearsal/PLAN.md).

- Группа ≤10 · 120 минут
- Это финал блока A. Публичная проверка всего: сервер → JS → API → fetch → CSS.

## Результат

Каждый ученик запустил сервер и за ≤6 минут показал MediaGameHub v1. Сосед по рубрике отмечает зачёт. Преподаватель не принимает питч с адресом `file://`.

## Тайминг

| Мин | Фаза | Действие |
| --- | --- | --- |
| 0–10 | Правила | Порядок из 7 шагов и рубрика. Серверы поднимаются до вызова |
| 10–70 | Питчи | ≤6 мин × ученик |
| 70–90 | Ревью | Пара проходит чек-лист по экрану соседа |
| 90–110 | Правка | Только провал зачёта |
| 110–120 | Голосование / родители | Последние 45–60 мин можно пускать гостей |

## Порядок одного питча

1. Адресная строка `/` — это ответ сервера.
2. Показать `ITEMS` и `SHOP_ITEMS` в `app.py`.
3. Открыть `/api/items` — JSON в браузере.
4. Открыть `/catalog` — каталог через `fetch`.
5. Открыть `/shop` — товары через `fetch`.
6. Перейти на `/game` — сыграть раунд.
7. Добавить товар в корзину, перейти на `/cart`.
8. Открыть `/fake` — свой 404.

## Рубрика защиты блока

| Критерий | Не зачёт | Зачёт | Сильно |
| --- | --- | --- | --- |
| Запрос | Сайт открыт как `file://` | Все страницы с `127.0.0.1` | Ученик называет метод, путь, обработчик |
| Данные | Карточки в HTML | Список в Python, цикл в каталоге | Может добавить поле и показать в шаблоне |
| Форма | Кнопка ничего не меняет | Валидная карточка появляется, пустая — нет | Объясняет, зачем redirect после POST |
| Ошибка | Чужой путь — белая страница Flask | Свой 404 и на пустой `id` | Ссылка с 404 возвращает на главную |
| Авторство | Тексты стенда | Свои карточки и обложки | Рассказывает, что перенёс со своего сайта спринта 1 |
| API | Нет `/api/` | JSON возвращается, страницы на `fetch` | Может добавить новый endpoint |
| CSS | Жёсткие цвета | `tokens.css`, hover/focus | Адаптив, `prefers-reduced-motion` |

## Что говорит ведущий, если питч буксует

- Сайт открыт с диска — остановить, запустить `flask run`.
- Карточки зашиты в HTML — попросить показать `fetch`. Нет `fetch`: зачёт по API не ставить.
- Форма добавляет пустую карточку — это провал проверки.
- После питча сервер можно оставить включённым до ревью.
