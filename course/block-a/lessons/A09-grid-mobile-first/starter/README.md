Код-блоки стартера и эталона — в [`../teacher/lecture.md`](../teacher/lecture.md) (§8 «Делаешь сам»):

1. Проверить `viewport` meta в `head` — без него телефон «притворится десктопом».
2. `section.tracks` с шестью карточками; `img { max-width: 100%; }`.
3. База: `.tracks` — grid, одна колонка, gap 16px.
4. Медиазапросы **внизу файла**: 720px → 2 колонки, 1200px → 3 колонки.
5. Бейдж: `.cover` — relative, `.badge` — absolute в углу.
