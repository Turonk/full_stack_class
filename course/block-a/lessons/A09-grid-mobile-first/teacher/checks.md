# A09 · Checks (стоп-краны)

## Retrieval (0–5)
**Q1:** Чем sticky отличается от fixed?
**Ожидание:** sticky в потоке, прилипает у края; fixed прибит к окну, перекрывает контент.

**Q2:** Что делает `flex: 1`?
**Ожидание:** зона забирает всё свободное место.

**Q3:** Зачем `padding-bottom` у body после A08?
**Ожидание:** запас — плеер не съедает последнюю карточку.

## Predict (5–15, до кода)
**Q:** Соберёт ли flex сетку 3×2 ровно?
**Ожидание:** нет — flex одна линия, ряды будут неровные; для двух осей — grid.
**Mist:** «соберёт, wrap же есть» → показать на стенде неровный последний ряд, затем grid 3×2.

## Checkpoint mid (55–60, порог 7/10)
**Q1:** Чем grid отличается от flex?
**Ожидание:** grid — две оси (ряды+колонки), flex — одна линия.

**Q2:** Почему медиазапросы пишут после базовых стилей?
**Ожидание:** каскад A07 — при равной силе побеждает нижнее правило; mobile-first добавляет улучшения.

**Mist majority:** возврат на стенд — ползунок ширины, класс предсказывает колонки на 360/720/1200. Не пускать в You do.

## You do · критерий «готово» (65–100)
- [ ] viewport meta на месте
- [ ] 1 → 2 → 3 колонки на 360 / 720 / 1200
- [ ] медиазапросы внизу файла, `min-width`
- [ ] нет горизонтального скролла на 360px
- [ ] бейдж в углу обложки
- [ ] `img { max-width: 100% }`

**Mist «страница уехала вбок»:** «viewport meta есть? Телефон без него притворяется десктопом.»
**Mist «медиазапрос не сработал»:** «Он выше базы? Каскад — перенеси вниз.»
**Mist «бейдж в углу страницы»:** «У `.cover` есть relative? Магниту нужна полка.»

## Gallery (100–110)
**Формат:** DevTools → ползунок 360→1200 вживую + бейдж.
**Mist:** одна колонка всегда → проверить порядок медиазапросов и `min-width`.

## Exit (110–120)
Термин (grid / mobile-first / 1fr) + два скрина (360 и 1200). Прогноз: три свойства иерархии текста. Нет скринов → прислать до следующего урока.
