# Grid — две оси сразу
```css
.tracks {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}
```
flex — очередь в столовой · grid — шахматная доска

---

# Mobile-first
```css
.tracks { grid-template-columns: 1fr; }        /* база — телефон */
@media (min-width: 720px)  { /* 2 колонки */ }
@media (min-width: 1200px) { /* 3 колонки */ }
```
- медиазапросы **внизу** файла — каскад!
- `min-width` = «при расширении добавляем»
- горизонтальный скролл = **баг**

---

# Трюк: сетка-резинка
```css
grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
```
Без медиазапросов: «влезает столько колонок по 220px — столько и строй»

# Бейдж на обложке
