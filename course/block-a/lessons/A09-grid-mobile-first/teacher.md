# Урок A09. Grid и адаптив, mobile-first

> **Ресеквенс:** mobile-first **вместе** с Grid (сначала 1 колонка, потом 2+). `position` — только `relative/absolute/sticky` на плеере/бейдже, не четыре модели за урок. Gates: `teacher/CURRICULUM-GATES.md`.

- Блок: A
- Тип: обычный
- Длительность: 120 минут
- Минипроект: MusicHub
- Практикум (опционально): больше вёрстки, блоки

## Цель урока

Строит сетку треков через grid и медиазапрос от 720px. На 360px — одна колонка. Sticky/absolute — точечно на плеере, без обзора всех scheme position.

## Результат на экране

Телефон: колонка. Планшет: 2 колонки. Десктоп: 3.

## Новая тема

- Mobile-first: база = телефон.
- grid-template-columns repeat(auto-fit, minmax(220px, 1fr)).
- @media (min-width: 720px).
- Viewport meta уже должен быть.

## Практика в классе

1. Сетка карточек grid.
2. База 1 колонка.
3. 720px → 2+.
4. Проверка DevTools device toolbar.
5. Горизонтальный скролл = баг, чиним.

## Частые ошибки 12–14 лет

- max-width медиа вместо min-width при mobile-first.
- Картинка шире экрана без max-width:100%.
- Фиксированная ширина 1200px на body.
