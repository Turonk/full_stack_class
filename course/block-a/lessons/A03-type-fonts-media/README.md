## Как пользоваться

1. Открой [`teacher/lesson.md`](./teacher/lesson.md) — там весь урок сверху вниз: тайминг, реплики, порядок примеров, проверки.
2. Презентация на проектор — готовый `.pptx`. Если хочешь изменить слайды: правь [`generate-slides.py`](./teacher/generate-slides.py) и запусти `python generate-slides.py` (нужен `pip install python-pptx`).
