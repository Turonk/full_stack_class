# A03 · Задача ученика

Добавь **обложку** и наведи порядок в тексте Pulse FM.

**Зачем:** чтобы эфир звучал с интонацией — обложка без «жвачки», заголовок громче подписи.

## Сделай
1. Картинка в квадратной рамке (`width`/`height` или aspect).
2. `object-fit: cover`.
3. `alt` своими словами (не пустой).
4. Заголовок заметно крупнее подписи.

## Готово, когда
- [ ] Обложка не растянута «жвачкой»
- [ ] Понятно, где главный текст
- [ ] Можешь сказать, чем cover отличается от contain
