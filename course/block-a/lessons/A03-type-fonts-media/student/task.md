# A03 · Задача ученика

> Полный ход урока (что и когда рассказывает учитель): [`../teacher/lesson.md`](../teacher/lesson.md)

В карточке трека обложка пока **заглушка** — серый блок с градиентом, нарисованный в CSS. Замени её настоящей картинкой и наведи порядок в тексте.

**Зачем:** обложка — первое, что видят. Растянутая «жвачка» или пустое место превращают эфир в черновик.

## Сделай

1. Вместо `<p class="cover">` (заглушка) вставь настоящую картинку:
   ```html
   <img src="https://picsum.photos/seed/tvoeslovo/400/400" alt="Обложка трека Pixel Tide">
   ```
   Слово в `seed/` можешь заменить на своё — картинка будет своя. Можно и своё фото.
2. Сделай рамку квадратом: в CSS для `.card img` — `width: 100%` и `aspect-ratio: 1` (или `width`/`height` одинаковые на самой картинке).
3. Добавь `object-fit: cover` — картинка заполнит квадрат и не «растянется».
4. `alt` — своими словами, что на обложке. Не «img1» и не пустой.
5. Заголовок трека (`h2`) сделай заметно крупнее подписи исполнителя (`.muted`).

## Готово, когда

- [ ] Вместо заглушки-градиента — настоящая картинка
- [ ] Квадрат: лицо/обложка не сплющены, «жвачки» нет
- [ ] `alt` описывает обложку, а не файл
- [ ] Название трека — самый заметный текст на карточке
- [ ] Можешь объяснить, чем cover отличается от contain

## Не делай

- Не оставляй градиент-заглушку — это черновик
- Не пиши `alt="img"` или пустой `alt`
- Не растягивай картинку через `width`/`height` без `object-fit`
