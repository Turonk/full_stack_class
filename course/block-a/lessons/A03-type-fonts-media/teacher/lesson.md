## 3. Иерархия текста · 10 мин

**Сказать:**

> На карточке три строки одинакового размера — название трека, исполнитель, длительность. Класс: «непонятно, на что смотреть, всё орёт одинаково».
>
> Правило: у карточки один главный смысл. Обычно это название. Оно — крупное и ярче. Подпись — меньше и приглушённее, сероватым цветом. Тогда глаз за секунду находит, что смотреть.

**Спросить:** Что на вашей карточке поставите самым заметным?
**Ждём:** название трека. Если «Слушать» — принять, уточнить: название — смысл, кнопка — действие.

**Сказать:**

> В разметке это честно разнесено: смысл в `h2`, поддержка в `p`. Не путаем — заголовок для смысла, абзац для подписи.

### Схема иерархии

```
Громко  ●  Название трека          ← h2, крупный, яркий
Тише    ○  Исполнитель             ← p, поменьше
Тихо    ·  Длительность 3:14       ← p, приглушённый серый
```

### Пример кода (HTML)

```html
<article class="card">
  <h2>Pixel Tide</h2>
  <p class="muted">Nova Park</p>
  <p class="muted">3:14</p>
</article>
```

### Пример кода (CSS)

```css
h2 { font-size: 1.25rem; color: #f4f1ea; }
.muted { font-size: 0.9rem; color: #9aa3b8; }
```

**Проверка глазами:** `h2` крупнее и ярче, чем `.muted`. Иерархия видна без слов.

### Шаг 4.1 · Подключаем шрифты (5 мин)

Открой [`../demo/index.html`](../demo/index.html). В `head` уже стоят три строки — покажи их.

**Что показать (HTML):**

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=IBM+Plex+Sans:wght@400;600&family=Syne:wght@700&display=swap" rel="stylesheet">
```

**Что сказать:**

> Это как «pip install» для букв — браузер скачает шрифты по ссылке. Первые две строки `preconnect` — заранее поздороваться с сервером шрифтов, чтобы загрузка была быстрее.
>
> Если интернета нет — вёрстка не сломается: браузер возьмёт запасной шрифт `sans-serif`. Курс обязан работать офлайн.

**Что сказать про два семейства:**

> У нас два шрифта с разными ролями. Syne — «плакатный», для заголовков: крупный, заметный, но длинный текст им читать тяжело. IBM Plex Sans — «интерфейсный», для абзацев и кнопок: на нём текст читается легко.

**Что показать (CSS):**

```css
body { font-family: "IBM Plex Sans", sans-serif; }
h1, h2, .badge { font-family: Syne, sans-serif; }
```

**Проверка глазами:** заголовки «звучат» по-другому, чем абзацы.

### Шаг 4.2 · Картинка без правил (5 мин)

Временно убери `object-fit: cover` с `.quest img` (или добавь картинку без него).

**Спросить:** Что с лицом на картинке?
**Ждём:** «растянуто», «как жвачка», «искажено».

**Сказать:**

> Браузер растягивает картинку под рамку, пока ему не скажешь, как себя вести внутри. Это поведение по умолчанию — и оно ломает лица и логотипы.

### Шаг 4.3 · object-fit: cover (5 мин)

**Что показать (CSS):**

```css
.quest img {
  width: 100%;
  aspect-ratio: 1;      /* форма рамки — квадрат, пока файл грузится */
  object-fit: cover;    /* заполнил кадр, края обрезал */
  border-radius: 12px;
  display: block;
}
```

**Что сказать:**

> У `object-fit` три режима:
> - **cover** — заполнить рамку целиком, края можно обрезать, как кроп в фоторедакторе. Пропорции живые, лицо не плывёт.
> - **contain** — показать картинку целиком, по бокам останутся поля.
> - **fill** — растянуть под рамку, как захочется браузеру; логотипы и лица обычно ломаются.

**Что сказать про квадрат:**

> `aspect-ratio: 1` задаёт форму рамки заранее, пока картинка грузится. Вёрстка не прыгает, место под обложку зарезервировано.

### Схема трёх режимов

```
cover                  contain               fill
┌────────────┐        ┌────────────┐        ┌────────────┐
│████████████│        │   ██████   │        │≈≈≈≈≈≈≈≈≈≈≈≈│
│████████████│        │   ██████   │        │≈≈≈≈≈≈≈≈≈≈≈≈│
│████████████│        │   ██████   │        │≈≈≈≈≈≈≈≈≈≈≈≈│
└────────────┘        └────────────┘        └────────────┘
заполнил,             вся картинка,         растянул под
края обрезал          поля по бокам         рамку (обычно ломает)
```

**Почему cover — для обложек:** так живут аватарки Discord и превью YouTube — квадрат всегда плотный.

**Спросить:** Для обложки в квадрате — какой режим и почему?
**Ждём:** cover — заполняет кадр, края можно обрезать, пропорции целы.

### Шаг 4.4 · Переключаем режимы вместе (10 мин)

> Фаза «Делаем вместе». Класс диктует, ты нажимаешь. Не открывай это заранее — сначала слова, потом клик.

**Проверка (после фазы):** каждому — выбрать режим для обложки и объяснить почему. Порог: 7 из 10 верно. Если меньше — повтори переключение ещё раз.

## 5. alt · слова вместо картинки · 10 мин

**Сказать:**

> Интернет моргнул — картинка не загрузилась. На её месте пустота. А человек со скринридером слышит просто «изображение».
>
> `alt` — описание картинки словами на случай, когда картинку не видно. Для обложки: «Обложка трека Pixel Tide».

**Плохо и хорошо:**

```html
<!-- плохо: есть место, нет смысла -->
<img src="oblozhka.jpg" alt="img1">

<!-- хорошо: смысл картинки словами -->
<img src="oblozhka.jpg" alt="Обложка трека Pixel Tide">
```

**Спросить:** Для кого на самом деле пишем `alt`?
**Ждём:** для тех, кто не видит картинку: скринридеры, отвалившийся интернет, поиск.

**Показать в действии:** в DevTools сними галочку с картинки (или сломай `src`) → по `alt` понятно, что там было.

## Типичные ошибки (12–14 лет) · фикс за 15 секунд

| Симптом | Фикс |
| --- | --- |
| `alt="img1"` или пустой | «Опиши обложку одной фразой — это и есть alt» |
| Картинка растянута | Проверить `object-fit` на самом `img`, а не на родителе |
| Вся обложка через `background` | Для контентной обложки — `<img>` с `alt` |
| Syne на абзацах | Вернуть `body` на Plex |

## Вопросы, которые могут задать

- **Почему браузер растягивает по умолчанию?** У `img` два «настоящих» размера, браузер растягивает их под CSS-рамку. `object-fit` говорит, как вести себя внутри рамки.
- **Зачем `aspect-ratio`, если есть cover?** Пока картинка грузится, браузер резервирует квадрат → вёрстка не прыгает.
- **Можно ли обложку через `background`?** Для контента — `<img>`: у него есть `alt`, он часть смысла. `background` — для декора.
- **Почему Syne нельзя на абзацы?** Декоративный гротеск, в длинном тексте устают глаза.

## Шпаргалка · термины одной фразой

| Термин | Одной фразой |
| --- | --- |
| иерархия | главный текст заметнее остальных |
| `object-fit: cover` | заполнил кадр, края обрезал |
| `object-fit: contain` | вся картинка видна, поля по бокам |
| `object-fit: fill` | растянул под рамку (обычно ломает) |
| `aspect-ratio: 1` | форма рамки — квадрат без скачков |
| `alt` | смысл картинки словами |
| `preconnect` | заранее поздороваться с сервером шрифтов |
| Syne | «плакатный» шрифт для заголовков |
| IBM Plex Sans | «интерфейсный» шрифт для текста |
