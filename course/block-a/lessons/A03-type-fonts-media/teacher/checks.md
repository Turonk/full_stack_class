# A03 · Checks

## Retrieval
**Q:** Зачем `alt`?  
**Ожидание:** доступность / если картинка не загрузилась / смысл для скринридера.  
**Mist:** «для SEO только» → принять частично, добавить a11y.

## Checkpoint mid
**Q:** Для обложки трека в квадрате — cover, contain или fill? Почему?  
**Ожидание:** **cover** — рамка заполнена, как в плейлистах; края могут обрезаться.  
**Mist:** fill → показать растянутое лицо; contain → показать поля.

## Spot check alt
Пустой alt на смысловой обложке → попросить одну фразу: «Обложка трека X».

## Exit
Скрин квадратной обложки без искажений.
