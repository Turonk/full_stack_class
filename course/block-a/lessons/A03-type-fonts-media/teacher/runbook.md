## Якоря
- cover = заполнить рамку, края можно обрезать (плейлисты).
- contain = вся картинка видна, возможны поля.
- fill = растянуть (обычно плохо для лиц/обложек).
- Offline: system-ui стек, если Google Fonts недоступен.
