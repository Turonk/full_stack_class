# Урок A21. Корзина: добавить / удалить / сумма

- Блок: A
- Тип: обычный
- Длительность: 120 минут
- Минипроект: MerchShop
- Практикум (опционально): массивы, DOM

## Цель урока

Полный сценарий корзины: qty, удаление строки, сумма.

## Результат на экране

Список позиций, сумма, кнопки +/−/удалить.

Для showcase/защиты: использовать тайминг из `course/templates/showcase.md` или `diploma.md` вместо таблицы выше.

## Новая тема

- Найти товар по id.
- Если есть — qty++ иначе push.
- reduce или цикл для суммы.
- Перерисовка renderCart().

## Практика в классе

1. addToCart(id).
2. removeLine(id).
3. changeQty.
4. render.
5. Пустая корзина — текст «пусто».

## Частые ошибки 12–14 лет

- Дубли строк вместо qty.
- Сумма строкой «199»+«199»=«199199».
- Не вызывают render после изменения.
