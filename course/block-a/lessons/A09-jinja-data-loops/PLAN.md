- Группа ≤10 · 120 минут
- Один концепт: повторяющиеся карточки описываются данными в Python, шаблон рисует их циклом.

## Результат

В `app.py` список `ITEMS` минимум из 6 своих карточек. В шаблоне каталога один блок карточки внутри `{% for item in items %}`. На экране те же обложки, что вчера, но правка `title` в Python меняет страницу без правки HTML.

Поле `id` уже заполняется, даже если ссылка `/item/...` заработает только на уроке 10.

## Не входит

`base.html`, динамический URL, форма, 404. Главная может показывать тот же цикл, что и каталог: отдельный срез `ITEMS[:3]` — необязательный запас для тех, кто раньше.

## Теория

Словарь карточки — контракт из [PROJECT.md](../../projects/01b-flask-hub/PROJECT.md): `id`, `title`, `subtitle`, `meta`, `img`, `blurb`.

`render_template("catalog.html", items=ITEMS)` кладёт список в переменную шаблона `items`. Имя слева — в шаблоне, справа — в Python. Они могут совпадать, на уроке так и делаем.

`{{ item.title }}` подставляет текст и экранирует HTML. `{% for item in items %}` … `{% endfor %}` повторяет блок. `{% if item.meta %}` прячет пустую подпись. Внутри `{% %}` нет `{{ }}`.

## Live-coding

```python
ITEMS = [
    {
        "id": "pixel",
        "title": "Pixel Tide",
        "subtitle": "Nova Park",
        "meta": "3:14",
        "img": "pixel.jpg",
        "blurb": "Карточка стенда, не для копирования.",
    },
]

@app.route("/catalog")
def catalog():
    return render_template("catalog.html", items=ITEMS)
```

```html
{% for item in items %}
<article class="card">
  <img src="{{ url_for('static', filename='img/' ~ item.img) }}" alt="{{ item.title }}">
  <h2>{{ item.title }}</h2>
  <p>{{ item.subtitle }}</p>
  {% if item.meta %}<p>{{ item.meta }}</p>{% endif %}
</article>
{% endfor %}
```

`~` в шаблоне склеивает строки. Показать ошибку нарочно: `filename=item.img` без папки `img/` — картинка 404, и это повод назвать слой «приложение», не «сервер умер».

## Практика

1. Выписать 6 своих карточек в `ITEMS`. `id` — латиница.
2. Оставить в шаблоне один `<article>`.
3. Удалить остальные скопированные карточки.
4. Проверить, что смена `title` в списке видна после обновления.
5. Пустой `meta` у одной карточки не рисует лишний абзац.

## Ошибки

| Симптом | Куда смотреть |
| --- | --- |
| На странице видно `{{ item.title }}` | Файл открыт как `file://` или это не шаблон Flask |
| Цикл молчит | В `render_template` не передали `items`, либо список пуст |
| `UndefinedError` | Опечатка поля: в данных `subtitle`, в шаблоне `sub_title` |
| Картинки пропали после цикла | В `filename` нет `img/` или в данных лежит `src/pic.jpg` |
