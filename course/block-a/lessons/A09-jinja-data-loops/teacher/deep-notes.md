# A09 Deep Notes · Подготовка преподавателя

## Техническая модель урока
В уроке A09 вводится важнейшая концепция архитектуры веб-приложений: отделение данных (Data Model) от представления (Presentation Layer).
1. `Jinja2` — шаблонизатор, компилирующий шаблоны в оптимизированный байткод Python.
2. Автоматическое экранирование (Auto-escaping): по умолчанию Jinja экранирует любые опасные символы (`<`, `>`, `&`, `"`) в переменных `{{ }}`, защищая от XSS-атак.
3. Синтаксис словарей в Python чувствителен к пунктуации: запятая после каждого ключа-значения, двоеточие между ключом и значением, кавычки вокруг строковых ключей.

## Частые ошибки 12–14 лет
| Симптом | Причина | Исправление |
| --- | --- | --- |
| `SyntaxError: invalid syntax` в `app.py` | Забыта запятая между словарями или между полями словаря | Проверить закрывающие фигурные скобки и запятые после них |
| `UndefinedError: 'item' is undefined` | Написали `{% for it in items %}`, а внутри обратились к `{{ item.title }}` | Сверить имя переменной в цикле и в подстановке |
| `{{ }} внутри {% %}` | Написали `{% for item in {{ items }} %}` | Внутри управляющих тегов процента имена пишутся напрямую, без `{{ }}` |
| Цикл не выводит ничего | В вызове `render_template` забыли передать именованный аргумент `items=ITEMS` | Проверить вызов: `render_template("catalog.html", items=ITEMS)` |
| Картинки не загрузились | В поле `img` словаря указан путь `src/pic.jpg` вместо простого имени `pic.jpg` | В словаре указывать только имя файла; папку склеивать в шаблоне: `'img/' ~ item.img` |

## Дифференциация темпа
- **Если отстает:** ограничиться 4 словарями в `ITEMS`. Проверить только ключевые поля: `title`, `subtitle`, `img`.
- **Если опережает:** реализовать на главной странице срез топ-3: `items=ITEMS[:3]`, а на отдельной странице `/catalog` отдавать весь список; добавить условный бейдж `{% if loop.first %}<span class="badge">ТОП-1</span>{% endif %}`.
