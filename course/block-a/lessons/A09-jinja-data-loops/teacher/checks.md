# A09 Checks · Контрольные точки

## Retrieval
**Q:** В какую папку Flask смотрит при `render_template`? Зачем нужен `url_for('static', ...)`?  
**Ожидание:** шаблоны в `templates/`, ассеты в `static/`. `url_for` строит абсолютный путь, защищая от поломки вложенных маршрутов.

## Checkpoint mid (обязательный)
**Q1:** В чем разница между `{{ item.title }}` и `{% for item in items %}`?  
**Ожидание:** двойные фигурные скобки `{{ }}` выводят значение переменной; скобки с процентами `{% %}` выполняют логические конструкции (цикл, условие).  
**Q2:** Что выведет цикл, если список `ITEMS` в Python будет пустым?  
**Ожидание:** ничего не сломается; цикл сделает 0 итераций, контейнер с карточками останется пустым.

## Контроль практики (You do)
**Критерий:**
1. В `app.py` оформлен список `ITEMS` минимум из 6 словарей со всеми полями (`id`, `title`, `subtitle`, `meta`, `img`, `blurb`).
2. В файле каталога остался ровно один тег `<article class="card">` внутри цикла `{% for %}`.
3. Все карточки на экране показывают свои уникальные картинки и заголовки.
4. При изменении поля `title` в `app.py` и обновлении страницы заголовок меняется без изменения HTML.

## Exit ticket
1. Зачем каждой карточке уникальный `id`?
2. Скриншот фрагмента `ITEMS` в `app.py` и результирующего каталога на экране.
