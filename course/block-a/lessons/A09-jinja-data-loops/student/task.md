# A09 · Задача ученика

Вынеси все свои карточки из HTML в список словарей Python и настрой автоматическую отрисовку через цикл Jinja.

## Результат
В `app.py` оформлен список `ITEMS` минимум из 6 твоих карточек.
В шаблоне каталога удалены повторяющиеся теги `<article>`: остался ровно один шаблон карточки внутри цикла `{% for %}`.
На экране видны все твои карточки с их картинками и текстами.

## Шаги выполнения

1. В `app.py` перед маршрутами создай список словарей `ITEMS`:
   ```python
   ITEMS = [
       {
           "id": "латинское-имя-1",
           "title": "Название 1",
           "subtitle": "Автор / игра",
           "meta": "Длительность / год",
           "img": "имя_файла.расширение",
           "blurb": "Короткое описание для карточки",
       },
       # ... добавь минимум 6 карточек
   ]
   ```
2. В маршруте каталога передай список в шаблон:
   ```python
   @app.route("/")
   def home():
       return render_template("catalog.html", items=ITEMS)
   ```
3. В шаблоне каталога найди блок с карточками.
4. Оставь **одну** карточку и оберни её в цикл Jinja:
   ```html
   <div class="row">
     {% for item in items %}
       <article class="card">
         <img class="cover-img" src="{{ url_for('static', filename='img/' ~ item.img) }}" alt="{{ item.title }}">
         <h3>{{ item.title }}</h3>
         <p class="muted">{{ item.subtitle }} · {{ item.meta }}</p>
       </article>
     {% endfor %}
   </div>
   ```
5. Удали все остальные скопированные вручную карточки.
6. Сохрани файлы, обнови страницу и проверь результат.
7. Проверь «магию сервера»: измени одно название прямо в списке `ITEMS` в `app.py` и нажми F5 в браузере.

## Готово, когда
- [ ] В `app.py` описан список `ITEMS` (не менее 6 словарей)
- [ ] В HTML-шаблоне нет дубликатов `<article>`, работает один цикл `{% for %}`
- [ ] Все карточки отображаются со своими картинками и названиями
- [ ] Правка словаря в Python меняет страницу без редактирования HTML
