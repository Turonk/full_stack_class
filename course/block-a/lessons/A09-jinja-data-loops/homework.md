# Домашка A09 · 45–70 минут

Перенести абсолютно все карточки своего сайта Спринта 1 в список `ITEMS` в `app.py`.

## Критерии приёмки
- [ ] В `ITEMS` не менее 6 словарей со всеми полями (`id`, `title`, `subtitle`, `meta`, `img`, `blurb`)
- [ ] Каталог рендерится ровно одним циклом `{% for item in items %}`
- [ ] Все картинки карточек корректно отображаются
- [ ] На странице нет сломанных или пустых тегов благодаря `{% if %}`

## Формат сдачи
1. Скриншот фрагмента кода `ITEMS` в файле `app.py`.
2. Скриншот работающего каталога в браузере.
