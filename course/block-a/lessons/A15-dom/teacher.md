# Урок A15. DOM: найти, изменить, создать элемент

- Блок: A
- Тип: обычный
- Длительность: 120 минут
- Минипроект: PulseBeat
- Практикум (опционально): DOM, элементы страницы

## Цель урока

Выводит счёт на страницу, создаёт кнопки-площадки из массива.

## Результат на экране

Четыре кнопки и span#score.

## Новая тема

- document.querySelector.
- textContent vs innerHTML (не вставляем сырой HTML от игрока).
- createElement, append.
- classList.add.

## Практика в классе

1. #score в HTML.
2. JS пишет score в span.
3. Цикл создаёт кнопки.
4. Контейнер #pads.
5. Без innerHTML для имён.

## Частые ошибки 12–14 лет

- querySelector null — скрипт слишком рано.
- innerHTML в цикле каждую миллисекунду.
