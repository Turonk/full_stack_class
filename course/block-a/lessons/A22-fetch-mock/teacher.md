# Урок A22. fetch и мок-данные каталога

> **Ресеквенс:** fetch только после A20–A21 (локальное состояние + корзина) и рабочего Live Server. Не смешивать с первым знакомством с storage.

- Блок: A
- Тип: обычный
- Длительность: 120 минут
- Минипроект: MerchShop
- Практикум (опционально): запросы к данным на уровне идеи

## Цель урока

Каталог грузится из products.json через fetch, карточки строятся в JS.

## Результат на экране

6 карточек с сервера-файла, без хардкода в HTML.

## Новая тема

- fetch(url).then или async/await база.
- response.ok.
- Создавать карточки из данных.
- Жить через Live Server, не file:// (CORS).

## Практика в классе

1. products.json.
2. fetch.
3. map в карточки.
4. Ошибка загрузки — сообщение.
5. Кнопка «в корзину» с data-id.
