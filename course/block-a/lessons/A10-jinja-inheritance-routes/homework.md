# Домашка A10 · 45–70 минут

1. Создать страницу `about.html`, наследующую `base.html`, с описанием вашей станции и автора.
2. Проверить, что поле `blurb` выводится на детальной странице каждой карточки.
3. Проверить, что все ссылки меню в `base.html` используют `url_for(...)`.

## Критерии приёмки
- [ ] Переход по ссылкам в шапке работает без сбоев
- [ ] Каждая карточка каталога открывает свою страницу `/item/<id>` с уникальным текстом `blurb`
- [ ] Кнопка возврата возвращает в каталог

## Формат сдачи
Два скриншота:
1. Каталог карточек.
2. Детальная страница любой вашей карточки с видимым адресом `/item/...` в адресной строке.
