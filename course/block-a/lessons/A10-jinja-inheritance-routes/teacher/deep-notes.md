# A10 Deep Notes · Подготовка преподавателя

## Техническая модель урока
1. `Шаблонное наследование (Template Inheritance)` — мощнейший инструмент Jinja2, реализующий концепцию Don't Repeat Yourself (DRY) на уровне разметки.
   - `{% extends "parent.html" %}` сообщает парсеру Jinja, что текущий шаблон расширяет родительский. Любой контент вне блоков `{% block %}` в дочернем шаблоне игнорируется!
   - `{% block name %} ... {% endblock %}` определяет область переопределения. В `base.html` блоки могут иметь дефолтный контент или быть пустыми.
2. `Динамические конвертеры URL (URL Variable Converters)`:
   - Синтаксис `<variable_name>` по умолчанию принимает любую строку без слэшей (тип `string`).
   - Имя переменной в маршруте должно строго совпадать с именем аргумента функции-обработчика: `@app.route("/item/<item_id>")` -> `def item_page(item_id):`.
3. `Поиск объекта в памяти`:
   - В спринте 2 мы используем линейный поиск по списку `ITEMS` в памяти процесса: перебор циклом `for it in ITEMS: if it["id"] == item_id: found = it`. Это готовит ребят к понятию первичного ключа (Primary Key) в базах данных.

## Частые ошибки 12–14 лет
| Симптом | Причина | Исправление |
| --- | --- | --- |
| Контент шапки дублируется дважды | В дочернем шаблоне остался старый `<header>`, скопированный из базы | Удалить всё лишнее из дочернего шаблона, оставить только `block content` |
| `TypeError: item_page() missing 1 required positional argument` | В декораторе написали `/item/<id>`, а в функции `def item_page(item_id):` | Уравнять имена: либо везде `id`, либо везде `item_id` |
| `BuildError: Could not build url for endpoint 'item_page'` | В вызове `url_for('item_page')` забыли передать параметр `item_id=item.id` | Дописать именованный аргумент: `url_for('item_page', item_id=item.id)` |
| Пустая страница без стилей | Забыли тег `{% extends "base.html" %}` в начале шаблона | Дописать первой строкой дочернего файла |

## Дифференциация темпа
- **Если отстает:** перевести на наследование только `catalog.html` и сделать простую страницу `item.html`. Страницу `about` отложить на домашку.
- **Если опережает:** добавить динамический блок заголовка вкладки: `{% block title %}{{ item.title }} · Pulse FM{% endblock %}` в `item.html` и `{% block title %}Pulse FM{% endblock %}` в `base.html`.
