# Урок 10 · Общий каркас и страница одной карточки

Паспорт. Полный пакет ещё не собран. Проект: [хаб 2.0](../../projects/01b-flask-hub/PROJECT.md). После [урока 9](../A09-jinja-data-loops/PLAN.md).

- Группа ≤10 · 120 минут
- Один концепт: общая оболочка страниц живёт в `base.html`, а конкретная карточка выбирается параметром URL.

## Результат

`/` , `/catalog` и `/about` показывают одну и ту же шапку. С каталога ссылка ведёт на `/item/<id>`. Существующий `id` открывает одну карточку. Чужой `id` пока можно временно возвращать коротким текстом «нет такой карточки»: свой красивый 404 — урок 12. Навигация уже не копируется в каждый файл.

## Не входит

Форма POST, `flash`, полноценный `@app.errorhandler`. Валидация пустых полей не нужна.

## Теория

`{% extends "base.html" %}` ставится первой строкой дочернего шаблона. `{% block content %}{% endblock %}` в базе — место, куда дочерняя страница подставляет своё. Повторять `<header>` в каждом файле больше не нужно. Блок `title` — по желанию, если группа не тонет: заголовок вкладки.

Параметр маршрута:

```python
@app.route("/item/<item_id>")
def item_page(item_id):
    ...
```

Имя в скобках URL и имя аргумента функции совпадают. Поиск по списку — обычный цикл Python, без базы:

```python
found = None
for item in ITEMS:
    if item["id"] == item_id:
        found = item
        break
if found is None:
    return "Нет такой карточки", 404
return render_template("item.html", item=found)
```

Кортеж `("текст", 404)` уже отдаёт статус. На уроке 12 текст заменится шаблоном. Сегодня важно, что неизвестный id не показывает чужую карточку.

Ссылка в каталоге: `href="{{ url_for('item_page', item_id=item.id) }}"`. Имя функции, не строка пути. Тогда смена пути в декораторе не заставляет искать ссылки по всему проекту.

## Live-coding

1. Вырезать шапку стенда в `templates/base.html`.
2. Подключить CSS в базе один раз.
3. `index.html` и `catalog.html` начинают с `extends`.
4. Добавить маршрут и шаблон одной карточки: картинка, title, subtitle, blurb.
5. В цикле каталога заменить заголовок на ссылку.

## Практика

1. Перенести свою шапку и меню в `base.html`.
2. Подключить к базе главную, каталог и новую `about.html` со своим текстом.
3. Сделать `/item/<item_id>` на своих данных.
4. В меню три ссылки через `url_for`: главная, каталог, об авторе.
5. Проверить два существующих id и один выдуманный.

Главная показывает `items=ITEMS[:3]`. Каталог — весь список. Если срез путает группу, обе страницы получают полный список, срез остаётся домашкой.

## Ошибки

| Симптом | Куда смотреть |
| --- | --- |
| На странице виден текст `{% extends %}` | Снова открыт файл с диска |
| Шапка пропала | В дочернем шаблоне нет `block content` или база без этого блока |
| Ссылка ведёт на `/item/` без id | В `url_for` не передан `item_id` |
| Всегда первая карточка | Сравнение `id` не с аргументом функции, а с зашитой строкой |
| `BuildError` | Имя во `url_for` не совпадает с именем функции |
