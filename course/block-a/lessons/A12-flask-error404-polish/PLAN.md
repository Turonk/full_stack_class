# Урок 12 · Свой 404 и сборка перед защитой

Паспорт. Полный пакет ещё не собран. Проект: [хаб 2.0](../../projects/01b-flask-hub/PROJECT.md). После [урока 11](../A11-flask-forms-post/PLAN.md). Перед [защитой](../A13-showcase-flask-hub/PLAN.md).

- Группа ≤10 · 120 минут
- Один концепт: неизвестный адрес — тоже ответ приложения, и к защите проект проходит один и тот же чек-лист.

## Результат

Несуществующий путь и несуществующий `item_id` открывают `templates/404.html` в своём оформлении, со ссылкой на главную. Статус ответа — 404. Пустая форма по-прежнему не портит список. Меню ведёт на все рабочие страницы. В README ученика записаны команды запуска.

Новых видов страниц не добавляем. День нужен, чтобы уже сделанное пережило чужой URL и завтрашний питч.

## Теория и код

```python
@app.errorhandler(404)
def not_found(_error):
    return render_template("404.html"), 404
```

Запятая перед `404` обязательна: это кортеж «тело, статус». Без неё браузер может получить страницу со статусом 200, и «страница ошибки» соврёт.

Маршрут карточки при пустом поиске вызывает `abort(404)`, чтобы сработал тот же обработчик, а не вторая копия шаблона.

```python
from flask import abort

if found is None:
    abort(404)
```

Шаблон ошибки наследует `base.html`, чтобы шапка не исчезала. Текст свой: «Такого адреса нет» и ссылка `url_for("home")`.

## Практика

Пройти чек-лист проекта и чинить только проваленные пункты. Не начинать новую страницу.

Отдельно проверить:

- `/no-such-page`
- `/item/no-such-id`
- форма с пустым названием
- форма с нормальным названием
- исходный код 404 в инструментах браузера: статус 404

README проекта ученика: как создать `.venv`, поставить Flask, запустить `flask --app app run --debug`, какие адреса открыть.

## Ошибки

| Симптом | Куда смотреть |
| --- | --- |
| Белая страница Flask на кривом URL | Нет `errorhandler` или шаблон не найден, и ошибка случилась внутри обработчика ошибки |
| Красивая страница, но статус 200 | Забыли `, 404` |
| `/item/нет` показывает текст, а `/abc` — шаблон | `abort(404)` не вызывается, маршрут отвечает своей строкой |
| Ссылка «на главную» с 404 ведёт в никуда | Жёсткий `href="/"` можно оставить, но `url_for("home")` надёжнее, если функцию переименуют |

Закрыть красные пункты чек-листа. Прислать скрин своего 404 и список адресов, которые откроет завтра на питче. Сервер перед сном остановить, утром поднять заново и убедиться, что карточки из кода на месте, а добавленные только через форму — нет. Это ожидаемо.
