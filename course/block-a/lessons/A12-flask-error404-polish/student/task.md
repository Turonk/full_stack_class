# A12 · Задача ученика

Сверстай фирменную страницу `404.html`, подключи обработчик ошибок во Flask и подготовь проект к защите по чек-листу.

## Результат
1. Несуществующий адрес (например `/fake-page`) открывает красивый `404.html` со ссылкой на главную.
2. Несуществующий ID карточки (например `/item/fake-id`) вызывает `abort(404)` и открывает ту же страницу ошибки.
3. В DevTools Network статус ответа строго равен `404`.
4. Проект успешно проходит все 5 пунктов чек-листа в [PROJECT.md](../../projects/01b-flask-hub/PROJECT.md).

## Шаги выполнения

1. Создай шаблон `templates/404.html`, наследующий `base.html`:
   ```html
   {% extends "base.html" %}

   {% block content %}
   <section class="hero">
     <h1>404 · Адрес не найден</h1>
     <p class="tagline">Сервер работает отлично, но по этой ссылке ничего нет.</p>
     <a class="btn" href="{{ url_for('home') }}">Вернуться на главную</a>
   </section>
   {% endblock %}
   ```
2. В `app.py` добавь обработчик ошибки 404:
   ```python
   @app.errorhandler(404)
   def page_not_found(error):
       return render_template("404.html"), 404
   ```
3. В маршруте детальной карточки `@app.route("/item/<item_id>")` используй `abort`:
   ```python
   from flask import abort

   # если карточка не найдена в ITEMS:
   if found is None:
       abort(404)
   ```
4. В корне проекта проверь файл `README.md` — там должны быть точные команды запуска сервера.
5. Прогони проект по чек-листу защиты:
   - [ ] Сервер стартует по `http://127.0.0.1:5000/`
   - [ ] Главная и каталог показывают карточки из Python
   - [ ] Работают динамические переходы на карточки по `id`
   - [ ] Форма `/suggest` добавляет новую запись в ротацию
   - [ ] Любой кривой адрес открывает твой `404.html` со статусом 404
6. Проведи 2-минутную репетицию с соседом по парте!

## Готово, когда

- [ ] Кнопка со страницы 404 возвращает на главную
- [ ] Все пункты предзащитного чек-листа выполнены
