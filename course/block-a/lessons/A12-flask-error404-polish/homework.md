# Домашка A12 · 45–70 минут

Финальная подготовка перед завтрашним Showcase.

1. Убедиться, что в файле `README.md` вашего проекта записаны команды запуска:
   ```powershell
   .\.venv\Scripts\python.exe -m flask --app app run --debug
   ```
2. Проверить, что на странице 404 работает кнопка возврата на главную.
3. Проверить отображение сайта на ширине 1200px и 360px (в инструментах разработчика).

## Формат сдачи
Скриншот фирменной страницы 404 в браузере с открытой вкладкой Network, где виден статус ответа `404`.
