# Проблема
Пользователь опечатался в адресе:
`http://127.0.0.1:5000/traks`
- Серая скучная ошибка браузера
- Пользователь думает, что сайт сломан
- Нет кнопки вернуться назад

Решение: фирменная страница 404!

---

# Статус 404 Not Found
404 — это **не** падение сервера!
- Сервер работает идеально
- Запрос успешно принят
- Просто по этому пути нет ресурса

Опытный разработчик всегда оформляет ошибки!

---

# Обработчик ошибок во Flask
Декоратор перехватывает ошибку:

```python
@app.errorhandler(404)
def page_not_found(error):
    return render_template("404.html"), 404
```

Обратите внимание на запятую и цифру **404**!
Без неё сервер отправит статус `200 OK` (ложь)!

---

# Функция abort(404)
На странице отдельной карточки:

```python
from flask import abort

@app.route("/item/<item_id>")
def item_page(item_id):
    found = ...
    if found is None:
        abort(404)  # Мгновенный вызов страницы 404!
    return render_template("item.html", item=found)
```

Единый стиль ошибок по всему сайту!

# Чек-лист предзащиты
1. **Старт:** сервер запускается по `127.0.0.1:5000`
2. **Данные:** карточки выводятся из `ITEMS` в Python
3. **Навигация:** клик по карточке открывает её страницу `/item/<id>`
4. **Форма:** можно добавить новый трек через `/suggest`
5. **Ошибки:** выдуманный URL открывает красивый `404.html`
