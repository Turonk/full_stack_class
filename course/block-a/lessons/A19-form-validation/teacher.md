# Урок A19. Формы и валидация на JS

- Блок: A
- Тип: обычный
- Длительность: 120 минут
- Минипроект: MerchShop
- Практикум (опционально): формы, условия

## Цель урока

Форма заказа не уходит пустой: имя и email проверяются, ошибка на экране.

## Результат на экране

Красные подсказки под полями, кнопка не «молча мёртвая».

## Новая тема

- input.value.trim().
- Простая проверка email через includes('@').
- setCustomValidity или свой span.error.
- submit + preventDefault пока не ок.

## Практика в классе

1. Форма заказа.
2. preventDefault.
3. Проверки.
4. Показать ошибку.
5. Успех: сообщение «заказ принят» (пока без сервера).

## Частые ошибки 12–14 лет

- alert на каждую букву.
- Проверка только CSS :invalid без текста.
- email без @ проходит.
