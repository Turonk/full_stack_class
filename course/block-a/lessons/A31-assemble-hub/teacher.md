# Урок A31. Сборка MediaGameHub на шаблонах

- Блок: A
- Тип: обычный
- Длительность: 120 минут
- Минипроект: Flask-финал
- Практикум (опционально): нет

## Цель урока

Игра и магазин встроены: шаблоны + старый JS. Навигация единая.

## Результат на экране

Портал: музыка, игра PulseBeat, корзина (localStorage ещё ок).

## Новая тема

- Не выкидываем клиентский JS: сервер отдаёт страницу, JS оживляет.
- Идентичные id, которые ждёт скрипт.
- Общий base.

## Практика в классе

1. game.html + script.
2. shop.html + cart js.
3. Прогон трёх сценариев.
4. Баг-лист.
5. README черновик.

## Частые ошибки 12–14 лет

- Два разных css конфликтуют.
- JS ищет #pads, в шаблоне другое имя.
