# Урок A17. Игровой цикл, счёт, CSS-анимация удара

- Блок: A
- Тип: обычный
- Длительность: 120 минут
- Минипроект: PulseBeat
- Практикум (опционально): таймеры на уровне идеи, DOM

## Цель урока

Раунд 30 секунд: случайная площадка вспыхивает, успел кликнуть — очко, нет — жизнь.

## Результат на экране

Таймер, вспышки, game over, рестарт.

## План 120 минут

| Минуты | Блок | Преподаватель | Ученики |
| --- | --- | --- | --- |
| 0–15 | Разогрев и повтор | 3 вопроса по прошлому файлу | Отвечают, открывают проект |
| 15–60 | Live-coding | Одна идея, кодим вслух | Повторяют |
| 60–100 | Практика | Чек-лист, хождение по залу | Шаги практики |
| 100–120 | Демо и домашка | 2–3 показа, критерии | Записывают ДЗ |

Для showcase/защиты: использовать тайминг из `course/templates/showcase.md` или `diploma.md` вместо таблицы выше.

## Новая тема

- setInterval / clearInterval.
- Math.floor random index.
- CSS class is-active + animation.
- Кнопка restart обнуляет state.

## Практика в классе

1. startGame().
2. interval 800ms выбирает pad.
3. hit / miss.
4. timer 30s.
5. restart.

## Частые ошибки 12–14 лет

- Несколько interval параллельно.
- Нет clearInterval.
- Слишком быстрый темп для 12 лет — 800–1000ms.
