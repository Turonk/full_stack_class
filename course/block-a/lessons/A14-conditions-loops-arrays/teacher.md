# Урок A14. Условия, циклы, массивы

- Блок: A
- Тип: обычный
- Длительность: 120 минут
- Минипроект: PulseBeat
- Практикум (опционально): массивы, условия

## Цель урока

Хранит площадки в массиве, циклом рендерит их названия в консоль, if по жизням.

## Результат на экране

В консоли список площадок. if lives===0 → 'game over'.
