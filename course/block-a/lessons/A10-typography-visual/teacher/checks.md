# A10 · Checks (стоп-краны)

## Retrieval (0–5)
**Q1:** Прочитай `repeat(auto-fit, minmax(220px, 1fr))`.
**Ожидание:** столько колонок не уже 220px, сколько влезет; лишнее место поровну.

**Q2:** Mobile-first — это?
**Ожидание:** база — телефон; медиазапросы добавляют улучшения.

**Q3:** Пара свойств для бейджа в углу обложки?
**Ожидание:** `relative` у родителя, `absolute` у бейджа.

## Predict (5–15, живой тест)
**Действие:** засечь 5 секунд — зал ищет название трека в карточке «всё одним размером».
**Ожидание:** большинство не успевает → вывод: иерархии нет.
**Q:** Три ручки иерархии?
**Ожидание:** размер, вес, цвет. Рамка/мигание — не ручки, а крик.

## Checkpoint mid (55–60, порог 7/10)
**Q1:** Назови три ручки иерархии.
**Ожидание:** размер, вес, цвет.

**Q2:** Зачем `line-height: 1.5` на body?
**Ожидание:** воздух между строк; длинный текст не сливается в плиту; норма WCAG.

**Mist majority:** карточка «всё одним размером» на стенде — класс командует, какую ручку крутить. Не пускать в You do.

## You do · критерий «готово» (65–100)
- [ ] два шрифта, роли назначены
- [ ] шкала 1 / 0.9 / 1.6 / 2.4 rem, без «на глаз»
- [ ] `line-height: 1.5`
- [ ] hero на `clamp()`
- [ ] `--radius` + тень на карточках
- [ ] muted читается (контраст ≥ 4.5:1)

**Mist «Syne на абзацах»:** «Диктор анонсов не говорит весь вечер. Абзацы — в Plex.»
**Mist «шрифты не применились»:** кавычки в `"IBM Plex Sans"`, целая строка link, Ctrl+F5.
**Mist «серый на сером»:** WebAIM; «приглушённый ≠ невидимый».

## Gallery (100–110)
**Формат:** зрительный тест — зал ищет название за секунду; открыть `:root`; сузить до 360px.
**Mist:** иерархии нет → не позорим, хвалим порядок в коде, фикс — одна ручка в ДЗ.

## Exit (110–120)
Термин (иерархия / rem / clamp / line-height) + скрин каталога. Прогноз: transition/:hover/transform для «оживления». Нет скрина → прислать до следующего урока.
