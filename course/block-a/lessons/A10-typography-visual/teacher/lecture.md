## 2. Завязка + предсказание · 10 мин

### Сцена и живой тест

**Сказать:**

> Эксперимент на 5 секунд. Смотрим на карточку стенда: название трека, исполнитель, длительность — все три строки одного размера и цвета. Задание: **найди название передачи**. Засекаю.

> …Стоп. Кто нашёл за секунду — у того глаз цепляется за смысл. Кто искал дольше — добро пожаловать в проблему: **всё орёт одинаково**. Если на экране всё одной громкости, глаз не понимает, куда сесть. Как в музыке: одна нота — это не мелодия.

### Предсказание

**Спросить:** Какие три «ручки» помогут сделать главную строку заметнее? Голосуем руками, можно несколько вариантов: размер, цвет, жирность, рамка, мигание.
**Ждём:** размер, цвет/контраст, жирность.

**Сказать:**

> Верно — это три ручки иерархии: **размер**, **вес** (жирность) и **цвет**. Рамка и мигание — не ручки иерархии, это крик «посмотрите сюда!!!». Дизайнеры Netflix и Spotify подбирают размер шрифта так, чтобы вы находили следующую серию за три секунды. Иерархия — не про «красиво», а про **скорость чтения**.

## 3. Показываю · Блок 1: Два шрифта, две роли · 8 мин

> Стенд открыт, Live Server включён. Каждая правка — сначала предсказание класса, потом Enter.

**Сказать:**

> Вы уже подключали шрифты в A03 — вспомнили? Сегодня превращаем это в правило, которое живёт во всём курсе: **два шрифта, две роли**.

```html
<!-- в head -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=IBM+Plex+Sans:wght@400;600&family=Syne:wght@700&display=swap" rel="stylesheet">
```

```css
body { font-family: "IBM Plex Sans", sans-serif; }
h1, h2, h3, .logo { font-family: Syne, sans-serif; }
```

> **Syne** — «плакатный»: крупный, характерный, заметный издалека. Им кричат афиши и заголовки. Читать им длинный текст тяжело — как слушать песню, где все ноты громкие.
> **IBM Plex Sans** — «интерфейсный»: спокойный, ровный, создан, чтобы его читали часами. Абзацы, подписи, кнопки — его территория.

**Аналогия:**

> В озвучке игры есть два голоса: диктор анонсов (яркий, редкий) и голос персонажа, которого слушаешь весь вечер (ровный, не утомляет). Syne — диктор анонсов. Plex — голос персонажа.

**Спросить:** Почему после `Syne` написан `sans-serif`?
**Ждём:** запасной шрифт — если интернет отвалится или Syne не загрузится, браузер возьмёт любой гротеск. Вёрстка не сломается.

**Кадр:** включаю/выключаю строку с Syne — заголовки «звучат» по-другому, текст — тем же голосом.

**Инженерная минутка:**

> Почему два, а не пять? Каждый шрифт — это файл, который качается. Пять шрифтов — сайт грузится дольше, а выглядит как лоскутное одеяло. Правило профессионалов: **один для заголовков, один для текста**. Discord, Spotify, GitHub — живут так же.

## 4. Блок 2: Шкала размеров на `rem` · 7 мин

**Сказать:**

> Теперь размеры. Ошибка новичка — ставить каждый размер «на глаз»: тут 17px, тут 23px, тут 19.5px. Получается не шкала, а каша. Профессионалы заводят **шкалу** — несколько ступеней, и все размеры берут только с них.

```css
h1 { font-size: 2.4rem; }  /* главный заголовок страницы */
h2 { font-size: 1.6rem; }  /* заголовки секций и карточек */
body { font-size: 1rem; }  /* обычный текст */
.muted { font-size: 0.9rem; } /* подписи — тише */
```

> Что за `rem`? Это «размер относительно корневого шрифта браузера». По умолчанию корень — 16px, значит `1rem` = 16px, `2.4rem` ≈ 38px. Зачем не px напрямую? **Доступность:** если человек в настройках браузера увеличил шрифт (плохо видит), `rem` уважит его выбор, а жёсткие px — нет. Плюс шкалу в rem легче держать в голове: 1 — текст, 1.6 — заголовок, 2.4 — главный.

**Аналогия:**

> Шкала — как уровни громкости в плеере: 1, 2, 3, а не «47.3%». Кнопки должны быть понятными.

**Спросить:** Сколько разных размеров в нашем каталоге достаточно?
**Ждём:** 3–4 ступени. Верно: h1, h2, body, muted. Больше — каша.

## 5. Блок 3: Воздух между строк и резиновый заголовок · 6 мин

**Сказать:**

> Размер — половина дела. Вторая половина — **воздух**. Сравните два абзаца на стенде: один с `line-height: 1.2`, другой с `1.6`. Первый — кирпич, второй — дышит.

```css
body { line-height: 1.5; }
```

> `line-height: 1.5` — расстояние между строками в полтора размера шрифта. Норма доступности (WCAG) — не меньше 1.5 для основного текста. Заголовкам можно меньше (1.1–1.2): они короткие, им плотнее — даже лучше.

> А теперь фокус для главного заголовка:

```css
.hero h1 { font-size: clamp(1.8rem, 5vw, 2.4rem); }
```

> `clamp(минимум, резина, максимум)`: размер плавно растёт вместе с шириной экрана (`5vw` — 5% ширины окна), но не падает ниже 1.8rem и не выше 2.4rem. На телефоне заголовок компактный, на проекторе — плакатный. **Без единого медиазапроса.**

**Спросить:** Зачем минимум и максимум, если есть резина?
**Ждём:** чтобы на очень узком экране не стало нечитаемо, а на очень широком — нелепо гигантским. Проверить на стенде: тянем окно — заголовок растёт, но в рамках.

## 6. Блок 4: Контраст — текст видно или не видно · 5 мин

**Сказать:**

> Последняя ручка — цвет. На тёмном фоне легко сделать «красиво», но **невидимо**: серый текст на тёмно-сером фоне. Это не вкус, это баг.

> У доступности есть число: контраст основного текста к фону — не ниже **4.5:1**. Проверяется за десять секунд сервисом WebAIM Contrast Checker: два hex — оценка. Наш `--text` #F4F1EA на `--bg` #0B0F1A — примерно 16:1, отлично. Приглушённый `--muted` #9AA3B8 — около 6:1, проходит. А если взять muted ещё темнее — упадёт ниже нормы, и вечером в тёмной комнате текст поплывёт.

**Кадр:** на стенде делаю `.muted` слишком тёмным — класс видит, что подписи «утонули». Возвращаю — снова читаемо.

**Сказать:**

> Правило: **приглушённый — не значит невидимый**. Muted делает строку тише, а не стирает её. И запомните пару цветов нашего стиля: фон `--bg`, поверхность карточек `--bg-elev`, текст `--text`, подписи `--muted`, акцент `--accent`. Это палитра PulseLab — она одна на весь курс, от MusicHub до финального проекта.

**Минутка визуального стиля:**

> Форма — тоже голос. Скругления и тени у нас не «на глаз», а токенами:

```css
:root { --radius: 20px; }          /* добавляем к переменным A07 */
.card {
  border-radius: var(--radius);
  box-shadow: 0 18px 40px rgba(0, 0, 0, 0.35);
}
```

> Один `--radius` на все карточки, кнопки и бейджи — сайт сразу выглядит **собранным**, как будто его делала студия, а не девять человек в чате.

## 7. Делаем вместе · 20 мин

> Класс диктует — я печатаю на стенде. Порядок строго такой, каждый шаг сначала предсказываем.

1. **Шрифты:** подключаем Syne + Plex (класс помнит A03 — кто назовёт все три строки в head?). Назначаем роли: заголовки — Syne, всё остальное — Plex.
2. **Шкала:** расставляем h1 / h2 / body / muted по ступеням. Класс решает, что в карточке главное — название.
3. **Воздух:** `line-height: 1.5` на body. Сравниваем «до/после» — класс голосует, стало ли легче.
4. **clamp()** на hero-заголовок. Тянем окно — наблюдаем резину.
5. **Контраст:** прогоняем `--text`/`--bg` и `--muted`/`--bg` через WebAIM (или показываю скрин оценки). Добавляем `--radius: 20px` и тень на карточки.

**Реплики-якоря по ходу:**

- «Два шрифта, две роли. Пятый шрифт — лишний рот.»
- «Размеры — только со шкалы: 1 / 0.9 / 1.6 / 2.4.»
- «Текст должен дышать: line-height 1.5.»
- «Приглушённый — не значит невидимый.»

**Checkpoint-вопрос перед переменей (порог 7/10):**

1. Назови три ручки иерархии. — **Размер, вес, цвет.**
2. Зачем `line-height: 1.5` на body? — **Воздух между строк: длинный текст читается, не сливается в плиту.**

Если меньше 7 верно — ещё один круг: показываю карточку «всё одним размером» → класс командует, какую ручку крутить.

## 10. Выход + ДЗ · 10 мин

**Exit ticket (каждому):**

## FAQ — вопросы, которые могут задать

- **А можно другие шрифты?** Можно, но сохрани правило ролей: один плакатный + один интерфейсный. На showcase «свой голос» — плюс, «пять шрифтов» — минус.
- **Что будет без интернета на уроке?** Google Fonts не загрузится — сработает запасной `sans-serif`. Вёрстка не сломается: курс обязан работать офлайн.
- **Чем `rem` отличается от `em`?** `rem` — от корневого шрифта (стабильный), `em` — от родителя (накапливается вложенностью). Для шкалы берём `rem`.
- **Что такое `vw` в clamp?** Viewport width — 1% ширины окна браузера. `5vw` — резина, растёт вместе с экраном.
- **Зачем тень, если фон тёмный?** Тень отделяет карточку от фона — появляется «глубина», поверхность приподнята. Поэтому переменная и называется `--bg-elev` (elevated — приподнятая).
- **Проверяют ли контраст настоящие разработчики?** Да, это часть доступности (a11y). В госпроектах и больших компаниях — обязательные проверки. WebAIM и DevTools (контраст-подсказка в инспекторе цвета) — стандартные инструменты.

| Термин | Одной фразой |
| --- | --- |
