## Реплики-якоря

- «Два шрифта, две роли. Пятый шрифт — лишний рот.»
- «Размеры — только со шкалы: 1 / 0.9 / 1.6 / 2.4.»
- «Текст должен дышать: line-height 1.5.»
- «Приглушённый — не значит невидимый: контраст ≥ 4.5:1.»
- «Один `--radius` на всех — сайт выглядит собранным.»

## Стоп-кран

Checkpoint <7/10 → карточка «всё одним размером» на стенде: класс командует, какую ручку крутить. Только потом You do.
