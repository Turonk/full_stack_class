# Три ручки иерархии
1. Размер
2. Вес (жирность)
3. Цвет (контраст)

Рамка и мигание — не ручки, а крик.
Иерархия = скорость чтения, не «красиво».

# Шкала rem
```css
h1 2.4rem · h2 1.6rem · body 1rem · .muted 0.9rem
body { line-height: 1.5; }
.hero h1 { font-size: clamp(1.8rem, 5vw, 2.4rem); }
```
Ступени, а не «17.5px на глаз».
Текст должен дышать.
