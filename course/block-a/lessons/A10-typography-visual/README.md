**Артефакт дня:** узнаваемый PulseLab: Syne на заголовках + IBM Plex Sans на тексте, шкала rem, `line-height 1.5`, `clamp()`, `--radius` + тень на карточках.
**Один концепт:** читаемость важнее «красивого шрифта»; иерархия — три ручки: размер, вес, цвет.

**Как пользоваться:** открой [`teacher/lecture.md`](./teacher/lecture.md) и иди сверху вниз — тайминг, реплики, код, стартер и эталон внутри одного файла.

**Не путать с A03:** A03 — картинка и подпись в одной карточке (`object-fit`, `alt`); A10 — стиль **всего каталога** (шрифты, шкала, контраст, токены).
**Входной гейт:** A09 (сетка держится). Гейты: [`../../teacher/CURRICULUM-GATES.md`](../../teacher/CURRICULUM-GATES.md) (Sprint 2).
