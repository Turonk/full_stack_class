# Урок 7 · Задача ученика

Сделай страницу, которой нет файлом на рабочем столе.

## Результат

К концу работы у тебя:

1. `http://127.0.0.1:5000/` открывается и показывает ответ функции `home`.
2. `http://127.0.0.1:5000/about` показывает твоё имя и одну фразу про твоё радио.
3. Ты меняешь фразу в `app.py`, обновляешь вкладку и видишь новый текст.

Новый `index.html` не создавай. Свой Pulse FM целиком сюда не переноси.

## Сделай

Стартер: [starter/app.py](./starter/app.py). Окружение на уроке уже может быть включено. Если нет — команды в конце.

1. Запусти сервер из папки `starter` и открой `http://127.0.0.1:5000/`.
2. В `app.py` зарегистрируй маршрут `/about` и добавь функцию-обработчик. Её `return` задаёт тело ответа:

```python
@app.route("/about")
def about():
    return "<h1>Твоё имя</h1><p>Одна фраза про твоё радио.</p>"
```

3. Сохрани файл. Обнови вкладку `http://127.0.0.1:5000/about`.
4. Поменяй фразу на другую, сохрани, обнови ещё раз.

## Готово, когда

- [ ] В адресной строке `127.0.0.1`, не путь к файлу на диске
- [ ] `/` и `/about` отвечают разными текстами
- [ ] На `/about` твоё имя и твоя фраза
- [ ] После правки `return` текст на сайте меняется без нового HTML-файла

## Не делай

- Не копируй весь Pulse FM в этот файл
- Не открывай страницу двойным щелчком по `app.py`
- Не ставь Flask командой `pip` в системный Python, если учитель дал окружение `.venv`

## Если сервер ещё не запускается

Из папки `starter` в PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m flask --app app run --debug
```

Окно не закрывай. Сайт жив, пока жива эта команда.
