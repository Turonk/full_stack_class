# Домашка · урок 7 · 45–70 минут

Сервер у тебя уже запускается. Дома меняется текст, не устройство.

## Сделай

1. В `student/starter/app.py` (или в своей копии) у маршрута `/radio` замени название стенда на имя своей станции и одну свою фразу.
2. Проверь, что `/about` по-прежнему отдаёт твоё имя.
3. Запусти сервер и открой оба адреса.

## Критерии приёмки

- [ ] `http://127.0.0.1:5000/radio` показывает твоё радио, не Night Circuit
- [ ] `http://127.0.0.1:5000/about` показывает твоё имя
- [ ] Оба текста приехали из `return` в `app.py`

## Формат сдачи

Два скрина: адресная строка видна. В сообщении — три команды, которыми ты запускаешь сервер на своём Windows:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m flask --app app run --debug
```

Если команды у тебя другие — пришли свои, рабочие.
