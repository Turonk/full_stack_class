# 04 · Архитектура

**Frontend и backend разделяет HTTP**

- Frontend — клиентская часть в браузере: HTML/CSS, отображение, рендеринг полученного HTML.
- Backend — серверная часть на Python/Flask: принимает запрос, выбирает обработчик, формирует ответ.

Граница ответственности: HTTP-запрос → HTTP-ответ.

# 05 · Адрес запроса

**URL: протокол, хост, порт и путь**

`http://127.0.0.1:5000/radio`

- `http` — протокол передачи.
- `127.0.0.1` — loopback-адрес: этот же компьютер.
- `5000` — порт процесса Flask.
- `/radio` — путь к ресурсу и ключ выбора маршрута.

# 06 · Протокол HTTP

**Запрос задаёт действие, ответ фиксирует результат**

Запрос клиента:

```http
GET /radio HTTP/1.1
Host: 127.0.0.1:5000
```

Ответ сервера:

```http
HTTP/1.1 200 OK
Content-Type: text/html

<h1>Night Circuit</h1>
```

Если маршрута нет, сервер вернёт `404 Not Found`. Это тоже корректный HTTP-ответ.

# 07 · Жизненный цикл запроса

**Один GET проходит пять шагов**

1. Браузер формирует `GET /radio`.
2. Flask принимает запрос на порту `5000`.
3. Маршрут сопоставляет путь `/radio` с обработчиком.
4. Функция выполняет Python-код и возвращает строку.
5. Браузер рендерит HTML из тела ответа.

# 08 · Flask

**Маршрут связывает URL с функцией-обработчиком**

```python
from flask import Flask

app = Flask(__name__)


@app.route("/radio")
def radio():
    return "<h1>Night Circuit</h1>"
```

- `@app.route("/radio")` регистрирует правило URL.
- `radio()` — функция-обработчик для этого пути.
- `return` задаёт тело HTTP-ответа.

# 09 · Тело ответа

**Браузер рендерит тело ответа, а не файл Python**

- `return "PulseLab"` — браузер покажет обычный текст.
- `return "<h1>PulseLab</h1>"` — браузер разберёт HTML и отобразит заголовок.

# 10 · Практический результат

**Три маршрута — три обработчика**

- `/` → `home()` — проверка: сервер запущен и отвечает.
- `/radio` → `radio()` — готовый пример маршрута.
- `/about` → `about()` — самостоятельная реализация: имя и описание станции.

# 14 · Диагностика

**Если страница не открывается, проверяйте по слоям**

1. Среда: Flask установлен в `.venv`, из которого запускается сервер.
2. Процесс: сервер запущен, терминал не закрыт.
3. Сеть: адрес `127.0.0.1`, порт `5000` не занят другим процессом.
4. Приложение: маршрут зарегистрирован, файл сохранён, страница обновлена.

Порядок важен: сначала процесс и адрес, затем код маршрута.
