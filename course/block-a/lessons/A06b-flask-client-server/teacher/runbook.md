## Реплики-якоря

- «`file://` — браузер читает готовый файл. `http://` — программа формирует ответ по запросу».
- «Frontend и backend разделяет HTTP: запрос в одну сторону, ответ в другую».
- «`127.0.0.1` — loopback, `5000` — порт процесса, `/radio` — путь».
- «Маршрут связывает URL с обработчиком. `return` задаёт тело ответа».
- «Flask формирует ответ. Рендеринг выполняет браузер».

## Если контрольная точка не пройдена

Не переходить к лабораторной работе. Вернуться на слайд 07 и на живом стенде выполнить трассировку `GET /radio`: показать URL, правило `@app.route`, функцию и ответ. Затем один ученик повторяет цепочку без подсказок.

## Если окружение не готово

Использовать ветку из deep-notes: установка `.venv` занимает до 15 минут, лабораторная часть сокращается до изменения обработчика `home`. Контрольную точку по жизненному циклу запроса не сокращать.

## Если страница не открывается

Диагностика по слайду 14, строго по слоям:

1. среда `.venv`;
2. процесс сервера;
3. адрес и порт;
4. регистрация маршрута, сохранение файла, обновление страницы.
