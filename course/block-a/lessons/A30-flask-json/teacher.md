## Новая тема

- jsonify.
- fetch('/api/hits').
- JSON vs HTML: два языка ответа.

## Практика в классе

1. Данные hits в python list.
2. /api/hits.
3. fetch + then/await.
4. Нарисовать 3 карточки.
5. Смотреть статус 200.

## Частые ошибки 12–14 лет

- fetch на чужой домен без нужды.
- Шаблон и API расходятся данными — сверяем один источник.
