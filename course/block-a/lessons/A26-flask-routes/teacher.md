# Урок A26. Роуты и несколько страниц

- Блок: A
- Тип: обычный
- Длительность: 120 минут
- Минипроект: Flask-финал
- Практикум (опционально): нет

## Цель урока

Четыре маршрута: дом, музыка, игра, магазин. Пока простой HTML-строкой или render заглушки.

## Результат на экране

Переключение URL руками.

Для showcase/защиты: использовать тайминг из `course/templates/showcase.md` или `diploma.md` вместо таблицы выше.

## Новая тема

- Один app — много route.
- Имена функций уникальны.
- 404 если опечатка в URL.
- url_for позже, сначала явные пути.

## Практика в классе

1. / /music /game /shop.
2. Разный заголовок на каждой.
3. Ссылки <a href> между ними.
4. Сломать URL, увидеть 404 Werkzeug.
5. debug reload.

## Частые ошибки 12–14 лет

- Два route на одну функцию без понимания.
- Windows: путают слэши.
