# A01 · Checks

## Retrieval
**Q:** Сайт — картинка или текст+правила?  
**Ожидание:** текст (HTML) + правила стиля (CSS).  
**Mist:** «это картинка» → открыть F12 Elements, показать теги.

## Predict (до кода)
**Q:** Нет `<link>`, CSS на диске есть. Цвет фона?  
**Ожидание:** белый / дефолт браузера.  
**Mist:** «тёмный, файл же есть» → аналогия с `import`; файл не подключён = не существует для браузера.

## Checkpoint mid (обязательный)
**Действие:** на demo или своём файле удалить `<link>`, **сначала сказать вслух**, потом обновить.  
**Ожидание:** стили пропали; после возврата link — вернулись.  
**Mist majority:** We do ещё раз на проекторе. Не пускать в длинный You do.

## Gallery
**Критерий экрана:** виден баннер, не сырой HTML-текст, кнопка заметна.  
**Mist:** inline `style=""` everywhere → мягко: «один CSS-файл — наша норма курса».

## Exit
Термин своими словами + скрин. Нет скрина → ДЗ = прислать до следующего урока.
