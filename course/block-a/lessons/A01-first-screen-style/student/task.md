# A01 · Задача ученика

Собери баннер **Pulse FM** в папке starter.

**Зачем:** чтобы на экране появился эфир с кнопкой «Слушать», а не белый лист — браузер должен увидеть связь двух файлов.

## Сделай

1. Открой `index.html` и `styles.css`.
2. Подключи стиль через `<link rel="stylesheet" href="styles.css">`.
3. Добавь заголовок радио, короткий слоган, кнопку «Слушать».
4. Тёмный фон, светлый текст. Цвета свои (можно фиолетовый акцент `#7C5CFF`).

## Готово, когда

- [ ] Страница открывается через Live Server
- [ ] Без «белого голого» вида
- [ ] Тексты не скопированы с PulseDeck (Night Circuit)

## Не делай

- Не копируй бренд и тексты со стенда проектора.
- Не клади весь CSS в атрибут `style=""`.
