# Showcase Interactive Hub — рубрика

## Порядок защиты (≤6 минут)

1. Открыть `/` — это ответ сервера.
2. Показать `ITEMS` в `app.py` и `/api/items` — JSON.
3. Открыть `/catalog` — каталог через `fetch`.
4. Перейти на `/game` — сыграть раунд.
5. Обновить страницу — `localStorage` показал рекорд.
6. Открыть `/fake` — свой 404.

## Рубрика

| Критерий | Не зачёт | Зачёт | Сильно |
| --- | --- | --- | --- |
| Сервер | Открыт как `file://` | Все страницы с `127.0.0.1` | Объясняет `jsonify` |
| API | Нет `/api/items` | JSON возвращается, каталог на `fetch` | Может добавить поле |
| Игра | Не запускается | Раунд прошёл, счёт обновляется | `localStorage` сохраняет |
| Связь с Hub | Два разных проекта | Один `app.py` | Единая навигация |
| Авторство | Тексты стенда | Свои карточки, свои вопросы | Рассказывает архитектуру |
