# A06 · Задача ученика (день показа)

**Зачем:** показать свой эфир слушателям — один приём своими словами, без чужого стенда Night Circuit.

## До выхода к экрану
- [ ] Live Server открыт на твоём Pulse FM
- [ ] Hover на карточке работает
- [ ] Выбран **один** CSS-приём для рассказа
- [ ] Знаешь баг недели (даже мелкий)

## На сцене (6 минут)
1. Покажи экран целиком.  
2. Наведи мышь / Tab на карточку.  
3. Открой 10–20 строк CSS и объясни.  
4. Назови баг, который починил.

## После питча
Заполни peer-карточку соседу (что круто / совет / вопрос).  
Сделай **один** фикс по совету до конца урока.
