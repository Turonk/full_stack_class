# Урок A06 · Showcase · Demo Day перед родителями

- Тип: отчётный · 120 минут
- На сцене: **только Pulse FM ученика**
- PulseDeck: до 60 секунд в начале как карта приёмов (не продукт ребёнка)

## Цель

Каждый показывает законченное радио и объясняет **один** CSS-приём своими словами. Тренируем навык демо — такой же рабочий, как flex.

## Тайминг 120 (совпадает с runbook)

| Мин | Фаза | Что |
| --- | --- | --- |
| 0–10 | Правила | Рубрика + структура речи + карта приёмов; опционально 60с demo |
| 10–70 | Питчи | ≤6 мин × ученик; группа ≤10 → ≤60 мин |
| 70–90 | Peer review | Пары по карточке; формула «круто / совет / вопрос» |
| 90–110 | Правки | Один фикс по фидбеку |

## 1. Зачем два проекта были нужны

> Шесть недель мы **учили** на стенде PulseDeck и **собирали** личное радио Pulse FM. Сегодня на сцене только эфир ученика. Чужой Night Circuit вместо своего слогана = чужая работа.

## 2. Карта приёмов (шпаргалка на доске)

| Приём | Где в радио |
| --- | --- |
| Два файла + `link` | `<head>` |
| Box model / padding | `.card` |
| `object-fit: cover` | обложка |
| Flex | шапка `.top` |
| Hover / focus | плитка |

Задача питча — выбрать **один** приём и рассказать про него, не каталог.

## 3. Чек-лист готовности (вход на сцену)

- [ ] Тёмный PulseLab, **фиолетовый** акцент (не зелёный лаунчер)
- [ ] Свои тексты и названия треков
- [ ] Flex-шапка с якорями
- [ ] Баннер + кнопка
- [ ] Три карточки, cover, alt
- [ ] Hover или focus виден
- [ ] `box-sizing: border-box` на месте
- [ ] Проект открывается за ≤15 секунд

Нет интернета: шрифты отвалятся — системный fallback уже в эталоне; не паниковать.

## 4. Карточка речи ученика (раздать / на доске)

1. Покажи шапку → скажи слово **flex**.
2. Покажи карточку → скажи **padding** или **коробка**.
3. Наведи курсор / нажми Tab.
4. Открой CSS на 15 секунд — одно правило.
5. Назови один баг, который чинил.

## 5. Вопросы залу после каждого демо (не допрашивать выступающего)

- Где на этом экране flex, а где просто padding?
- Что будет, если убрать `link`?
- Зачем `object-fit: cover`?

## 6. Рубрика фидбека (без отметок-штрафов)

| Критерий | Смотрим |
| --- | --- |
| Работает | Открылось, якоря, ничего критично не разъехалось |
| PulseLab-вид | Тёмный, кнопка, карточки, не белый лист |
| Понимание | Может указать flex / коробку / cover |
| Рассказ | Уложился во время, не читал файл целиком |
| Своё | Тексты не с PulseDeck |

## 7. Типичные срывы и реакция преподавателя

| Срыв | Что сказать / сделать |
| --- | --- |
| Не та папка / нет стилей | Спокойно помочь открыть; минута не из таймера речи |
| Нет сети, шрифты пали | «Fallback ок, продукт жив» |
| Стыдно выходить | Второй слот после 2–3 смелых; можно показывать с места |
| Принёс Night Circuit | «Это стенд. Покажи свой FM или расскажи, что успел своё» |
| Читает HTML | Мягко: «Вернись на экран браузера, покажи hover» |
