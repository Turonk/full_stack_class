# Урок A06. Showcase · Demo Day перед родителями

- Тип: отчетный · 120 минут
- На сцене: **только Pulse FM ученика**
- PulseDeck: до 5 минут в начале как карта приёмов (не продукт ребёнка)

## Цель

Каждый показывает законченное радио и объясняет **один** CSS-приём своими словами. Тренируем навык демо — такой же рабочий, как flex.

## Зачем два проекта были нужны (сказать залу и родителям коротко)

> Шесть недель мы **учили** на учебном лаунчере PulseDeck и **собирали** личное радио Pulse FM. Сегодня на сцене только эфир ученика. Чужой Night Circuit вместо своего слогана = чужая работа.

---

## 1. Хук и правила · 0–10 мин

**Показать (по желанию):** 60 сек PulseDeck → «вот стенд, на котором тренировались». Сразу убрать.

**Сказать:**

> В студиях и продуктовых командах это называют demo day / sprint review: короткий показ, один риск, вопросы. Не контрольная с двойкой. Таймер **6 минут** на человека.
>
> Структура речи (написать на доске):
> 1. Экран целиком  
> 2. Hover на карточке  
> 3. Один кусок CSS (10–20 строк)  
> 4. Баг недели, который починил  
> Не читать HTML с первой строки.

### Карта приёмов (шпаргалка на доске)

| Приём | Где в радио |
| --- | --- |
| Два файла + `link` | `<head>` |
| Box model / padding | `.card` |
| `object-fit: cover` | обложка |
| Flex | шапка `.top` |
| Hover / focus | плитка |

---

## 2. Индустрия · как устроены демо в IT · 8–10 (вплести в хук)

**Сказать одной минутой:**

> На работе вы не «сдаёте тетрадь» — вы показываете билд живым людям: команде, менеджеру, иногда клиенту. Умение уложиться в время и ответить на вопрос «почему так сделал» ценится рядом с кодом. Code review позже спросит то же: где flex, зачем border-box. Сегодня тренируем мышцу показа.

---

## 3. Чек-лист готовности (вход на сцену)

Преподаватель / ученик отмечают до очереди:

- [ ] Тёмный PulseLab, **фиолетовый** акцент (не зелёный лаунчер)
- [ ] Свои тексты и названия треков
- [ ] Flex-шапка с якорями
- [ ] Баннер + кнопка
- [ ] Три карточки, cover, alt
- [ ] Hover или focus виден
- [ ] `box-sizing: border-box` на месте
- [ ] Проект открывается за ≤15 секунд

Нет интернета: шрифты могут отвалиться — системный fallback уже в эталоне; не паниковать.

## 4. Тайминг Demo Day

| Мин | Блок | Действия преподавателя |
| --- | --- | --- |
| 0–10 | Правила + карта приёмов | Таймер, очередь, DevTools открыть заранее |
| 10–90 | Демо 5–7 мин/чел | Следить за таймером, мягко останавливать на 7:00 |
| 90–110 | Фидбек | Формула: **1 сильно + 1 улучшить**; без «цвет фу» без причины |
| 110–120 | Итог спринта 1 | Аплодисменты; анонс спринта 2: телефон, Grid, sticky-плеер |

Если группа большая: часть демо строго 5 мин; остальные — «экран + один вопрос».

---

## 5. Карточка речи ученика (раздать / на доске)

1. Покажи шапку → скажи слово **flex**.  
2. Покажи карточку → скажи **padding** или **коробка**.  
3. Наведи курсор / нажми Tab.  
4. Открой CSS на 15 секунд — одно правило.  
5. Назови один баг, который чинил.

---

## 6. Вопросы залу после каждого демо (ловушки-повтор)

Преподаватель бросает в зал (не допрашивает выступающего):

- Где на этом экране flex, а где просто padding?  
- Что будет, если убрать `link`?  
- Зачем `object-fit: cover`?

Так закрепляем теорию на чужих работах.

## 7. Рубрика фидбека (без отметок-штрафов)

| Критерий | Смотрим |
| --- | --- |

## 8. Типичные срывы и реакция преподавателя

| Срыв | Что сказать / сделать |
| --- | --- |
| Не та папка / нет стилей | Спокойно помочь открыть; минута не из таймера речи |
| Нет сети, шрифты пали | «Fallback ок, продукт жив» |
| Стыдно выходить | Второй слот после 2–3 смелых; можно показывать с места |
| Принёс Night Circuit | «Это стенд. Покажи свой FM или расскажи, что успел своё» |
| Читает HTML | Мягко: «Вернись на экран браузера, покажи hover» |
