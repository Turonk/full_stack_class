# Домашка после A06 · 30–45 минут

Список из 3 правок по фидбеку, который ты получил на showcase.

## Сделай

- [ ] Запиши 3 правки из фидбеков (своих и peer-карточки)
- [ ] Внеси хотя бы одну правку в код сегодня
- [ ] Убедись, что проект открывается за **15 секунд** (Live Server + одна вкладка)

## Критерии приёмки

- [ ] Три правки записаны (список/чекбокс в тетради или issue)
- [ ] Один фикс уже в коде
- [ ] Проект открывается быстро, без мороки с папками

## Сдать

Скрин радио после фикса (можно «было/стало» одним скрином).

## Если не получилось

Правки можно вести вместе с учителем на следующем уроке в первые 10 минут — это не наказание, а рабочий процесс после демо.
