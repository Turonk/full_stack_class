**Артефакт дня:** ученик пишет JS-скрипт, который считает очки в консоли браузера. Переменные `let/const`, функции, мост с Python — таблица соответствий.  
**Один концепт:** JS — не новый язык, а тот же Python в другой синтаксической обёртке. `let` = `var`, `function` = `def`, `console.log` = `print`.
