## Новая тема

- Браузер просит, сервер отвечает.
- venv, pip install flask.
- app = Flask(__name__), @app.route, return строку/html.
- flask --app app run --debug.
- Это не замена Python, который они знают: это библиотека.

## Практика в классе

1. python -m venv .venv.
2. activate (Windows PowerShell ExecutionPolicy при необходимости).
3. pip install flask.
4. app.py hello.
5. Открыть URL.

## Частые ошибки 12–14 лет

- pip в системный Python, потом «модуля нет».
- Запустили файл, он сразу закрылся — нет app.run и нет flask run.
- Порт занят.
