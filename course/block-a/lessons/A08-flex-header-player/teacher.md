# Урок A08. Flex: шапка, плеер, сетка карточек

- Блок: A
- Тип: обычный
- Длительность: 120 минут
- Минипроект: MusicHub
- Практикум (опционально): блоки, отступы, раскладка

## Цель урока

Кладёт шапку в строку, карточки — в ряд на широком экране через flex.

## Результат на экране

Лого слева, меню справа. Карточки в ряд. Внизу полоска плеера.

## Новая тема

- display:flex, gap, align-items, justify-content.
- flex-wrap.
- Плеер: position sticky bottom.
- Не используем float.

## Практика в классе

1. header flex space-between.
2. .tracks display:flex; wrap.
3. Карточка min-width.
4. .player sticky.
5. Проверка при сужении окна.

## Частые ошибки 12–14 лет

- Забыли flex-wrap — вылезает за экран.
- height:100vh на каждой карточке.
- Плеер перекрывает контент без padding-bottom у main.
