# Предикт (руки)
Плеер всегда виден при прокрутке. Берём:
1. `position: fixed` — прибит к окну
2. `position: sticky` — прилипает у края

---

# Sticky = честный HUD
```css
.player { position: sticky; bottom: 0; }
body { padding-bottom: 88px; }
```
- живёт в потоке
- прилипает у нижнего края
- **прибил панель — дай запас снизу**

---

# Flex-панель: три зоны
`[▶ Play]  [название — flex: 1]  [прогресс — flex: 2]`
- `align-items: center` — по центру высоты
- `gap` — воздух
- `flex-wrap: wrap` — телефон не лопнет
- `min-width: 0` — длинный трек не рвёт панель
