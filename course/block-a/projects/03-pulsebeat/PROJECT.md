# Минипроект 3. PulseBeat — JS-игра

- Спринт: A13–A18
- Showcase: A18
- Стек: HTML + CSS + JS

## История

Игрок ловит «биты», кликая по вспыхивающим площадкам. Счёт растёт, промахи отнимают жизни. Короткий раунд 30 секунд.

## Must-have

- Старт / пауза / рестарт
- Счёт и жизни на экране
- CSS-анимация появления бита
- Клавиатура или мышь
- Конец игры с результатом

## Приёмка

Запустил, набрал очки, проиграл, перезапустил без перезагрузки файла вручную (кнопка рестарт).
