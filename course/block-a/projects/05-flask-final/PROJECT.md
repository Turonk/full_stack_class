# Минипроект 5. Финал блока A — Flask + шаблоны + JS

- Спринт: A25–A34
- Защита: A34
- Стек: Flask, Jinja, CSS, JS

## История

MediaGameHub живёт на сервере. Один layout, страницы: дом, музыка, игра, магазин, «написать нам». Поиск треков идёт на сервер. JS берёт JSON со списком хитов.

## Must-have

- `app.py` с роутами `/`, `/music`, `/game`, `/shop`, `/contact`
- `base.html` + дочерние шаблоны
- Статика CSS/JS
- POST формы контакта + flash
- `/api/hits` JSON и fetch на главной
- README: как создать venv и запустить

## Защита

Демо сценария 5 минут + показ одного шаблона и одного роута.
