# MerchShop на Flask — Спринт 5

- Спринт: A21–A26
- Защита: A26
- Стек: Flask, Jinja, CSS, session, POST
- База: [Interactive Hub](projects/04-interactive-hub/PROJECT.md) (Спринт 4)

## История

Ученик уже имеет рабочий сервер с Hub (каталог карточек, мини-игра, форма, 404). Теперь он **копирует** этот проект и строит на его базе e-commerce: каталог товаров, корзина в `session`, форма заказа с валидацией.

**Важно:** это не переписывание — это клонирование. Ученик копирует `app.py`, `templates/`, `static/` и добавляет новые маршруты. Тот же `base.html`, те же `static/css/style.css`, те же `static/img/`.

## Must-have

### Серверная часть

- Новый маршрут `@app.route("/shop")` — каталог товаров
- Новый маршрут `@app.route("/api/cart")` — JSON корзины
- Новый маршрут `GET /cart` — страница корзины
- Новый маршрут `POST /checkout` — обработка заказа
- `session` для корзины: `session["cart"] = [...]`
- `app.secret_key` для session
- `static/css/shop.css` — стили магазина
- `static/img/shop/` — картинки товаров

### Каталог товаров

- Минимум 6 товаров в `SHOP_ITEMS`
- Каждый товар: `id`, `name`, `price`, `description`, `img`
- Карточки товаров на `/shop` — цикл `{% for item in shop_items %}`
- Кнопка «В корзину» → `POST /api/cart/add`

### Корзина

- `session["cart"]` — список объектов `{id, name, price, qty}`
- `/cart` — страница с таблицей товаров в корзине
- Удаление позиции: `POST /api/cart/remove`
- Сумма заказа
- Пустая корзина — сообщение «Корзина пуста»

### Форма заказа

- Поля: `name`, `email`, `address`
- Валидация: имя не пустое, email содержит `@`
- `POST /checkout` → `flash` с подтверждением
- После успешного заказа — очистка `session["cart"]`

## Маршруты

| Путь | Метод | Что делает |
| --- | --- | --- |
| `GET /` | GET | Главная |
| `GET /catalog` | GET | Каталог карточек |
| `GET /item/<id>` | GET | Карточка |
| `GET /about` | GET | Об авторе |
| `GET /suggest` | GET | Форма добавления |
| `POST /suggest` | POST | Добавление |
| `GET /game` | GET | Мини-игра |
| `GET /api/items` | GET | JSON карточек |
| `GET /shop` | GET | Каталог товаров |
| `POST /api/cart/add` | POST | Добавить в корзину |
| `POST /api/cart/remove` | POST | Удалить из корзины |
| `GET /cart` | GET | Страница корзины |
| `POST /checkout` | POST | Оформление заказа |
| любой другой | — | `404.html` |

## Защита на A26

До 6 минут на ученика.

1. Открыть `/shop` — каталог товаров.
2. Добавить 2 товара в корзину.
3. Перейти на `/cart` — показать таблицу, сумму.
4. Удалить один товар.
5. Оформить заказ — показать flash-подтверждение.
6. Показать, что Hub-маршруты (`/game`) по-прежнему работают.

Оценка по рубрике:

| | Не зачёт | Зачёт | Сильно |
| --- | --- | --- | --- |
| Корзина | Не добавляется | Товары в `session`, сумма считается | Может добавить qty, пересчитать |
| Форма | Не валидируется | Пустое имя → ошибка, `@` в email | Красивые сообщения, не `alert` |
| Связь с Hub | Два отдельных проекта | Один `app.py`, меню навигации | Единый `base.html`, общий `static/` |
| Авторство | Тексты стенда | Свои товары, свои цены | Рассказывает, что скопировал, что добавил |
