# Interactive Hub — Спринт 4

- Спринт: A15–A20
- Защита: A20
- Стек: Flask, Jinja, CSS, JavaScript
- База: [Flask Hub v1](projects/01b-flask-hub/PROJECT.md) (Спринт 3)

## История

Ученик уже имеет рабочий сервер: Pulse FM Hub с каталогом карточек, формой добавления и страницей 404. Теперь к этому же серверу добавляется JavaScript: мини-игра-квиз, которая считает очки в браузере и сохраняет результат в `localStorage`. На A19 каталог карточек начнёт загружаться через `fetch` с нового API-маршрута `/api/items`.

**Важно:** это не новый проект. Ученик открывает **свой же** `app.py` из Спринта 3. Не копирует, не начинает с нуля — добавляет.

## Must-have

### Серверная часть (расширение)

- Новый маршрут `@app.route("/api/items")` — отдаёт `ITEMS` как JSON через `jsonify`
- Новый маршрут `@app.route("/game")` — отдаёт шаблон `game.html` с мини-игрой
- `static/js/game.js` — JS-файл с игрой
- `static/js/api.js` — JS-файл с `fetch` для каталога
- `requirements.txt` содержит `flask`

### Мини-игра (quiz)

- Страница `/game` с HTML-разметкой
- `let score = 0`, `let lives = 3`
- Функция `showQuestion()` — показывает случайный вопрос из массива
- Функция `checkAnswer(selected, correct)` — сравнивает, обновляет счёт
- Кнопка «Рестарт» обнуляет state
- CSS-анимация при правильном/неправильном ответе

### localStorage

- После игры: `localStorage.setItem("hub-score", score)`
- При загрузке `/game`: `localStorage.getItem("hub-score")` — показать последний результат
- Кнопка «Очистить рекорд»

### Каталог без перезагрузки (A19)

- `fetch("/api/items")` получает JSON с сервера
- Функция `renderCatalog(items)` рисует карточки
- Старый цикл `{% for %}` в `catalog.html` заменяется на `fetch` + JS-рендер
- Данные те же — `ITEMS` в `app.py`, но браузер получает JSON

## Маршруты

| Путь | Что делает |
| --- | --- |
| `GET /` | Главная — 3 карточки из `ITEMS` |
| `GET /catalog` | Все карточки (JS-рендер через `fetch`) |
| `GET /item/<id>` | Одна карточка |
| `GET /about` | Текст об авторе |
| `GET /suggest` | Форма добавления |
| `POST /suggest` | Добавление карточки |
| `GET /game` | Мини-игра-квиз |
| `GET /api/items` | JSON: `[{id, title, ...}, ...]` |
| любой другой | `404.html` |

## Данные

Те же `ITEMS`, что в Спринте 3. Минимум 6 карточек.

Для игры — отдельный массив вопросов в `static/js/game.js`:

```javascript
const questions = [
    {
        question: "Какой метод HTTP используется для отправки формы?",
        options: ["GET", "POST", "PUT", "DELETE"],
        correct: 1
    },
    // ещё 4–6 вопросов
];
```

## Критерий «проект готов»

- [ ] Сервер запускается: `flask --app app run --debug`
- [ ] `/` — главная с 3 карточками
- [ ] `/catalog` — каталог загружается через `fetch("/api/items")`, не через `{% for %}`
- [ ] `/game` — игра работает: вопрос → ответ → счёт
- [ ] `localStorage` сохраняет и показывает рекорд
- [ ] Кнопка «Рестарт» обнуляет игру
- [ ] `/suggest` — форма добавляет карточку
- [ ] `/item/fake-id` — свой 404
- [ ] `static/js/game.js` подключён через `<script defer>`
- [ ] README: команды запуска

## Защита на A20

До 6 минут на ученика.

1. Открыть `/` — это ответ сервера.
2. Показать `/api/items` — JSON в браузере.
3. Показать `/catalog` — каталог без `{% for %}`, всё на `fetch`.
4. Перейти на `/game` — сыграть раунд, показать счёт.
5. Обновить страницу — `localStorage` показал рекорд.
6. Открыть `/item/not-real` — свой 404.

Оценка по рубрике:

| | Не зачёт | Зачёт | Сильно |
| --- | --- | --- | --- |
| Сервер | Открыт как `file://` | Все страницы с `127.0.0.1` | Ученик объясняет, что такое `jsonify` |
| API | Нет `/api/items` | JSON возвращается, каталог на `fetch` | Может добавить поле в JSON |
| Игра | Не запускается | Раунд прошёл, счёт обновляется | `localStorage` сохраняет и восстанавливает |
| Связь с Hub | Два разных проекта | Один `app.py`, маршруты вместе | Единая навигация, общий `base.html` |
| Авторство | Тексты стенда | Свои карточки, свои вопросы в игре | Рассказывает, что изменил в своём коде |
