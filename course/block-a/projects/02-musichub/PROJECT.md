# Минипроект 2. MusicHub — адаптив и анимации

- Спринт: A07–A12
- Showcase: A12
- Стек: HTML + CSS
- Берём разметку спринта 1

## Must-have

- Подключение `tokens.css` идейно (свои переменные)
- Шапка на flex, карточки треков, «липкий» плеер-заглушка
- Mobile-first: колонка на 360px, сетка от 720px
- Hover/focus на карточках
- Одна CSS-анимация (эквалайзер или pulse на обложке)
