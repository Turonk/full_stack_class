# Политика Практикума и внешних курсов

## Нельзя

- Сохранять уроки [Практикума](https://practicum.yandex.ru/) (kids-web, frontend-developer и др.) в HTML/MD «для нашего курса».
- Копировать формулировки, задания, персонажей, картинки и сюжеты Практикума в пакеты PulseLab.
- Открывать аккаунт ученика/преподавателя в браузере агенту, чтобы тот «собрал все материалы».

`course/kids-web/` — **референс тона** для автора материалов (короткие абзацы, метафора → правило → код → вопрос). Это не канон и не раздаточный материал группы.

## Можно

- Смотреть бесплатную часть **самому** как самоподготовку (см. таблицу ниже).
- Писать **оригинальную** теорию PulseLab: радио, PulseDeck, Python-мосты, игры.
- Держать у преподавателя файл `teacher/lecture.md` — речь вслух на 15–25 минут теории.

## Самоповтор тем (не копировать задания)

| Наши уроки | Тема для самоповтора руками |
| --- | --- |
| A01–A05 | HTML-каркас, CSS-файл, box model, шрифты, картинки, flex |
| A07–A11 | Переменные, плеер, grid+mobile, тип, motion |
| A13–A17 | JS-мост, DOM, события |
| A19–A23 | Формы, state, storage, fetch |
| A25–A30 | Flask — в Практикуме нет аналога ядра |
