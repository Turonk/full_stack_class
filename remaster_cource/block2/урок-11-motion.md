# Урок 11 · Motion: одна анимация без ряби

**Проект:** MusicHub — пульс бейджа «В эфире» (@keyframes) + уважение к reduced-motion.
**Цель урока:** одна живая анимация на сайте, не укачивающая пользователя; студент объясняет, чем transition отличается от keyframes.

## Тайминг (120 мин)
Повторение 0–5 · Завязка+предсказание 5–15 · Показываю (стенд) 15–40 · Делаем вместе 40–55 · Перемена 55–60 · Делаешь сам 60–100 · Галерея 100–110 · Выход+ДЗ 110–120.

---

## Сценарий

### Повторение (0–5)
> «Три ручки иерархии?» / «Что делает clamp()?»

### Завязка+предсказание (5–15)

**Сказать:**
> «Музыкальный сайт без жизни — просто каталог. Смотрите: бейдж „В эфире" стоит, как приклеенный. А у настоящих радио бейдж „пульсирует" — как сердцебиение. Класс: „давай анимируй всё!"».

**Спросить:** «А что будет, если анимировать всё подряд?»
**Ждём:** «рябит», «глаза устают», «плохо читать».

**Предсказание:**
> «Как сделать, чтобы пользователю, который не выносит анимацию, было тоже хорошо?»
**Ждём:** обычно молчание → подводим: «у системы есть настройка: „уменьшить движение". Сегодня научимся её уважать».

### Показываю на стенде (15–40)

**transition vs @keyframes:**

> «transition — это переход между двумя состояниями (hover → не-hover). @keyframes — сценарий по шагам: можно менять одно и то же свойство несколько раз подряд, зациклить».

```css
@keyframes pulse {
  0%   { box-shadow: 0 0 0 0 rgba(124, 92, 255, 0.6); }
  70%  { box-shadow: 0 0 0 12px rgba(124, 92, 255, 0); }
  100% { box-shadow: 0 0 0 0 rgba(124, 92, 255, 0); }
}

.live-badge {
  animation: pulse 2s infinite;
}
```

> «Три процента времени: 0% — точка, 70% — расширилась и растворилась, 100% — снова точка. infinite — зациклить».

**prefers-reduced-motion:**

```css
@media (prefers-reduced-motion: reduce) {
  .live-badge {
    animation: none;
  }
}
```

> «У людей бывают вестибулярные ограничения: постоянное движение на экране вызывает головокружение или рвоту. Системная настройка „уменьшить движение" существует, и наш код её уважает. Это профессиональный стандарт — а не «фича для вежливых»».

**Правило курса: одна анимация на экран.** Без ряби, без трейлов, без укачивания.

### Делаем вместе (40–55)
Собираем пульс бейджа на PulseDeck. Класс диктует: цвет пульса, скорость. Включаем в системе «уменьшить движение» — бейдж замирает.

### Делаешь сам (60–100)
1. Пульс бейджа через @keyframes (свой цвет акцента).
2. Проверить prefers-reduced-motion.
3. Проверить, что анимация не мешает тексту (не мигает, не трясётся).

Ошибки возраста:
- animation-name забыт в свойстве (указан keyframes, но не подключён);
- слишком быстрая частота (<1s) — раздражает;
- забыт reduced-motion.

### Галерея (100–110)
2–3 пульса: «кто меньше всего укачивает?»

### Выход и ДЗ (110–120)
Термин: «@keyframes — это…». ДЗ: один пульс в своём проекте; бонус — анимация появления карточек при загрузке (fadeIn 0.4s) с той же защитой reduced-motion.
