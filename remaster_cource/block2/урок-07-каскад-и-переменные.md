# Урок 7 · Каскад и переменные: один источник цвета

**Проект:** MusicHub — стартовый скелет с хаосом цветов → лечение через :root.
**Цель урока:** студент понимает специфичность и умеет выносить цвета в :root; страница перекрашивается одной строкой.

## Тайминг (120 мин)
Повторение 0–5 · Завязка+предсказание 5–15 · Показываю (стенд) 15–40 · Делаем вместе 40–55 · Перемена 55–60 · Делаешь сам 60–100 · Галерея 100–110 · Выход+ДЗ 110–120.

---

## Сценарий

### Повторение (0–5)
> «Расскажи о своей защите: что было сильным и что бы улучшил?» (2–3 студента).

### Завязка+предсказание (5–15)

**Сказать:**
> «Вас наняли диджеем PulseLab: „смените акцентный цвет на сайте". Вы открываете код — и находите этот цвет в шести местах: в кнопке, в бейдже, в ссылках, в заголовках, в активной вкладке и в hover. Меняете шесть раз — и где-то забыли. Класс: „цвет на странице, как попугай — влезает всюду"».

**Спросить:** «Что если бы цвет был объявлен один раз, а все эти шесть мест только „ссылалось" на него?»
**Ждём:** «поменял бы в одном месте». Это и есть переменная.

**Предсказание:**
> «Есть правило .nav a { color: #7C5CFF; } и правило a { color: #F4F1EA; }. Какое победит?»
**Ждём:** спор. Правильный: .nav a (специфичность выше: 0-1-1 против 0-0-1).

### Показываю на стенде (15–40)

**Специфичность как «ранги»:**

| Селектор | Ранг | Сила |
|---|---|---|
| p | 0-0-1 | слабая |
| .card | 0-1-0 | средняя |
| #hero | 1-0-0 | сильная |
| style="" | — | почти непобедимая (не используем) |

> «Побеждает не тот, кто крикнул раньше, а тот, у кого выше ранг. При равном ранге побеждает правило ниже в файле. Отсюда правило курса: стилизуем классами. id для стилей почти не используем — его невозможно переопределить».

**Ловушка-предсказание:**
> «Пишу .card .title { color: white; } и .title { color: red; }. Какой цвет у заголовка?»
**Ждём:** белый (.card .title — ранг 0-2-0 против 0-1-0).

**CSS-переменные:**

```css
:root {
  --bg: #0B0F1A;
  --surface: #141A2A;
  --text: #F4F1EA;
  --muted: #9AA3B8;
  --accent: #7C5CFF;
}

body { background: var(--bg); color: var(--text); }
.card { background: var(--surface); }
.btn  { background: var(--accent); }
a:hover { color: var(--accent); }
```

> «:root — самый корень документа. Переменные наследуются всем. Хочешь сменить акцент — меняешь одну строку, а не шесть. Как константа в Python: PY_COLOR = ... один раз, используешь всюду».

**Живой эксперимент:**
> «Смена акцента одной строкой: было фиолетовый #7C5CFF → стал искра #FFC857. Смотрите, как весь сайт перекрасился. Это и есть дизайн-система в миниатюре».

### Делаем вместе (40–55)
Забиваем MusicHub переменными: bg, surface, text, muted, accent. Вставляем классы вместо старых хексов (сразу).

### Делаешь сам (60–100)
1. Перенести :root из Style.md в свой MusicHub.
2. Заменить все цвета на var(...).
3. Задать hover через переменные.
4. Проверка: сменить акцент — весь сайт реагирует.

Ошибки возраста:
- var(--accent) вместо --accent, и наоборот («var» на месте применения, без — на объявлении);
- забыл точку с запятой после последнего свойства;
- var не найден → цвет исчезает (проверка: что покажет браузер — наследуется или дефолт).

### Галерея (100–110)
Смена акцента на глазах у всех: «кто как менялся — у кого сломалось?»

### Выход и ДЗ (110–120)
Термин: «специфичность — это…». ДЗ: довести переменные на своём Pulse FM (его тоже переводим на :root); бонус — добавить третью тему (неоново-зелёная).

## Стартер (MusicHub, хаос цветов)

```html
<!-- стартер/index.html: скелет MusicHub, цвета продублированы -->
<body>
  <header class="top">
    <span class="logo">MusicHub</span>
    <nav>
      <a href="#" class="nav-link">Обзор</a>
      <a href="#" class="nav-link">Обложки</a>
      <a href="#" class="nav-link">Радио</a>
    </nav>
  </header>
  <main>
    <section class="hero">
      <h1>Музыка на любой час</h1>
      <p>Каталог передач и живой эфир станции.</p>
    </section>
    <section class="tracks">
      <!-- TODO: три карточки с обложками (picsum) -->
    </section>
  </main>

```

```css
/* стартер/styles.css: хаос — один цвет в шести местах */
body { background: #0B0F1A; color: #F4F1EA; }
.top { background: #141A2A; padding: 16px; }
.logo { color: #7C5CFF; font-weight: 700; }
.nav-link { color: #F4F1EA; }
.nav-link:hover { color: #7C5CFF; }
.hero h1 { color: #7C5CFF; }
/* ... остальные места с #7C5CFF у студента в коде */
```

## Эталон (после лечения)

```css
:root {
  --bg: #0B0F1A;
  --surface: #141A2A;
  --text: #F4F1EA;
  --muted: #9AA3B8;
  --accent: #7C5CFF;
}

body { background: var(--bg); color: var(--text); }
.top { background: var(--surface); padding: 16px; }
.logo { color: var(--accent); font-weight: 700; }
.nav-link { color: var(--text); }
.nav-link:hover { color: var(--accent); }
.hero h1 { color: var(--accent); }
/* все остальные места — через var(...), ноль магических хексов */
```
