# Урок 10 · Типографика каталога: иерархия, читаемость

**Проект:** MusicHub — читаемая витрина: заголовок крупнее, подписи приглушённее, line-height.
**Цель урока:** страница «читается глазами»: главный элемент найдён за секунду, мелкий текст не вливается в фон.

## Тайминг (120 мин)
Повторение 0–5 · Завязка+предсказание 5–15 · Показываю (стенд) 15–40 · Делаем вместе 40–55 · Перемена 55–60 · Делаешь сам 60–100 · Галерея 100–110 · Выход+ДЗ 110–120.

---

## Сценарий

### Повторение (0–5)
> «Что делает repeat(auto-fit, minmax(260px, 1fr))?» / «Почему mobile-first?»

### Завязка+предсказание (5–15)

**Сказать:**
> «В каталоге три строки текста в карточке одним размером: название, диджей, время. Класс: „всё орёт одинаково". Задача на 5 секунд: найди в этой карточке название передачи».
**Замер времени.** Вывод: «если тебе нужно больше 2 секунд — иерархии нет».

**Предсказание:**
> «Какие три параметра могут подсказать глазу, что главное?»
**Ждём:** размер, цвет (контраст), жирность. Это и есть три ручки иерархии.

### Показываю на стенде (15–40)

**Три ручки:**

```css
.card h3 {
  font-size: 1.25rem;
  font-weight: 700;
  color: var(--text);
}
.card .meta {
  font-size: 0.9rem;
  color: var(--muted);
}
```

> «Мутед — не „серый серый", а цвет с чуть меньшим контрастом. Смысл — он не главное. Если всё яркое — глаз потерялся, если всё тусклое — тоже. Нужна одна главная точка».

**line-height:**

```css
body { line-height: 1.6; }
```

> «Межстрочный интервал 1.6 делает длинный текст читаемым. По норме WCAG 1.5 — минимум для body-текста. Проблема новичка: line-height: 1.2 для всего — текст сливается в плиту».

**clamp():**

```css
h1 { font-size: clamp(2rem, 5vw, 3rem); }
```

> «Плавный размер между 2rem и 3rem в зависимости от ширины экрана: на телефоне 2rem, на десктопе до 3rem. Меньше медиазапросов — меньше веток».

**Контраст (проверка):**
> «Правило доступности: основной текст — контраст не ниже 4.5:1 к фону. Проверяем WebAIM Contrast Checker. Приглушённый текст на тёмном фоне легко уезжает ниже нормы — читайте свои же страницы вечером».

**Дизайн-факт:** «Иерархия — не про „красиво", а про скорость чтения. Дизайнеры Netflix и Spotify подбирают размер шрифта так, чтобы вы находили следующую серию за 3 секунды».

### Делаем вместе (40–55)
Настраиваем иерархию на PulseDeck: класс диктует, что крупнее/приглушённее. Вставляем line-height и clamp.

### Делаешь сам (60–100)
1. Иерархия: h3 крупный и яркий, .meta приглушённый.
2. line-height 1.6 на body.
3. clamp() на заголовке hero.
4. Проверка контраста (WebAIM) — основной текст.

Ошибки возраста:
- всё одним размером → иерархии нет;
- мутед слишком тусклый (контраст ниже нормы);
- line-height 1.2 на абзацах → текст «плита».

### Галерея (100–110)
2–3 работы: «найди главную строку за 3 секунды».

### Выход и ДЗ (110–120)
Термин: «line-height — это…». ДЗ: пройтись clamp() по всем заголовкам, поправить контраст в .meta; бонус — подключить 3-й вес шрифта (font-weight 300) для слогана.
