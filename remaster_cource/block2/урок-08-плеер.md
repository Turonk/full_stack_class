# Урок 8 · Плеер: панель управления внизу

**Проект:** MusicHub — плеер снизу (sticky), flex-панель: play, название, прогресс.
**Цель урока:** плеер прилипает к низу и не перекрывает контент; студент объясняет sticky.

## Тайминг (120 мин)
Повторение 0–5 · Завязка+предсказание 5–15 · Показываю (стенд) 15–40 · Делаем вместе 40–55 · Перемена 55–60 · Делаешь сам 60–100 · Галерея 100–110 · Выход+ДЗ 110–120.

## Сценарий

### Повторение (0–5)
> «Какой ранг у .nav a? Зачем :root?» (по своей карточке из прошлого урока)

### Завязка+предсказание (5–15)

**Сказать:**
> «MusicHub — как Spotify: каталог сверху, плеер снизу. Смотрите, что сейчас: плеер лежит в самом низу страницы — надо скроллить до конца, чтобы нажать Play. Класс: „плеер как в подвале"».

**Предсказание:**
> «Есть позиционирование: relative — сдвиг на месте, absolute — вырваться и привязаться к родителю, fixed — прибит к окну. Что подходит плееру?»
**Ждём:** споры. Варианты:
- fixed — прибит к окну, но перекроет контент внизу страницы;
- sticky — „плывёт" с прокруткой и останавливается у края контейнера. Наш выбор для плеера.

### Показываю на стенде (15–40)

**sticky:**

```css
.player {
  position: sticky;
  bottom: 0;
  display: flex;
  align-items: center;
  gap: 16px;
  padding: 12px 20px;
  background: var(--surface);
  border-top: 1px solid #2A3350;
}
```

> «sticky — это relative, который „прилипает", когда докручиваешь до точки. bottom: 0 — „не отпускай меня вниз экрана". Важно: sticky работает только внутри родителя-контейнера; если родитель короткий — плеер „отпустит"».

**Ошибка возраста:**
> «Плеер перекрыл последнюю карточку каталога — её не докрутить. Решение: у main padding-bottom: 80px. Правило: sticky-элемент занимает своё место в потоке, но надо дать контенту „запас" снизу».

**Flex-панель:**

```css
.player .controls {
  display: flex;
  align-items: center;
  gap: 12px;
}
.player .title {
  flex: 1;              /* название растёт, занимает всё среднее */
  min-width: 0;         /* не даём переполнить строку */
}
.player .progress {
  flex: 2;
  height: 6px;
  background: #2A3350;
  border-radius: 3px;
}
```

> «Классическая раскладка плеера: слева play, в центре название (растёт), справа громкость. flex: 1 у названия — „занимай всё свободное"».

**Аналогия:** «В игровом HUD внизу обычно панель жизни/патронов — она всегда на экране. Наш плеер — тот же HUD для сайта».

### Делаем вместе (40–55)
Собираем панель плеера на PulseDeck: play-кнопка, название «Ночной джаз — 22:00», полоска прогресса. Класс диктует пропорции flex.

### Делаешь сам (60–100)
1. Плеер sticky bottom с поверхностью и границей.
2. Flex-панель: кнопка play (иранж/круг), название (flex:1), громкость.
3. Прогресс-бар: полоса 6px с заливкой 40% (внутренний div).
4. main { padding-bottom: 80px; } — контент не перекрыт.

Ошибки возраста:
- забыт padding-bottom у main;
- flex не на .controls, а на самой кнопке;
- progress 100% вместо 40% (залили всё).
