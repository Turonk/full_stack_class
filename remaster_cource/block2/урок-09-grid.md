# Урок 9 · Grid + mobile-first: каталог передач

**Проект:** MusicHub — каталог обложек: сетка 1 → 2 → 3 колонки.
**Цель урока:** каталог перестраивается при сужении окна; студент объясняет разницу flex/grid и читает repeat(auto-fit, minmax(...)).

## Тайминг (120 мин)
Повторение 0–5 · Завязка+предсказание 5–15 · Показываю (стенд) 15–40 · Делаем вместе 40–55 · Перемена 55–60 · Делаешь сам 60–100 · Галерея 100–110 · Выход+ДЗ 110–120.

---

## Сценарий

### Повторение (0–5)
> «Какая разница между sticky и fixed? Что делает flex: 1?»

### Завязка+предсказание (5–15)

**Сказать:**
> «Каталог MusicHub сейчас: три обложки столбиком. На телефоне — норм. На десктопе — весь экран пустой справа: три столбика выглядят бедно. Класс: „карточек мало, а экран большой"».

**Предсказание:**
> «У нас уже есть flex. Можно ли им сделать сетку 3×2?»
**Ждём:** спор. Flex — одна линия (ряд или колонка), Grid — две оси сразу. Для сетки 3×2 нужен grid.

### Показываю на стенде (15–40)

**Grid:**

```css
.tracks {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}
```

> «1fr — „одна доля свободного места". Три колонки по 1fr делят место поровну. gap работает и по строкам, и по колонкам — не надо два свойства».

**Mobile-first:**

```css
/* база: телефон */
.tracks { display: grid; grid-template-columns: 1fr; gap: 16px; }

/* планшет */
@media (min-width: 768px) {
  .tracks { grid-template-columns: repeat(2, 1fr); }
}

/* десктоп */
@media (min-width: 1200px) {
  .tracks { grid-template-columns: repeat(3, 1fr); }
}
```

> «Mobile-first: сначала стили для узкого экрана, потом медиазапросами ДОБАВЛЯЕМ улучшения для широких. Почему не наоборот? Потому что сузить проще, чем расширить: при desktop-first приходится вычищать лишнее для телефона».

**Брейкпоинты:** 375px (телефон), 768px (планшет), 1200px (десктоп). Это не магические числа, а договорённость команды.

**Автофит (трюк):**

```css
.tracks {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(260px, 1fr));
  gap: 16px;
}
```

> «Читается так: „влезает карточек шириной 260px — столько и строй, а лишнее место делите поровну". Сетка передач сама перестраивается без единого медиазапроса. Но для макета „боковая колонка + контент" медиазапросы всё равно нужны».

**DevTools → режим устройства:** Ctrl+Shift+M, ползунок ширины, список телефонов.

### Делаем вместе (40–55)
Собираем каталог MusicHub: 6 карточек. Прогоняем через брейкпоинты. Класс диктует, где виден перелом.

### Делаешь сам (60–100)
1. Каталог обложек в grid: auto-fit + minmax(260px, 1fr).
2. Прогнать в DevTools: 360, 768, 1200.
3. Сетка карточек диджеев (если в проекте) — так же.

Ошибки возраста:
- media написаны до базовых стилей → на телефоне «пусто»;
- забыли meta viewport → страница уехала вбок;
- auto-fit без minmax → колонки схлопнулись.

### Галерея (100–110)
2–3 каталога: «нажми Ctrl+Shift+M и сузь до 360 — всё живо?»

### Выход и ДЗ (110–120)
Термин: «1fr — это…». ДЗ: каталог передач перестраивается в 3 брейкпоинтах; бонус — сетка 4 колонок от 1400px.
