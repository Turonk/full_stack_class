# Урок 3 · Типографика и обложка трека

**Проект:** Pulse FM — обложка передачи в карточке: квадрат через aspect-ratio, картинка через object-fit, осмысленный alt.
**Цель урока:** обложка не сплющена, у карточки видна иерархия текста, alt говорит по-человечески.

## Тайминг (120 мин)
Повторение 0–5 · Завязка+предсказание 5–15 · Показываю (стенд) 15–40 · Делаем вместе 40–55 · Перемена 55–60 · Делаешь сам 60–100 · Галерея 100–110 · Выход+ДЗ 110–120.

## Сценарий

### Повторение (0–5)
> «Покажи руками: где padding, где margin?» (по своей карточке из прошлого урока).

### Завязка+предсказание (5–15)

**Сказать:**
> «В карточке сверху рамка. Вы вставили фото с телефона — 4000×3000. Браузер натянул его в квадрат 200×200, как наклейку на кривую кружку: логотип сплющен, лицо вытянуто. Класс говорит: „обложка сломана, как жвачка"».

**Спросить:** «Кто виноват — фото или браузер?»
**Ждём:** браузер / никто не задал правило.

**Предсказание:**
> «Есть два режима: cover (заполнить квадрат, обрезав края) и contain (вписать целиком, оставив пустоты). Что выберете для обложки музыкального трека?»
**Ждём:** споры. checkpoint — потом код.

### Показываю на стенде (15–40)

**Сказать:**
> «Обложки в Spotify и Apple Music — квадратные не потому, что дизайнерам было лень. Квадрат — это плотный кадр: он одинаково читается в списке, в мини-плеере и в подкасте. Мы сделаем так же».

```css
.cover {
  width: 100%;
  aspect-ratio: 1 / 1;   /* квадрат, сколько бы колонок ни было */
  object-fit: cover;     /* заполняем, обрезая края */
  border-radius: 8px;
}
```

```html
<img class="cover" src="https://picsum.photos/400/400"
     alt="Обложка передачи: ночной город, неоновые вывески">
```

**alt — не формальность:**
> «alt — то, что скажет скринридер незрячему слушателю. „foto.jpg" — ничего не скажет. „Обложка передачи: ночной город" — скажет. По данным ВОЗ, нарушения зрения имеют более 2,2 млрд человек в мире. Для них alt — это способ услышать вашу страницу».

**Иерархия текста:**
> «Три строки одинакового размера — название, диджей, время — и глаз не понимает, на что смотреть. Всё орёт одинаково. Правило: у карточки один главный смысл — название. Оно крупное и ярче. Подпись — меньше и приглушённее».

```css
.card h3 { font-size: 1.25rem; color: #F4F1EA; }
.card .meta { font-size: 0.9rem; color: #9AA3B8; }
```

**Схема иерархии:**
```
Громко  ●  Название передачи      ← h3
Тише    ○  Диджей                 ← .meta
Тихо    ·  22:00                  ← .meta
```

**Шрифты:**
> «Заголовки — Syne (характерный, „синтвейв"), текст — IBM Plex Sans. Сравните: если все заголовки Syne, а текст Plex — страница начинает звучать как бренд, а не как черновик».

### Делаем вместе (40–55)
Собираем карточку обложки на PulseDeck: класс диктует cover или contain для конкретных фото (портрет → contain, пейзаж → cover). Пишем alt вслух: «Что видишь на картинке? Скажи по-русски одним предложением».

### Делаешь сам (60–100)
Три карточки передач с обложками: картинки picsum (400/400), cover, alt-предложения, иерархия текста (h3 крупнее, meta приглушённее).

Ошибки возраста:
- aspect-ratio забыли → высота скачет от картинки к картинке;
- alt пустой → «представь, что ты слушаешь свою страницу, что ты услышал?»;
- все строки одним размером → «иерархия пропала, глаз потерялся».

### Галерея (100–110)
2–3 карточки: «найди главную строку глазами за 2 секунды».

### Выход и ДЗ (110–120)
Термин: «object-fit: cover — это…». ДЗ: добавить alt на все картинки, подключить пару шрифтов, бонус — тёмная тема обложек (фильтр saturate).
