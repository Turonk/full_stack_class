# Урок 5 · Витрина и состояния: карточки откликаются + ремонтная мастерская

**Проект:** Pulse FM — три карточки треков с hover и focus-visible; вторая половина — полировка перед защитой.
**Цель урока:** карточки откликаются мышью и клавиатурой, плавно (~0.2s), переносятся на узком экране; каждый студент прогоняет свой Pulse FM по чек-листу защиты и знает, что доделать.

## Тайминг (120 мин)
Повторение 0–5 · Завязка+предсказание 5–15 · Показываю (стенд) 15–35 · Делаем вместе 35–50 · Перемена 50–55 · Делаешь сам 55–85 · Ремонтная мастерская 85–110 · Выход+ДЗ 110–120.

---

## Сценарий

### Повторение (0–5)
> «Куда включается flex? Что делает space-between?» (по своей шапке)

### Завязка+предсказание (5–15)

**Сказать:**
> «Три карточки треков. Курсор наезжает — тишина. Класс: „трек без реакции плеера". Мозг ждёт отклик примерно за 200 миллисекунд — не ноль и не полсекунды».

**Предсказание:**
> «Сегодня карточки будут отвечать: мышью и клавиатурой. Без JavaScript: браузер сам знает :hover и :focus. Что должно измениться на карточке при наведении?»
**Ждём:** «подпрыгнет», «подсветится», «тень вырастет».

### Показываю на стенде (15–35)

**Состояния UI:**

```css
.card:hover,
.card:focus-visible {
  transform: translateY(-4px);
  box-shadow: 0 12px 24px rgba(0, 0, 0, 0.35);
}
```

> «У интерактивного элемента есть жизни: обычное, наведение, фокус с клавиатуры, иногда disabled. Если сделали только hover — человек с Tab ходит вслух. Клавиатура — тоже геймпад сайта. :focus-visible — кольцо, когда фокус пришёл с клавиатуры, а не после каждого клика мыши».

**transition без жадности:**

```css
.card {
  transition: transform 0.2s ease, box-shadow 0.2s ease;
}
```

> «transition: all 0.2s кажется удобным, но анимирует всё подряд, иногда тормозит и сюрпризит. Лучше перечислить: transform, box-shadow. 0.15–0.25s — сладкая зона. Полсекунды — уже „плывёт". Ноль — дёргается».

**wrap на 360px:**

```css
.shelf {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}
```

> «Три карточки в ряд с gap красивы на широком. На телефоне 360px они не обязаны давиться в один ряд до горизонтального скролла всей страницы. flex-wrap: wrap — „не влезло — перенеси"».

**Checkpoint:** DevTools → 360px → витрина жива, страница не едет вбок.

### Делаем вместе (35–50)
Собираем на PulseDeck полку из трёх игр: hover + focus + wrap + transition. Класс диктует: «тень мягче», «подъём больше/меньше».

### Делаешь сам (55–85)
Pulse FM: три карточки с hover/focus-visible/transition/wrap.

### Ремонтная мастерская (85–110)

**Сказать:**
> «На следующем уроке — защита перед аудиторией. У каждого есть чек-лист (ниже). Пройдите его по своему проекту. Кто доделал — помогает соседу: парное ревью».

**Чек-лист перед защитой:**
- [ ] Live Server открыт на моём Pulse FM
- [ ] Шапка: лого слева, меню справа (flex)
- [ ] Три карточки: hover, focus-visible, transition ~0.2s
- [ ] Карточки переносятся на 360px (flex-wrap)
- [ ] Обложки: aspect-ratio + object-fit: cover + осмысленный alt
- [ ] Иерархия: заголовок заметно крупнее подписи
- [ ] Классы названы по смыслу (нет .div2, .style1)
- [ ] Могу объяснить любую строку своего CSS

**Парное ревью (15 минут):**
> «Меняемся ноутбуками: прохожу чек-лист соседа, выписываю: что круто / что починить / вопрос „почему так?". Разговор идёт вежливо и по делу — как ревью в команде».

### Выход и ДЗ (110–120)
Термин: «:focus-visible — это…». ДЗ: довести чек-лист до конца; написать 3 реплики своего питча (см. урок 6).
