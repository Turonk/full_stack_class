# Урок 2 · Коробки: карточка трека

**Проект:** Pulse FM — карточка трека с паддингами, рамкой, тенью.
**Цель урока:** на экране — карточка с padding, border-radius, тенью; студент объясняет box model на своей карточке в DevTools.

## Тайминг (120 мин)
Повторение 0–5 · Завязка+предсказание 5–15 · Показываю (стенд) 15–40 · Делаем вместе 40–55 · Перемена 55–60 · Делаешь сам 60–100 · Галерея 100–110 · Выход+ДЗ 110–120.

---

## Сценарий

### Повторение (0–5)
> «Зачем у каждой картинки alt?» / «link — это что? одной фразой».

### Завязка+предсказание (5–15)

**Сказать:**
> «В списке эфира у каждой передачи должна быть карточка — как трек в Spotify. Смотрите, что получается, если просто обернуть текст в div: текст прилип к краям, рамки нет, карточки слиплись. Класс: „это шпаргалка, а не плеер"».

**Спросить:** «Где кончается текст и начинается коробка?»
**Ждём:** непонятно → «потому что у каждого элемента есть невидимая рамка. Сегодня мы её увидим руками».

**Предсказание:**
> «Берем два абзаца: у первого padding: 16px, у второго margin: 16px. Что изменится?»
**Ждём:** почти все путают. Это checkpoint — руки до кода.

### Показываю на стенде (15–40)

**Сказать:**
> «Каждый элемент — коробка. Внутри — контент. Вокруг него — padding: обивка, внутри коробки. Дальше border: сама рамка. Дальше margin: дистанция до соседей, снаружи».

Аналогия: посылка в картонной коробке — зазор между игрушкой и картоном это padding, сама коробка это border, свободное место на полке вокруг коробки это margin.

DevTools: Computed → показать цветные слои (содержимое/паддинг/бордер/маргин).

```css
.card {
  background: #141A2A;
  padding: 20px;           /* обивка */
  border: 1px solid #2A3350;
  border-radius: 12px;     /* углы */
  margin-bottom: 16px;     /* дистанция до соседа */
}
```

**Бомба урока — box-sizing:**

**Сказать:**
> «Ставим карточке width: 300px и padding: 20px. Вопрос: сколько занимает карточка по ширине?»
**Ждём:** большинство скажут 300. Итог: 340px без border-box, 300px с border-box.

> «По умолчанию width — это только контент: паддинги и рамки добавляются сверху. Правило курса, которое ставится в каждый проект первой строкой: * { box-sizing: border-box; }. С ним width = всё вместе».

Факт: до border-box вёрстку считали на калькуляторе — «вычти паддинги из ширины». Это правило как раз спасает от арифметических багов.

**Схлопывание маргинов (30 сек):**
> «Два соседних блока: у одного margin-bottom: 30px, у следующего margin-top: 20px. Между ними будет не 50px, а 30px — берётся больший. Не баг, а модель. Знать — значит не удивляться».

### Делаем вместе (40–55)
Собираем на PulseDeck карточку передачи: обложка-заглушка (градиент), название, время. Класс диктует: «паддинг больше», «тень мягче».

### Делаешь сам (60–100)
Карточка трека на Pulse FM: фон поверхности, радиус 12px, паддинг 20px, отступ между карточками, лёгкая тень.

Ошибки возраста:
- паддинг и маргин перепутаны → «нажми в DevTools на слой, увидишь разницу»;
- тень слишком чёрная → «тень как эфирная подсветка, не как кот ночью»;
- забыли border-box → карточки едет.

### Галерея (100–110)
2–3 карточки на проектор: «найди паддинг этой карточки глазами».

### Выход и ДЗ (110–120)
Термин: «padding — это…». ДЗ: три карточки передач (утро/день/вечер), каждой свои заголовок и время; бонус — тень с прозрачностью.

```css
  background: #141A2A;
  padding: 20px;
  border: 1px solid #2A3350;

  margin-bottom: 16px;
  box-shadow: 0 8px 24px rgba(0, 0, 0, 0.35);
}
```
