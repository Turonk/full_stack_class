# Урок 1 · Первый экран: сайт — это два файла

**Проект:** Pulse FM — радио ученика. **Стенд:** PulseDeck (demo/ из репо).
**Цель урока:** к концу пары на экране тёмный баннер с названием станции, слоганом и кнопкой «Слушать». Два файла связаны link'ом.

## Тайминг (120 мин)
| Фаза | Время | Что происходит |
|---|---|---|
| Повторение | 0–5 | Кто такой браузер? Один вопрос |
| Завязка+предсказание | 5–15 | Сцена «белый лист», предсказание |

## Сценарий

### Повторение (0–5)

**Сказать:**
> «Быстрый вопрос на разминку: когда вы открываете сайт — кто начинает разговор первым, ваш браузер или сервер?»
**Ждём:** браузер. Если тишина — сравнение с кафе: «клиент всегда первым говорит, кухня не приходит сама».

### Завязка+предсказание (5–15)

**Сказать:**
> «Представьте: вы открываете своё радио Pulse FM. На экране белый лист. Заголовка нет. Кнопки „Слушать" нет. Похоже на тетрадку, не на продукт».

**Спросить:** «Что вы скажете про такой экран одной фразой?»
**Ждём:** «пусто» / «не радио» / «где кнопка?»

**Сказать:**
> «Сегодня не учим теги списком. Сегодня собираем первый живой экран: тёмный баннер, слоган, кнопка. К концу урока у каждого на ноуте — эфир, а не черновик.
>
> Стена: учебный лаунчер PulseDeck — Night Circuit, зелёный неон. Это стенд. Его тексты в своё радио не копируем. Уносим приём: два файла и связь между ними».

**Хук:**
> «Кто хоть раз жал F12 в Discord или Steam — просто посмотреть?»
**Ждём:** руки. Если тихо — открыть Elements на секунду.

**Предсказание (главное):**
> «В папке лежат два файла: index.html и styles.css. Экран белый. Вопрос-предсказание: почему? Голосуйте: (а) браузер сломался, (б) файлы не связаны, (в) нужна перезагрузка».
**Ждём:** чаще всего (а) и (в). Правильный ответ — (б): «файл же есть на диске!» — не аргумент. Браузер читает только то, на что есть стрелка.

### Показываю на стенде (15–40)

**Сказать:**
> «HTML — список предметов на сцене: тут заголовок, тут кнопка, тут абзац. CSS — костюмы и свет: цвет, размер, отступы. Браузер — движок: читает оба файла и рисует кадр. Как в игре: есть модели персонажей и есть скин. Вы пишете Python — значит уже умеете разделять данные и отображение. Здесь то же: смысл в HTML, вид в CSS».

Код на стенде, комментируем каждую строку:

```html
<!-- index.html -->
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Волна.FM</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <header class="hero">
    <h1>Волна.FM</h1>
    <p>Музыка, которая работает, пока вы работаете</p>
    <button class="btn">Слушать</button>
  </header>
</body>
</html>
```

**Сказать:**
> «Стрелка между файлами — третья строка сверху: rel="stylesheet" — „это таблица стилей", href="styles.css" — „лежит рядом". Переименуете файл и забудете href — стили „исчезнут", хотя файл на диске цел. Это как забытый import в Python: модуль есть, имени в программе нет».

```css
/* styles.css */
body {
  background: #0B0F1A;
  color: #F4F1EA;
}

.hero {
  padding: 64px 24px;
  text-align: center;
}

.btn {
  background: #7C5CFF;
  color: #fff;
  border: none;
  border-radius: 12px;
  padding: 12px 32px;
  font-size: 16px;
}
```

**Сказать:**
> «Тёмный холст — не потому что „круто", а потому что обложки и неон на светлом фоне орят. Discord и плееры живут в той же логике. Цвет кнопки описан в CSS один раз, а не копирован на три кнопки руками. Завтра смените акцент — правите одно место».

**Checkpoint (10 секунд):**
> «Стиль в styles.css, link в HTML нет. Экран тёмный или белый?» — «Белый». — «Уберём link на стенде — увидим сами».

### Делаем вместе (40–55)
Класс диктует, лектор печатает: свой слоган, свой цвет кнопки. Все реплики — в таблицу переноса.

| Стенд PulseDeck | Радио Pulse FM |
|---|---|
| Night Circuit | название вашей станции |
| «Твоя сцена в ночи» | ваш слоган |
| зелёный акцент | ваш акцент (можно тот же) |
| Play | «Слушать» |

### Делаешь сам (60–100)
Студенты повторяют сборку на своём Pulse FM: два файла, link, фон, h1, слоган, кнопка. Реплика:
> «Критерий „готово": Live Server открыт, фон тёмный, слоган свой, кнопка на месте. Если на экране Night Circuit — это не ваша работа, это стенд».

Ошибки возраста (нормализуем):
- незакрытый тег → «полстраницы стало жирным — так ломается у всех, вот 15 секунд на починку»;
- забытый link → «стилей нет, а файл на месте»;
- кириллица без charset → кракозябры.

### Галерея (100–110)
Три экрана на проектор: что получилось. Одна реплика похвалы + один вопрос.

### Выход и ДЗ (110–120)
Термин своими словами: «link — это…».
ДЗ: добавить раздел «Что в эфире» со списком ul>li; найти 3 сайта радиостанций и выписать их блоки.
