# Аудит курса block-a: Первые 12 уроков

## Executive Summary

Курс block-a — это учебный курс для подростков 12-14 лет по разработке MediaGameHub v1 на Flask-шаблонах. Курс состоит из 34 уроков и разбит на 6 спринтов.

**Текущее состояние первых 12 уроков:**

| Урок | Статус | Качество lecture.md | Полнота пакета |
|------|--------|---------------------|----------------|
| A01 | ✅ Отлично | Полный, литературный стиль, реплики, аналогии с Python | Полный пакет по стандарту |
| A02 | ✅ Отлично | Полный, литературный стиль, аналогия с коробкой, DevTools | Полный пакет по стандарту |
| A03 | ⚠️ Частично | Единый файл `teacher/lesson.md` вместо стандартизированного пакета | Нестандартная структура |
| A04 | ✅ Хорошо | Полный, но немного короче чем A01-A02 | Полный пакет по стандарту |
| A05 | ✅ Хорошо | Полный, но немного короче | Полный пакет по стандарту |
| A06 | ⚠️ Showcase | README только как hub, lecture.md есть | Пакет showcase |
| A07-A12 | ❌ Критично | Только `teacher.md` — сухие выжимки, нет lecture.md | Неполный пакет |

## Детальный анализ по спринтам

### Спринт 1 (A01-A06): Два контура

#### A01: Первый экран и стиль ✅
**Сильные стороны:**
- Полный lecture.md с литературным стилем
- Чёткая структура: Открытие → 5 блоков → Мосты → Шпаргалка
- Реплики "Сказать/Спросить/Ждём" — можно читать почти дословно
- Аналогии с Python (`import` ≈ `<link>`)
- Хорошие аналогии для подростков (скин, сцена, движок)
- Шпаргалка терминов с односложными определениями

**Слабые стороны:**
- Можно добавить больше визуальных схем (Mermaid)
- Нет явного чек-понимания в конце (как в remaster_cource)

#### A02: Box Model ✅
**Сильные стороны:**
- Отличная аналогия с коробкой (content=podушка, padding=ковёр, margin=улица)
- Чёткое объяснение 300 vs 344 пикселей
- DevTools как "рентген", не чит
- Хорошая шпаргалка терминов

**Слабые стороны:**
- Можно добавить больше реплик-якорей в runbook

#### A03: Типографика и медиа ⚠️
**Проблема:**
- Использует устаревший формат `teacher/lesson.md` вместо стандартизированного пакета
- Фактически это самый полный урок по структуре (есть тайминг, схема проблем, примеры кода)
- Но не соответствует `LESSON-PACKET-STANDARD.md`

**Рекомендация:**
- Разделить на стандартные файлы: `lecture.md`, `runbook.md`, `slides.md`, `deep-notes.md`, `checks.md`

#### A04: Flex header ✅
**Сильные стороны:**
- Хорошая структура
- Аналогия с HUD в игре
- Чёткое объяснение осей flex

**Слабые стороны:**
- Короткий (всего ~15 минут контента вместо ~45)
- Можно добавить больше интерактива

#### A05: Карточки и состояния ✅
**Сильные стороны:**
- Хорошее объяснение hover/focus-visible
- Акцент на доступность
- Объяснение transition без `all`

**Слабые стороны:**
- Аналогично A04 — короткий

#### A06: Showcase Pulse FM ⚠️
**Статус:**
- Showcase-день, структура отличается от обычных уроков
- README как hub — соответствует стандарту
- Нужна проверка содержимого teacher файлов

### Спринт 2 (A07-A12): MusicHub

#### КРИТИЧЕСКАЯ ПРОБЛЕМА: A07-A12

Все уроки Спринта 2 имеют **только `teacher.md`** — это сухие выжимки без литературного стиля.

**A07: CSS Cascade + Variables**
```markdown
## Цель урока
Подключает CSS-файл, задаёт :root переменные PulseLab, красит body и header.

## Результат на экране
Тёмный фон, светлый текст, фиолетовый акцент на ссылках.

## План 120 минут
| Минуты | Блок | Преподаватель | Ученики |
| 0–15 | Разогрев и повтор | 3 вопроса по прошлому файлу | Отвечают, открывают проект |
| 15–60 | Live-coding | Одна идея, кодим вслух | Повторяют |
...
```

**Проблемы:**
1. Нет `lecture.md` — преподавателю нечего рассказывать вслух
2. Нет сценария, реплик "Сказать/Спросить"
3. Нет аналогий с миром подростков
4. Нет метафор и хуков
5. Нет шпаргалки терминов
6. План 120 минут шаблонный — нет детализации по минутам
7. "Одна идея, кодим вслух" — это не инструкция, а намёк

**A08: Flex header player** — те же проблемы
**A09: Grid mobile-first** — те же проблемы
**A10: Typography visual** — те же проблемы
**A11: CSS animations** — те же проблемы
**A12: Showcase MusicHub** — те же проблемы + showcase формат

## Проверка последовательности A01-A12

### Логическая цепочка:
```
A01: HTML + CSS файлы, link → баннер
A02: Box model → карточка трека
A03: Типографика, object-fit, alt → обложка
A04: Flexbox → шапка
A05: Hover/focus, transition → витрина
A06: Showcase Pulse FM
─────────────────────────────────
A07: Cascade, CSS variables → тема
A08: Flex (углубление) → плеер
A09: Grid + mobile-first → сетка
A10: Типографика → стиль каталога
A11: Animations → эквалайзер
A12: Showcase MusicHub
```

**Логика последовательности:** ✅ корректная
- От простого к сложному
- CSS variables перед использованием в компонентах
- Flex перед Grid
- Базовая типографика перед продвинутой
- Анимации после всех базовых концептов

**Потенциальные пробелы:**
- A03 и A10 оба про типографику — нужно проверить отсутствие дублирования
- A04 и A08 оба про flex — A08 должен явно углублять, а не повторять
